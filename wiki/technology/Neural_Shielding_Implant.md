# Neural Shielding Implant

## Quick Facts

- **Category:** Starship
- **Subcategory:** Scan deflector
- **Type:** Hostile cargo scan deflector
- **Added in:** Endurance
- **Description:** Blocks hostile cargo probes

**Neural Shielding Implant** is a Living starship technology.

## Summary

**Neural Shielding Implant** is a [[Living Ship (Starship)|Living Ship]] [[technology]] and can evolve into [[Neural Shielding]] which allows blocking of hostile cargo probes.

## Game description

A pre-grown bionic implant, designed to facilitate the fusion of bio-technology to sentient starships. Use  to begin the installation process.

A beautiful living weave of nanotubes, laced through the vessel's neural assembly. This structure can be energised as the ship deems fit, creating a field that blocks hostile cargo probes.

Use the Quick Menu while a scan is in progress to ask that the ship might block the scan.

## Sources

Grown from [[Psychonic Egg]].
