# Burnt-Out Compressor

## Quick Facts

- **Category:** Starship
- **Type:** Damaged Starship Component
- **Added in:** ExoMech

**Burnt-Out Compressor** is a Damaged Component.

## Summary

**Burnt-Out Compressor** is a [[Damaged Component]] that can be found on a [[Crashed Ship]] and fixing it allows access to previously prevented function.

## Game description

Starship subsystem critically damaged.

Slot cannot be used for storage or technology until damage is repaired. Use / (PC/PS4) to begin repair process.

## Repair

- **Repair**: 2 × [[Wiring Loom]] + 3 × [[Antimatter]]

## Release history

- [[Synthesis]] - Added as a Damaged Component. It has the same icon as [[Mining Beam Upgrade]] module.
