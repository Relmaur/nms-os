# Beam Focus V1

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Laser
- **Level:** 1
- **Type:** Companion Unit
- **Description:** Lv. 1 - Slightly increases speed of element extraction.
- **Added in:** Release

**Beam Focus V1** is a multi-tool upgrade.

## Summary

The **Beam Focus V1** is a second-level laser technology upgrade for the Multi-tool's Mining Beam.

## Game description

Faster Mining Beam processes on resource-rich materials.

User will enjoy quicker element extraction from crystals, rocky outcrops and planetary vegetation.

Operates automatically once constructed within user's multi-tool inventory.

## Crafting

- **Crafting (obsolete)**: 20 × [[Iron]] + 20 × [[Heridium]] + 25 × [[Plutonium]] → 1 × Beam Focus V1
