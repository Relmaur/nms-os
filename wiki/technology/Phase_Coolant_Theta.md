# Phase Coolant Theta

## Quick Facts

- **Category:** Starship
- **Subcategory:** Weapons
- **Level:** 3
- **Type:** Phase Beam Companion Unit

**Phase Coolant Theta** is a weapon upgrade.

## Summary

**Phase Coolant Theta** is [[weapons technology]] for a [[starship]]'s [[Phase Beam]].

## Game description

Phase beam laser cool-down times are significantly reduced. Operates automatically once constructed within user's starship inventory.
