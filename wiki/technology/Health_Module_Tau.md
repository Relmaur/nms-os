# Health Module Tau

## Quick Facts

- **Category:** Exosuit
- **Subcategory:** Health
- **Level:** 2
- **Type:** Exosuit Companion Unit
- **Description:** Increases user's health once primary systems have failed.
- **Added in:** Atlas Rises

**Health Module Tau** is an exosuit upgrade.

## Summary

**Health Module Tau** is a second-level [[health technology]] upgrade for the [[exosuit]].

## Game Description

Increases user's health once primary systems have failed. Automatically consumed when [[Life Support]], Shield and [[Hazard Protection]] systems are offline.

## Location

Blueprints for this upgrade are only found in [[Abandoned Building|Abandoned Buildings]].
