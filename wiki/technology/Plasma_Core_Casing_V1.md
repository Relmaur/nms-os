# Plasma Core Casing V1

## Quick Facts

- **Category:** Weapon
- **Updated:** Pre-release

**Plasma Core Casing V1** is a weapon technology upgrade.

## Summary

A core casing improves fission efficiency for a beam weapon by encasing the core in durable kiltenic alloy. Various sources indicate that this provides the ability to "shoot large plasma bolts" or "improve the fission efficiency of a weapon." The tool can then be used for heavy mining, or deforming the local landscape.

## Game Description

*Increase [sic] plasma core strength and improves fission efficiency by encasing the core in durable kiltenic alloyw [sic]*

## Sources

### Salvaging

Plasma Core Casing V1 is a type of technology that was salvageable on the pre-release planet of Moncherev. It rewards the player with Units.

## Crafting

Plasma Core Casing V1 can be built using a blueprint and the following ingredients:

- Cb ×100 → [[File:|18px|text-bottom|link=Plasma Core Casing V1]] Plasma Core Casing V1

Crafting a casing is demonstrated in the **No Man's Sky - 18 Minute Gameplay Demo**, Sean Murray goes to the weapon segment of the menu and selects a blank square. A list of blueprints is available via a drop-down control, and "Plasma Core Casing V1" is selected. A total of 100 Cb resource units are used to craft and apply this upgrade.
