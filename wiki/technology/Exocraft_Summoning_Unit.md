# Exocraft Summoning Unit

## Quick Facts

- **Category:** Exosuit
- **Type:** Exocraft Technology
- **Updated:** Worlds Part II

The **Exocraft Summoning Unit** is an Exosuit technology upgrade.

## Summary

The Exocraft Summoning Unit is an Exosuit technology module that allows players to directly summon an Exocraft from **anywhere** in a galaxy, bypassing the need for dedicated technologies like the Exocraft Summoning Station or the Orbital Exocraft Materializer. However, while it is easy to obtain the blueprint for the summoning unit, the materials required to craft it can only be obtained after completing the In Stellar Multitudes side mission. As a result, it may be a long way off for some players.

## Game Description

A high-powered matter teleportation device, this personal translocator allows any connected Exocraft to be instantly transported to your location, from anywhere in the galaxy.

Interfaces with the Exosuit Quick Menu for ease of use.

## Source

This blueprint can be bought from the Exosuit upgrade merchant on the Space Anomaly.

## Crafting

Exocraft Summoning Unit can be built using a blueprint and the following ingredients:

- Activated Quartzite ×140 + Quantum Computer ×3 + Crystallised Helium ×90 → Exocraft Summoning Unit

Exocraft Summoning Unit can be dismantled after construction, returning the following ingredients:

- Exocraft Summoning Unit → Activated Quartzite ×70 + Quantum Computer ×2 + Crystallised Helium ×45

## Notes

- If you plan on using Exocraft for planetary exploration, then the Exocraft Summoning Unit is a must.
