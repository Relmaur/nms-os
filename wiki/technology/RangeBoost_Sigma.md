# RangeBoost Sigma

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Scanner
- **Level:** 1
- **Type:** Scanner Companion Unit
- **Description:** Increases the scanner's detection range
- **Added in:** Atlas Rises

**RangeBoost Sigma** is multi-tool upgrade.

## Summary

**RangeBoost Sigma** is a first-level [[scan technology]] upgrade for the [[multi-tool|multi-tool's]] [[Scanner]].

## Game Description

Scanner's detection range is increased.

A powerful output modulator filters local information from increased distance into user's visualisation systems.

Operates automatically once constructed within user's multi-tool inventory.
