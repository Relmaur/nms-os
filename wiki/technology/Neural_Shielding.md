# Neural Shielding

## Quick Facts

- **Category:** Starship - Scan deflector
- **Type:** Hostile cargo scan deflector
- **Updated:** Endurance

**Neural Shielding** is a Living starship technology.

## Summary

**Neural Shielding** is a Living Ship technology and allows blocking of hostile cargo probes.

## Game description

A beautiful living weave of nanotubes, laced through the vessel's neural assembly. This structure can be energised as the ship deems fit, creating a field that blocks hostile cargo probes.

Use the Quick Menu while a scan is in progress to ask that the ship might block the scan.

## Sources

Neural Shielding is grown from Neural Shielding Implant.

## Crafting

Neural Shielding can be repaired using the following ingredients:

- Processed Meat ×8 + Runaway Mould ×20

Neural Shielding can be dismantled after construction, returning the following ingredients:

- Neural Shielding → Processed Meat ×8 + Runaway Mould ×20

## Additional information

Neural Shielding has the same icon as Fragile Neural Stem.

## Release history

- Endurance - Added as a technology.
