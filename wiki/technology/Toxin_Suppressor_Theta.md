# Toxin Suppressor Theta

## Quick Facts

- **Level:** 3
- **Category:** Exosuit
- **Subcategory:** Utilities
- **Type:** Companion Unit
- **Description:** Provides increased protection from toxic rain damage.
- **Stats:** Toxic Protection = 490.0
- **Added in:** Atlas Rises

The **Toxin Suppressor** is an exosuit upgrade.

## Summary

The **Toxin Suppressor Theta** upgrade protects the user from toxic damage.

## Game description

Provides increased protection from toxic rain damage.

Device is charged by Oxide elements. Operates automatically once constructed within user's exosuit inventory.

## Crafting

- **Crafting (obsolete)**: 2 × [[Microdensity Fabric]] + 1 × [[Electron Vapour]] + 1 × [[Gravitino Ball]] → 1 × Toxin Suppressor Theta

This identical formula is used to craft four separate [[hazard protection]] upgrades for the [[exosuit]]:
- [[Coolant Network Theta]]
- [[Radiation Deflector Theta]]
- [[Thermic Layer Theta]]
- Toxin Suppressor Theta

Toxin Suppressor Theta is an obsolete item and no longer has a purpose in the game.
