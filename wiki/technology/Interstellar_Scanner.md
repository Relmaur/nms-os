# Interstellar Scanner

## Quick Facts

- **Category:** Freighter - Scanner
- **Type:** Freighter Technology
- **Updated:** Endurance

## Summary

The **Interstellar Scanner** is a freighter technology that allows remote scanning of star systems.

## Game description

An upgrade to the freighter's galactic-scale sensors.

This device allows the user to access detailed economic and conflict data for a system, even without having previously visited.

## Sources

The blueprint can be researched at the Upgrade Control terminal for four Salvaged Frigate Modules.

## Crafting

Interstellar Scanner can be built using a blueprint and the following ingredients:

- Chromatic Metal ×160 + Magnetised Ferrite ×70 + Wiring Loom ×2 → Interstellar Scanner

Interstellar Scanner can be dismantled after construction, returning the following ingredients:

- Interstellar Scanner → Chromatic Metal ×80 + Magnetised Ferrite ×35 + Wiring Loom ×1
