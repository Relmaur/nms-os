# Drift Suspension

## Quick Facts

- **Category:** Vehicle
- **Subcategory:** Handling
- **Level:** A
- **Type:** Exocraft Handling Modification
- **Stats:** +200% Forwards Grip, -34% Angular Grip
- **Added in:** Beyond

**Drift Suspension** is a [[technology]].

## Summary

**Drift Suspension** is a technology which changes the handling characteristics of an [[Exocraft]], making it drift easily.

## Game description

Overhauls Exocraft handling values through a combination of software tweaks, pressure adjustments and the insertion of microgravity wells into key suspension components.

Specifically tuned to increase the ability of the Exocraft to drift.
