# Protection Mesh

## Quick Facts

- **Category:** Exosuit
- **Subcategory:** Health
- **Type:** Exosuit Environmental Shielding
- **Description:** Basic shielding of user from environmental hazards.
- **Added in:** Pre-release

**Protection Mesh** is a feature of the exosuit.

## Summary

**Protection Mesh** is a type of [[exosuit]] [[health technology]].

This standard mesh provides additional protection from planetary hazards.

## Game description

Basic shielding of the user from environmental hazards. Reduces user peril during planetary exploration. Micro-vibrations increase electromagnetic wave reflection, thereby reduction absorption.

Device is charged by [[Resource|Oxide]] elements. Operates automatically when hazards are detected.
