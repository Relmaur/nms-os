# Radiation Deflector Tau

## Quick Facts

- **Level:** 2
- **Category:** Exosuit
- **Subcategory:** Utilities
- **Type:** Companion Unit
- **Description:** Provdes user with increased protection from radiation damage.
- **Stats:** Radiation Protection = 225.0
- **Added in:** Atlas Rises

**Radiation Deflector Tau** is an exosuit upgrade.

## Summary

The **Radiation Deflector Tau** upgrade protects the user from radiation damage.

## Game description

Provides user with increased protection from radiation damage.

Device is charged by [[Oxide elements]]. Operates automatically once constructed within user's [[exosuit]] inventory.

## Crafting

- **Crafting (obsolete)**: 50 × [[Zinc]] + 100 × [[Carbon]] + 1 × [[Microdensity Fabric]] → 1 × Radiation Deflector Tau

This identical formula is used to craft five separate [[hazard protection]] upgrades for the exosuit:
- [[Aeration Membrane Tau]]
- [[Coolant Network Tau]]
- Radiation Deflector Tau
- [[Thermic Layer Tau]]
- [[Toxin Suppressor Tau]]

## Upgrade progression

- [[Radiation Deflector Sigma]]
- Radiation Deflector Tau
- [[Radiation Deflector Theta]]

## Additional information

- Works automatically when located in a player's Exosuit inventory
- Recharged with Oxide elements and Defensive Energy Sources ([[Shielding Shard]], [[Shielding Plate]], [[Shielding Sheet]])
