# Trident Key (Damaged Component)

## Quick Facts

- **Category:** Artifact
- **Type:** Offering to the Sea
- **Added in:** Abyss

**Trident Key** is a Damaged Component.

## Summary

**Trident Key** is a [[Damaged Component]] that can be found on [[Sealed Sea Chest|Sealed Sea Chests]] at [[Submerged Ruins]].

## Game Description

The chest requires a Trident Key, given to those who study the mysterious sites in the deep ocean.

## Repair

- **Repair**: 1 × [[Trident Key]]

## Release history

- [[Abyss]] - Added as a Damaged Component. It has the same icon as [[Trident Key]].
