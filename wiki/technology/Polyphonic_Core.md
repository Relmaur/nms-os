# Polyphonic Core

## Quick Facts

- **Category:** Multi-Tool - Scanner
- **Type:** Autophage Resonance Key
- **Stats:** Echo Resonator: Enabled / +11% Scan Radius
- **Recharged with:** Atlantideum
- **Updated:** Echoes

**Polyphonic Core** is a technology.

## Summary

**Polyphonic Core** is a Multi-Tool technology upgrade for the Scanner. It reveals nearby sentience echo sites, cloaked Autophage NPCs, locates Autophage Camps, and gives +11% to scan radius.

To locate camps, the Polyphonic Core must be activated from the Multi-Tool technology inventory. It must be fully charged to use this ability.

While using the Analysis Visor on Dissonant Planets, an icon will appear for sentience echoes within scanner range. Once the site is reached, initiating a local scan pulse will reveal the sentience echo, which can then be mined to obtain an Echo Seed.

A scan pulse at Autophage Camps and Harmonic Camps will also reveal cloaked Autophage NPCs.

## Game Description

An attachment for the Multi-Tool Scanner that allows the device to detect and decode the cloaking signal of nearby Autophage units.

Use (//) (PC/PS/XB) to activate the Scanner. As its detector waveform passes over the local area, it will automatically reveal any nearby Autophage entities.

In addition, this device can be used to locate Autophage settlements. Use Locate Autophage Camp to pinpoint a planetary gathering of Autophage.

## Source

The blueprint is given in the Autophage questline for free. A Polyphonic Core is also included on any Staff Multi-Tool crafted at Autophage Synthesis Terminals and Harmonic Interfaces.

## Crafting

Polyphonic Core can be built using a blueprint and the following ingredients:

- Atlantideum ×190 + Quantum Computer ×1 + Living Glass ×1 → Polyphonic Core

Polyphonic Core can be repaired using the following ingredients:

- Atlantideum ×95 + Quantum Computer ×1 + Living Glass ×1

Polyphonic Core can be dismantled after construction, returning the following ingredients:

- Polyphonic Core → Atlantideum ×95 + Quantum Computer ×1 + Living Glass ×1

## Recharge

This scanner technology can be recharged using Atlantideum - 2.5%/unit

## Additional Information

- The Scan Harmoniser provides the same uncloaking ability and stat increase. However, it can't locate Autophage Camps.
- This technology does not count toward the 3-upgrade limit.
