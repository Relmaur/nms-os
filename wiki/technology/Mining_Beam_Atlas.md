# Mining Beam (Atlas)

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Laser
- **Type:** Mineral Extraction Laser
- **Recharge:** Isotope
- **Added in:** Atlas Rises

The **Mining Beam** is a core component of the [[multi-tool]].

## Summary

The Mining Beam is a [[multi-tool]] accessory used to expose and capture [[resource|Elements]] within planetary rock formations and vegetation. If not used carefully, the Mining Beam may result in [[Sentinel]] scrutiny. While all multi-tools will have this function, you can find the blueprint for this item.

## Sources

The Mining beam is one of the several basic tools players receive upon starting the journey.

Cannot be [[dismantle|dismantled]] or otherwise lost, since every [[multi-tool]] has this tech installed. If somehow this tech is lost, it can be crafted.

## Recharge

This directed laser mining tool can be charged by [[Isotope elements]] (such as [[Carbon]]) and by other charging mechanism:

- 1x [[Carbon]] by 0,5%
- 1x [[Thamium9]] by 1%
- 1x [[Plutonium]] by 1,5%
- 1x [[Power Gel]] by 25%
- 1x [[Power Canister]] by 37%
- 1x [[Power Reservoir]] by 50%

## Additional information

- When adding upgrades for the Mining Beam, placing them next to each other in the multi-tool inventory will result in a [[Upgrade bonus|minor increase]] to the upgrade's effectiveness.
