# Pulse Jet Sigma

## Quick Facts

- **Level:** 1
- **Category:** Ship
- **Subcategory:** Utilities
- **Type:** Pulse Engine Companion Unit
- **Added in:** Atlas Rises

**Pulse Jet Sigma** is the first-level upgrade for the [[Pulse Engine]].

## Summary

This technology allow players to consume less Iron when using pulse engine.

## Game Description

Provides increased maneuverability and longer boosts during spaceflight.

Also improves user's [[Iron]] consumption.

## Crafting

- **Crafting (obsolete)**: 100 × [[Chrysonite]] + 200 × [[Iron]] + 50 × [[Zinc]] → 1 × Pulse Jet Sigma

## Upgrade Progression

- Pulse Jet Sigma
- [[Pulse Jet Tau]]
- [[Photonix Core]]

## Additional information

- This upgrade shares same crafting cost to the [[Photonix Core]] but are not the same.
- While Pulse Jet Sigma cost same and gives same attributes as "Photonix Core", technology Photonix Core is only unlocked to pre-ordered players.
