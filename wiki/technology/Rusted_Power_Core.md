# Rusted Power Core

## Quick Facts

- **Category:** Multi-Tool
- **Type:** Damaged Multi-Tool Component
- **Added in:** Waypoint

**Rusted Power Core** is a Damaged Component.

## Summary

**Rusted Power Core** is a [[Damaged Component]] that can be found on a broken [[Multi-tool]] and fixing it allows access to previously prevented function.

## Game description

Multi-Tool subsystem critically damaged.

Slot cannot be used until damage is repaired. Use / (PC/PS4) to begin repair process.

Repairing will free slot up for general use.

## Repair

- **Repair**: 25 × [[Ionised Cobalt]]

## Release history

- [[Beyond]] - Added as a Damaged Component.
- [[Expeditions]] - Repair info changed previously required 50 Ionised Cobalt.
