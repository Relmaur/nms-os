# Cooling System (Frigate)

## Quick Facts

- **Category:** Frigate
- **Type:** Damaged Component
- **Added in:** Frontiers

**Cooling System** is a Damaged Component.

## Summary

**Cooling System** is a [[Damaged Component]] that can be found at a [[frigate]] and fixing it allows access to previously prevented function.

## Game description

A pump and heat exchange system designed to keep the device from overheating. It has itself overheated, and is no longer functional.

## Repair

- **Repair**: 20 × [[Gold]] + 5 × [[Oxygen]]
