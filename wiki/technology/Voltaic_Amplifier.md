# Voltaic Amplifier

## Quick Facts

- **Category:** Multi-tool - Weapons
- **Type:** Damage Overload Module
- **Stats:** Damage stunned entities +21%
- **Updated:** SentinelUp

The **Voltaic Amplifier** is a multi-tool upgrade.

## Summary

The **Voltaic Amplifier** is a general Multi-tool upgrade for all multi-tool weapons.

## Game Description

A generalised upgrade for all Multi-Tool weapon systems, causing its projectiles to resonate dramatically upon impact with any appropriate electromagnetic field.

Will significantly increase the damage dealt to any organic and inorganic entities that are currently stunned.

Stats: Damage stunned entities +21%

## Source

The blueprint can be acquired in the Space Anomaly for 180.

## Crafting

Voltaic Amplifier can be built using the following ingredients:

- Basalt ×70 + Ion Battery ×2 + Wiring Loom ×1 → Voltaic Amplifier

Voltaic Amplifier can be repaired using the following ingredients:

- Basalt ×35 + Ion Battery ×1 + Wiring Loom ×1

Voltaic Amplifier can be dismantled after construction, returning the following ingredients:

- Voltaic Amplifier → Basalt ×35 + Ion Battery ×1 + Wiring Loom ×1
