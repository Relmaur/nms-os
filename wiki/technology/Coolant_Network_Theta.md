# Coolant Network Theta

## Quick Facts

- **Level:** 3
- **Category:** Exosuit
- **Subcategory:** Utilities
- **Type:** Companion Unit
- **Description:** Provides increased protection from extreme heat damage on scorched worlds.
- **Stats:** Heat Protection = 490.0
- **Added in:** Atlas Rises

**Coolant Network Theta** is an Exosuit utility.

## Summary

The **Coolant Network Theta** upgrade protects the user from heat damage.

## Game Description

Provides increased protection from extreme heat damage on scorched worlds.

Device is charged by Oxide elements. Operates automatically once constructed within user's exosuit inventory.

## Crafting

- **Crafting (obsolete)**: 2 × [[Microdensity Fabric]] + 1 × [[Electron Vapour]] + 1 × [[Gravitino Ball]] → 1 × Coolant Network Theta

This identical formula is used to craft four separate [[hazard protection]] upgrades for the [[exosuit]]:
- Coolant Network Theta
- [[Radiation Deflector Theta]]
- [[Thermic Layer Theta]]
- [[Toxin Suppressor Theta]]
