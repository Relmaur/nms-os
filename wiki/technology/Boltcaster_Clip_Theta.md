# Boltcaster Clip Theta

## Quick Facts

- **Category:** Weapon
- **Subcategory:** Projectile
- **Level:** 3
- **Type:** Companion Unit
- **Description:** Increases the boltcaster's clip size
- **Stats:** Clip Size = +75%
- **Added in:** Atlas Rises

**Boltcaster Clip Theta** is a third-level multi-tool upgrade.

## Summary

**Boltcaster Clip Theta** is a third-level upgrade for the [[Boltcaster]].

This technology increased the Boltcaster's ammunition clip by 60.

## Game Description

Boltcaster's ammo clip capacity is increased.

Deepened ion reservoir allows user to inflict a sequence of destructive shots without the inconvenience of an early reload.

Operates automatically once constructed within user's multi-tool inventory.

## Crafting

- **Crafting (obsolete)**: 50 × [[Plutonium]] + 50 × [[Zinc]] + 150 × [[Nickel]] → 1 × Boltcaster Clip Theta

## Additional information

- Works automatically when located in a player's Multi-tool inventory with the Boltcaster
- Needs no fuel or recharging
- The tooltip displays the name as "Boltcaster Clip Theta" but the icon ticker displays "Plasma Clip Theta"
