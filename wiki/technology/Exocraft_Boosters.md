# Exocraft Boosters

## Quick Facts

- **Category:** Vehicle
- **Type:** Exocraft Engine Upgrade
- **Added in:** Waypoint

**Exocraft Boosters** is a technology.

## Summary

**Exocraft Boosters** is a propulsion upgrade for the [[Exocraft]].

## Game description

An efficient plasma injector coupled to the engine that allows short bursts of speed.

## Build

- **Crafting** · needs the blueprint: 15 × [[Magnetised Ferrite]] + 50 × [[Chromatic Metal]] + 2 × [[Carbon Nanotubes]] → 1 × Exocraft Boosters

- **Dismantle** returns: 7 × [[Magnetised Ferrite]] + 25 × [[Chromatic Metal]] + 1 × [[Carbon Nanotubes]]

## Additional information

The upper case name that is displayed in the blueprint is "Exocraft Boost Module". The lower case name "Exocraft Boosters" is displayed in the tech install select menu.

## Release history

- [[Pathfinder]] - Added as a technology.
- [[NEXT]] - Blueprint changed, formerly used [[Heridium]] and [[Armadium]].
- [[Update 4.00|Waypoint]] - Renamed from "Exocraft Acceleration Module" to "Exocraft Boosters".
