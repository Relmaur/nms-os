# Thermal Protection Module (Cold)

## Quick Facts

- **Category:** Exosuit
- **Subcategory:** Hazard
- **Type:** Generated Upgrade
- **Added in:** Waypoint

**Thermal Protection Module (Cold)** is an exosuit hazard upgrade.

## Summary

**Thermal Protection Modules (Cold)**, contained within [[Exosuit|Exosuit Upgrade Modules]], are procedurally generated upgrades granting bonuses to the [[exosuit]]'s [[Hazard Protection]].

It needs to be installed in an exosuit [[Technology]] slot for it to take effect.

## Game Description

Increase the base capacity of the Hazard Protection system, allowing the user to spend longer in frozen sub-zero temperature environments without requiring a recharge of the traveler's  [[Hazard Protection Unit]] in the Exosuit.

## Upgrade properties

Sub-Zero Temperature Protection Upgrades grant the following bonus:
- *Cold Protection*

|   | **Module Name** | **Module Improves** | B-class | A-class | S-class |   |   |   |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **Min** | **Max** | **Min** | **Max** | **Min** | **Max** |   |   |   |
|   | [[Thermal Protection Module (Cold)]] | *Cold Protection* | 200 | 300 | 240 | 320 | 280 | 360 |

Up to three protections upgrades can be installed in the Exosuit. Installing four or more upgrades will disable all upgrades of that type until the upgrade count is reduced to three or less.

## Acquisition

The [[upgrades]] can be acquired from:
- A [[Technology Merchant]] in a [[Space station]] for a variable price generally in line with the class of the upgrade.  This is the most common and predictable/reliable way to obtain the upgrade module.  The upgrade modules are always the same in given system space station, although they will only replenish if purchased after the traveller has moved on and visited at least three [ed. note: need confirmation on count] different star systems before returning.
- As a reward for helping a NPC traveller to repair a [[Crashed Ship]] (Non-replicable result)
- As a reward for selecting the appropriate course of action at a [[Monolith]] puzzle (Non-replicable result)
- As a reward for selecting the appropriate course of action at a [[Manufacturing Facility]] repair puzzle (Non-replicable result)

## Recharge

Recharge using [[Ion Battery]] or [[Dioxite]].
