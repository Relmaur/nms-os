# Phase Coolant Tau

## Quick Facts

- **Category:** Starship
- **Type:** Phase Beam Companion Unit
- **Subcategory:** Weapons
- **Level:** 2
- **Description:** Reduces Phase Beam cool-down times
- **Stats:** Heat Dispersion = +100%
- **Added in:** Atlas Rises

**Phase Coolant Tau** is a weapons upgrade.

## Summary

**Phase Coolant Tau** is [[weapons technology]] for a [[starship]]'s [[Phase Beam]].

Phase Coolant reduces Phase Beam laser cool-down times. This is a level-2 upgrade.

## Game description

Phase beam laser cool-down times are significantly reduced.

Operates automatically once constructed within user's starship inventory.
