# Resonance Amplifier

## Quick Facts

- **Category:** Multi-Tool - Scanner
- **Type:** Echo Seed Detection Device
- **Stats:** Echo Resonator: Enabled / +11% Scan Radius
- **Updated:** WorldsOne

**Resonance Amplifier** is a technology.

## Summary

**Resonance Amplifier** is a Multi-Tool technology upgrade for the Scanner that gives +11% to scan radius and reveals nearby sentience echo sites and cloaked Autophage NPCs.

While using the Analysis Visor on Dissonant Planets, an icon will appear for sentience echoes within scanner range. Once the site is reached, a local scan pulse will reveal the sentience echo, which can then be mined to obtain an Echo Seed.

A scan pulse at Autophage Camps and Harmonic Camps will also reveal cloaked Autophage NPCs.

## Game Description

An attachment for the Multi-Tool Scanner, designed by Specialist Polo for the detection of atlantideum-infused sentience echoes.

On dissonant worlds, use the **Analysis Visor** (//) (PS4/PC/Xbox) to locate sentience echoes. On arrival at an echo site, use (//) (PC/PS/XB) to fully reveal nearby anomalies.

## Source

The blueprint of this technology was formerly acquired by talking to Specialist Polo during Expedition 10: Singularity (Lost Souls). The blueprint can no longer be obtained through normal gameplay, however Third-Party Tools like the **NMS Save Editor** may be used to get the blueprint.

## Crafting

Resonance Amplifier can be built using a blueprint and the following ingredients:

- Di-hydrogen ×160 + Gravitino Ball ×3 + Radiant Shard ×1 → Resonance Amplifier

Resonance Amplifier can be repaired using the following ingredients:

- Di-hydrogen ×80 + Gravitino Ball ×2 + Radiant Shard ×1

Resonance Amplifier can be dismantled after construction, returning the following ingredients:

- Resonance Amplifier → Di-hydrogen ×80 + Gravitino Ball ×2 + Radiant Shard ×1

## Additional Information

- The Scan Harmoniser replaced the Resonance Amplifier entirely as a near-identical alternative.
- The Polyphonic Core provides the same stats and abilities, as well as the ability to locate Autophage Camps.
- This technology does not count toward the 3-upgrade limit.

## Release History

- Singularity - Added as a technology blueprint.
- Echoes - Replaced by the Scan Harmoniser.
