# Acceleration Module

**Acceleration Module technology** is related to exocraft.

## Summary

**Acceleration Module technology** is technology that upgrades a player's exocraft.

The three upgrades for the basic Acceleration Module have been obsolete since NEXT.

## Technologies

- Exocraft Acceleration Module

The following modules are all obsolete:

- Exocraft Acceleration Module Upgrade Sigma
- Exocraft Acceleration Module Upgrade Tau
- Exocraft Acceleration Module Upgrade Theta
