# Impact Igniter

## Quick Facts

- **Category:** Multi-tool - Weapons
- **Type:** Pulse Spitter Upgrade
- **Stats:** +80 Fire Damage 4s Impact Fire Duration
- **Updated:** SentinelUp

**Impact Igniter** is a multi-tool upgrade.

## Summary

Impact Igniter is a Multi-tool upgrade which causes every projectile from the Pulse Spitter to set its target on fire, as well as deal damage on impact. It is acquired as a blueprint, which blueprint can be purchased from Iteration: Eos for 180.

Impact Igniter needs to be crafted and then stored in a Multi-tool inventory slot for it to have its effect. Unlike Pulse Spitter Upgrades, this technology does not count toward the three-upgrade limit, making it useful for enhancing Upgrade bonuses on other upgrades.

## Game Description

A powerful combat upgrade for the Pulse Spitter. This module installs series of delicately calibrated fuel-injection nozzles within the fireing chamber, which are used to initiate a controlled burn within its plasma projectiles

Causes targets hit by the Pulse Spitter to burn for a short while, causing additional damage.

## Crafting

Impact Igniter can be built using a blueprint and the following ingredients:

- Phosphorus ×200 + Hermetic Seal ×4 + Wiring Loom ×1 → Impact Igniter

Impact Igniter can be repaired using the following ingredients:

- Phosphorus ×100 + Hermetic Seal ×2 + Wiring Loom ×1

Impact Igniter can be dismantled after construction, returning the following ingredients:

- Impact Igniter → Phosphorus ×100 + Hermetic Seal ×2 + Wiring Loom ×1
