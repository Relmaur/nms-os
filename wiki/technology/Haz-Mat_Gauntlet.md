# Haz-Mat Gauntlet

## Quick Facts

- **Category:** Exosuit
- **Type:** Exosuit Augmentation
- **Updated:** Expeditions

**Haz-Mat Gauntlet** is a type of technology.

## Summary

**Haz-Mat Gauntlet** technology allows a player to handle or harvest hazardous plants and other materials..

- Albumen Pearl Orb - yields Albumen Pearl
- Cave Plant - yields Oxygen or Sodium
- Gutrot Flower - yields Faecium
- Frostwort - yields Frost Crystal
- Fungal Cluster - yields Fungal Mould
- Gamma Weed - yields Gamma Root
- Gravitino Host - yields Gravitino Ball
- Mordite Root - yields Mordite
- NipNip - yields NipNip Buds
- Solar Vine - yields Solanium
- Star Bramble - yields Star Bulb
- Venom Urchin - yields Sac Venom

## Game Description

Upgrades the metallic shielding of the Exosuit's gloves.

An advanced blend of reinforced metal and catalytic shielding allows the user to safely handle hazardous substances, as well as perform the necessary feats of strength required to harvest certain farmable flora.

## Source

This blueprint can be bought from the Exosuit upgrade merchant on the Space Anomaly.

## Crafting

Haz-Mat Gauntlet can be built using a blueprint and the following ingredients:

- Chromatic Metal ×50 + Sodium Nitrate ×20 → Haz-Mat Gauntlet

Haz-Mat Gauntlet can be repaired using the following ingredients:

- Chromatic Metal ×25 + Sodium Nitrate ×10

Haz-Mat Gauntlet can be dismantled after construction, returning the following ingredients:

- Haz-Mat Gauntlet → Chromatic Metal ×25 + Sodium Nitrate ×10

## Additional information

- Echinocactus and Candle Kelp, yielding Cactus Flesh and Kelp Sac respectively, can be harvested without Haz-Mat Gauntlet.
- A longer name, *Hazardous Material Gauntlets* is only mentioned in the game description of Destablised Sodium.
