# Ablative Armour

## Quick Facts

- **Category:** Ship - Shield
- **Type:** Starship Shield Upgrade
- **Stats:** +7% Shield Strength
- **Updated:** Origins

**Ablative Armour** is a shield technology for the starship.

## Summary

**Ablative Armour** is a shield technology for the starship which improves shield durability.

## Source

The blueprint can be acquired from Iteration: Hyperion in Space Anomaly.

## Game description

Adds a layer of superheated shielding to the starship's defense array, vaporising incoming fire.

Significantly increases starship shield performance.

## Crafting

Ablative Armour can be built using the following ingredients:

- Gold ×100 + Sodium Nitrate ×50 + Wiring Loom ×1 → Ablative Armour

Ablative Armour can be repaired using the following ingredients:

- Gold ×50 + Sodium Nitrate ×25 + Wiring Loom ×1

Ablative Armour can be dismantled after construction, returning the following ingredients:

- Ablative Armour → Gold ×50 + Sodium Nitrate ×25

## Additional information

- Upgrade bonuses trigger if Ablative Armour is adjacent to Deflector Shield or Deflector Shield Upgrades, increasing its bonus above the listed value. Ablative Armour does not count toward the three-upgrade limit; however, only one Ablative Armour technology can be installed at a time.
