# Melted Fuel Cell

## Quick Facts

- **Category:** Starship
- **Type:** Damaged Starship Component
- **Added in:** ExoMech

**Melted Fuel Cell** is a Damaged Component.

## Summary

**Melted Fuel Cell** is a [[Damaged Component]] that can be found on a [[Crashed Ship]] and fixing it allows access to previously prevented function.

## Game description

Starship subsystem severely damaged. Slot cannot be used for storage or technology until damage is repaired. Use / (PC/PS4) to begin repair process.

Core starship functionality is not affected. Repairing this damage will free slot up for general inventory use.

## Repair

- **Repair**: 125 × [[Pyrite]] + 125 × [[Phosphorus]] + 3 × [[Metal Plating]]

## Release history

- [[Synthesis]] - Added as a Damaged Component.  It has the same icon as [[Cryo-Pump]].
