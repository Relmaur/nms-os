# Laser technology

**Laser technology** is technology that upgrades a player's weapon.

## Technologies

The following laser technology upgrades can be crafted for a player's weapon using a blueprint:

- Mining Laser
- Beam Amplifier
- Combat Amplifier
- Beam Coolant System
