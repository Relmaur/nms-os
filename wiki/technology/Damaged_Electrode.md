# Damaged Electrode

## Quick Facts

- **Category:** Drop Pod
- **Type:** Damaged Component
- **Added in:** Expeditions

**Damaged Electrode** is a Damaged Component.

## Summary

**Damaged Electrode** is a [[Damaged Component]] and can be found on the [[Drop Pod]]. Once repaired along with two other components, the pod automatically opens rewarding the player with 1 additional [[exosuit]] [[inventory]] slot.

## Game description

This Exosuit Upgrade Module is critically damaged. Repair systems to restore upgrade functionality.

If repaired, User will not be charged for any Exosuit Upgrades.

## Repair

- **Repair**: 10 × [[Sodium Nitrate]]
