# Input Terminal

## Quick Facts

- **Category:** Point of Interest
- **Type:** Damaged Component

**Input Terminal** is a Damaged Component.

## Summary

**Input Terminal** is a [[Damaged Component]] that can be found at various [[Point of Interest|Points of Interest]] and fixing it allows access to previously prevented function.

A terminal designed to allow manual control of the device. Damage prevents it actually receiving any input.
