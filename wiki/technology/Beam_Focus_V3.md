# Beam Focus V3

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Laser
- **Type:** Companion Unit
- **Description:** Lv. 3 - Slightly increases speed of element extraction.
- **Added in:** Pathfinder

**Beam Focus V3** is a multi-tool upgrade.

## Summary

The **Beam Focus V3** is a third-level laser technology upgrade for the Multi-tool's Mining Beam.

## Game description

Beam Focus V3 automatically increases the speed of Mining Beam processes on resource-rich materials. When used, players will enjoy slightly faster element extraction from crystals, rocky outcrops, and planetary vegetation.

## Crafting

- **Crafting (obsolete)**: 50 × [[Plutonium]] + 200 × [[Chrysonite]] + 200 × [[Platinum]] → 1 × Beam Focus V3
