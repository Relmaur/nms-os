# Photonix Core

## Quick Facts

- **Category:** Ship - Utilities
- **Type:** Pulse Engine Companion Unit
- **Stats:** +15% Pulse Drive Efficiency / +15% Boost / +11% Maneuverability [sic]
- **Updated:** Omega

**Photonix Core** is a starship upgrade.

## Summary

**Photonix Core** is a starship technology and upgrade for the Pulse Engine.

## Game description

Provides increased manoeuvrability and longer boosts during spaceflight.

## Sources

The blueprint is only available for players who bought the Limited Edition (PS4) version of the game, or got it from the day-one patch.

It also comes pre-installed on the Starborn Runner, which is rewarded by completing Expedition 12: Omega, allowing players from other platforms, and new PS4 players, to get a Photonix Core.

If the player starts a run of the Omega expedition from their main save, they can get a second Starborn Runner, and thus a second Photonix Core, by copying it back from the expedition save at the end. To do this, the Starborn Runner, or whatever ship has the Photonix Core installed, must be the current ship in the expedition when ending it.

## Crafting

Photonix Core can be built using the following ingredients:

- Pure Ferrite ×100 + Condensed Carbon ×100 → Photonix Core

Photonix Core can be repaired using the following ingredients:

- Pure Ferrite ×50 + Condensed Carbon ×50

Photonix Core can be dismantled after construction, returning the following ingredients:

- Photonix Core → Pure Ferrite ×50 + Condensed Carbon ×50

## Additional info

Some users saw a stats description using the word *maneuverability* (AE spelling) instead of *manoeuvrability* (BE spelling).

## Release history

- Release - Added as a technology.
- NEXT - Blueprint changed, formerly used Chrysonite, Iron and Zinc. Stats changed, previously +25% Pulsedrive Power and +10% Boost were given.
- Omega - A single module comes equipped on the Starborn Runner ship. The module can be unequipped and attached to another ship.
