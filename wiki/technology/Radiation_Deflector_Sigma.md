# Radiation Deflector Sigma

## Quick Facts

- **Level:** 1
- **Category:** Exosuit
- **Subcategory:** Utilities
- **Type:** Companion Unit
- **Description:** User is shielded from radiation damage.
- **Stats:** Radiation Protection = 75.0
- **Added in:** Atlas Rises

**Radiation Deflector Sigma** is an exosuit upgrade.

## Summary

The **Radiation Deflector Sigma** upgrade protects the user from radiation damage.

## Game description

User is shielded from radiation damage.

Greatly reduces user peril during the exploration of [[Biome - Irradiated|irradiated worlds]]. Micro-vibrations increase electromagnetic wave reflection, thereby reducing absorption.

Device is charged by [[Oxide elements]]. Operates automatically once constructed within user's exosuit inventory.

## Crafting

- **Crafting (obsolete)**: 50 × [[Iron]] + 100 × [[Carbon]] → 1 × Radiation Deflector Sigma

This identical formula is used to craft five separate [[hazard protection]] upgrades for the [[exosuit]]:
- [[Aeration Membrane Sigma]]
- [[Coolant Network Sigma]]
- Radiation Deflector Sigma
- [[Thermic Layer Sigma]]
- [[Toxin Suppressor Sigma]]
