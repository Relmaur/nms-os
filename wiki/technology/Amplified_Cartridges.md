# Amplified Cartridges

## Quick Facts

- **Category:** Multi-tool - Weapons
- **Type:** Pulse Spitter Upgrade
- **Stats:** +20.0 Clip Size
- **Updated:** Origins

**Amplified Cartridges** is a multi-tool upgrade.

## Summary

Amplified Cartridges is a Multi-tool upgrade which significantly increases the number of rounds which can be held by the Pulse Spitter. It is acquired as a blueprint, which blueprint can be purchased from Iteration: Eos.

Amplified Cartridges needs to be crafted and then stored in a Multi-tool inventory slot for it to have its effect. Unlike Pulse Spitter Upgrades, this technology does not count toward the three-upgrade limit, making it useful for enhancing Upgrade bonuses on other upgrades.

## Game Description

Specialist harmonic resonators allow the Pulse Spitter to split inserted ammunition, effective [sic] manufacturing more shots from fewer materials.

Increases weapon clip size.

## Crafting

Amplified Cartridges can be built using a blueprint and the following ingredients:

- Solar Mirror ×1 + Wiring Loom ×1 → Amplified Cartridges

Amplified Cartridges can be repaired using the following ingredients:

- Solar Mirror ×1 + Wiring Loom ×1

Amplified Cartridges can be dismantled after construction, returning the following ingredients:

- Amplified Cartridges → Solar Mirror ×1 + Wiring Loom ×1
