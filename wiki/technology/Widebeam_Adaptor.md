# Widebeam Adaptor

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Laser
- **Type:** Mining Beam Companion Unit
- **Description:** Directed laser tool for simultaneous mining of multiple targets.
- **Added in:** Pre-release

The **WideBeam Adaptor** is a [[laser technology]] upgrade for the [[MineLaser|mining beam]] portion of the [[Multi-tool]]

## Summary

This technology is used to modify the [[MineLaser|Mining Beam Laser]].

In the released game, this functionality is covered by the [[Wideshot Adaptor]].

## Game description

Mining Beam laser is modified to allow simultaneous mining of multiple targets. Widens laser impact radius so multiple targets in close proximity will receive damage during mining processes. Operates automatically once constructed within user's [[multi-tool]] inventory.

## Upgrades

The WideBeam Adaptor has the following upgrade available.
