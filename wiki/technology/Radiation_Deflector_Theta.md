# Radiation Deflector Theta

## Quick Facts

- **Level:** 3
- **Category:** Exosuit
- **Subcategory:** Utilities
- **Type:** Companion Unit
- **Description:** Provide user with increased protection from radiation damage.
- **Stats:** Radiation Protection = 490.0
- **Added in:** Atlas Rises

**Radiation Deflector Theta** is an exosuit upgrade.

## Summary

The **Radiation Deflector Theta** upgrade protects the user from radiation damage.

## Game description

Provides user with increased protection from radiation damage.

Device is charged by [[Oxide elements]]. Operates automatically once constructed within user's exosuit inventory.

## Crafting

- **Crafting (obsolete)**: 2 × [[Microdensity Fabric]] + 1 × [[Electron Vapour]] + 1 × [[Gravitino Ball]] → 1 × Radiation Deflector Theta

This identical formula is used to craft four separate [[hazard protection]] upgrades for the [[exosuit]]:
- [[Coolant Network Theta]]
- Radiation Deflector Theta
- [[Thermic Layer Theta]]
- [[Toxin Suppressor Theta]]

## Upgrade progression

- [[Radiation Deflector Sigma]]
- [[Radiation Deflector Tau]]
- Radiation Deflector Theta

## Additional information

- Works automatically when located in a player's Exosuit inventory
- Recharged with Oxide elements and Defensive Energy Sources ([[Shielding Shard]], [[Shielding Plate]], [[Shielding Sheet]])
