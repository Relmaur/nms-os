# Beam Coolant System Sigma

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Mining Beam
- **Level:** 1
- **Type:** Mining Beam Companion Unit
- **Description:** Mining Beam is modified to extend time between cool-down periods.
- **Added in:** Pathfinder

The **Beam Coolant System Sigma** is a first-level [[laser technology]] upgrade for the [[multi-tool|multi-tool's]] [[Mining Beam]].

## Game description

[[Mining Beam]] is modified to extend time between cool-down periods.

Allows user to mine with less interruptions and with a vastly reduced sensation of burning.

Operates automatically once constructed within user's [[Multi-tool]] inventory.

Stats: Heat Dispersion +29%

## Crafting

- **Crafting (obsolete)**: 50 × [[Iridium]] + 20 × [[Heridium]] → 1 × Beam Coolant System Sigma

## Additional information

- Needs no fuel or recharging
