# Launch Thruster

## Quick Facts

- **Category:** Propulsion
- **Subcategory:** Enhancement
- **Type:** Vertical Take-off System
- **Description:** Used during initial takeoff and landings
- **Recharge:** Uranium or Starship Launch Fuel
- **Added in:** Echoes

**Launch Thruster** is a starship technology.

## Summary

**Launch Thruster** is a [[starship]] [[technology]] that is required for the starship's landing and lift-off.

Launch Thrusters consumes fuel each time the starship launched from the surface of a [[planet]] or [[moon]], which must eventually be recharged using [[Uranium]] (2.5%/unit) or [[Starship Launch Fuel]] (100%/unit).

There will be no fuel cost when [[Landing Pad|Landing Pads]] or designated landing spots (indicated in flight by concentric blue rings which turn green when the starship gets close enough to land on the spot) are used.

The following table shows the fuel usage for lift-offs.

| [[Starship\|Starship<br>archetypes]] | [[Game mode]] |   |   |   |
| --- | --- | --- | --- | --- |
| Creative | Normal | Survival | Permadeath |   |
| [[Starship\|Exotic]] | 0 % | 25 % | 50 % | 50 % |
| [[Starship\|Explorer]] | 0 % | 12.5 % | 25 % | 25 % |
| [[Starship\|Fighter]] | 0 % | 25 % | 50 % | 50 % |
| [[Starship\|Hauler]] | 0 % | 25 % | 50 % | 50 % |
| [[Starship\|Shuttle]] | 0 % | 16.6 % | 33.3 % | 33.3 % |

If Launch Thrusters is damaged by rough handling or enemy fire, the starship will be unable to lift-off until it is repaired.

## Game description

Vital launch and landing gear system.

User is advised that specialised, [[Deuterium]]-derived fuel is required to recharge thruster. Launch procedures require sufficient fuel levels before activation.

Hold [W] to take off from planet.

Hold [Circle/Shift/B] to initiate in-flight speed boost.

## Additional Information

- Summoning a starship via the [[Quick Menu]] deducts one launch's worth of fuel regardless of its previous location. If there is less than one launch's worth of thruster fuel in that starship, the player will not be able to summon it in this manner until it is refueled.
- Launch Thruster can be refueled remotely if the starship's inventory contains the required fuel items.

  - If Efficient Thrusters is installed adjacent to Launch Thrusters, an [[Upgrade bonus]] triggers which indirectly affects Launch Thrusters. However Efficient Thrusters doesn't get a bonus in this circumstance as the -20% boost fuel cost is a flat rate reduction. This is the case for survival and perma death modes at least and is unknown if this is intended or error.
- If Launch Thrusters are installed in a supercharged slot, the fuel cost to lift-off is increased.
