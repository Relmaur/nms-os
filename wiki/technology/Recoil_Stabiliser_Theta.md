# Recoil Stabiliser Theta

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Projectile
- **Level:** 3
- **Type:** Boltcaster Companion Unit
- **Description:** Defensive weapon upgrade.
- **Stats:** Recoil = (-60%)
- **Added in:** Atlas Rises

**Recoil Stabiliser Theta** is the third-level [[weapon]] upgrade for the Boltcaster.

## Summary

The Recoil Stabiliser Theta upgrade automatically decreases the [[Boltcaster]]'s kick-back when firing by using an internal dampening field to increase players' ability to shoot more accurately.

## Game Description

Fully suppresses Boltcaster's kick-back, eliminating all primary kinetic impulses created by energy bolt discharge.

User enjoys minimal directional disruption when firing repeated shots at targeted lifeforms and environmental structures.

Operates automatically once constructed within user's [[multi-tool]] inventory.
