# Personal Refiner

## Quick Facts

- **Category:** Exosuit
- **Type:** Exosuit Upgrade
- **Updated:** Echoes

**Personal Refiner** is an exosuit technology.

## Summary

**Personal Refiner** is a technology that allows a player to Refine different substances on the move.

It needs to be installed in an exosuit tech inventory slot for it to take effect.

It can be replaced with an upgraded version, the Personal Refiner Mk 2, which can combine two materials instead of only one.

## Game Description

A compact extension to the Exosuit, installing a small Portable Refiner, accessible directly from the user's Exosuit interface.

Unit requires fuel and is limited to refining one substance at a time.

## Source

The blueprint can be acquired from Iteration: Selene in the Space Anomaly for 360.

## Crafting

Personal Refiner can be built using a blueprint and the following ingredients:

- Chromatic Metal ×100 + Oxygen ×150 → Personal Refiner

Personal Refiner can be repaired using the following ingredients:

- Chromatic Metal ×50 + Oxygen ×75

Personal Refiner can be dismantled after construction, returning the following ingredients:

- Personal Refiner → Chromatic Metal ×50 + Oxygen ×75
