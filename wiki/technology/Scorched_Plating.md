# Scorched Plating

## Quick Facts

- **Category:** Starship
- **Type:** Damaged Starship Component
- **Added in:** ExoMech

**Scorched Plating** is a Damaged Component.

## Summary

**Scorched Plating** is a [[Damaged Component]] that can be found on a [[Crashed Ship]] and fixing it allows access to previously prevented function.

## Game description

Starship subsystem is critically damaged.

Slot cannot be used for storage or technology until damage is repaired. Use / (PC/PS4) to begin repair process.

## Repair

- **Repair**: 150 × [[Chromatic Metal]] + 50 × [[Pugneum]] + 50 × [[Platinum]]

## Release history

- [[Synthesis]] - Added as a Damaged Component.  It has the same icon as [[Poly Fibre]].
