# Beam Intensifier Tau

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Mining Beam
- **Level:** 2
- **Type:** Companion Unit
- **Description:** Mining Beam laser is strengthened to speed up terrain destruction.

**Beam Intensifier Tau** is a multi-tool upgrade.

## Summary

The **Beam Intensifier Tau** is a second-level [[laser technology]] upgrade for the [[Multi-tool|Multi-tool's]] [[Mining Beam]].

## Game Description

Mining Beam laser is strengthened to speed up terrain destruction.

Operates automatically once constructed within user's Multi-tool inventory.
