# Waveform Engine

## Quick Facts

- **Category:** Starship
- **Type:** Highly Customised Starship Engine
- **Description:** Highly tuned Pulse Engine
- **Recharge:** Tritium, Pyrite
- **Added in:** Frontiers

**Waveform Engine** is a starship engine.

## Summary

The **Waveform Engine** is advanced version of the standard Pulse drive and was first introduced in [[Expedition 3: Cartographers]].

It is a highly-tuned alternative pulse drive for the player's starting starship, but must first be repaired as part of Phase 3 of the expedition.

Once repaired, it can be recharged with [[Tritium]] or [[Pyrite]].

## Game Description

A highly-tuned version of the conventional starship Pulse Engine. Wavefront occupancy has been pushed to the limit, creating a pulse experience that is both efficient and highly responsive.

User is advised that Tritium is required to charge the drive. Tritium is abundant in near-space [[asteroid]] fields.

## Repairs

- **Repair**: 3 × [[Crystal Sulphide]] + 1 × [[Magnetic Resonator]]
