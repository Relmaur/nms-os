# Sentinel Exosuit Fragment

## Quick Facts

- **Category:** Exosuit
- **Subcategory:** Consumable

- **Added in:** WorldsOne

**Sentinel Exosuit Fragment** is a consumable.

## Summary

**Sentinel Exosuit Fragment** is a [[Consumable]] that yields a [[Forbidden Exosuit Module]] when used.

## Game Description

An anomalous upgrade for Exosuit. Use () to begin upgrade installation process.

This strange fragment of debris has been extracted from Sentinel technology. Its exact effect upon suit performance is impossible to predict before the nanite foam has fully spread within the Exosuit's systems.
