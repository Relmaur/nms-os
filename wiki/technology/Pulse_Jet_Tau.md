# Pulse Jet Tau

## Quick Facts

- **Category:** Ship - Utilities
- **Type:** Pulse Engine Companion Unit
- **Updated:** Atlas Rises

**Pulse Jet Tau** is a Pulse Engine upgrade.

## Summary

**Pulse Jet Tau** is the second-level upgrade for a Starship's Pulse Engine.

## Game description

Provides increased manoeuvrability and longer boosts during spaceflight.
Also improves user's Iron consumption.

## Crafting

Pulse Jet Tau cannot be crafted.

Original formula:

Nickel x100 + Thamium9 x50 + Neutrino Module x2 → Pulse Jet Tau

## Upgrade progression

- Pulse Jet Sigma
- Pulse Jet Tau
- Photonix Core

## Additional Info

After testing on PC version, this technology provided the following extensions:

- Core upgrade increased to a total of two (2) minutes
- Sigma version increased to a total of six (6) minutes
- Tau version increased to a total of eight (8) minutes

When all three technologies were linked to create a bonus, the Pulse Jump usage time extended up to 14 minutes.

## Release history

- Release - Added as a technology.
- NEXT - Removed from the game. If it was installed, it has turned into Obsolete Technology.
