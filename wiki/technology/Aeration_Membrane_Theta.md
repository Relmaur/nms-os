# Aeration Membrane Theta

## Quick Facts

- **Category:** Exosuit
- **Subcategory:** Life Support
- **Type:** Companion Unit
- **Description:** Extends duration of underwater exploration.
- **Added in:** Atlas Rises

**Aeration Membrane Theta** upgrades a user's [[Life support|Life Support System]].

## Summary

Aeration Membranes increase a user's ability to swim underwater longer. This is a level three upgrade.

It allows the user to breathe for two minutes underwater. This effect is not increased by additional Aeration Membranes in the user's inventory, although they will automatically take over when this upgrade runs out.

## Game description

Provides an increased ability to swim underwater for extended periods.
Can be used alongside other Aeration Membrane upgrades.
Device is charged by [[Oxide elements|Oxide Elements]]. Operates automatically once constructed within user's exosuit inventory.

## Craft

- **Crafting (obsolete)**: 2 × [[Microdensity Fabric]] + 1 × [[Electron Vapour]] + 1 × [[AquaSphere]] → 1 × Aeration Membrane Theta

This formula used to use a Gravitino Ball instead of an AquaSphere which made the blueprint identical to blueprints for crafting four separate [[hazard protection]] upgrades for the [[exosuit]]:
- [[Coolant Network Theta]]
- [[Radiation Deflector Theta]]
- [[Thermic Layer Theta]]
- [[Toxin Suppressor Theta]]

## Dismantle

This upgrade can be dismantled for:

- Microdensity Fabric x1

## Upgrade progression

- [[Aeration Membrane Sigma]]
- [[Aeration Membrane Tau]]
- Aeration Membrane Theta

## Additional information

- Works automatically when charged and located in a player's [[Exosuit]] inventory.
- Charged with [[Zinc]], [[Titanium]], or [[Shielding Shard|Shielding Shards]].

NOTE: Prior to the [[Update 1.10|Foundation Update]], any of the [[Oxide elements]] could be used for recharging.
