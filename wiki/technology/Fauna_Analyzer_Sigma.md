# Fauna Analyzer Sigma

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Scanner
- **Level:** 1
- **Type:** Binocular Tagging Device
- **Description:** Used to improve detection of fauna
- **Added in:** Atlas Rises

The **Fauna Analyzer Sigma** is a 1st level technology upgrade.

## Summary

The **Fauna Analyzer Sigma** is an attachment for the [[Multi-tool]] that, when used, increases the [[units]] awarded to a player when discovering planetary fauna.

## Game Description

An extension to the Multi-Tool [[Analysis Visor]]. This upgrade unit boosts the resolution of creature scans, increase the value of new discoveries.
