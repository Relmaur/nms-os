# Toxin Suppressor Sigma

## Quick Facts

- **Level:** 1
- **Category:** Exosuit
- **Subcategory:** Utilities
- **Type:** Companion Unit
- **Description:** User is protected from toxic damage.
- **Stats:** Toxic Protection = 75.0
- **Added in:** Atlas Rises

**Toxic Suppressor Sigma** is an exosuit upgrade.

## Summary

The **Toxic Suppressor Sigma** upgrade protects the user from toxic damage.

## Game description

User is protected from toxic damage.

Reactive compounds within the Suppressor remove toxic liquids that fall on the user, thereby reducing peril and choking hazards.

Device is charged by [[Oxide elements]]. Operates automatically once constructed within user's [[exosuit]] inventory.

## Crafting

- **Crafting (obsolete)**: 50 × [[Iron]] + 100 × [[Carbon]] → 1 × Toxin Suppressor Sigma

This identical formula is used to craft five separate [[hazard protection]] upgrades for the exosuit:
- [[Aeration Membrane Sigma]]
- [[Coolant Network Sigma]]
- [[Radiation Deflector Sigma]]
- [[Thermic Layer Sigma]]
- Toxin Suppressor Sigma
