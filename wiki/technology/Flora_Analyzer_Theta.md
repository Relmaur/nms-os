# Flora Analyzer Theta

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Scanner
- **Level:** 3
- **Type:** Binocular Tagging Device
- **Description:** Used to improve detection of flora
- **Added in:** Atlas Rises

The **Flora Analyzer Theta** is a 3rd level technology upgrade.

## Summary

The **Flora Analyzer Theta** is an attachment for the [[Multi-tool]] that, when used, increases the [[units]] awarded to a player when discovering planetary flora.

## Game Description

An extension to the Multi-Tool [[Analysis Visor]]. This upgrade unit boosts the resolution of botanical scans, increase the value of new discoveries.
