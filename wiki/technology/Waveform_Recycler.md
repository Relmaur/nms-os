# Waveform Recycler

## Quick Facts

- **Category:** Multi-tool - Scanner
- **Type:** MultiTool Upgrade
- **Stats:** -20% Recharge Time / +11% Scan Radius
- **Updated:** Frontiers

**Waveform Recycler** is a technology.

## Summary

**Waveform Recycler** is a technology that increases the scan radius and decreases the recharge time of the Scanner.

It needs to be installed in a Multi-tool inventory slot for it to take effect.

## Game Description

A powerful lateral processor inserted into the Multi-Tool Scanning System allows the device to recharge at a significantly improved rate.

Increase potential scan frequency.

## Source

The blueprint can be acquired from a Technology Merchant for 120.

## Crafting

Waveform Recycler can be built using a blueprint and the following ingredients:

- Magnetised Ferrite ×100 + Ion Battery ×1 → Waveform Recycler

Waveform Recycler can be repaired using the following ingredients:

- Magnetised Ferrite ×50 + Ion Battery ×1

Waveform Recycler can be dismantled after construction, returning the following ingredients:

- Waveform Recycler → Magnetised Ferrite ×50

## Additional Info

Even though it is technically possible to extend scan radius by a considerable amount with multiple upgrades, the hard limit to the overall scan radius is currently confirmed to be at 750 u, regardless of the effects of other upgrades.
