# Shield Lattice

## Quick Facts

- **Category:** Exosuit - Hazard
- **Type:** Hazard Protection Upgrade
- **Stats:** +20% Hazard Protection Battery
- **Updated:** Desolation

**Shield Lattice** is an exosuit upgrade.

## Summary

Shield Lattice is a technology that increases the Hazard Protection of the exosuit.

It needs to be installed in an exosuit inventory slot for it to take effect.

## Game Description

Increase the base capacity of the Hazard Protection system, allowing the user to spend longer in hazardous environments without recharging their Exosuit.

## Crafting

The blueprint can be acquired from a Technology Merchant for 120.

Shield Lattice can be built using a blueprint and the following ingredients:

- Sodium Nitrate ×60 + Antimatter ×1 → Shield Lattice

Shield Lattice can be repaired using the following ingredients:

- Sodium Nitrate ×60 + Antimatter ×1

Shield Lattice can be dismantled after construction, returning the following ingredients:

- Shield Lattice → Sodium Nitrate ×30 + Antimatter ×1
