# Scatter Blaster Accuracy Tau

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Scatter Blaster
- **Level:** 2
- **Type:** Scatter Blaster Companion Unit

**Scatter Blaster Accuracy Tau** is a multi-tool upgrade.

## Summary

The **Scatter Blaster Accuracy Tau** is a second-level upgrade for the [[multi-tool]]'s [[Scatter Blaster]].

## Game description

Increases accuracy of the Multi-tool's Scatter Blaster weapon mode by reducing the spread of the projectile by a moderate amount.
