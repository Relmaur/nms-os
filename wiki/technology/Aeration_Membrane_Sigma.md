# Aeration Membrane Sigma

## Quick Facts

- **Category:** Exosuit
- **Subcategory:** Life Support
- **Type:** Companion Unit
- **Description:** Extends duration of underwater exploration.
- **Stats:** Oxygen Tank = 38.0
- **Added in:** Atlas Rises

**Aeration Membrane Sigma** upgrades a users [[Life support|Life Support System]].

## Summary

Aeration Membranes increase a user's ability to swim underwater longer, and can be used alongside other Aeration Membrane upgrades. It allows the user to breath for 38 seconds underwater. This effect is not increased by additional Aeration Membranes in the user's inventory, although they will automatically take over when this runs out..

## Game description

User is able to swim underwater for extended periods.

Absorbs gasses dissolved in water through a membrane contactor that, if user is of a conventionally structured species, is placed over the mouth or facial breathing hole.

Operates automatically once constructed within user's exosuit inventory.
