# Rocket Boots

## Quick Facts

- **Category:** Exosuit - Movement
- **Type:** Exosuit Upgrade
- **Stats:** Advanced Jump System: Enabled
- **Updated:** Origins

**Rocket Boots** is an exosuit technology.

## Summary

**Rocket Boots** is a technology that allows a player to fire their jetpack rapidly in effort to fly a greater distance and increase flight time.

It needs to be installed in an exosuit inventory slot for it to take effect.

## Game Description

Equips the Exosuit jetpack with advanced jump capabilities, allowing the user to take huge leaps with ease.

Activate jump systems by rapidly pressing // (PS4/PC/Xbox).

## Source

The blueprint can be acquired from a Technology Merchant for 200.

## Crafting

Rocket Boots can be built using a blueprint and the following ingredients:

- Tritium ×100 + Hydraulic Wiring ×1 → Rocket Boots

Rocket Boots can be repaired using the following ingredients:

- Tritium ×50 + Hydraulic Wiring ×1

Rocket Boots can be dismantled after construction, returning the following ingredients:

- Rocket Boots → Tritium ×50

## Additional information

- Upgrade bonuses trigger if Rocket Boots are adjacent to Neural Stimulator or Movement System Upgrades, but the technology is not actually affected by these bonuses. Rocket Boots does not count toward the three-upgrade limit; however, only one Rocket Boots technology can be installed at a time.
