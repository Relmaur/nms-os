# Beam Coolant System Theta

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Mining Beam
- **Level:** 3
- **Type:** Mining Beam Companion Unit
- **Description:** Attains longest span of uninterrupted element extraction possible for all current Mining Beam technologies.
- **Added in:** Pathfinder

The **Beam Coolant System Theta** is a third-level [[laser technology]] upgrade for the [[multi-tool|multi-tool's]] [[Mining Beam]].

## Summary

The Beam Coolant System attains longest span of uninterrupted element extraction possible for all current Mining Beam technologies.

Additional frenium coolant capillaries safely transfer excess heat from the lasers crystal excitement chamber, resulting in minimum disruption to mining processes.
