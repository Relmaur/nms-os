# High-Gravity Freighter Trail

## Quick Facts

- **Category:** Freighter
- **Type:** Freighter Engine Flare Override
- **Description:** Changes the colour of the Freighter's engine flare.
- **Added in:** Polestar

This is a Freighter Engine Flare Override.

## Summary

**High-Gravity Freighter Trail** is a [[Freighter]] [[Technology]] used to change your freighter trail color. The trail color can be changed using the [[Upgrade Control|Upgrade Control Terminal]].

## Game Description

An exclusive Freighter Engine Flare Modifier.

High-energy exhaust gases rapid condense as they exit the freighter's colossal engines, collapsing into micro-singularities.

Transform the appearance of your freighter at the Upgrade Control Terminal on the bridge.

## Obtained

The **High-Gravity Freighter Trail** color was rewarded for completing [[Expedition 8: Polestar]] - Phase 2.
