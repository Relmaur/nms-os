# Pulse Spitter Accuracy Tau

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Pulse Spitter
- **Level:** 2
- **Type:** Pulse Spitter Companion Unit

**Pulse Spitter Accuracy Tau** is a multi-tool upgrade.

## Summary

The **Pulse Spitter Accuracy Tau** is a second-level upgrade for the [[multi-tool]]'s [[Pulse Spitter]].

## Game description

Increases accuracy of the Multi-tool's Pulse Spitter weapon mode by reducing the spread of the projectile by a moderate amount.
