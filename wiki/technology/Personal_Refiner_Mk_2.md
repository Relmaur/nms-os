# Personal Refiner Mk 2

## Quick Facts

- **Category:** Exosuit
- **Type:** Exosuit Upgrade
- **Updated:** Echoes

**Personal Refiner Mk 2** is an exosuit technology.

## Summary

**Personal Refiner Mk 2** is a technology that allows a player to refine two different substances on the move.

It needs to be installed in an exosuit tech inventory slot for it to take effect.

It's an upgraded form of the Personal Refiner, allowing refining two materials instead of only one.

## Game Description

A compact extension to the Exosuit, installing an advanced yet portable Medium Refiner, accessible directly from the user's Exosuit interface.

Unit requires fuel and is able to refine more complex recipes than the standard personal refiner unit.

## Source

The blueprint can be acquired from Iteration: Selene in the Space Anomaly for 580.

## Crafting

Personal Refiner Mk 2 can be built using a blueprint and the following ingredients:

- Ionised Cobalt ×120 + Magnetic Resonator ×2 + Quantum Computer ×3 → Personal Refiner Mk 2

Personal Refiner Mk 2 can be repaired using the following ingredients:

- Ionised Cobalt ×60 + Magnetic Resonator ×1 + Quantum Computer ×1

Personal Refiner Mk 2 can be dismantled after construction, returning the following ingredients:

- Personal Refiner Mk 2 → Ionised Cobalt ×60 + Magnetic Resonator ×1 + Quantum Computer ×2
