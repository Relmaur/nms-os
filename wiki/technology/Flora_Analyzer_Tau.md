# Flora Analyzer Tau

## Quick Facts

- **Category:** Multi-tool
- **Subcategory:** Scanner
- **Level:** 2
- **Type:** Binocular Tagging Device
- **Description:** Used to improve detection of flora
- **Added in:** Atlas Rises

The **Flora Analyzer Tau** is a 2nd level technology upgrade.

## Summary

The **Flora Analyzer Tau** is an attachment for the [[Multi-tool]] that, when used, increases the [[units]] awarded to a player when discovering planetary flora.

## Game Description

An extension to the Multi-Tool [[Analysis Visor]]. This upgrade unit boosts the resolution of botanical scans, increase the value of new discoveries.
