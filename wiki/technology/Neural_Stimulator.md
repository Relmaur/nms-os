# Neural Stimulator

## Quick Facts

- **Category:** Exosuit - Movement
- **Type:** Exosuit Movement Upgrade
- **Stats:** +20% Jetpack Tanks / +10% Sprint Distance / +11% Recharge Rate / +21% Sprint Recovery Time
- **Updated:** SentinelUp

**Neural Stimulator** is an exosuit upgrade.

## Summary

**Neural Stimulator** is a technology that allows a player to fire their jetpack longer and to run a greater distance.

It needs to be installed in an exosuit inventory slot for it to take effect.

## Game Description

Increases the capacity of the Exosuit's Jetpack Tanks and Adrenal Pump Reserves, allowing the user to both fly and sprint longer.

## Source

The blueprint can be acquired from Iteration: Selene on the Space Anomaly for 90.

## Crafting

Neural Stimulator can be built using a blueprint and the following ingredients:

- Chromatic Metal ×100 + Condensed Carbon ×100 → Neural Stimulator

Neural Stimulator can be repaired using the following ingredients:

- Chromatic Metal ×50 + Condensed Carbon ×50

Neural Stimulator can be dismantled after construction, returning the following ingredients:

- Neural Stimulator → Chromatic Metal ×50 + Condensed Carbon ×50

## Additional information

- Upgrade bonuses trigger if Neural Stimulator is adjacent to Rocket Boots or Movement System Upgrades, increasing its bonuses above the listed values.
- Neural Stimulator does not count toward the 3-upgrade limit of "Movement System Upgrades" because it is a "Movement Upgrade". Note that only one Neural Stimulator can be installed at a time.
