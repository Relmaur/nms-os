# Beam Intensifier Theta

## Quick Facts

- **Category:** Multi-tool

- **Type:** Companion Unit

The **Beam Intensifier Theta** is a multi-tool upgrade.

## Summary

The **Beam Intensifier Theta** is a third-level [[laser technology]] upgrade for the [[Multi-tool|Multi-tool's]] [[Mining Beam]].

## Game description

[[Mining Beam]] laser is strengthened to speed up terrain destruction.

Operates automatically once constructed within user's [[Multi-tool]] inventory.
