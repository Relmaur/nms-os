# Azimuth-Class Reactor

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Azimuth-Class Reactor** is a corvette building component.

## Summary

**Azimuth-Class Reactor** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A powerful reactor core for a corvette-class starship, designed to power and enhance critical systems.

This module is automatically linked to the corvette's navigation systems, providing a powerful performance boost.

## Upgrade properties

The Azimuth-Class Reactor functions similarly to an A-class Pulse Engine upgrade, granting the following bonuses:
- *Pulse Drive Fuel Efficiency*: decreases the rate of Pulse Drive fuel consumption during Pulse Jumps.
- *Automatic Recharging: Enabled*
- *Launch Cost*
