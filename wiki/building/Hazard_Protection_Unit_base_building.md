# Hazard Protection Unit (base building)

## Quick Facts

- **Category:** Base Building
- **Type:** Hazard Protection Charging System
- **Added in:** Origins
- **Power:** 10 kPs

**Hazard Protection Unit (base building)** is a base building product.

## Summary

**Hazard Protection Unit** is a [[base building]] [[product]] which, once it has been charged with 10 units of [[Ferrite Dust]], can be activated once to fully recharge one's [[Hazard Protection]].

Though the permanent technology object is intended to be attached to walls, it can be placed on any free non-terrain surface, including floors and ceilings.

While it *can* be placed on basic material surfaces, it will only receive power when placed in prefabricated powered buildings. Alternatively, it can be placed on a [[Storage Container]] and be powered that way.

## Game description

A wall mounted module that can be used to recharge the user's Hazard Protection systems.

The Hazard Protection Unit requires 10 [[Ferrite Dust]] to provide service in [[Origins]] release.

## Source

The blueprint can be acquired from the [[Blueprint Analyser]].
