# Globe Tree

## Quick Facts

- **Category:** Base Building
- **Type:** Organic decoration
- **Value:** 500
- **Added in:** NextGen

**Globe Tree** is a base-building component.

## Summary

**Globe Tree** is an item used in base building.

## Game description

A thin tree with a large, fleshy root system, well adapted to hot climates.

Root bulb may be tapped for a source of drinkable liquid, but this is not advised outside of the most dire circumstances.
