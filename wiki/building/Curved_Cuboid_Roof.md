# Curved Cuboid Roof

## Quick Facts

- **Category:** Base Building
- **Type:** Construction module
- **Power:** 5kP
- **Added in:** Origins

**Curved Cuboid Roof** is a base building component.

## Summary

**Curved Cuboid Roof** is a [[Base building]] structure designed to be placed at upper edges of custom-made chambers.

The small room component's preview auto-snaps to many horizontal anchors as well as upward-pointing vertical anchors.

## Game description

A curved, glass-fronted roof module that can be stacked or linked to form larger structures.
