# Ceto-Class Reactor

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Ceto-Class Reactor** is a corvette building component.

## Summary

**Ceto-Class Reactor** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A powerful reactor core for a corvette-class starship, designed to power and enhance critical systems.

This module is automatically linked to the corvette's defensive systems, providing a powerful performance boost.

## Upgrade properties

The Ceto-Class Reactor functions similarly to an A-class Deflector Shield upgrade, granting the following bonus:
- *Shield Strength:* Increases the Shield Absorption, indirectly increasing the Deflector Shield's durability for each upgrade.
