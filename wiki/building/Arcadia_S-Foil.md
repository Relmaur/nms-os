# Arcadia S-Foil

## Quick Facts

- **Category:** Corvette Building

## Summary

**Arcadia S-Foil** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A wing module for a Corvette-class starship, stabilising the vessel during atmospheric flight.

Assemble a corvette at the dedicated Corvette Workshop aboard any Space Station.
