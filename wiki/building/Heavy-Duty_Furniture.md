# Heavy-Duty Furniture

## Quick Facts

- **Category:** Base Building
- **Type:** Salvaged Base Part

**Heavy-Duty Furniture** is a base building product.

**Heavy-Duty Furniture** is a [[base building]] [[product]] that can be found on [[Derelict Freighter|Derelict Freighters]].

Robustly constructed interior decoration, created with the needs of industrial spacefaring in mind.
