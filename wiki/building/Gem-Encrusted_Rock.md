# Gem-Encrusted Rock

## Quick Facts

- **Category:** Base Building
- **Type:** Organic decoration
- **Value:** 500
- **Added in:** Prisms

**Gem-Encrusted Rock** is a base-building component.

## Summary

**Gem-Encrusted Rock** is an item used in base building. It is rock with small gems attached to it.

## Game description

Once a discarded byproduct of deep-level crystal mining, the aesthetic value of the rocks is now better appreciated.

It provides decorative opportunities for bases.
