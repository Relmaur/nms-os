# Antimatter Reactor

## Quick Facts

- **Category:** Base Building
- **Type:** Baryogenesis Unit
- **Added in:** Omega

**Antimatter Reactor** is a base building product.

## Summary

**Antimatter Reactor** is a [[base building]] [[product]], which allows the player to autonomously harvest [[Antimatter]]. Its model and colors are the exact same as the [[Base Salvage Capsule|base salvage capsule]] and the only way to differentiate the two is selecting them.

It does not consume any power in the base.

## Game description

An autonomous baryogenesis reactor, this device can be left to harvest reality paradoxes and convert them into usable antimatter. User must monitor fuel levels to ensure continued operation.

The resulting antimatter is safely contained, ready for use in all standard hyperspace power units.

## Source

The blueprint can be acquired from the [[Construction Research Station]] aboard the [[Space Anomaly]].

- **Crafting** · needs the blueprint: 5 × [[Storm Crystal]] + 2 × [[Antimatter]] + 2 × [[Metal Plating]] → 1 × Antimatter Reactor

## Fuel sources

The Antimatter reactor has a [[Generator Coupling]], which requires 80 [[Carbon]] or 27 [[Condensed Carbon]] to be fully charged.

A full charge generates 20 Antimatter and only takes a few minutes.

It is much more resource-efficient than manually crafting Antimatter in your inventory.

## Release history

- [[Beyond]] - Added as a base building product.

## Additional information

- This building is only available in the build menu if you are on a base, making it impossible to be built on a freighter.
- The [[Barrel Fabricator]] is another source of antimatter which doesn't require any refueling.  However, its output is completely random and takes much, much longer to generate output.
- The quantity of antimatter produced is tied to the stack size of antimatter.  If mods are used to increase stack size, the antimatter reactor will produce the new maximum stack size for antimatter over the same production duration as usual, potentially increasing production efficiency astronomically.
