# Viewing Sphere

## Quick Facts

- **Category:** Base Building
- **Type:** Construction module
- **Base complexity:** ??
- **Added in:** Beyond
- **Power:** 1 kPs

**Viewing Sphere** is a base building component.

## Summary

**Viewing Spheres** are [[Base building]] structures designed to allow one to view the surrounding environment without also being subjected to its hazards.

During placement, the previews of these large structures auto-snap only to horizontal anchors.

## Game description

A self-contained spherical viewing platform which affords the user stunning views of the surrounding environment.
