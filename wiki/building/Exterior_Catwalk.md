# Exterior Catwalk

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Construction Module
- **Added in:** Endurance

**Exterior Catwalk** is a base building product.

## Summary

**Exterior Catwalk** is a [[base building]] [[product]] specifically designed for [[freighter|freighters]].

## Game description

This exterior wakway intelligently adjoins to existing freighter roons, creating decking outside the hull of large starships.

A [[Bulkhead Door]] must be installed to allow access to exterior spaces.
