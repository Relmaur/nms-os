# Mission Radar

## Quick Facts

- **Category:** Corvette Building
- **Type:** Mission Location System
- **Added in:** Voyagers

**Mission Radar** is a corvette building product.

## Summary

**Mission Radar** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

An access panel for the Mission Radar, which allow Travellers to search the local system for mission opportunities.

Listing posted on the mission radar are challenging, and may require a corvette's full crew.

This module is installed along the entire wall of a Corvette Hab.

## Build

- **Crafting**: 40 × [[Gold]] + 1 × [[Microprocessor]] + 1 × [[Ion Battery]] → 1 × Mission Radar
