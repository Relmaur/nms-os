# Torpedo Launcher

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Torpedo Launcher** is a corvette building component.

## Summary

**Torpedo Launcher** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A dedicated weapon platform for a Corvette-class starship.

This module is automatically linked to the corvette's rocket batteries, providing a powerful performance boost.

## Upgrade properties

The Torpedo Launcher functions as an A-class upgrade, granting the following bonuses:
- *Range*
- *Heat Recovery*
- *Damage:* increases the damage of each shot.
