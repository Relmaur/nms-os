# Holo-Door

## Quick Facts

- **Category:** Base Building
- **Type:** Component
- **Power:** 1kps
- **Added in:** ExoMech

**Holo-Door** is a [[Base building]] structure.

## Summary

The **Holo-Door** provides room entry while controlling temperature and atmosphere to the adjoining rooms.

## Game description

An elegant holographic door which allows quick access to any structure while regulating the temperature and toxicity of the interior.

## Source

- **Crafting** · needs the blueprint: 40 × [[Gold]] + 40 × [[Pure Ferrite]] + 40 × [[Silicate Powder]] → 1 × Holo-Door

## Additional information

Does not need a hook up spot like other items do, but uses the room power instead
