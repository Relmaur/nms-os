# Refiner Unit

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Interior Furnishing
- **Added in:** Voyagers

**Refiner Unit** is a corvette building product.

## Summary

**Refiner Unit** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A powerful refiner, this in-ship module allows three different substances to be processed into more powerful and more advanced materials.

This module is installed along the entire wall of a Corvette Hab.

## Build

- **Crafting**: 20 × [[Platinum]] + 1 × [[Hydraulic Wiring]] → 1 × Refiner Unit
