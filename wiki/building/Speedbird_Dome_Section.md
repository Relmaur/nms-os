# Speedbird Dome Section

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module

**Speedbird Dome Section** is a corvette building component.

## Summary

**Speedbird Dome Section** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A piece of hull cowling for a Corvette-class starship, designed to streamline and protect core ship components.

Assemble a corvette at the dedicated Corvette Workshop aboard any Space Station.
