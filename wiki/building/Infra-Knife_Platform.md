# Infra-Knife Platform

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Breach

**Infra-Knife Platform** is a corvette building component.

## Summary

**Infra-Knife Platform** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A dedicated weapon platform for a Corvette-class starship.

This module is automatically linked to the corvette's Infra-Knife Accelerator array, providing a powerful performance boost.
