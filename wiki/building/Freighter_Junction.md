# Freighter Junction

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Interior Module
- **Added in:** Visions

**Freighter Junction** is a base building component.

## Summary

**Freighter Junction** is a [[Base building]] structure designed to connect rooms together within a [[Freighter]]. This freighter component is only buildable within the designated build area.

## Game description

This expansion module allows for the rapid construction of habitable spaces inside large starships.

Construction unit is fabricated complete with pressure bulkhead and all necessary attachment points.

## Sources

- **Crafting** · needs the blueprint: 80 × [[Silver]] + 10 × [[Tritium]] → 1 × Freighter Junction

## Additional Information

- This item serves the same purpose as a [[T-Shaped Corridor]] does for a planetary base.
