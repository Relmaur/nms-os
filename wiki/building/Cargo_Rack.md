# Cargo Rack

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Interior Furnishing
- **Added in:** Voyagers

**Cargo Rack** is a corvette building product.

## Summary

**Cargo Rack** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A combination storage device and easy-access panel. This unit allows access to [[Storage Container|Storage Containers]] while travelling tthrough deep space.

This module is installed along the entire wall of a Corvette Hab.

## Build

- **Crafting**: 3 × [[Metal Plating]] + 1 × [[Microprocessor]] → 1 × Cargo Rack
