# Timber Wall

## Quick Facts

- **Category:** Base Building
- **Type:** Timber Construction Component
- **Added in:** Frontiers

**Timber Wall** is a base building component.

## Summary

**Timber Wall** is a [[Base building]] structure used to erect basic structures.

The basic component's preview auto-snaps to the edges of other basic components.

## Game description

Reinforced Timber building module, widespread in basic structures across the galaxy.

Conforms to Universal Building Standards 2.3b, ensuring maximum compatibility with other prefab structure. Rapid Grid snapping allows for quick assembly of custom shelter layouts
