# Photon Cannon Array

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Photon Cannon Array** is a corvette building component.

## Summary

**Photon Cannon Array** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A dedicated weapon platform for a Corvette-class starship.

This module is automatically linked to the corvette's Photon Cannon array, providing a powerful performance boost.

## Upgrade properties

The Photon Cannon Array functions similarly to an A-class Photon Cannon upgrade, granting the following bonuses:
- *Heat Dispersion*: allows to fire the weapon continuously for longer before it overheats.
- *Fire Rate*:  decreases the time between each shot.
- *Damage:* increases the damage of each shot.
