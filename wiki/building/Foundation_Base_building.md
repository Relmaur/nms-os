# Foundation (Base building)

## Quick Facts

- **Category:** Base Building
- **Type:** Base
- **Base complexity:** 5
- **Added in:** NextGen

**Foundation** is a base building component.

## Summary

A **Foundation** can be used to start construction projects, and gives support beams to cylindrical and cubical structures that do not sit on the ground.

## Game description

The base unit for all construction projects, providing a solid foundation for any structure. Can be anchored to all types of terrain.
