# Wheel of Hirk Firework

## Quick Facts

- **Category:** Base Building
- **Type:** Exotic Collectibles
- **Added in:** Prisms

**Wheel of Hirk Firework** is a base building product.

## Summary

**Wheel of Hirk Firework** is a [[base building]] [[product]] and can be found in the Exotic Collectibles category.

## Game description

A luxury firework. When activated, this pyrotechnic marvel turns and whorls in a mesmerising spiral. Ignite to create glitter displays in the sky.

Place launch tube via the Build Menu (z). Warning: Aim away from living creatures. Not recommended for indoor use.

## Build

Once unlocked, the product can be purchased from the [[Quicksilver Synthesis Companion]] in the [[Space Anomaly]] for 50  Quicksilver. The maximum number available for purchase is 1000.
