# Nutrient Processor

## Quick Facts

- **Category:** Base Building
- **Value:** 10.0
- **Type:** Portable Sustenance Unit
- **Added in:** Fractal

**Nutrient Processor** is a base building product.

## Summary

The **Nutrient Processor** is a portable [[base building]] [[product]] that is used for [[cooking]] various [[ingredients]]. Unlike the [[Portable Refiner]], it does not require any additional fuel or power to be functional.

Up to three ingredients can be inserted on the input side and if the combination is a valid recipe, the end product will be shown on the output side. All operations take 2.5 seconds to complete and they are always 1:1 ratio.

## Game description

A portable nutrient extractor, able to process and refine gathered ingredients into edible food products.

User is advised that consumption of generated products is entirely at their own risk.

## Source

The [[blueprint]] can be acquired from the [[Construction Research Station]] on the [[Space Anomaly]] for 10 [[Salvaged Data]].

## Build

- **Crafting** · needs the blueprint: 2 × [[Metal Plating]] + 1 × [[Hermetic Seal]] + 25 × [[Sodium]] → 1 × Nutrient Processor

## Additional information

- It accesses the global [[Ingredient Storage]], which provides fifty (50) slots shared across all Nutrient Processors. Each slot can hold up to fifty (50) units of a single ingredient. Some ingredients have unique limits:
  - [[Hypnotic Eye]] and [[Larval Core]]: 5 units per slot
  - [[Carbon Nanotubes]]: 10 units per slot
  - [[Creature Pellets]]: 25 units per slot
  - Most other cooking components (e.g. [[Carbon]], [[Salt]], [[Frost Crystal]]) use standard normal/survival stack capacities.
- When clicking on an input slot, all accessible ingredients from [[Ingredient Storage]] will appear.
- Some players report (possibly legacy saves) that they only have 10 slots available instead of 50. There is no known fix for this issue, and Hello Games has not officially acknowledged it.
- A special instance of the Nutrient Processor can be found aboard the [[Space Anomaly]], near [[Iteration: Cronus]]. See: [[Cronus's Grill System]].
