# Cultivation Chamber

## Quick Facts

- **Category:** Base Building
- **Type:** Agriculture
- **Added in:** Endurance

**Cultivation Chamber** is a base building product.

## Summary

**Cultivation Chamber** is a [[Freighter Base Building]] module allowing growing of [[Farming|agricultural crops]].

## Game description

A temperature controlled bio-room. A bed of nutrient-rich soil provides ideal conditions for cultivating agricultural crops.

This module is placed as an entire room and comes with its functional units pre-installed.
