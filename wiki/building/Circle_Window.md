# Circle Window

## Quick Facts

- **Category:** Base Building
- **Type:** Construction item
- **Added in:** Waypoint

**Circle Window** is a base building product.

## Summary

**Circle Window** is a [[base building]] [[product]] and can be found in the Structures/Windows building category.

The blueprint is acquired from the [[Blueprint Analyser]].

## Game description

A window made from self-cleaning, UV-treated, hermetically sealed glass.

## Build

- **Crafting** · needs the blueprint: 5 × [[Ionised Cobalt]] + 1 × [[Glass]] → 1 × Circle Window

- **Dismantle** returns: 5 × [[Ionised Cobalt]] + 1 × [[Glass]]
