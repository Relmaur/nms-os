# Message Module

## Quick Facts

- **Category:** Base Building
- **Type:** Communications terminal
- **Added in:** Origins

**Message Module** is a base building product.

## Summary

**Message Module** is a [[base building]] [[product]] and can be found in the Equipment/Portable Technology building category.

It allows players to leave behind messages for other players to find, similar to the [[Communications Station]]. After building the Message Module the player will need to interact with it to set its message.

The message does not require activation to be read, instead it is displayed as white glowing text in the center of screen for anyone who approaches the Message Module.

## Game description

A small and accessible information container for leaving messages or viewing left messages and short strings of information.

## Source

As of Beyond, the blueprint is available from the construction technology vendor at the Anomaly.
