# Square Room

## Quick Facts

- **Category:** Base Building
- **Type:** Structure
- **Base complexity:** 40
- **Added in:** Frontiers
- **Power:** 10 kPs

**Square Room** is a base-building component.

## Summary

A **Square Room** is a [[Base building]] [[Structure types|structure]] designed to act as a standalone room.

Square rooms are rooms that can be added onto. [[Window|Windows]] can be built on the walls. They can be stacked vertically, with [[ladder|ladders]] being used to connect the floors. [[Bio-Dome|Bio-Domes]] may be placed on top. It may also be connected with corridors, to create larger structures.

## Game description

A square alternative to the core module for base construction, providing a generous central space on which to expand.
