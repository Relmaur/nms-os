# Ion Barrier

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Ion Barrier** is a corvette building component.

## Summary

**Ion Barrier** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A shield generator system for a Corvette-class starship.

This module is automatically linked to the corvette's shielding system, providing a significant performance boost.

## Upgrade properties

The Ion Barrier functions similarly to a B-class Deflector Shield upgrade, granting the following bonus:
- *Shield Strength:* Increases the Shield Absorption, indirectly increasing the Deflector Shield's durability for each upgrade.
