# Teleport Cable

## Quick Facts

- **Category:** Base Building
- **Value:** 0
- **Added in:** Echoes

**Teleport Cable** is a base building product.

## Summary

**Teleport Cable** is a [[base building]] [[product]] that connects two [[Short-Range Teleporter|Short-Range Teleporters]].

Unlike most items in No Man's Sky, it costs nothing to build.

## Game Description

Advanced fibre-optic cabling, designed to link one or more Short-Range Teleporters.

## Utilisation

Both teleport units in a pair need to be connected to each other using a teleport cable, which cannot be longer than approximately 200u, the maximum observed distances between teleport pairs, although this can be in any direction, horizontal or vertical (even through underground layers or NPC/player-constructed buildings).

Teleporter cables can only be 200u long. If you try to run it longer, the player will receive a "connection too long" error. It is possible to build relays to extend the length, by daisy chaining short range teleporter pairs adjacent to each other.

The cables cannot cross base boundaries.

## Additional Information

- [[Electrical Cloaking Unit|Electrical Cloaking Units]] do not hide Teleport Cables.
