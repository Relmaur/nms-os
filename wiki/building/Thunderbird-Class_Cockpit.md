# Thunderbird-Class Cockpit

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Thunderbird-Class Cockpit** is a corvette building component.

## Summary

**Thunderbird-Class Cockpit** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

The core command-and-control centre for a Corvette-class starship, housing both pilot and vital avionics systems.

This module is automatically linked to the corvette's flight control systems, providing a moderate performance boost.

## Upgrade properties

The Thunderbird-Class Cockpit functions similarly to a C-class Pulse Engine upgrade, granting the following bonuses:
- *Maneuverability:* increases the Starship's turn rate.
- *Boost:* increases maximum speed while boosting.
