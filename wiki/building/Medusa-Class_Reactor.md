# Medusa-Class Reactor

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Medusa-Class Reactor** is a corvette building component.

## Summary

**Medusa-Class Reactor** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A powerful reactor core for a corvette-class starship, designed to power and enhance critical systems.

This module is automatically linked to the corvette's flight control systems, providing a powerful performance boost.

## Upgrade properties

The Medusa-Class Reactor functions similarly to an A-class Pulse Engine upgrade, granting the following bonuses:
- *Maneuverability:* increases the Starship's turn rate.
- *Boost:* increases maximum speed while boosting.
