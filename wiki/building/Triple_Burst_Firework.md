# Triple Burst Firework

## Quick Facts

- **Category:** Base Building
- **Type:** Exotic Collectibles
- **Added in:** Prisms

**Triple Burst Firework** is a base building product.

## Summary

**Triple Burst Firework** is a [[base building]] [[product]] and can be found in the Exotic Collectibles category.

## Game description

A luxury firework, featuring a triple-burst symphony of colour. Ignite to create glitter displays in the sky.

Place launch tube via the Build Menu (z). Warning: Aim away from living creatures. Not recommended for indoor use.

## Build

The product can be purchased from the [[Quicksilver Synthesis Companion]] in the [[Space Anomaly]] for 50  Quicksilver. The maxium number available for purchase is 1000.
