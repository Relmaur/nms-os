# Large Refiner

## Quick Facts

- **Category:** Base Building
- **Type:** Automated Refinery Unit
- **Added in:** Expeditions

A **Large Refiner** is a base building product.

## Summary

A **Large Refiner** is a [[base building]] [[product]] for purifying and combining three elements to create another or to crack higher unique elements to create smaller and more concentrated resources. It is the largest of the four Refiners.

For example, it can be used to refine [[Gold]], [[Silver]], and [[Cadmium]] into  [[Chromatic Metal]] x10.

Some end products of the refinery tree are reversible.

## Game description

A vital piece of planetary equipment. The Refiner allows gathered substances to be processed into more powerful and more advanced materials.

The Large Refiner allows three different substances to be combined into one new material, or materials to be processed at better ratios.

The Large Refiner must be installed in a Habitable Base, but does not require additional power sources.

## Fuel sources

The Large Refiner is non-portable and needs no fuel. It also consumes no power from the power grid of the base or personal [[Freighter]]

## Build

- **Crafting** · needs the blueprint: 200 × [[Chromatic Metal]] + 100 × [[Sodium Nitrate]] + 5 × [[Microprocessor]] → 1 × Large Refiner

The blueprint can be obtained as part of the [[Scientific Research]] missions.

Deleting the Large Refiner will refund all materials.

No more than two Large Refiners and three [[Medium Refiner|Medium Refiners]] can be built in a 50u area.

## Crafting

A refiner can be used to refine or grind a number of materials. A list of these can be found on the [[Refiner]] page.
