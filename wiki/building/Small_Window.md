# Small Window

## Quick Facts

- **Category:** Base Building
- **Type:** Construction item
- **Added in:** Waypoint

**Small Window** is a base building product.

## Summary

**Small Window** is a [[base building]] [[product]] and can be found in the Structures/Windows building category.

The blueprint is acquired from the [[Blueprint Analyser]].

## Game description

A window made from self-cleaning, UV-treated, hermetically sealed glass.

## Build

- **Crafting** · needs the blueprint: 5 × [[Ionised Cobalt]] + 1 × [[Glass]] → 1 × Small Window

- **Dismantle** returns: 5 × [[Ionised Cobalt]] + 1 × [[Glass]]
