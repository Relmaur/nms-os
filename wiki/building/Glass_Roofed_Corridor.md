# Glass Roofed Corridor

## Quick Facts

- **Category:** Base Building
- **Type:** Structure
- **Base complexity:** 30
- **Added in:** Beyond

**Glass Roofed Corridor** is a Base building component.

## Summary

**Glass Roofed Corridors** are a [[Base building]] structure designed to connect structures. As the name suggests, they contain large glass windows.

The offer better views than regular [[Straight Corridor|Straight Corridors]] with windows attached.

## Game description

Corridor with reinforced glass roofing.
