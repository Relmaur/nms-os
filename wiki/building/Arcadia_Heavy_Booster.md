# Arcadia Heavy Booster

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Arcadia Heavy Booster** is a corvette building component.

## Summary

**Arcadia Heavy Booster** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A main engine for a Corvette-class starship, delivering propulsion during atmospheric and deep-space flight.

This module is automatically linked to the corvette's main engines, providing a powerful performance boost.

## Upgrade properties

The Arcadia Heavy Booster functions similarly to an A-class Pulse Engine upgrade, granting the following bonuses:
- *Pulse Drive Fuel Efficiency*: decreases the rate of Pulse Drive fuel consumption during Pulse Jumps.
- *Maneuverability:* increases the Starship's turn rate.
- *Boost:* increases maximum speed while boosting.
