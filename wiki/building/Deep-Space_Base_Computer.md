# Deep-Space Base Computer

## Quick Facts

- **Category:** Base Building
- **Type:** Site Evaluation Device
- **Added in:** Cosmos

**Deep-Space Base Computer** is a base building product.

## Summary

**Deep-Space Base Computer** is a [[base building]] [[product]] which is described as a portable land registration service. A base computer is required to set up a [[Habitable Base]] on a [[Habitable Asteroid]] or [[Habitable Comet Fragment]], as base building is only enabled once a Base computer is deployed and successfully activated.

When deployed, the Base Computer can be interacted with to establish a new base. The base first must be activated, which checks to ensure no other base computer in the area has claimed part of the nearby territory. If activation is successful, it will create a buildable area around itself. This will enable the construction of all base components found in the [[Build Menu]].

Once a base is established, the Base Computer can also be interacted with to rename the base, change the base's thumbnail screenshot or delete the base altogether, which removes both the Base Computer and everything constructed around it.

## Additional Information

### Limitations

A self-build space station can not be uploaded to the Hello Games network, which prevents it from being shown to any other instance of your own game or other players. It is yet unknown if other players in a shared game instance as a group can see and use other players self-build space stations.

This seems to be a similar limitation like the claimable space stations, which can upload a screenshot and allegedly the base, but none of those changes is shown to other players.

In case of the standard space stations this is reasonable, as a troll owner could block access to elements by building walls inside of it. For self-build deep space outposts, this is odd.

To generate gravity it is necessary to build outside walkways on which landing pads can be build. Further to supply electricity to any "freighter" building complexes, the electrical line has to be linked to a consumer inside of it (the standalone wormhole portal works). After one consumer is linked up with a solar array, all objects inside the freighter halls are supplied with energy automatically. This oddity seems to stem from the bastard system which allows combining planetary base parts with stellar base parts.

### Bugs

Due the [[Space Station]] claim limit being removed since [[Update 7.04]] and unlimited, once you claim many stations all their core parts seem to count towards your total build parts limit. This leads to all base parts and basic signal boosters or save points reporting "Construction Limit reached". This basically softlocks a player character and makes them unable to build any new bases or basic tools in any system or on any planet. This is a serious bug.

The reason why these systems have to interact is unknown.

Outside walkways can not be directly linked to rooms, the outer walls will glitch out and be transparent from the inside. A corridor has to be used to link the outside walkways and the internal rooms to avoid this.
