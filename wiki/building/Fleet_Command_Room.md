# Fleet Command Room

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Construction Module
- **Added in:** Waypoint

**Fleet Command Room** is a base building product.

## Summary

**Fleet Command Room** is a [[base building]] [[product]] specifically designed for [[freighter|freighters]], and used as a control center for a [[frigate]] fleet.

## Game description

Core Fleet Management Station. This advanced holographic communications station is vital for managing [[Frigate Expedition|Frigate Expeditions]] from the comfort of your capital ship.

User is advised that a dedicated station is required to manage each fleet that will be sent on an expedition at a time, for example to have five simultaneous fleet expeditions, five of these terminal rooms will be required.

## Additional Information

Fleet Command Stations in use display their assigned fleets. For active fleets, the ships are rotating (cyan color), while those awaiting debrief are stationary (green color).
