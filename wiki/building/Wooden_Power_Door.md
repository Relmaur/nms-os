# Wooden Power Door

## Quick Facts

- **Category:** Base Building
- **Type:** Wooden Construction Component

**Wooden Power Door** is a base building component.

## Summary

**Wooden Power Door** is a [[Base building]] structure used to erect simple shelters.

The basic component's preview auto-snaps to the edges of other basic components.

## Game description

A power-operated door. Can be connected to a power grid and operated using various switches.

Fashioned from pressure-treated, resin injected wood.
