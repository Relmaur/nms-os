# Electric Cube

## Quick Facts

- **Category:** Base Building
- **Type:** Stabilised Reality Glitch
- **Used for:** Building
- **Value:** 1,000.0
- **Added in:** Visions

**Electric Cube** is a base building product.

## Summary

**Electric Cube** is a [[base building]] [[product]] and it can be acquired from [[Wire Cell]] type [[Biome - Exotic|exotic]] planets.

Picking it up gives 1 piece of the product, but it does not unlock its [[blueprint]].

It can be found in the Build Menu under the Decoration/Glitches.

## Game description

A rare [[Stabilised Reality Glitch|stabilised glitch]], retrieved from a malfunctioning planet. Safe for rehousing in habitable bases.

## Additional information

Electric Cube has a blueprint ([[Pure Ferrite]] x10), but it is not possible to unlock it through normal gameplay.

However, if the player has one specimen in their inventory, they can build as many in a row as their supply of Pure Ferrite allows.
