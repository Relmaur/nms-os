# Large Window

## Quick Facts

- **Category:** Base Building
- **Type:** Construction item
- **Added in:** Waypoint

**Large Window** is a base building product.

## Summary

**Large Window** is a [[base building]] [[product]] and can be found in the Structures/Windows building category.

The blueprint is acquired from the [[Blueprint Analyser]].

## Game description

A window made from self-cleaning, UV-treated, hermetically sealed glass.

## Build

- **Crafting** · needs the blueprint: 10 × [[Ionised Cobalt]] + 1 × [[Glass]] → 1 × Large Window

- **Dismantle** returns: 10 × [[Ionised Cobalt]] + 1 × [[Glass]]
