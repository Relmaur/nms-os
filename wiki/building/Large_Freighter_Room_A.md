# Large Freighter Room A

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Interior Module
- **Added in:** Waypoint

**Large Freighter Room A** is a base building component.

## Summary

**Large Freighter Room A** is a [[Base building]] structure designed to hollow out large portions of the interior of a [[Freighter]]. This freighter component is only buildable within the designated build area.

## Game description

This expansion module allows for the rapid construction of habitable spaces inside large starships.

Construction unit is fabricated complete with pressure bulkhead and all necessary attachment points.

## Sources

- **Crafting** · needs the blueprint: 120 × [[Silver]] + 20 × [[Tritium]] → 1 × Large Freighter Room A

## Additional Information

This item serves the same purpose as a [[Cuboid Room]] does for a planetary base.

There are three freighter room variants:
