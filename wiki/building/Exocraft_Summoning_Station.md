# Exocraft Summoning Station

## Quick Facts

- **Category:** Base Building
- **Type:** Vehicle Translocation Device
- **Added in:** SentinelUp

**Exocraft Summoning Station** is a base building product.

## Summary

**Exocraft Summoning Station** is a [[base building]] [[product]] that is used to summon [[Exocraft]].

Once the station is built, the player can summon an exocraft on any planet in that system as long as the player has built the geobay for that exocraft somewhere else in the system.

## Game description

Construction allows the user to summon any owned Exocraft from anywhere else in that system.

Interfaces with the Exosuit Quick Command Menu to ease of use. Can be compressed and carried within the Exosuit with // (PC/PS/XB) for later redeployment.

## Crafting

- **Crafting** · needs the blueprint: 100 × [[Uranium]] + 100 × [[Tritium]] + 4 × [[Unstable Plasma]] → 1 × Exocraft Summoning Station

- **Dismantle** returns: 100 × [[Uranium]] + 100 × [[Tritium]] + 4 × [[Unstable Plasma]]

## Additional information

- The blueprint can be acquired from the [[Construction Research Station]] for 12 [[Salvaged Data]].
