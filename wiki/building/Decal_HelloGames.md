# Decal (HelloGames)

## Quick Facts

- **Category:** Base Building
- **Type:** Component
- **Added in:** Prisms

**Decal (HelloGames)** is a base-building component.

## Summary

**Decals** are items used in base building. There are a variety of patterns, all with the same blueprint formula.

This decal is the Hello Games logo.

## Game description

Placeable decorative decals.

## Sources

- **Crafting** · needs the blueprint: 20 × [[Carbon]] → 1 × Decal (HelloGames)

## Additional Information

While the Hello Games decal can be purchased, it doesn't appear in the base building menu. As a result, the decal can't actually be used.

- [[Pathfinder]] - added as a base-building component.
