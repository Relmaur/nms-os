# Cuboid Room Foundation Strut Quad

## Quick Facts

- **Category:** Base Building
- **Type:** Cuboid Rooms
- **Base complexity:** 5
- **Added in:** NEXT

**Cuboid Room Foundation Strut Quad** is a base-building component.

## Summary

**Cuboid Room Foundation Strut Quad** is an item used in the construction of [[Cuboid Room|Cuboid Rooms]].

When Cuboid Rooms are built, struts can be used to provide better support for their construction and flooring. Single [[Cuboid Room Foundation Strut|struts]] can be used, or this pre-built set of four can be used instead.

## Game description

A prefabricated set of four legs for supporting cuboid rooms.
