# Anomalous Timepiece

## Quick Facts

- **Category:** Base Building
- **Type:** Space Station Decoration
- **Added in:** Cosmos

**Anomalous Timepiece** is a base building component.

## Summary

**Anomalous Timepiece** is a rare [[Space Station]] [[Base building]] decoration.

## Game Description

A rare orbital construction adornment, recovered from deep space.

## Sources

The blueprint is acquired from an [[Anomalous Numbers Station]] interaction upon accepting the signal.

The item is for decoration only and serves no function in the actual game.

- **Crafting** · needs the blueprint: 3 × [[Industrial Salvage]] + 3 × [[Fuel Rod]] + 80 × [[Contaminated Metal]] → 1 × Anomalous Timepiece
