# Reinforced Hull Link

## Quick Facts

- **Category:** Corvette Building

**Reinforced Hull Link** is a corvette building component.

## Summary

**Reinforced Hull Link** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A heavy-duty structural support for a Corvette-class starship, designed for connecting larger modules.

Assemble a corvette at the dedicated Corvette Workshop aboard any Space Station.
