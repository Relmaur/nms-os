# Cuboid Room Frame

## Quick Facts

- **Category:** Base Building
- **Type:** Construction module
- **Added in:** Origins

**Cuboid Room Frame** is a base building component.

## Summary

**Cuboid Room Frame** is a [[Base building]] structure used to support custom-made chambers.

The small room component's preview auto-snaps to many horizontal and vertical anchors.

## Game description

Lightweight cuboid support structures which can be stacked or linked to form large industrial structures.
