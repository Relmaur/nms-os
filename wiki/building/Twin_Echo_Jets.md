# Twin Echo Jets

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Twin Echo Jets** is a corvette building component.

## Summary

**Twin Echo Jets** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A main engine for a Corvette-class starship, delivering propulsion during atmospheric and deep-space flight.

This module is automatically linked to the corvette's main engines, providing a significant performance boost.

## Upgrade properties

The Twin Echo Jets function similarly to a B-class Pulse Engine upgrade, granting the following bonuses:
- *Pulse Drive Fuel Efficiency*: decreases the rate of Pulse Drive fuel consumption during Pulse Jumps.
- *Maneuverability:* increases the Starship's turn rate.
- *Boost:* increases maximum speed while boosting.
