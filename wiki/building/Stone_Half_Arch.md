# Stone Half Arch

## Quick Facts

- **Category:** Base Building
- **Type:** Stone Construction Component
- **Added in:** Frontiers

**Stone Half Arch** is a base building component.

## Summary

**Stone Half Arch** is a [[Base building]] structure used to erect basic structures.

The basic component's preview auto-snaps to the edges of other basic components.

## Game description

Reinforced Stone building module, widespread in basic structures across the galaxy.

Conforms to Universal Building Standards 2.3b, ensuring maximum compatibilty with other prefab structurs. Rapid Grid snapping allows for quick assembly of custom shelter layouts
