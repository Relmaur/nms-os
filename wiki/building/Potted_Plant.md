# Potted Plant

## Quick Facts

- **Category:** Base Building
- **Type:** Decoration
- **Added in:** Outlaws

**Potted Plant** is a base building component.

## Summary

**Potted Plant** is a [[Base building]] product used for decoration.

The farming object is designed for attachment to walls, but it can be placed on any free surface, including floors and ceilings.

## Game description

A decorative pot for indoor plants.
