# Short-Range Teleporter

## Quick Facts

- **Category:** Base Building
- **Type:** Short-Distance Matter Transfer Device
- **Value:** 1
- **Added in:** Endurance

**Short-Range Teleporter** is a base building product.

## Summary

**Short-Range Teleporter** is a [[base building]] [[product]] that provide short distance rapid movement across a large base in any direction.  It is especially useful when a single base is divided into several different locations in the same area but are not easily accessible to each other on foot or via [[exocraft]] or [[starship]].

Short-range teleporters need to be deployed in pairs in a base to be functional.

## Game description

A low-powered teleporter, construction for instantaneous travel across short distances.

When wired to both a power source and another short-range teleporter, allows near-instant travel between nearby locations.

## Source

The [[blueprint]] can be obtained from the [[Construction Research Station]] aboard the [[Space Anomaly]], costing 10 [[Salvaged Data]] to unlock.

## Build

- **Crafting** · needs the blueprint: 2 × [[Metal Plating]] + 40 × [[Chromatic Metal]] + 30 × [[Gold]] → 1 × Short-Range Teleporter

## Connection

A short-range teleporter can only be connected to one other matching unit, thus they are deployed in pairs.

Both units in a pair need to be connected to each other using a [[Teleport Cable]], which cannot be longer than approximately 200u, the maximum observed distances between teleport pairs, although this can be in any direction, horizontal or vertical (even through underground layers or NPC/player-constructed buildings).

The two units must be connected directly to one another with a single Teleport Cable in order to function, no other arrangement will work. Although teleport cables can have one of their ends placed on the ground by enabling Free Placement, and thus chained together like [[Electrical Wiring]], teleport cables placed in this manner will not function.

## Additional information

- The [[Desolation]] update broke the power requirement where any entrance unit in the pair had to be powered (at 5kPs each) using Electrical Wiring, however if only one-directional travel was desired - the exit unit did not need to be powered. Due to this bug, no power is required at all for teleportation to work, although the 'no power' icon would show when hooked up.
- [[Proximity Switch]] was a useful addition to conserve power while there were no players nearby. Other logic was useful as well, but can no longer be used to control the power flow.
