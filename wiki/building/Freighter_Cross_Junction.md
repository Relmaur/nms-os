# Freighter Cross Junction

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Interior Module
- **Added in:** NextGen

**Freighter Cross Junction** is a base building component.

## Summary

**Freighter Cross Junction** is a [[Base building]] structure designed to connect rooms together within a [[Freighter]]. This freighter component is only buildable within the designated build area.

## Game description

This expansion module allows for the rapid construction of habitable spaces inside large starships.

Construction unit is fabricated complete with pressure bulkhead and all necessary attachment points.

## Sources

- **Crafting** · needs the blueprint: 80 × [[Silver]] + 10 × [[Tritium]] → 1 × Freighter Cross Junction

## Additional Information

- This item serves the same purpose as an [[X-Shaped Corridor]] does for a planetary base.
- The Cross Junction can not be installed on the 1st level Freighter deck.
