# L-Shaped Corridor

## Quick Facts

- **Category:** Base Building
- **Type:** Structure
- **Base complexity:** 10
- **Added in:** NEXT

**L-Shaped Corridor** is a base building component.

## Summary

**L-Shaped Corridors** are a [[Base building]] structure designed to connect structures. As its name suggests it connects base pieces on a 90 degree angle.

They are primarily used as corner pieces in longer corridors. They can have windows built on the outsides or top.

## Game description

A sturdy, corridor module for connecting rooms, with an L-shaped bend.
