# Small Crate

## Quick Facts

- **Category:** Base Building
- **Type:** Decoration
- **Added in:** Visions

**Small Crate** is a base building product.

## Summary

**Small Crate** is a [[base building]] [[product]] which is only useful for aesthetics. Despite being in the Storage category in the Build Menu, it is incapable of holding items.

The object can be placed on any free horizontal surface.

## Game description

Buildable ornament to beautify your base.

## Source

The blueprint can be acquired from the [[Blueprint Analyser]].
