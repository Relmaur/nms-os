# Access Ramp

## Quick Facts

- **Category:** Base Building
- **Type:** Construction item
- **Added in:** Visions

**Access Ramp** is a base building component.

## Summary

**Access Ramp** is a [[Base building]] structure used to facilitate entry into a building from the outside.

The ramp's preview auto-snaps to existing ramps and to the bottom edges of [[Door|Doors]], [[Holo-Door|Holo-Doors]] and [[Watertight Door|Watertight Doors]].

## Game description

A reinforced, non-ferrous ramp to provide access to buildings.

- **Crafting** · needs the blueprint: 50 × [[Pure Ferrite]] + 50 × [[Carbon]] → 1 × Access Ramp
