# Autonomous Mining Unit

## Quick Facts

- **Category:** Base Building
- **Type:** Portable mining device
- **Value:** 1.0
- **Added in:** Echoes

**Autonomous Mining Unit** is a base building product.

## Summary

**Autonomous Mining Unit** is a [[base building]] [[product]] used to increase the efficiency of mining [[resource|resources]]. It can extract the planet's [[Resource Deposit|Resource Deposits]] without the need for constant supervision and without depleting them.

## Game description

An automated harvester for the mining of resources. Once activated, the AMU extracts minerals without the need for supervision, providing a regular yield until the site is exhausted.

## Build

- **Crafting**: 100 × [[Uranium]] + 2 × [[Metal Plating]] + 1 × [[Ion Battery]] → 1 × Autonomous Mining Unit

Autonomous Mining Unit returns resources when [[dismantle|dismantled]], but only if the player has enough inventory space.

## Fuel sources

The Autonomous Mining Unit has a [[Fuel Inverter]], which requires 100 [[Carbon]] or 34 [[Condensed Carbon]] to be fully charged.

## Additional Information

- Once installed, a red light will flash on the top of the device while it is working. It will slowly grow in size as the resource is harvested. Once full, the light will turn green.
- When installing an AMU, be sure to place a [[Save Beacon]] nearby, or it will be hard to locate later.
- A fully charged device will harvest a maximum of 250 units over a time period of roughly 60 minutes.
- The device can not be picked up but it can be deleted for a full refund like any other base item when in construction range of a base.
- Workarounds for the bug that causes the AMU to collect the wrong resource:
  - Delete and rebuild it. This is free and always possible, otherwise only if it is built within the boundary of a base you own, but not possible otherwise. Note: Any content and fuel left in the device when deleted is lost if not collected before.
  - Move and re-place the AMU on the resource deposit. This will also delete all content and fuel left in the AMU.
  - When collecting the resource from the AMU leave behind 10 of whatever the item is and it should not change what it collects. You can do this by rolling the mouse wheel down one click after picking up the resource.
- Only 5 AMUs can be placed in any local area.

## Bugs

- Similar to refiners and harvesters (i.e. [[Oxygen Harvester]], [[Atmosphere Harvester]], [[Portable Refiner]], [[Medium Refiner]], and [[Large Refiner]]), the energy and output of Autonomous mining units will randomly vanish if left alone for long enough, reloading a game or leaving too far away. The [[Bugs|bug]] is long-standing since the introduction of the AMU and continues to exist as of [[Waypoint]] era. For more reliable resource collection, utilize a network of [[Mineral Extractor|Mineral Extractors]] and [[Supply Depot|Supply Depots]].

It would appear as if an intermittent internet connection is a cause for a lot of problems experienced with this thing. Simply leaving the zone also exhibits issues, as do many other devices for the aforementioned reasons.
