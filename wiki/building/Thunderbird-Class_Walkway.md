# Thunderbird-Class Walkway

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Thunderbird-Class Walkway** is a corvette building component.

## Summary

**Thunderbird-Class Walkway** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A compact-sized living area for a Corvette-class starship, providing space for passengers as well as installable utility modules.

This module is automatically linked to the corvette's cargo systems, providing a moderate performance boost.

## Upgrade properties

The Thunderbird-Class Walkway functions as a C-class upgrade, granting the following bonus:
- *Cargo Slots:* +1
