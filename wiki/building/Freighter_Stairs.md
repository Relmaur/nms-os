# Freighter Stairs

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Interior Module
- **Added in:** Endurance

**Freighter Stairs** is a base building component.

## Summary

**Freighter Stairs** is a [[Base building]] structure designed to connect rooms at different elevations together within a [[Freighter]]. This freighter component is only buildable within the designated build area.

## Game description

This expansion module allows for the rapid construction of habitable spaces inside large starships.

Construction unit is fabricated complete with pressure bulkhead and all necessary attachment points.

## Sources

- **Crafting** · needs the blueprint: 50 × [[Silver]] → 1 × Freighter Stairs

## Additional Information

- This item has no true large-structure equivalent; however, its function is similar to that of [[Interior Stairs]].
