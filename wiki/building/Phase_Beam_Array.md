# Phase Beam Array

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Phase Beam Array** is a corvette building component.

## Summary

**Phase Beam Array** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A dedicated weapon platform for a Corvette-class starship.

This module is automatically linked to the corvette's laser defense array, providing a powerful performance boost.

## Upgrade properties

The Phase Beam Array functions similarly to an A-class Phase Beam upgrade, granting the following bonuses:
- *Heat Dispersion*: allows to fire the weapon continuously for longer before it overheats.
- *Damage:* increases the damage of each shot.
