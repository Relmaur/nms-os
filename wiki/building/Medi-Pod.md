# Medi-Pod

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Interior Furnishing
- **Added in:** Voyagers

**Medi-Pod** is a corvette building product.

## Summary

**Medi-Pod** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

This installable module provides a range of medical services, including automatic wound suturing, infection control, and AI-driven viral containment features. Note: pod must be wired to airlocks for full functionality to be enabled.

This module is installed along the entire wall of a Corvette Hab.

## Build

- **Crafting**: 50 × [[Gold]] + 3 × [[Hermetic Seal]] + 1 × [[Amino Chamber]] → 1 × Medi-Pod
