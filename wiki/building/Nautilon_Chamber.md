# Nautilon Chamber

## Quick Facts

- **Category:** Base Building
- **Type:** Submarine Docking Bay
- **Added in:** Origins

**Nautilon Chamber** is a base building product.

## Summary

**Nautilon Chamber** is a [[base building]] [[product]] and can be found in the Equipment/Exocraft Modules building category.

## Game description

An advanced, fully-airlocked docking station for the [[Nautilon]] submarine.

## Source

The blueprint can be acquired from the [[Dreams of the Deep]] secondary mission or can be bought for 10 [[Salvaged Data]] from the [[Blueprint Analyser]].

If the second method is used, the player can choose an appropriate slot to install the [[Humboldt Drive]].

## Build

- **Crafting** · needs the blueprint: 5 × [[Metal Plating]] + 4 × [[Crystal Sulphide]] + 100 × [[Salt]] → 1 × Nautilon Chamber

- **Dismantle** returns: 5 × [[Metal Plating]] + 4 × [[Crystal Sulphide]] + 100 × [[Salt]]
