# Cuboid Room Flooring

## Quick Facts

- **Category:** Base Building
- **Type:** Construction item
- **Added in:** Abyss

**Cuboid Room Flooring**is a base building product.

## Summary

**Cuboid Room Flooring** is a [[base building]] [[product]] and can be found in the Decoration/Interior Decoration building category.

It can be used as in interface between the two layers, when [[Cuboid Room|Cuboid Rooms]] are stacked on each other. A [[Ladder]] can be installed from one level to the next.

## Game description

Hard-wearing composite floor panels cut for cuboid rooms.
