# Refiner Room

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Construction Module
- **Added in:** Endurance

**Refiner Room** is a base building product.

## Summary

**Refiner Room** is a [[Freighter Base Building]] module replacing [[Large Refiner]].

## Game description

Vital integrated freighter equipment. The Freighter Refiner allows three different substances to be processed into more powerful and more advanced materials.

This module is placed as an entire room and comes with its functional units pre-installed.

## Additional Information

- [[Bugs|There is an ongoing bug where you may lose the items placed in these items and this includes other refiner machines.]]
