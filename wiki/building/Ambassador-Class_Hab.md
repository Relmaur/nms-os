# Ambassador-Class Hab

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Ambassador-Class Hab** is a corvette building component.

## Summary

**Ambassador-Class Hab** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

The main living area for a Corvette-class starship, providing space for passengers as well as installable utility modules.

This module is automatically linked to the corvette's cargo systems, providing a significant performance boost.

## Upgrade properties

The Ambassador-Class Hab functions as a B-class upgrade, granting the following bonus:
- *Cargo Slots:* +3
