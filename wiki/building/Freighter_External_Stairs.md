# Freighter External Stairs

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Construction Module
- **Added in:** Endurance

**Freighter External Stairs** is a base building product.

## Summary

**Freighter External Stairs** is a [[base building]] [[product]] specifically designed for [[freighter|freighters]].

## Game description

A sturdy, non-slip staircase with an ergonomic incline, for traversing vertically between freighter decks.

These robust stairs can be affixed outside the freighter hull, creating connections between exterior catwalks and platforms.
