# Zenith-Class Reactor

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Zenith-Class Reactor** is a corvette building component.

## Summary

**Zenith-Class Reactor** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A powerful reactor core for a corvette-class starship, designed to power and enhance critical systems.

This module is automatically linked to the corvette's warp core, providing a powerful performance boost.

## Upgrade properties

The Zenith-Class Reactor functions similarly to an A-class Hyperdrive upgrade, granting the following bonuses:
- *Hyperdrive Range:* Increases the maximum distance of a hyperjump by a fixed amount.
- [[Warp Cell|Warp Cell Efficiency]]: Increases the fuel range of the ship by 100% each.
