# Corner Table

## Quick Facts

- **Category:** Base Building
- **Type:** Furniture

**Corner Table** is a base building product.

## Summary

**Corner Table** is a [[base building]] [[product]].

The item is for decoration only and serves no function in the actual game.

An all-purpose work surface built from non-magnetic, corrosion resistant materials.
