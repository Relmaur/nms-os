# Orbital Exocraft Materialiser

## Quick Facts

- **Category:** Base Building
- **Type:** Rapid Deployment Freighter Module
- **Added in:** Echoes

**Orbital Exocraft Materialiser** is a base building module.

## Summary

**Orbital Exocraft Materialiser** is a [[Freighter Base Building]] module that is used to summon [[Exocraft]].

## Game Description

Advanced integrated freighter equipment. Construction allows the user to summon any owned Exocraft while in the same system as their freighter. This module is placed as an entire room and comes with its functional units pre-installed.

Interfaces with the Exosuit Quick Command Menu for ease of use.

## Crafting

- **Crafting** · needs the blueprint: 60 × [[Gold]] + 50 × [[Ionised Cobalt]] + 3 × [[Warp Cell]] → 1 × Orbital Exocraft Materialiser

- **Dismantle** returns: 150 × [[Gold]] + 50 × [[Ionised Cobalt]] + 3 × [[Warp Cell]]

## Additional Information

- The blueprint can be acquired from the [[Construction Research Station]] in the [[Space Anomaly]] for 1 [[Salvaged Data]].
- It can only be built on a freighter.
- Orbital Exocraft Materialiser built prior to the Endurance update has to be replaced with a new one which needs to be researched.
