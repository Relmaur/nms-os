# Locked Crate

## Quick Facts

- **Category:** Base Building
- **Type:** Fabricator
- **Added in:** ExoMech

**Locked Crate** is a base building product.

## Summary

**Locked Crate** is a [[base building]] [[product]] which is only useful for aesthetics. Despite being in the Storage category in the Build Menu, it is incapable of holding items.

The object can be placed on any free horizontal surface.

## Game description

Regularly fabricates useful items for its constructor.

## Source

The blueprint can be acquired from the [[Blueprint Analyser]].

## Build

- **Crafting** · needs the blueprint: 10 × [[Pure Ferrite]] → 1 × Locked Crate

## Additional information

- While the game description claims to fabricate items, it currently does not.
