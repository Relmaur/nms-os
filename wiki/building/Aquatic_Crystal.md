# Aquatic Crystal

## Quick Facts

- **Category:** Base Building
- **Type:** Organic decoration
- **Value:** 500
- **Added in:** NextGen

**Aquatic Crystal** is a base-building component.

## Summary

**Aquatic Crystal** is an item used in base building. It is a tall flowering light-producing plant.

## Game description

An eye-catching cluster of crystallised oceanic minerals. These crystals grow in a shard-like structure, and feature an unusual marbled colouration.
