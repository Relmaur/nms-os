# Industrial Cargo Link

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module

**Industrial Cargo Link** is a corvette building component.

## Summary

**Industrial Cargo Link** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A heavy-duty structural support for a Corvette-class starship, designed for connecting larger modules.

Assemble a corvette at the dedicated Corvette Workshop aboard any Space Station.
