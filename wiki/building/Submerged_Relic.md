# Submerged Relic

## Quick Facts

- **Category:** Container
- **Added in:** SentinelUp

**Submerged Relic** is a container.

## Summary

**Submerged Relic** is a container that can be found underwater on the ocean floor. It rewards the player with 1 [[Hadal Core]] and an oxygen tank refill when opened.

## Additional information

- It uses the same skin as [[AquaSphere]], which was removed with the [[NEXT]] update.

## Release history

- [[Abyss]] - Added as a container.
- [[Origins]] - Reward changed to Hadal Core, was [[Chloride Lattice]].
