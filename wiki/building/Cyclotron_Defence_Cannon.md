# Cyclotron Defence Cannon

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module

**Cyclotron Defence Cannon** is a corvette building component.

## Summary

**Cyclotron Defence Cannon** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

A dedicated weapon platform for a Corvette-class starship.

This module is automatically linked to the corvette's Cyclotron Defence array, providing a powerful performance boost.
