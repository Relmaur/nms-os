# Qitanian Empire Decal

## Quick Facts

- **Category:** Base Building
- **Type:** Component
- **Added in:** Prisms

**Qitanian Empire Decal** is a base-building component.

## Summary

**Decals** are decoration items used in base building. There are a variety of patterns, all with the same blueprint formula.

## Game description

An exclusive placeable decal, to add flair and decoration to bases.

This decal represents the Qitanian Empire, and the spirit of charity, kindness, peace and reason.

## Sources

- **Crafting** · needs the blueprint: 20 × [[Carbon]] → 1 × Qitanian Empire Decal
