# Cargo Pod

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Cargo Pod** is a corvette building component.

## Summary

**Cargo Pod** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

An exterior attachment for a Corvette-class starship.

Assemble a corvette at the dedicated Corvette Workshop aboard any Space Station.

This module is automatically linked to the corvette's cargo systems, providing a moderate performance boost.

## Upgrade properties

The Cargo Pod functions as a C-class upgrade, granting the following bonus:
- *Cargo Slots:* +1
