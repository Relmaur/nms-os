# Freighter Glass Stairs

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Construction Module
- **Added in:** Endurance

**Freighter Glass Stairs** is a base building product.

## Summary

**Freighter Glass Stairs** is a [[base building]] [[product]] specifically designed for [[freighter|freighters]].

## Game description

A sturdy, non-slip staircase with an ergonomic incline, for traversing vertically between freighter decks.

Constructed from low thermal expansion glass, these stairs provide the user with a thrilling view into deep space.
