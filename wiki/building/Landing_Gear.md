# Landing Gear

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Landing Gear** is a corvette building component.

## Summary

**Landing Gear** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

An advanced landing system for a Corvette-class starship, compatible with both standard interstellar docks and planetary descents alike.

This module is automatically linked to the corvette's launch systems, providing a significant performance boost.

## Upgrade properties

Landing Gear functions similarly to a B-class Launch Thruster upgrade, granting the following bonuses:
- *Launch Cost*
- *Boost:* increases maximum speed while boosting.

|   | Module Name | Module Improves | B-class |   |
| --- | --- | --- | --- | --- |
| Min | Max |   |   |   |
|   | [[Landing Gear]] | *Launch Cost* | -10 | -15 |
| *Boost* | 2 | 5 |   |   |
