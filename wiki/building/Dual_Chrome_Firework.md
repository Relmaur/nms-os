# Dual Chrome Firework

## Quick Facts

- **Category:** Base Building
- **Type:** Exotic Collectibles
- **Added in:** Prisms

**Dual Chrome Firework** is a base building product.

## Summary

**Dual Chrome Firework** is a [[base building]] [[product]] and can be found in the Exotic Collectibles category.

## Game description

A luxury firework, exploding into sparkling wedges of [[indium]] and [[cadmium]]. Ignite to create glitter displays in the sky.

Place launch tube via the Build Menu (z). Warning: Aim away from living creatures. Not recommended for indoor use.

## Build

Once unlocked, the product can be purchased from the [[Quicksilver Synthesis Companion]] in the [[Space Anomaly]] for 50  Quicksilver. The maximum number available for purchase is 1000.
