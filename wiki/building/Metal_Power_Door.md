# Metal Power Door

## Quick Facts

- **Category:** Base Building
- **Type:** Metal Construction Component
- **Added in:** Frontiers

**Metal Power Door** is a base building component.

## Summary

**Metal Power Door** is a [[Base building]] structure used to erect simple shelters.

The basic component's preview auto-snaps to the edges of other basic components.

## Game description

A power-operated door. Can be connected to a power grid and operated using various switches.

Fashioned from high-strength metal alloys.
