# Cuboid Inner Door

## Quick Facts

- **Category:** Base Building
- **Type:** Construction module

**Cuboid Inner Door** is a base building component.

## Summary

**Cuboid Inner Door** is a [[Base building]] structure used to partition sections of custom-made chambers.

The small room component's preview auto-snaps to interior edges of spaces created using [[Cuboid Room|Cuboid Rooms]].
