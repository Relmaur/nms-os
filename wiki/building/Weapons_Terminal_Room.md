# Weapons Terminal Room

## Quick Facts

- **Category:** Base Building
- **Type:** Freighter Construction Module
- **Added in:** Endurance

**Weapons Terminal Room** is a base building product.

## Summary

**Weapons Terminal Room** is a [[Freighter Base Building]] module accomodating [[Armourer]] terminal.

## Game description

Integrated freighter research equipment tailored to the needs of armourer, and equipped for the development of munitions and explosives as well as selected civilian tech.

This module is placed as an entire room and comes with its functional units pre-installed.
