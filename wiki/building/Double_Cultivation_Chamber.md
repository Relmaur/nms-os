# Double Cultivation Chamber

## Quick Facts

- **Category:** Base Building
- **Type:** Agriculture
- **Added in:** Endurance

**Double Cultivation Chamber** is a base building product.

## Summary

**Double Cultivation Chamber** is a [[Freighter Base Building]] module allowing growing of [[Farming|agricultural crops]].

## Game description

A temperature controlled bio-room. Two beds of nutrient-rich soil provides ideal conditions for cultivating agricultural crops.

This module is placed as an entire room and comes with its functional units pre-installed.
