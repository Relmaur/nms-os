# Mag-Field Landing Thrusters

## Quick Facts

- **Category:** Corvette Building
- **Type:** Corvette Construction Module
- **Added in:** Voyagers

**Mag-Field Landing Thrusters** is a corvette building component.

## Summary

**Mag-Field Landing Thrusters** is a building component specifically designed for [[Corvette|Corvettes]].

## Game description

An advanced landing system for a Corvette-class starship, compatible with both standard interstellar docks and planetary descents alike.

This module is automatically linked to the corvette's launch systems, providing a significant performance boost.

## Upgrade properties

Mag-Field Landing Thrusters function similarly to a B-class Launch Thruster upgrade, granting the following bonuses:
- *Launch Cost*- *Boost:* increases maximum speed while boosting.
