# Message in a Bottle

## Quick Facts

- **Category:** Fish
- **Type:** Collected Flotsam
- **Value:** 1,000.0
- **Added in:** Aquarius

**Message in a Bottle** is a type of fish.

## Summary

**Message in a Bottle** is a [[fish]], that can be caught as an item by the player. It is one of the [[Collected Flotsam]] items that can be caught when [[fishing]].

## Game Description

A sealed bottle, found floating in the water. There appears to be a message inside.

Use  to unseal the bottle and read the message within.

## Use

- Can be sold.
- Can be unsealed, giving the player a [[Recovered Message]].

## Source

Obtained via [[fishing]].

## Additional Information

It is not clear if the messages have any practical meaning outside of the [[Expedition 15: Aquarius|Aquarius Expedition]].
