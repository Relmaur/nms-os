# Custom wiki articles

Hand-written articles go in `wiki/custom/<category>/<Slug>.md`, where `<category>` is one of
`resources`, `products`, `cooking`, `technology` or `guides`. This folder is committed; everything
else under `wiki/` is generated by `npm run sync:wiki` and git-ignored.

After adding or editing a file, run `npm run index:wiki` to pick it up in the Codex.
