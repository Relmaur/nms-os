# 'Organic' Rock

## Quick Facts

- **Category:** Resource Node
- **Type:** Resource Node
- **Added in:** Origins
- **Description:** Resource collection point

The **'Organic' Rock** is a point of interest resource node.

## Summary

The **'Organic' Rock** minerals are a type of rare [[resource]] node found in [[Biome - Scorched|scorched and desert]] biomes. Some have to be mined with the [[Mining Beam]] and some can be picked. They will yield one of the following resources when harvested:

- [[Chlorine]] is found on scorched worlds.
- [[Mordite]] is found on desert worlds.

They can be revealed with [[Analysis Visor]] and will be indicated with  icon.
