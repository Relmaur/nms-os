# Ancient Data Structure

## Quick Facts

- **Category:** Resource Node
- **Added in:** Singularity

**Ancient Data Structure** is a type of resource node.

## Summary

**Ancient Data Structure** is a type of [[resource]] node and can be harvested by hand. All planets of a system share the same node type.

It can be revealed with [[Analysis Visor]] and will be indicated with  icon. It contains one of the following:
- [[Navigation Data]]
- [[Drop Pod Coordinate Data]]

## Additional information

- The largest discovered data cluster had 35 pedestals. It was found on the planet **35** in the **Shisteeni** system.
- [[Vortex Cube]] used the same kind of pedestal prior to the NEXT update.
