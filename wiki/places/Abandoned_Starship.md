# Abandoned Starship

## Quick Facts

- **System types:** Any
- **Interaction:** Use communicator
- **Rewards:** None
- **Added in:** Echoes

**Abandoned Starship** is a space encounter.

## Summary

**Abandoned Starship** is a [[Space Encounter|space encounter]].

## Appearance

The Abandoned Starship appears as a solar [[starship]] floating in space.

## Behaviour

Upon approach, the Abandoned Starship will attempt to communicate with the player. If the communicator is opened, the player will be given a quest with a broken message related to the "Voice of Freedom".

Firing on an Abandoned Starship won't deal any damage on them, nor will they become aggressive.

It will only appear once. If you want to encounter it again, you need to search for an old save which you not encountered it yet, or create a new save.

## Location

They can be randomly found in any [[star system]] and always appear when the conditions for the quest are matched.
