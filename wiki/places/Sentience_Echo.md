# Sentience Echo

## Quick Facts

- **Category:** Resource Node
- **Type:** Resource Node
- **Added in:** Aquarius

**Sentience Echo** is a type of resource node.

## Summary

**Sentience Echo** is a type of resource node that can be mined. They are located on [[Dissonant Planet]], and have an appearance of a purple crystal, larger than [[Atlantideum]] crystals and [[Radiant Shard]] crystals. They can be found using the [[Analysis Visor]] while having a [[Scan Harmoniser]], a [[Polyphonic Core]], or a [[Resonance Amplifier]] installed. They are marked with two triple crystal in a purple background, with an exclamation mark on top.

Once the echo has reached, nothing will be there; with the above technology, a scan sweep can be used to decloak a crystal. The crystal cannot be mined normally and requires installation of the [[Advanced Mining Laser]] for the crystal to be mined.

They will always award an [[Echo Seed]] when mined.
