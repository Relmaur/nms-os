# Floating Crystal

## Quick Facts

- **Category:** Resource Node
- **Description:** Floating Crystals are nodes of base resources in a supercondensed form.
- **Added in:** Origins

**Floating Crystals** are a type of resource node.

## Summary

**Floating Crystals** are a type of rare [[resource]] node and mined with the [[Advanced Mining Laser|advanced beam]]. All planets of a system share the same node type.

They can be revealed with [[Analysis Visor]] and will be indicated with  icon.

Each Floating crystal contains one [[Glowing Mineral]].

## Use

Resources found in Glowing Minerals are used in high-end [[Crafting]].

The biggest discovered cluster so far has been 25 crystals.
