# Curious Deposit

## Quick Facts

- **Category:** Resource Node
- **Added in:** Expeditions

**Curious Deposits** are a type of resource node.

## Summary

**Curious Deposits** are a type of rare [[resource]] node and mined with the [[Mining Beam]]. They sometimes roll when struck with the mining beam. All planets of a system share the same node type; though some planets can have an additional element, including nodes, randomly added from any other planet or system type, rarely resulting in two node types on a planet.

They can be revealed with an [[Analysis Visor]] and will be indicated with the  icon.

Each Curious Deposit contains certain amount of [[Runaway Mould]].

## Use

Processing the Runaway Mould in a refiner generates [[Nanite Cluster|Nanite Clusters]].
