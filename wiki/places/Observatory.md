# Observatory

## Quick Facts

- **Category:** Shelter
- **Type:** Puzzle location
- **Added in:** Singularity

**Observatory** is a Point of Interest.

## Summary

**Observatory** is a [[shelter]] type [[Point of Interest]] in [[No Man's Sky]].

These can be found by using a [[Planetary Chart (inhabited outpost)]] (they can be bought from the cartographer on space stations) or by following Unknown Building markers while using the [[Analysis Visor]].

Observatories have short satellite dishes on top of their structures. Inside, the player will encounter a console that requests the next entry in a numerical sequence. If the player inputs a correct entry, the console will mark a nearby [[Ruin]].

The side rooms require an [[AtlasPass v2]] to enter and contain lots of plants (carbon) or several [[Cargo Drop|Cargo Drops]].

## Example Puzzle

**1092 - 0921 - 9210 - ?**

In this [[Access codes|puzzle]], the order of the digits is shifted to the left by one with each successive element, with the leftmost digit being moved to the far right position. Therefore, the correct input will be 2109.

## Additional Information

- More often than not, observatories are empty of any NPC, but occasionally, one can find a [[Traveller]] or a NPC of the system dominant civilization nearby. The Traveller will act like the travellers that can be encountered in space stations, and others NPC types found into the observatory will act like the ones in [[Minor Settlement|Minor Settlements]].
- A lifeform at an Observatory will occasionally give the player a mission to destroy [[Depot|Depots]]. If the player accepts the mission, they will instantly receive a five-star [[wanted level]].
- If you already have one observatory target marker that you have not yet investigated, then solving the puzzle at a second observatory will not give a second marker, and instead responds "nothing found". However, on success, it still grants one point of reputation with the local faction, and the terminal will remain active. This can be exploited to rapidly grind reputation, by simply reusing the terminal repeatedly.

## Release history

Prior to [[Atlas Rises]], Observatories could be found by using [[Signal Booster]] and scanning for Colonial Outpost.
