# Update 1.08

## Quick Facts

- **Release date:** 4 September 2016
- **Platforms:** PS4
- **Previous:** 1.07
- **Next:** 1.09
- **Added in:** Initial Release

**Update 1.08** is the sixth update to No Man's Sky.

## Summary

**Update 1.08** is the sixth update to [[No Man's Sky]] released as a separate update only on the Playstation 4 on 4 September 2016.

## Official Patch Notes

Patch notes taken from [Release Log](https://www.nomanssky.com/pc-patch-1-08/).

- Fixes for loading save files that have become corrupted.
- Fixes for several rare memory corruption bugs.
- Fixes for several small memory leaks when warping.
- Fix for loading from saves sometimes spawning you inside a building.
- Fix for anisotropic filtering settings not working on some PCs (improved on all).
- Fix for rare crash when warping many times on PS4.
- Fix for a potential rare random GPU crash on PS4.

## PC Release Information

PC users received the v1.08 fixes as part of [[Update 1.09]] on 16 September 2016.

The patch notes for v1.08 and v1.09 were released simultaneously for PC as discussed on [this thread](https://steamcommunity.com/app/275850/discussions/0/350542683188086445/) on the Steam community forum. There is no separate SteamDB entry for v1.08 and GOG users did not receive this as separate update either as detailed on [this thread](https://www.gog.com/forum/no_mans_sky/108) on the GOG community discussion forum.
