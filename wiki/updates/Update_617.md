# Update 6.17

**Update 6.17** is the 267th official update to No Man's Sky.

## Summary

**Update 6.17** is the 267th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on November 18, 2025 on PC.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Holiday Expeditions 2025, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.17, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed a multiplayer bug that could cause erratic physics impulses during starship landing sequence.
- Fixed an issue that prevented non-corvette parts from being retrieved from the corvette parts box.
- Fixed a text issue when salvaging a corvette.
- Fixed an issue that caused corvette modules awarded by expeditions to provide 0 units when sold at the corvette workshop.
- Fixed an issue which showed incorrect filters when buying and selling corvette or relic parts.
- Fixed an issue that would cause doors on the Space Anomaly to not render after flying in.
- Fixed an issue which caused Corvette ships to be placed in the wrong location when teleporting to a base.

- Improved performance when rendering large schools of fish.
- Optimised Vulkan memory usage.
- Fixed a number of rare crashes.
- Fixed a video memory issue.

- Optimised PS4 and PS5 graphics memory usage.
- Fixed an issue that could cause Xbox to hang on the pause menu.
- Fixed an issue which prevented appropriate messaging when inviting or joining a multiplayer session with certain privacy settings.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
Hello Games
