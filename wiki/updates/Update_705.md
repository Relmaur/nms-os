# Update 7.05

## Quick Facts

- **Release date:** 30 September, 2026
- **Platforms:** PC, Mac
- **Added in:** Cosmos
- **Previous:** 7.04
- **Next:** 7.06

**Update 7.05** is the 296th official update to No Man's Sky.

## Summary

**Update 7.05** is the 296th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on September 30, 2026 on PC and Mac.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Cosmos, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 7.05, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed an issue that prevented progress on the Beacon milestone if players manually upgraded a building from its control terminal.
- Fixed an issue that put the "Read Notes" on expedition milestones that had no accompanying notes.
- Fixed an issue that caused expedition artwork to have no collision.
- Improved messaging when redeeming expedition rewards.

- Improved the messaging in the deep-space outpost tutorial mission when the mission board is unavailable.
- Fixed an issue that could prevent access to underwater ruins, blocking players who need a trident key.
- Fixed a rare issue that could cause the mission marker for the Home in the Stars mission to appear in the wrong place.

- Fixed an issue that could cause some settlement buildings to fail to place correctly, blocking progress.
- Reduced waiting times when upgrading settlement buildings for the Beacon milestone.

- Balanced the alliance scoring algorithm to reduce the effectiveness of a small number of members gathering a large number of stations. Additional server-side balancing changes will continue.

- Fixed an issue that could cause the ship hatch to load in an incorrect open/closed state.
- Added an external control button to corvette hatches.
- Fixed an issue that caused a number of decorative corvette pieces to be missing from the shop.
- Fixed an issue that allowed players to become stuck inside geometry while reloading a save aboard a corvette.
- Fixed an issue that prevent powered objects from working on a corvette immediately after construction.
- Fixed an issue that made players leave their seats while trying to land at an outpost while playing VR with some specific controller types.

- Fixed an issue that caused some asteroids to lack collision.
- Fixed a number of collision issues aboard space outposts.

- Fixed an issue that prevented the gravitino coil from being holstered.

- Fixed a number of issues that could prevent derelict freighters from correctly being flagged as completed, especially when trying to complete one for an expedition milestone.
- Fixed an issue that caused heaters on derelict freighters to be always on, regardless of their visual state.
- Fixed an issue that caused all derelict freighters in the same region of the galaxy to share a name.
- Fixed an issue that prevented turrets from targeting the player correctly on derelict freighters.
- Fixed an issue that caused insufficiently random distribution of derelict freighter internal styles.
- Fixed a number of minor mission flow issues related to derelict freighters.
- Fixed an issue that caused drones on derelict freighters to become stuck in the ceiling.

- Fixed an issue that prevented decals from appearing when customising the Nomad exocraft.
- Fixed an issue that prevented decals from appearing when customising the Roamer exocraft.
- Fixed an issue that could caused some planetary junk to fall through the terrain if it fell from the Colossus.
- Fixed an issue that allowed planetary scrap to slip out the back of the Colossus Flatbed.

- Fixed an issue that prevented players from landing on a freighter after a battle.
- Fixed an issue that caused incorrect gravity inside freighters.

- Fixed an issue that caused some snake-like creatures to immediately be reported as extinct after being discovered.
- Fixed an issue that could cause player discoveries to vanish.
- Fixed an issue that could cause recently discovered objects to become undiscovered shortly after.

- Fixed an issue that caused solar panels to work incorrectly in space bases.
- Fixed an issue that prevented players from moving the Deep-Space Base Computer once it was placed.
- Fixed an issue that prevented base parts from being rotated while snapping mode was engaged.

- Fixed an issue that prevented powered objects from working correctly when built in space stations.
- Fixed a number of art issues with external station decoration.
- Added the ability to recolour more pieces of exterior station decoration.
- Added the ability to reset a space station base, freeing up parts for editing other bases.

- Fixed a large number of networking issues with moveable cargo objects.
- Fixed a number of networking exploits that could disrupt other players' games.
- Fixed a number of collision issues with moveable cargo objects.
- Fixed an issue that could cause players to get stuck inside the collision of another player's corvette while docked at a shared landing pad.

- Fixed a minor visual issue with some foliage types.
- Fixed a minor visual issue with floating island waterfalls.
- Fixed an issue that caused the vision seen at underwater ruins to be blown out.
- Fixed a number of visual issues related to HDR support.
- Fixed a minor visual issue with VFX in the terrain manipulator's flatten mode.
- Fixed a number of audio mix issues.

- Introduced a significant memory optimisation for PlayStation 5.
- Fixed an issue that prevented vignettes and scanlines from being turned off, on Switch 1 and 2.
- Fixed an issue on PSVR1/2 which caused rendering errors on refraction effects and ship decals.
- Fixed and issue on PSVR1/2 which caused rendering errors when under-water.

- Fixed a crash related to player networking.
- Fixed a crash related to physics systems.
- Fixed a crash related to physics systems.
- Fixed a crash related to NPC networking.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,

Hello Games
