# Update 6.11

- **Platforms:** PC

**Update 6.11** is the 264th official update to No Man's Sky.

## Summary

**Update 6.11** is the 264th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on October 24, 2025 on PC.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Voyagers, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.11, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed an issue that could cause the player to fall through the floor when teleporting to an Abandoned Space Station.
- Fixed an issue that could cause players to be pushed unexpectedly while space walking.

- Fixed a visual issue with the Aeron Blade corvette wing when placed on the right hand side.
- Fixed an issue that could cause weather effects to play when space walking.

- Fixed an issue that could cause overlapping UI when playing with Enlarged UI Text enabled.
- Improved readability of Egg Sequencer UI with Enlarged UI Text enabled.
- Fixed an overlapping text issue in the planet information when scanning a moon with Enlarged UI Text enabled.
- Fixed an issue that could cause overlapping UI when playing on the ROG Xbox Ally.

- Fixed a crash related to base building.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
