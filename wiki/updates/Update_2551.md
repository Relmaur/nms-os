# Update 2.55.1

## Quick Facts

- **Platforms:** PC
- **Added in:** Crossplay
- **Previous:** 2.55
- **Next:** 2.60

**Update 2.55.1** is the 91st official update to No Man's Sky.

## Summary

**Update 2.55.1** is the 91st official [[Patch notes|update]] to [[No Man's Sky]]. It was released on 26 June to the Windows platform.

It corrected issues with the Crossplay release. The previous update is [[Update 2.55]].

## Actual text

Hello everyone,

Thank you to everyone playing the Crossplay Update, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have an update for the Windows Store version.

## Patch Notes

- Fixed server connection for the Windows Store version to allow Discovery renaming, Base uploading, Quicksilver and Weekend Event missions.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,

Hello Games
