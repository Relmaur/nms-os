# Update 1.09.1

## Quick Facts

- **Platforms:** PC
- **Previous:** 1.09
- **Next:** 1.10
- **Added in:** Initial Release

**Update 1.09.1** is a minor update No Man's Sky.

## Summary

**Update 1.09.1** is a minor fix for [[Update 1.09]] released on 26 October 2016 to PC. No official patch notes from Hello Games exist for this update.

## Observations

### Threading Options and Code

According to [this post](https://www.gog.com/forum/no_mans_sky/gog_109_missingbroken_functionality_again) and [this post](https://www.gog.com/forum/no_mans_sky/patch_1091/post13), the patch activated these threading options in **TKGRAPHICSSETTINGS.MXML**:

<pre>&lt;Property name="NumHighThreads" value="1" /></pre>
<pre>&lt;Property name="NumLowThreads" value="2" /></pre>

### Installation Issues and other fixes

According to [this post](https://www.gog.com/forum/no_mans_sky/patch_1091/post22), the patch resolved some problems about missing files during installation, garbled text and flight control lag.
