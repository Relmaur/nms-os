## Summary

**Update 6.05.1** is the 260th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on September 19, 2025 on PC and Mac.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Voyagers, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.05.1, which is now live on Steam.

## Bug Fixes

- Fixed an issue that would cause your corvette to be moved to a freighter landing pad if you summoned a freighter when not piloting it.
- Fixed an issue that could cause the game to be stuck on a black screen when you load in to a save game.
- Fixed a crash that could occur when loading a save game with a corvette.
- Fixed a hang that could occur when playing in VR.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a [bug report](https://hellogames.zendesk.com/hc/en-us/requests/new?ticket_form_id=167605).

Thank you,

Hello Games
