# Update 2.08

## Quick Facts

- **Release date:** 21 August 2019
- **Platforms:** PS4/Xbox
- **Added in:** Beyond
- **Previous:** 2.07
- **Next:** 2.08A

**Update 2.08** is the 55th official update to No Man's Sky.

## Summary

**Update 2.08** is the 55th official [[Patch notes|update]] to [[No Man's Sky]] and was released on 21 August 2019 to PS4 and Xbox.

It addresses bugfixes. The previous update is [[Update 2.07]].

## Actual text

Hello everyone,

Thank you again to everyone playing Beyond, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of stability issues. Fixes for these were released on PC over the last few days. And this patch, 2.08 which is a consolidation of those fixes, is now live on consoles.

### Bug fixes

- Fixed a number of threading-related [[multiplayer]] matchmaking issues.
- Fixed an audio crash when quitting from the initial screen.
- Fixed a crash when quitting the game during audio initialisation.
- Fixed a rare issue where joining a full lobby causes an incorrect player ID.
- Fixed an issue where players joining a group can be taken to the wrong system.
- Fixed an issue that caused some network games not to appear in the Join game screen.
- Fixed an issue that caused the [[Exocraft]] [[Technician]] to have an incorrect interaction.
- Fixed a crash caused by an invalid base index.
- Fix for rare instance of falling through [[space station]] when interacting with vendor.
We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a [bug report](https://hellogames.zendesk.com/hc/en-us/requests/new?ticket_form_id=167605).

Thank you,<br>
Hello Games
