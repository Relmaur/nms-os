# Update 7.01

## Quick Facts

- **Release date:** 10 September, 2026
- **Platforms:** PC, Mac, PS, XB
- **Added in:** Cosmos
- **Previous:** 7.00
- **Next:** 7.02

**Update 7.01** is the 291st official update to No Man's Sky.

## Summary

**Update 7.01** is the 291st official [[Patch notes|update]] to [[No Man's Sky]]. It was released on September 10, 2026 on PC and Mac.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Cosmos, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 7.01, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed a number of geometry issues with new base parts.
- Fixed an issue that could cause station decoration to go missing in Korvax-controlled stations.
- Made a number of control improvements to space station decoration in VR.
- Fixed an issue that caused the Grave of the Ocean King to appear 600 times smaller than intended.
- Fixed an issue that could prevent some station exterior decorations from correctly unlocking after purchase.
- Some space station parts are now unlocked using salvaged materials.
- Fixed a number of geometry issues with the platform around the space station core.
- Improved the variety of decoration inside space outposts.

- Fixed an issue that could cause space station stairs to appear the wrong colour.
- Fixed an issue that could cause players to fall out the space station.

- Fixed an issue that could prevent players from using the Vent Cargo button on their tractor beam.
- Fixed a number of physics issues with salvageable props.
- Fixed an issue that caused the Leave button not to work when using pad controls and viewing the space station mission giver before completing the tutorial.
- Fixed an issue that could cause the pulse drive to immediately disengage after starting near a deep-space object.
- Fixed an issue that caused the tractor beam VFX to activate at inappropriate times.

- Improved messaging around space hulk meltdowns.
- Fixed an issue that caused Pathogen Sacs and Viral Hearts to swap icons.
- Added additional VFX around key space hulk pieces.
- Players completing a space hulk or infested outpost in multiplayer are now both able to claim the rare items.

- Fixed an issue that allowed players in creative to fly inside the sun.
- Fixed an issue that caused too many pirates or traders to spawn in asteroid fields.
- Fixed a number of issues that could occur when leaving a completed derelict freighter.

- Added a galactic trade terminal in the outpost Quartermaster's room.
- Improved the VFX while walking on corvette landing pads at a space outpost.
- Fixed an issue that could cause an NPC to sit inside a wall at some space outposts.
- Fixed an internal collision issue affecting some space outposts.

- Fixed an issue that could cause system discovery messages to fail to display.
- The current galaxy is now shown on the star system map.
- Improved the layout of popups on the star system map.
- Marking a planet on the star system map now uses the same icon as marking a planet from the discovery page.
- Some space objects now remain on the star system map after completion, allowing them to be re-visited if appropriate.

- Alliance names are now shown correctly on the teleporter UI.
- Fixed an issue where long alliance names could overflow the New Player Title Unlocked banner.
- Alliance names are now shown on the star system map.
- Fixed a number of text issues on the Claim Station page.
- Fixed a number of unclear UI states and errors that could occur when multiple people attempt to claim the same space station.
- Fixed an issue that could leave lingering markers after completing salvage missions.

- Fixed an issue that could cause the starship to turn abruptly while pulsing towards mission destinations on planets.
- Fixed an issue that could cause a grey cube to appear around frigates.
- Fixed a number of gravity issues affecting derelict freighters.
- Fixed an issue that could cause docked corvettes to begin flying after reloading a save on a deep-space outpost.
- Fixed an issue that could prevent players from entering a second player's corvette in multiplayer.

- The Gravitinio Coil is no longer automatically unholstered in VR.
- The teleport terminal now shows screenshots of space station bases where appropriate.
- Fixed an issue that could cause players to fall out of their freighter.
- Fixed an issue that could cause players to get out of their exocraft while trying to scroll the quick menu.
- Fixed a collision issue at the Nexus.

- Fixed an issue that caused UI glitching when opening a portal.
- Fixed an issue that caused an empty head to appear in the customiser.

- Fixed a number of camera issues when moving in and out of spacewalk.
- Fixed a number of issues with the photomode camera while spacewalking.
- Fixed a number of issues that could occur while spacewalking around large objects such as a freighter or frigate.
- Adjusted the third-person spacewalking camera while a weapon is drawn to more closely match the non-weapon camera.
- Fixed a number of camera issues while spacewalking in first person.

- Fixed a number of audio issues with stars.
- Fixed a number of visual issues with starship trails.
- Fixed a number of visual issues with corvette weapons.
- Fixed a number of visual issues that could occur when reloading a save that had the Gravitino Coil equipped.
- Fixed an issue that caused green stars to appear the wrong colour.
- Fixed an issue that caused some visual elements to missing from the star system map on Nintendo Switch.
- Fixed an issue that could cause planetary rings to draw while inside a space station.

- Fixed a crash related to audio management.
- Fixed a hang that affected Playstation 5 players using the PS4 version of No Man's Sky.
- Fixed a crash related to downloading base images.
- Fixed a crash related to Xeno Arena battles.
- Fixed a crash related to inventory rendering.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,

Hello Games
