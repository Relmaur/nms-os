**Update 6.34** is the 281th official update to No Man's Sky.

## Summary

**Update 6.34** is the 281th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on April 21, 2026 on PC.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Xeno Arena, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.34, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed an issue which cause holo-arena abilities which reset cooldowns to reset their own cooldown.
- Improved XP calculation for creatures during holo-arena battles.
- Fix misaligned background image for the holo-arena on widescreen setups.
- No longer show pets as exceeding max level after finishing a holo-arena battle.
- Fix for badly aligned particle effects in some creature battles.
- Fix a bug that caused some creatures in the holo-arena to have incorrect visual effects applied.
- Fixed an issue which caused the wrong creature to be displayed when selecting the team in the holo-arena.
- Fixed an issue in the holo-arena battle log.
- Improved the visibility of active Challenger and Champion Holo-Arena battle missions and allowed multiple active instances of those missions in the mission Log.
- Fixed unclear messaging when losing a Holo-Arena battle and not gaining any XP.
- Fix for creature battle stats appearing in the squadron pilot info UI.
- Fixed a soft-lock that could occur during holo-arena battle setup.
- Fixed a rare issue which could cause a soft lock when all pets were KO'd from both players.

- Fixed a number of issues affecting the Brood Mother.
- Fixed an issue where markers were being hidden incorrectly.
- Improved snake creature riding position.
- Fixed an issue that prevented the beam aboard corvette marker from showing when loading onboard a freighter.
- Fixed an issue which caused base parts to be placed incorrectly if built while flying in a corvette.
- Fixed an issue that could cause the construction terminal to be missing for large buildings in Settlements.
- Fixed an issue which could incorrectly limit ship lasers.
- Allow mouse wheeling bindings for quick left and quick right actions in the ship quick menu action set.
- Fixed a bug that double counted input if cycle weapon was bound to the same button as quick menu navigation.
- Improved checks when searching inventories for items used during crafting.
- Text improvements.
- Fixed an issue which could link to an incorrect discovery page.
- Fixed an issue that could cause missions to direct the player to the galaxy map instead of the teleporter when the mission location was in a different galaxy.
- Fix a terrain rendering bug where dark patches are occasionally seen with tessellation enabled.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
Hello Games
