# Update 7.02

## Quick Facts

- **Release date:** 15 September, 2026
- **Platforms:** PC, Mac
- **Added in:** Cosmos
- **Previous:** 7.01
- **Next:** 7.03

**Update 7.02** is the 292nd official update to No Man's Sky.

## Summary

**Update 7.02** is the 292nd official [[Patch notes|update]] to [[No Man's Sky]]. It was released on September 15, 2026 on PC and Mac.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Cosmos, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 7.02, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed an issue that caused mission text to sometimes report triple the amount of pirate starships than were actually present.
- Fixed an issue that caused organic frigates to repeat their story dialogue at every encounter.
- Fixed a number of issues with salvage missions that could occur when completing several at a time.
- Fixed an issue that could cause a %TIME% variable to appear in mission notifications.

- Fixed an issue that caused the "Fruit Tree" base part to be invisible.
- Fixed a number of minor geometry issues with space outposts.
- Fixed an issue that cause the Deep-Space Base Computer to be placeable for free.
- Fixed a number of issues with incorrect gravity behaviour on planetary base parts.

- Fixed an issue that added large invisible collision spheres to some pieces of exterior space station decoration, causing accidents as players took from the station.
- Fixed an issue that could get players into an invalid state while playing exterior space station parts.
- Fixed an issue that could duplicate props within a claimed space station.

- Fixed an issue that could reset corvette orientation after loading a save.
- Fixed an issue that could cause the phase beam to shoot the back of the corvette's own cockpit while flying in first person.
- Fixed an issue that prevented the handles on the Ambassador corvette cockpit from working in VR.
- Fixed an issue that could cause the corvette ramp to load in a closed state if the player save/loaded while stood on the ramp.
- Fixed an issue that caused the camera to be misaligned when moving from first-person on foot to first-person corvette piloting.
- Fixed an issue that prevented players from toggling free placement mode while editing a corvette.

- Fixed a minor collision issue on the Space Anomaly.
- Players can now return to the remains of a completed space hulk.
- Fixed an issue that could cause the system's star to appear the wrong size.
- Fixed a number of gravity issues around freighters.
- Fixed an issue that allowed players to unexpectedly land on civilian frigates.

- Fixed an issue that caused an incorrect icon to appear on the discovery page for planets that host swarm debris.
- Fixed an issue that revealed the names of unknown deep-space objects in the corvette auto-pilot menu.
- Fixed a rare issue that could cause a copy of the Initialise screen to appear briefly during the starfield load.

- Fixed a number of audio issues in asteroid belts.
- Softened some UI audio.
- Fixed a rare issue that could cause the tractor beam to be too loud.

- Fixed an issue with cloud rendering on AMD GPUs.
- Introduced a number of small visual improvements to cloud rendering.
- Fixed an issue that could cause starship trails to flicker.

- Introduced a number of optimisations to volumetric fog.
- Fixed an issue that could cause ship movement in the warp tunnel to stutter.

- Fixed a crash related to building a corvette.
- Fixed a PlayStation 5 streaming crash.
- Fixed a physic crash that could occur while closing the game.
- Fixed a crash related to frigate networking.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,

Hello Games
