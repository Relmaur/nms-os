# Update 6.33

## Quick Facts

- **Release date:** 15 April, 2026
- **Platforms:** PC
- **Added in:** Xeno Arena
- **Previous:** 6.32
- **Next:** 6.34

**Update 6.33** is the 280th official update to No Man's Sky.

## Summary

**Update 6.33** is the 280th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on April 15, 2026 on PC.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Xeno Arena, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.32, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- NPC Holo-Arena opponents will no longer use a move that would cause their final pet to be knocked out.
- During NPC holo-arena battles, opposing creatures will now have more appropriate affinities.
- Fixed an issue which prevented ramping damage from being dispellable during holo-arena battles.
- Fixed an issue that could cause stunned pets to still take bonus turns.
- Fixed an issue that prevented the turn timer activating for *Fireteam members during Holo-Arena matches.

- Improved NPC reactions during holo-arena matches.
- Holo-arena NPC opponents will now return to facing the table if they become distracted.
- Fixed an issue that caused Holo-Arenas to appear in Abandoned systems.
- Fixed an issue which could repeatedly send players to battle same NPC when using an invite from Oceanus.
- Fixed an issue which caused players to be thrown around during a holo-arena battle while in a storm on a planet.
- Fixed a rare issue that could occur if you started spectating a holo-arena battle at the end of a match.
- Fixed an issue that would cause status effects to trigger on knocked out creatures.
- Fixed an issue that could cause Holo-Arena battles to go out of sync.
- Fixed an issue that prevented starting new Holo-Arena battles after experiencing a disconnection from the server.
- Added audio to accompany a knock out at a Holo-Arena.
- Added audio to accompany a win result at a Holo-Arena.

- Show level up progress for creatures after a holo-arena battle.
- Fixed an issue that could cause overlapping UI when losing or winning a match at a Holo-Arena.
- Fixed an issue that would display chat messages during Holo-Arena battles.
- Fixed an issue that caused the win/lose screen to disappear quickly for the player who joined a Holo-Arena battle.
- Fixed an issue that caused camera framing to be incorrect for left handed players in VR during holo-arena battles.
- The collection of Arena League reward companions now display a thumbnail of the creature in Oceanus' shop interface.
- Fixed an issue that would cause the helix upgrade icon to appear erroneously in the companion register.

- Summoned pets are now hidden when starting a battle at a Holo-Arena.
- Fixed an issue that caused some robotic creatures to lay eggs with organic shells.
- Fixed an issue that prevented robotic eggs from being picked up.
- Fixed a texture issue with squid creatures.
- Improved squid creature movement.
- Fixed an issue that prevented creatures from depositing faecium after being fed.

- Fixed an issue that prevented the Analysis Visor scanning mode for creature stats to appear until you adopted a 2nd pet.
- Updated icons for creature traits displayed when using the Analysis Visor.
- Fixed an issue that prevented the starship from being automatically repaired at the end of the Remnant expedition if some milestones had been left incomplete.
- Fixed an issue that could cause the camera to behave erratically when the player was sitting.
- Fixed an issue when attempting to transfer a stack of items from a chest to another inventory.
- Fixed several missing text strings.
- Fixed an issue which could prevent markers from rendering.

- Upgrade OpenVR to version 2.15.6
- Fixed an issue that caused gaps in the terrain with some graphics settings when using an integrated Intel GPU.

- Fixed a crash when attempting to mutate a max level creature.
- Fixed a crash that could occasionally occur during load.
- Fixed a crash in the particles system on Switch.
- Optimised memory usage on PS4.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
Hello Games
