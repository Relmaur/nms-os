# Update 2.53

## Quick Facts

- **Release date:** 16 June 2020
- **Platforms:** All
- **Added in:** Crossplay
- **Previous:** 2.52
- **Next:** 2.54

**Update 2.53** is the 88th official update to No Man's Sky.

## Summary

**Update 2.53** is the 88th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on 16 June to all platforms.

It corrected a number of issues with the new Crossplay release. The previous update is [[Update 2.52]].

## Actual text

Hello everyone,

Thank you to everyone playing the Crossplay Update, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of stability issues. Some of these fixes were released earlier today as Patch 2.52.1 for PC. Additional console fixes have been added and combined into patch 2.53, which will be live on all platforms today.

## Patch Notes

- Fixed a rare networking crash related to base building.
- On PC only, fixed a crash that could occur when NPC pilots get into their ships to take off.
- We've fixed a number of issues specific to AMD GPUs. We are aware of other GPU specific crashes and are working with AMD to fix them on a driver level. In the meantime, they have recommended rolling back to the previous WHQL driver 20.4.2, which can be found here: [link](https://www.amd.com/en/support/graphics/amd-radeon-5700-series/amd-radeon-rx-5700-series/amd-radeon-rx-5700-xt/).
- We are also aware of a number of Windows 7 users who are unable to connect. This is a platform security issue, and requires an update to enable TLS 1.1 and TLS 1.2 as default secure protocols in WinHTTP in Windows, found here: [link](https://support.microsoft.com/en-gb/help/3140245/update-to-enable-tls-1-1-and-tls-1-2-as-default-secure-protocols-in-wi/)

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
