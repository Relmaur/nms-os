# Update 6.43

**Update 6.43** is the 286th official update to No Man's Sky.

## Summary

**Update 6.43** is the 286th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on June 1, 2026 on PC and Mac and on June 3, 2026 on PS.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – The Swarm, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.43, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed an issue that could cause the "Space Rescue" mission to erroneously appear in the Mission Log when fighting the Hive of Glass.
- Fixed an issue that caused the "Initialise" screen to get skipped if starting multiple new games in the same session without re-launching.
- Improved the messaging during the Countermeasures milestone to indicate when all missions have been completed for the current Swarm Activity period.
- Improved the balance of the fight in the Emperor of Glass milestone.
- Fixed an issue that could lead to incorrect colours displaying for the Purge/Restore/Sabotage milestones if the Swarm expedition was started offline.
- Fixed an issue that prevented interaction with the Prismatic Core if playing the Swarm expedition offline.
- Fixed an issue that allowed the Divine Intelligence milestone to be completed prior to the Disassembly milestone during the Swarm expedition.

- Fixed an issue which could cause too many corrupt sentinels to spawn during seasonal encounters.
- Allowed the extraction of corrupted ichor from swarmer debris recovered from crash sites.
- Improved the physics behaviour of removable components at swarmer crash sites.
- Improved the visual effects when dismantling fallen swarmers at crash sites.
- Fixed an issue with swarmer crash sites in Exterminator missions.

- Prevented the Space Anomaly from being summoned into battles against the Hive of Glass.
- Fixed an issue that could allow the Space Anomaly and freighters to be summoned intersecting with deep-space objects (e.g. Atlas Interfaces).
- Fixed an issue that caused a freighter icon to appear during battles against the Hive of Glass.

- Fixed an issue which could cause object markers to be offset.
- Fixed an issue that made it difficult to place a refiner on crucial expedition planets.
- Fixed a minor visual issue with the Direwasp Helm.
- Updated the game mode image for the Swarm expedition.
- Improved the legibility of the Swarm expedition team initialisation in VR.
- Added audio to the Prismatic Core.
- Improved audio balance during the Swarm expedition.

- Fixed a crash that could occur when continually opening and closing the Galaxy Map.
- Minor physics optimisation on Switch 1.
- Fixed a rare PS5 crash related to model streaming.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
