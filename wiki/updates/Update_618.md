# Update 6.18

- **Platforms:** PC

**Update 6.18** is the 270th official update to No Man's Sky.

## Summary

**Update 6.18** is the 270th official [[Patch notes|update]] to [[No Man's Sky]]. It was released on December 01, 2025 on PC.

## Actual text

Hello Everyone,

Thank you to everyone playing No Man’s Sky – Holiday Expeditions 2025, especially those taking the time to report any issues they encounter via Zendesk or console crash reporting.

We are listening closely to your feedback, and have identified and resolved a number of issues. These fixes are included in patch 6.18, which is now live on Steam, and will be coming to other platforms as soon as possible.

## Bug Fixes

- Fixed an issue that could cause Corvette technology slots to re-arrange themselves after playing in multiplayer.
- Fixed an issue which incorrectly allowed the placeholder Cargo Box corvette item to be obtainable.
- Fixed an issue that prevented the corvette landing gear from retracting during flight.
- Fixed a visual issue with bioluminescent creatures.
- Fixed an issue that could cause the ribcage on some fossil displays to appear invisible.
- Fixed an issue that could prevent corvette's from landing when they had a fossil display built inside.
- Fixed an issue that caused fossil holograms from having the incorrect orientation.
- Fixed an issue that would cause claimed character customisations to still appear as unclaimed in the Quicksilver shop on The Space Anomaly.

- Fixed an issue that could cause a crash when accepting game invites from a suspended state on Xbox consoles.
- Fixed an issue which could cause a black screen when running in 8k on PS5.

We will continue to release patches as issues are identified and resolved. If you experience any issues, let us know by submitting a bug report.

Thank you,
Hello Games
