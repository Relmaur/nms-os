## Summary

**Update 1.31** is the 16th [[Patch notes|update]] to *[[No Man's Sky]]* released on 12 August 2017 to Playstation 4 and PC.

It addresses mainly crashes.
The previous update is [[Update 1.30]].

- Fixed an issue causing some players to crash when accessing the [[Galactic Map|galactic map]] while having too many [[Waypoints]] active
- Fixed a crash some players experience when pinning certain tech
- Fixed a crash which occurs when players with particularly long play-throughs attempt to save the game
- Fixed an issue that sometimes resulted in [[guild]] missions not crediting correctly
