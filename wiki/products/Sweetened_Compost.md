# Sweetened Compost

## Quick Facts

- **Category:** Consumable
- **Type:** Herbivore Bait
- **Value:** 800.0
- **Added in:** NextGen

**Sweetened Compost** is a consumable.

## Summary

**Sweetened Compost** is a [[consumable]] and it is one of the [[Consumable|Herbivore Baits]].

## Game Description

A specialist bait for herbivores. Use the [[Analysis Visor]] to discover the bait preferences of specific creatures.

Created in a [[Nutrient Processor]] from [[Faecium]] and harvestable plants.

Feeding using the correct bait will allow creatures to be ridden or harvested. Chose  bait type from the [[Quick Menu]] (//).

## Source

## Additional Information

Sweetened Compost is the most common preferred herbivore bait.
