# Homeworld Repeater

## Quick Facts

- **Category:** Curiosity

**Homeworld Repeater** is a curiosity.

## Summary

The **Homeworld Repeater** is a [[curiosity]] and one of the [[Curiosity|homing devices]].

## Game description

A makeshift device, cobbled from salvaged electronic components kept in deep storage for many years. This jumble of wires will attempt to make contact with the last-known remnants of the freighter's homeworld.

Select the device and select Broadcast // (PC/PS/XB) to begin the location process.
