# Biological Sample

## Quick Facts

- **Category:** Artifact
- **Type:** Biological Sample
- **Value:** 2,299,696
- **Used for:** Trading, Trading (High Value)
- **Added in:** Voyagers

**Biological Sample** is a type of Artifact.

## Summary

**Biological Sample** is one of several types of [[Artifact|Artifacts]] and it is a reward for opening [[Large Artifact Crate|Large Artifact Crates]] found in Ancient [[Ruin|Ruins]], completing [[Mission Board|missions]] or completing exploration type expeditions with [[frigate|frigates]].

## Name generation

The names are procedurally generated with certain terms using one of the following options: 1. Container + "of" + Adjective + Noun; 2. Adjective + Noun.

The sequence is taken from the game file.
