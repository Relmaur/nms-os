## Summary

**Hadal Core** is a [[tradeable]].

## Game description

A highly-pressurised fleshy orb.

One can feel it push back when touched, a flash of bioluminescence stirring in the inky black core of this mysterious object.

## Source

- Up to five pieces can be acquired from an [[Alluring Specimen]], but with each harvest there is a chance for an [[Abyssal Horror (anglerfish)|Abyssal Horror]] to appear, destroying the remaining cores.
- Can be found in [[Derelict Freighter]] containers.
- Can be found in the form of [[Submerged Relic|Submerged Relics]] (one piece).
- From [[Suspicious Packet (Goods)]].
- From [[Nexus]] and [[Mission Board]] Missions.
- As a gift from [[Planetary Settlement]] visitors.
