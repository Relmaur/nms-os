# Vector Compressors

## Quick Facts

- **Category:** Tradeable
- **Type:** Trade Goods (Industrial)
- **Value:** 50,000.0
- **Added in:** Adrift

**Vector Compressors** is a tradeable.

## Game description

**Vector Compressors** is a 5th tier [[tradeable]].

## Game Description

A large crate of high-capacity vector compressors.

The creation of interstellar drives often requires dimensions to be condensed and then re-rendered. Such high-tech component manufacture would not be possible without industrial-grade compressors such as these.

## Source

High Capacity Vector Compressor can be purchased from [[Galactic Trade Terminal|Galactic Trade Terminals]] in all high-wealth [[Manufacturing Economy]] [[star system|star systems]].
It can also be received as a reward for completing a [[Mission Board|mission]]

## Usage

High Capacity Vector Compressor can be sold for a profit in any [[Technology Economy]] star system.

It is not usable by the player in [[Crafting]] or [[Base building]].
