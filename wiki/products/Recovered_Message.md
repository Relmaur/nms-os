# Recovered Message

## Quick Facts

- **Type:** Collected Flotsam
- **Value:** 806
- **Added in:** Aquarius

**Recovered Message** is a type of product.

## Summary

**Recovered Message** is a type of [[product]] that can be obtained after unsealing [[Message in a Bottle]].

## Game Description

A scrap of paper recovered from a bottle found bobbling in the water. The message on it reads: xxx.

Sample message:
"Last contact was 9 days ago. Yesterday we used up the last of the power cells. It all happened so fast. Forgive me..."

## Use

Can be sold for 309 to 1,359 units Units depending on the message (Each message sells for a different price).
