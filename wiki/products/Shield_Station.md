# Shield Station

## Quick Facts

- **Category:** Technology
- **Type:** Shield
- **Description:** Shield Restoration
- **Added in:** Atlas Rises

A **Shield Station** is an item of Technology.

## Summary

A **Shield Station** is a station that allows the player to restore their Exosuit shield.

## Game description

A wall mounted module that can be used to recharge shields.

## Sources

The blueprint can be bought from a blueprint trader inside a habitable base.
