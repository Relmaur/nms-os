# Inverted Mirror

## Quick Facts

- **Category:** Component
- **Type:** Burning Glassy Remnant
- **Total Value:** 17,000.0
- **Updated:** WorldsOne

**Inverted Mirror** is a component.

## Summary

**Inverted Mirror** is a component that is used for crafting.

## Game Description

A pane of watchful g l a s s, retrieved from the smoking remains of the corrupted swarm's Dissonance Resonators. It emits more light than it reflects, casting a faint purple hue on its surroundings.

Highly sought after for salvage operations, as it can be used to bypass the security systems of key Sentinel ship technologies.

## Sources

- Loot from a Dissonance Resonator with the Inverted Mirror tag.
- May also be found on Harmonic Scrap.

## Use

**Inverted Mirror** is used in the repair of Sentinel multi-tools and crashed Interceptors.

### Crafting

**Inverted Mirror** is not used as an ingredient for crafting.

### Refining

**Inverted Mirror** is used as an ingredient for refining the following products using a Refiner:

- Nanite Cluster -- Inverted Mirror x1 → Nanite Cluster x95 (*"Purge Corruption"*, 8.8 sec./unit output)

### Cooking

**Inverted Mirror** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

When a Dissonance Resonator is destroyed, it will drop either an **Inverted Mirror** or an Echo Locator. Which it will drop is indicated by a tag below its name on the HUD when you are close to it.

## Release History

- Interceptor - Added as a component.
