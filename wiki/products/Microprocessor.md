# Microprocessor

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 2,000.0
- **Updated:** Prisms

**Microprocessor** is a component.

## Summary

**Microprocessor** is a component that is used for crafting.

## Game description

A compact, low-heat microchip. Assembled from processed Chromatic Metal, created from one of several specialised terrain metals.

Used in the creation of a wide range of advanced technologies.

## Source

- Blueprint can be awarded in the Scientific Research mission, found in Manufacturing Facilities and Operations Centres, or purchased from Synthesis Laboratory for 250.

Microprocessor can be built using a blueprint and the following ingredients:

- Chromatic Metal ×40 + Carbon Nanotubes ×1 → Microprocessor

Also available from any Galactic Trade Terminal.
