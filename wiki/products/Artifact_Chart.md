## Summary

**Artifact Chart** is a [[curiosity]].

## Game description

A map of a nearby planet. An ancient ruined site has been marked. Excavating this site is likely to yield valuable treasures.

Select the map and use Plot Route (// (PC/PS/XB)) to pin the location in your Exosuit display.

New maps can be gained by exchanging Navigation Data with a Space Station Cartographer.

## Source

Can be randomly obtained from all types of [[Planetary Chart]] from the Cartographer on a space station in exchange for Navigation Data.
