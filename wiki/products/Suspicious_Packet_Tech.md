# Suspicious Packet (Tech)

## Quick Facts

- **Category:** Curiosity
- **Type:** Contraband
- **Rarity:** Rare
- **Used for:** Upgrading
- **Added in:** Waypoint

**Suspicious Packet (Tech)** is a curiosity.

## Summary

Suspicious Packet (Tech) is a [[curiosity]] that gives one random [[Suspicious Module]] when opened.

It from the [[Space Station]]'s [[Scrap Dealer|scrap dealer]] or for ~74,000 Units in pirate-controlled systems.

## Game description

A suspicious looking parcel, acquired via an unusual transaction. The seller indicated it contained some sort of high-value or interesting item.

Select in the Inventory (// (PC/PS/XB)) and use // (PC/PS/XB) to examine the contents. No refunds.

## Contents

- Procedural products to open ("PROC_COG" and "PROC_DATA")
- Suspicious Mining Beam Module
- Suspicious Scanner Module
- Suspicious Life Support Module
- Suspicious Hazard Protection Module
- Suspicious Movement Module
- Suspicious Shield Module
- Suspicious Pulse Engine Module
- Suspicious Hyperdrive Module
- Suspicious Starship Shield Module
