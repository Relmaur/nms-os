# Hardframe Engine

## Quick Facts

- **Category:** Component
- **Type:** Anomalous Material
- **Total Value:** 28,000.0
- **Used for:** Upgrading
- **Updated:** SentinelUp

**Hardframe Engine** is a component.

## Summary

**Hardframe Engine** is a component that is used for upgrading.

## Game Description

This complex mechanical unit was once the central combustion chamber at the heart of a Sentinel Hardframe unit.

Though now cool to the touch, it still glows with a sinister red heat...

## Sources

- Interact with Combat Supplies dropped by Sentinel Hardframe to obtain. Destroying it will cause loss of loot.

## Use

**Hardframe Engine** is used as an ingredient for crafting the following products:

- Hardframe Legs -- Pugneum x120 + Hardframe Engine x1 → Hardframe Legs
