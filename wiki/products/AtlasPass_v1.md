# AtlasPass v1

## Quick Facts

- **Category:** Constructed Technology
- **Type:** Access Card
- **Value:** 0
- **Added in:** Prisms

**AtlasPass v1** is a Constructed Technology.

## Summary

**AtlasPass v1** is a [[Constructed Technology]] and it works as a key; the player crafts it once and it allows infinite unlocks. It unlocks barrel type [[Cargo Drop|Cargo Drops]].

## Game description

Security and permissions pass granted to specific travellers by many primary galactic species.

Provides access to low level restricted areas and outpost systems.

## Source

- Blueprint can be found in [[Manufacturing Facility|Manufacturing Facilities]] and [[Operations Centre|Operations Centres]], or purchased from [[Synthesis Laboratory]] for 250  Nanites.

- **Crafting** · needs the blueprint: 200 × [[Copper]] + 1 × [[Microprocessor]] → 1 × AtlasPass v1
