# Remembrance Terminal

## Quick Facts

- **Type:** Remembrance Terminal
- **Added in:** Orbital

**Remembrance Terminals** are a type of game terminal.

## Summary

A **Remembrance Terminal** comes into play as certain storylines are pursued. They can only be activated if the [[Remembrance]] upgrade has been installed.

## Location

These [[terminal|terminals]] can be found in [[Space station|abandoned space stations]] behind [[AtlasPass v3]] doors, and on [[planet|planets]] behind [[AtlasPass v2]] doors. Prior to the [[Orbital]] update they could also be found on regular [[space station|space stations]] behind AtlasPass v3 doors, but these areas were removed in the space station redesign.

## Usage

Upon accessing these terminals, you receive short Lore. As of yet there is no other usage for these terminals. It is unknown how many different terminals exist; for a transcript of expected recordings, refer to [[Rogue Data]].
