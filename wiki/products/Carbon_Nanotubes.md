# Carbon Nanotubes

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 500
- **Updated:** WorldsTwo

**Carbon Nanotubes** is a component.

## Summary

**Carbon Nanotubes** is a component that is used for crafting.

## Game description

Metres and metres of high capacity carbon nanotubes.

Their high tensile strength and mild conductivity make these a key component in many advanced technologies.

## Source

Available from some Galactic Trade Terminals.

Carbon Nanotubes can be built using a blueprint and the following ingredients:

- Carbon ×50 → Carbon Nanotubes

Carbon Nanotubes can be cooked using a Nutrient Processor with the following ingredients:

- Chewy Wires x1 → Carbon Nanotubes x1 (*"NOT RECOMMENDED"*, 2.5 sec./unit output)

## Use

### Crafting

**Carbon Nanotubes** is used as an ingredient for crafting the following products:

- Advanced Mining Laser -- Carbon Nanotubes x1 + Hermetic Seal x1 + Wiring Loom x2 → Advanced Mining Laser
- Air Filtration Unit -- Copper x160 + Carbon Nanotubes x5 + Wiring Loom x1 → Air Filtration Unit
- Analysis Visor -- Carbon Nanotubes x1 → Analysis Visor
- Appearance Modifier Room -- Silver x60 + Carbon Nanotubes x4 + Solar Mirror x1 → Appearance Modifier Room
- Ariadne's Flame -- Amino Chamber x1 + Metal Plating x4 + Carbon Nanotubes x10 → Ariadne's Flame
- Base Teleport Module -- Metal Plating x4 + Carbon Nanotubes x2 + Sodium x40 → Base Teleport Module
- Blueprint Analyser -- Magnetised Ferrite x20 + Carbon Nanotubes x1 → Blueprint Analyser
- Boltcaster -- Chromatic Metal x100 + Carbon Nanotubes x3 → Boltcaster
- Construction Research Unit -- Magnetised Ferrite x20 + Carbon Nanotubes x1 → Construction Research Unit
- Exocraft Boosters -- Magnetised Ferrite x15 + Chromatic Metal x50 + Carbon Nanotubes x2 → Exocraft Boosters
- Fishing Rig -- Carbon Nanotubes x3 + Di-hydrogen Jelly x1 + Chromatic Metal x60 → Fishing Rig
- Hydraulic Wiring -- Carbon Nanotubes x2 + Salt x20 + Di-hydrogen x40 → Hydraulic Wiring
- Message Module -- Metal Plating x1 + Carbon Nanotubes x1 → Message Module
- Microprocessor -- Chromatic Metal x40 + Carbon Nanotubes x1 → Microprocessor
- Signal Booster -- Metal Plating x1 + Carbon Nanotubes x1 + Sodium x15 → Signal Booster
- Terrain Manipulator -- Di-hydrogen Jelly x1 + Carbon Nanotubes x2 → Terrain Manipulator

### Refining

**Carbon Nanotubes** is not used as an ingredient for refining using a Refiner.

### Cooking

**Carbon Nanotubes** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Creature Pellets -- Mordite x1 + Carbon Nanotubes x1 → Creature Pellets x1 (*"Prepare Bait"*, 2.5 sec./unit output)

## Fishing Bait

When applied as bait, Carbon Nanotubes gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
