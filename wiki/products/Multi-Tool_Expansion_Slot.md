# Multi-Tool Expansion Slot

## Quick Facts

- **Category:** Curiosity
- **Type:** Upgrade Unit
- **Value:** 85,000.0
- **Added in:** Aquarius

**Multi-Tool Expansion Slot** is a curiosity.

## Summary

**Multi-Tool Expansion Slot** is a [[curiosity]].

It provides a one-slot upgrade.

## Game Description

A flexible upgrade circuit, compatible with all person Multi-Tools.

This module can be wired into a Multi-Tool at a Space Station [[Multi-Tool Upgrade Station]], granting the user more space in the Multi-Tool's internal layout to add further upgrades or technology specialisations.

## Source

- Can be chosen as a reward after completing a [[Manufacturing Facility]]'s puzzle. (100%)
- From Crashed Freighter containers (4%)
- Pirate Missionboard (3%)
- Nexus Missions (2%)
- Buried Cache (2%)
- Mission Board (1%)
- Rare reward when interacting with NPCs (0.7%)
- When opening Suspicious Packet (Goods) (0.3%)
- Can also be obtained when scrapping multi-tools in the Anomaly, with a higher reward chance the higher the tier of the scrapped multi-tool.

## Additional Information

- It can be exchanged at the **Multi-Tool Upgrade Station** to increase [[Multi-Tool]] inventory size by one slot.  Without these, the player must pay units to add slots to their multi-tool, at increasingly exorbitant rates.
- When fully unlocking all slots on a multi-tool, for the final 60th slot, a single Multi-Tool Expansion Slot can save 600,000,000 units, showing how valuable these can be.
- Sources have been extracted from the 3.99.1 version of the **REWARDTABLE.MBIN** game file. The chances have been calculated based on the weights in that file.
