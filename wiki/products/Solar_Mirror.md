# Solar Mirror

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 6,150.0
- **Updated:** Expeditions

**Solar Mirror** is a component.

## Summary

**Solar Mirror** is a component that is used for crafting.

## Game description

A specialist optical component. Employing an impossibly polished surface, this mirror is able to selectively filter different wavelengths of light, changing its reflective pattern based on nearby magnetic fields.

Used in the creation of a wide range of advanced technologies.

## Source

- Blueprint can be found in Manufacturing Facilities and Operations Centres, or purchased from Synthesis Laboratory for 250.
- Available from some Galactic Trade Terminals.
- Available from some Technology Merchants for 5000+ units.

Solar Mirror can be built using a blueprint and the following ingredients:

- Gold ×40 + Silver ×30 + Chromatic Metal ×25 → Solar Mirror
