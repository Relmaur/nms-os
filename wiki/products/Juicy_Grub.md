# Juicy Grub

## Quick Facts

- **Category:** Consumable
- **Type:** Vile Larva
- **Value:** 11,000
- **Added in:** WorldsTwo

**Juicy Grub** is a consumable.

## Summary

**Juicy Grub** is a [[consumable]] that can be harvested from Juicy Grubs.

## Game Description

This pupa, pulsating and warm, has begun its transformation from throbbing sac of mucus into an unspeakably vile insectoid.

Theoretically processable in a [[Nutrient Processor]] to generate edible products.

WARNING: grub-sac will release powerful pheromones if violated.

## Nutrient Ingestor

Exosuit nutrient system will provide **+11% Sprint Recovery**.
- When consumed through a [[Nutrient Ingestor]], **Juicy Grub** provides **+11% Sprint Recovery** for 1:30 minutes.

## Source

Can be harvested from Juicy Grubs.
