# Projectile Ammunition

## Quick Facts

- **Category:** Consumable
- **Type:** Universal Ammo Module
- **Value:** 1.0
- **Added in:** Aquarius

**Projectile Ammunition** is a product.

## Summary

**Projectile Ammunition** is a [[product]] and one of the [[Product|Universal Ammo Modules]].

It can be inserted in [[Multi-tool]] clip reloading system and used with [[Boltcaster]], [[Pulse Spitter]], [[Scatter Blaster]] and [[Incinerator]]. Crafting this item produces 1250 units of Projectile Ammunition, and each stack can hold up to 9,999 units.

## Game description

Advanced munition fragments, constructed to fit Universal Multi-Tool Standard 07/FF1.

Easily inserted into the Boltcaster, Pulse Spitter and Scatter Blaster via the Multi-Tool clip reloading system.

## Source

- **Crafting**: 50 × [[Ferrite Dust]] → 1250 × Projectile Ammunition

## Trivia

- Based on the sprite, it can be assumed the ammunition is loaded as-is to either be decoupled in an internal feed system for semiautomatic or automatic fire modes or discharged in a multi-chamber system for scattered fire.
- This would indicate the Scatter Blaster fires a spray of massive slugs instead of the equivalent of buckshot.
