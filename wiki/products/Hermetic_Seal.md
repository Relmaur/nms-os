# Hermetic Seal

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 800.0
- **Updated:** Origins

**Hermetic Seal** is a component.

## Summary

**Hermetic Seal** is a component that is used for crafting.

## Game description

A high-performance carbon seal, able to withstand both the harsh interstellar environment and the rigours of intensive, high-energy industrial use.

User is advised to regularly check seal integrity after installation.

## Source

Available from some Galactic Trade Terminals.

Hermetic Seal can be built using a blueprint and the following ingredients:

- Condensed Carbon ×30 → Hermetic Seal

## Use

**Hermetic Seal** is used as an ingredient for crafting the following products:

- Advanced Mining Laser -- Carbon Nanotubes x1 + Hermetic Seal x1 + Wiring Loom x2 → Advanced Mining Laser
- Atmosphere Harvester -- Ammonia x100 + Metal Plating x2 + Hermetic Seal x2 → Atmosphere Harvester
- Impact Igniter -- Phosphorus x200 + Hermetic Seal x4 + Wiring Loom x1 → Impact Igniter
- Medi-Pod -- Gold x50 + Hermetic Seal x3 + Amino Chamber x1 → Medi-Pod
- Nonlinear Optics -- Hermetic Seal x2 + Wiring Loom x1 + Tritium x100 → Nonlinear Optics
- Nutrient Processor -- Metal Plating x2 + Hermetic Seal x1 + Sodium x25 → Nutrient Processor
- Nutrition Unit -- Silver x30 + Gold x50 + Hermetic Seal x1 → Nutrition Unit
- Paralysis Mortar -- Hermetic Seal x2 + Di-hydrogen Jelly x2 + Wiring Loom x1 → Paralysis Mortar
- Plasma Launcher -- Amino Chamber x1 + Hermetic Seal x1 + Wiring Loom x1 → Plasma Launcher
- Pressure Membrane -- Oxygen x150 + Hermetic Seal x3 + Hydrothermal Fuel Cell x2 → Pressure Membrane
- Thermal Buffer -- Dioxite x80 + Hermetic Seal x2 + Wiring Loom x1 → Thermal Buffer

## Additional information

- It is required to repair the starship's Pulse Engine
- It is a bad idea to help a new player out while they are doing the first mission Awakenings, as it can cause a variety of problems. For example, giving them a Hermetic Seal will cause them to never get the blueprint for it; as the game expects them to get it from a nearby building near the start of the game.
