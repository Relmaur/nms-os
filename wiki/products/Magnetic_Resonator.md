# Magnetic Resonator

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 6,150.0
- **Updated:** Prisms

**Magnetic Resonator** is a component.

## Summary

**Magnetic Resonator** is a component that is used for crafting.

## Game description

An electromagnetic frequency oscillator, able to function in a wide-range of conditions thanks to both ferrous and non-ferrous magnetic properties.

Used in the creation of a wide range of advanced technologies.

## Source

- Blueprint can be found in Manufacturing Facilities and Operations Centres, or purchased from Synthesis Laboratory for 250.
- Available from some Galactic Trade Terminals.
- Available from some Technology Merchants for 5000+ units

Magnetic Resonator can be built using a blueprint and the following ingredients:

- Magnetised Ferrite ×40 + Ionised Cobalt ×40 → Magnetic Resonator
