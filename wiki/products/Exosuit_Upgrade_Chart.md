# Exosuit Upgrade Chart

## Quick Facts

- **Category:** Constructed Technology
- **Type:** Encrypted Navigation Data
- **Value:** 85,000.0
- **Added in:** WorldsOne

**Exosuit Upgrade Chart** is a Constructed Technology.

## Summary

**Exosuit Upgrade Chart** is a [[Constructed Technology]] and can be activated in one's inventory to locate a [[Drop Pod]].

## Game description

Encoded navigation data which, when properly decrypted, will reveal the location of a Drop Pod containing an Exosuit Inventory Upgrade.

Select the coordinates in the inventory and use Plot Route to pin the location in your Exosuit display.

## Source

- Can be purchased on [[Space Station|Space Stations]] from Cartographer.
- Can be received from [[Ancient Data Structure|Ancient Data Structures]] found on planets.
- Can be bought from the NPC vendor at some [[Minor Settlement|Minor Settlements]] or [[Colossal Archive|Colossal Archives]].
- May be provided as a reward for helping repair [[Crashed Ship]], [[Damaged Machinery]], or assisting to repair a NPC [[starship]] while in space
- Can be rewarded for completing [[The Nexus|Nexus missions]].
- Can be occasionally purchased at [[Trade Outpost|Trade Outposts]] at the [[Galactic Trade Terminal]]
- Can be often bought at the [[Freighter]]'s installable [[Galactic Trade Terminal]]
