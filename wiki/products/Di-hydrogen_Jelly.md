# Di-hydrogen Jelly

## Quick Facts

- **Category:** Component
- **Type:** Portable Life Support Power
- **Total Value:** 200.0
- **Updated:** Fractal

**Di-hydrogen Jelly** is a component.

## Summary

**Di-hydrogen Jelly** is a component that is used for crafting.

## Game Description

A faintly-glowing jelly. Its gentle light and soft wobble belie the fact that this sticky gel is both highly toxic and highly flammable. Skin contact is to be avoided at all costs.

Synthesised from Di-hydrogen.

## Source

Available from some Galactic Trade Terminals.

Di-hydrogen Jelly can be built using a blueprint and the following ingredients:

- Di-hydrogen ×40 → Di-hydrogen Jelly

Di-hydrogen Jelly can be refined using a Refiner with the following ingredients:

- Di-hydrogen ×30 → Di-hydrogen Jelly ×1 (*"Condense Di-hydrogen"*, 60 sec./unit output)

## Use

### Crafting

**Di-hydrogen Jelly** is used as an ingredient for crafting the following products:

- Construction Specialist's Room -- Silver x50 + Di-hydrogen Jelly x2 + Chromatic Metal x20 → Construction Specialist's Room
- Efficient Thrusters -- Di-hydrogen Jelly x1 + Tritium x100 + Wiring Loom x2 → Efficient Thrusters
- Fishing Rig -- Carbon Nanotubes x3 + Di-hydrogen Jelly x1 + Chromatic Metal x60 → Fishing Rig
- Life Support Gel -- Di-hydrogen Jelly x1 + Carbon x20 → Life Support Gel
- Medium Refiner -- Magnetised Ferrite x100 + Di-hydrogen Jelly x5 → Medium Refiner
- Oxygen Harvester -- Metal Plating x5 + Life Support Gel x5 + Di-hydrogen Jelly x3 → Oxygen Harvester
- Paralysis Mortar -- Hermetic Seal x2 + Di-hydrogen Jelly x2 + Wiring Loom x1 → Paralysis Mortar
- Pilgrim Geobay -- Metal Plating x5 + Di-hydrogen Jelly x5 + Silver x100 → Pilgrim Geobay
- Race Force Amplifier -- Metal Plating x5 + Di-hydrogen Jelly x2 → Race Force Amplifier
- Refiner Room -- Silver x60 + Di-hydrogen Jelly x2 + Gold x45 → Refiner Room
- Save Point -- Metal Plating x2 + Di-hydrogen Jelly x1 → Save Point
- Terrain Manipulator -- Di-hydrogen Jelly x1 + Carbon Nanotubes x2 → Terrain Manipulator

### Refining

**Di-hydrogen Jelly** is used as an ingredient for refining the following products using a Refiner:

- Di-hydrogen -- Di-hydrogen Jelly x1 → Di-hydrogen x40 (*"Di-hydrogen Cycling"*, 4 sec./unit output)

### Cooking

**Di-hydrogen Jelly** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

- It is required to repair the starship's Launch Thruster.
- Exploit - Because Di-hydrogen Jelly can be *refined* from only 30 Di-hydrogen using a refiner (compared to 40 Di-hydrogen from direct crafting), you can multiply your reserves of both Di-hydrogen and Di-hydrogen Jelly infinitely. It should be noted however that this method is rather slow and tedious compared to most other methods. For further information, see the "Exploit" section on the Di-hydrogen page.
