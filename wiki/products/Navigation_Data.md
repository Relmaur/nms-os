# Navigation Data

## Quick Facts

- **Category:** Curiosity
- **Type:** Encrypted Navigation Data
- **Value:** 1,000.0
- **Added in:** Waypoint

**Navigation Data** is a curiosity.

## Summary

**Navigation Data** is a [[curiosity]].

## Game description

Encoded navigation data. This highly portable data unit contains all relevant cartographical information for a planetary region.

May be traded with a [[Cartographer]] aboard a [[Space Station]] in exchange for usable [[Planetary Chart|star charts]].

## Source

- Can be received from [[Ancient Data Structure|Ancient Data Structures]], [[Cargo Drop|Red Canister Debris]] and [[Encrypted Navigation Data]].
- Also available from some [[Galactic Trade Terminal|Galactic Trade Terminals]].
- Can be received in multiple quantity using the Tower Calibration station at the top of an S-Class Tower (such as a Hydro-Refinery) constructed at a [[Planetary Settlement]]. (See [[Planetary Settlement - Construction Opportunities|Construction Opportunities: Player Benefits]] for details)
- Often available from minor outpost Galactic Trade Terminal

## Additional information

During [[NEXT]], Navigation Data could be used on a [[Signal Booster]] to locate [[Point of Interest|Points of Interest]].

Navigation Data may also be used to call starships to landing sites.

Reward table (<code>REWARDTABLE.MBIN</code>) entries for above documented behaviour are:
- Exchange 1 Navigation Data: <code>SEC_STARMAP</code>
- Exchange 5 Navigation Data: <code>SEC_STARMAP5</code>
- Exchange 10 Navigation Data: <code>SEC_STARMAP10</code>

## Release history

- [[NEXT]] - Added as a curiosity. It has the same icon as [[Master Circuit]], [[Quantum Processor]] and certain [[Upgrade Module]] types.
- [[Beyond]] - Navigation Data can be traded for a Planetary Chart.
- [[Frontiers]] - 5 navigation data can be exchanged for a settlement location, at a cartographer
- [[Waypoint]] - Icon changed.
