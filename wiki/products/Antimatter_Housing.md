# Antimatter Housing

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 6,500.0
- **Updated:** Frontiers

**Antimatter Housing** is a component.

## Summary

**Antimatter Housing** is a component needed to craft a Warp Cell.

## In-game description

Secure antimatter containment device, required before Antimatter can be safely secured as Warp Cells.

Rebound Oxygen forms a protective gas pocket, preventing the antimatter from reacting with the surrounding casing.

## Source

**Antimatter Housing** can be purchased at Galactic Trade Terminals and Planetary Technology Merchants.

This item has a 10% chance to drop out of barrel-type cargo. The AtlasPass v1 access card is required to open these.

Antimatter Housing can be built using a blueprint and the following ingredients:

- Oxygen ×30 + Ferrite Dust ×50 → Antimatter Housing

## Use

Crafting
**Antimatter Housing** is used as an ingredient for crafting the following products:

- Plasmatic Warp Injector -- Emeril x250 + Solar Mirror x1 + Antimatter Housing x5 → Plasmatic Warp Injector
- Reality De-Threader -- Indium x250 + Magnetic Resonator x1 + Antimatter Housing x6 → Reality De-Threader
- Warp Cell -- Antimatter Housing x1 + Antimatter x1 → Warp Cell
- Warp Core Resonator -- Cadmium x250 + Quantum Computer x1 + Antimatter Housing x4 → Warp Core Resonator
