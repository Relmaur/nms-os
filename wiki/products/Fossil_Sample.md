# Fossil Sample

## Quick Facts

- **Category:** Artifact
- **Type:** Fossil Sample
- **Value:** 2,295,346.0
- **Used for:** Trading, Trading (High Value)
- **Added in:** Singularity

**Fossil Sample** is a type of artifact.

## Summary

**Fossil Sample** is one of several types of [[artifact|artifacts]] and it is a reward for opening [[Large Artifact Crate|Large Artifact Crates]] found in Ancient [[Ruin|Ruins]], completing [[Mission Board|missions]] or completing exploration type expeditions with [[frigate|frigates]].

It can be exchanged at an [[Artifact Exchange Vault]] with the potential reward of an exchanged artifact of equal or more value.

The names are procedurally generated with certain terms using one of the following options: 1. Adjective + Animal + Part; 2. Adjective + Animal + Part.
