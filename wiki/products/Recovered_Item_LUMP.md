## Name Generation

The names are procedurally generated with certain terms using the following format: Adjective + Noun.

The sequence is taken from the game file.

**Trivia**: It is theoretically possible - by combining adjective #19 with noun #4 - for a Lump to generate with the name **Viscous Fluids**, therefore colliding name-wise with the actual item [[Viscous Fluids]].

**Note**: The nouns #9 and #10 are actual duplicates in the game files and not an error in the wiki. Therefore, accounting for duplicates, the total number of possible names is 266.
