# Delicate Flora (PLNT)

## Quick Facts

- **Category:** Artifact
- **Type:** Delicate Flora
- **Value:** 2,298,409
- **Used for:** Trading, Trading (High Value)
- **Added in:** Singularity

**Delicate Flora (PLNT)** is a type of [[Artifact]].

## Summary

**Delicate Flora (PLNT)** is one of several types of [[Artifact|Artifacts]] and it is a reward for opening [[Large Artifact Crate|Large Artifact Crates]] found in Ancient [[Ruin|Ruins]], completing [[Mission Board|missions]], completing exploration type expeditions with [[frigate]], breaking open [[Emergency Containment Device]] anomolies or completing a daily task given by the [[Farmer (NPC)|Farmer]].

## Name generation

The names are procedurally generated with certain terms using one of the following options: 1. Box + (Part1)(Part2) + Noun; 2. (Part1)(Part2) + Noun.

Delicate Flora (PLNT) and  [[Delicate Flora (FARM)]] use the same name generation, therefore they have the same naming order.

The sequence is taken from the game file.
