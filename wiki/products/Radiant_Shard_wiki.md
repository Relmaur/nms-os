# Radiant Shard

## Quick Facts

- **Category:** Component
- **Type:** Glassy Reality Intrusion
- **Total Value:** 1,900.0
- **Used for:** Crafting, Charging, Upgrading, Refining
- **Updated:** Echoes

**Radiant Shard** is a component.

## Summary

**Radiant Shard** is a component that is used for crafting.

## Game Description

A fragment of glassy lifeforce, chipped from a larger formation. Dynamic intermolecular binding gives the shard a strangely flexible, sinewy quality. It writhes gently, almost as if it were seeking something...

Highly sought after for salvage operations, as it can be used to bypass the security systems of key Sentinel ship technologies.

## Sources

- Mining large purple crystals on Dissonant Planets.

## Use

### Crafting

**Radiant Shard** is used as an ingredient for crafting the following products:

- Resonance Amplifier -- Di-hydrogen x160 + Gravitino Ball x3 + Radiant Shard x1 → Resonance Amplifier
- Scan Harmoniser -- Radiant Shard x1 + Microprocessor x1 + Runaway Mould x100 → Scan Harmoniser

### Refining

**Radiant Shard** is used as an ingredient for refining the following products using a Refiner:

- Nanite Cluster -- Radiant Shard x1 → Nanite Cluster x50 (*"Subjugation of Glass"*, 7.2 sec./unit output)

### Cooking

**Radiant Shard** is not used as an ingredient for cooking using a Nutrient Processor.
