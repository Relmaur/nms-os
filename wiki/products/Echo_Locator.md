# Echo Locator

## Quick Facts

- **Category:** Curiosity
- **Type:** Harmonic Location Tracker
- **Value:** 3,200
- **Added in:** Singularity

**Echo Locator** is a curiosity.

## Summary

**Echo Locator** is a [[curiosity]].

## Game Description

A curious mesh of old and new technology, a hybrid between two entirely separate methods of creation. Nonetheless, this location tracing device appears fully functional.

Select this device and use Resonate (// (PC/PS/XB)) to trace its harmonic origin.

## Source

Echo Locators are obtained via destroying a [[Dissonance Resonator]], as alternative loot to the common [[Inverted Mirror]] required to unlock crashed [[Sentinel Interceptor|Sentinel Interceptors]].  Echo Locators can also be found as a random drop from [[Corrupted Sentinel Quadruped|Corrupted Sentinel Quadrupeds]].

## Use

Can be used to locate a [[Harmonic Camp]]. Will be consumed on use.

## Additional Information

Destroying a Dissonance Resonator will trigger nearby [[Corrupted Sentinel Drone|Corrupted Sentinels]].

Activating the Echo Locator will try to locate the nearest Harmonic Camp within approximately 20ks. If no Harmonic Camp is located within the range, it will point to a specific Harmonic Camp, if one can be found within the planet/system.
