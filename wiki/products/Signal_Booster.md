# Signal Booster

## Quick Facts

- **Category:** Technology
- **Type:** Environmental scanner
- **Value:** 1.0
- **Added in:** Remnant

**Signal Booster** is a base building product.

## Summary

**Signal Booster** is a portable [[base building]] [[product]] that helps the player to locate structures, and resources and to obtain the [[Galactic Coordinates]] of the star system of the planet.

It is similar to the signal transmitter pole (also known as "save point"). When placed on a planet surface, inside or outside a base in any location, they will display the star system galactic coordinates and provide the user with an interaction menu. Upon interaction the player may choose "Locate Nearby Structures" to locate a random point of interest on the same planet.

## Game description

A versatile scanner that detects nearby buildings. Can decrypt Navigation Data to pinpoint specific locations.

The Signal Booster can be dismantled and redeployed for easy transportation.

## Build

- **Crafting**: 1 × [[Metal Plating]] + 1 × [[Carbon Nanotubes]] + 15 × [[Sodium]] → 1 × Signal Booster

## Options

<code>Locate Nearby Structures</code> has different effects based on the Signal Booster's location. Before [[Update 1.63|NEXT 1.63]], if the Signal Booster had been placed next to a [[Point of Interest]], this function will locate and mark another point of interest of the same type. Otherwise or since NEXT 1.63, <code>Locate Nearby Structures</code> will find and mark a nearby point of interest without restricting its type.

Since [[Beyond]], the Signal Booster cannot locate a specific type of Point of Interest. Instead, players can exchange Navigation Data for [[Planetary Chart]] with a **Cartographer**. Activating appropriate Planetary Chart from the inventory will mark a Point of Interest on the same or (if not on any) on the closest one.

There were more options in earlier versions, which have since been removed.

### Beyond to Endurance

The <code>Decipher</code> option allows the player to locate a Drop Pod to upgrade their inventory. It consumes one [[Drop Pod Coordinate Data]].

### Pre-Beyond

The <code>Input Data</code> option allows the player to select a "frequency range", which will further specify what kind of point of interest the player is looking for:
- Scan Secure Frequencies - Locates a [[Manufacturing Facility]], [[Depot]] or [[Operations Centre]]
- Scan Distress Frequencies - Locates a [[Drop Pod]], [[Observatory]], [[Abandoned Building]], [[Crashed Freighter]] or [[Crashed Ship]]
- Scan Habitable Outposts - Locates a [[Habitable Base]], [[Minor Settlement]], [[Shelter]] or [[Transmission Tower]]
- Scan for Artifacts - Locates an [[Plaque]], [[Monolith]] or [[Ruin]]
It consumes one [[Navigation Data]].

The Signal Booster will only reveal one location of the same type at once. If the Signal Booster located a location of each type within a frequency range, further scans in the same range will yield no result and the Navigation Data is lost.

Please see the respective links for more information about these points of interests.

## Additional Information

When placed on a [[planet]] or [[moon]] every Signal Booster emits [[Galactic Coordinates|coordinates]] when approached. It looks something like this one from the video below:

The 3 sections in the middle (046A:0081:0D6D) can be entered into a [[Coordinate Plotting App]] such as the [Pilgrim Star Path by: pahefu](https://pahefu.github.io/pilgrimstarpath/) or [No Man's Connect - Online Location Manager by: jaszhix](http://www.nexusmods.com/nomanssky/mods/363/?) to aid in galactic navigation.

For additional information, see [[Coordinates Guide]].

The Signal Booster is a portable technology which can be picked up and stored in the player's inventory as a distinct item, then redeployed in another location.

The item description still mentions the ability to decipher navigation data, despite the fact that this function has been removed.

The Signal Booster's <code>Locate Nearby Structures</code> option is normally free to use. Save files with the [[Game mode|Abandoned Universe modifier]], however, add a [[Surge Battery]] cost which must be paid on each use of this option.

## Release History

- [[Release]] - Added as a product. Signal Scanners showed the location of monoliths and shelters instead of resource deposits and [[Habitable Base|bases]].
- [[Update 1.10|Foundation]] - Signal Boosters replaced Signal Scanners as the main structure to aid in planetary navigation. Before this update, Signal Scanners were found on planetary surfaces and had to be unlocked with [[Bypass Chip|Bypass Chips]].
- [[Pathfinder]] - The **Colonial Outpost** option revealed the position of either a Manufacturing Facility or an Operations Centre.
- [[NEXT]] - Blueprint changed, formerly used [[Iron]] and [[Plutonium]]. It is now portable and options changed, formerly offered "Drop Pod", "Habitable Base", "Monolith" and "Resource Deposit" options.
- [[Update 1.57|NEXT 1.57]] - Fixed an issue that could cause the "Locate Nearby Structures" scan to fail.
- [[Update 1.63|NEXT 1.63]] - Fixed an issue that caused the "Locate Nearby Structures" option to find only buildings of the same type as the nearest building.
- [[Beyond]] - Options to select specific Points of Interest removed from the Signal Booster menu.
- [[Waypoint]] - Option removed to decipher Drop Pod Coordinate Data.
