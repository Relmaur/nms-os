# A Dreadful Wailing

## Quick Facts

- **Category:** Expedition tool
- **Type:** Loop Artifact
- **Value:** 16
- **Used for:** Expedition
- **Added in:** Outlaws

**A Dreadful Wailing** is an Expedition 7 reward.

## Summary

**A Dreadful Wailing** is one of the rewards in [[Expedition 7: Leviathan]]. It does not have any active uses, but is required for **Another Chance** task in Iteration 5.

## Game description

A relentless, despairing cry that will not let you rest. Listen at a personally significant location to remember what has been forgotten.

## Source

A Dreadful Wailing is obtained as a reward for reaching Anchor Point 5 in the Expedition 7: Leviathan.
