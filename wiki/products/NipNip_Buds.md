# NipNip Buds

## Quick Facts

- **Category:** Curiosity
- **Type:** Medicinal Substance
- **Value:** 47,284
- **Used for:** Building
- **Added in:** Echoes

**NipNip Buds** is a plant.

## Summary

**NipNip Buds** is a [[curiosity]] that can be harvested from the [[NipNip]] plant.

## Game Description

A pungent bud harvested from the NipNip plant, often used to produce [[GekNip|Gek Nip]].

## Source

The primary source is harvesting.

- Can be purchased in outlaw systems.
- Can be occasionally bought from [[Scrap Dealer|Scrap Dealers]] on space stations.
- Can be found in [[Derelict Freighter]] containers.
- Can occasionally be given as a reward for [[The Nexus|Nexus missions]].
- Can occasionally be purchased on planets from black market traders for nanites.
- Can occasionally be purchased on planets from landed ships.
- It is a possible reward from [[frigate]] expeditions.

## Use

Can not be consumed normally through inventory.
