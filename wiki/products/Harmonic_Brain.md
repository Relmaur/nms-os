# Harmonic Brain

## Quick Facts

- **Category:** Component
- **Type:** Harnessed Sentience
- **Total Value:** 480,016.0
- **Updated:** Singularity

**Harmonic Brain** is a component.

## Summary

**Harmonic Brain** is a component that is used for upgrading.

## Game Description

The central processing unit of a Sentinel interceptor ship. The circuitry appears stable, pulsing with a regular electrical heartbeat. It no longer reacts angrily to my presence.

Status: DOCILE

Install this unit in a disabled Sentinel ship to unlock its vestigial cockpit and enable manual piloting.

## Sources

- Received by presenting a Hyaline Brain (obtained from a crashed Sentinel Interceptor) to a Monolith
