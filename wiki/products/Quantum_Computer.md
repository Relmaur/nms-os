# Quantum Computer

## Quick Facts

- **Category:** Component
- **Type:** Crafted Technology Component
- **Total Value:** 4,200.0
- **Updated:** Frontiers

**Quantum Computer** is a component.

## Summary

**Quantum Computer** is a component that is used for crafting.

## Game description

An extremely fast advanced processing unit. Allows real-time solving of otherwise impossible calculations. However, protection against decoherence is not guaranteed.

Used in the creation of a wide range of advanced technologies.

## Source

- Blueprint can be found in Manufacturing Facilities and Operations Centres, or purchased from Synthesis Laboratory for 250.
- Available from some Galactic Trade Terminals.
- Available from some Technology Merchants for 5000+ units
- Can be produced from Salvaged Glass.

Quantum Computer can be built using a blueprint and the following ingredients:

- Microprocessor ×1 + Antimatter ×1 + Chromatic Metal ×25 → Quantum Computer
