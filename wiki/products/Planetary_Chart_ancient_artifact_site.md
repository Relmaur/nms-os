# Planetary Chart (ancient artifact site)

## Quick Facts

- **Category:** Curiosity
- **Type:** Cartographic Data
- **Value:** 3,200
- **Added in:** Waypoint

**Planetary Chart** is a curiosity.

## Summary

**Planetary Chart** is a [[curiosity]].

## Game description

A map of a nearby planet. An ancient artifact site has been marked.

Select the map and use Plot Route (// (PC/PS/XB)) to pin the location in your Exosuit display.

New maps can be gained by exchanging Navigation Data with a Space Station Cartographer.

## Source

Randomly obtained from all types of [[Planetary Chart]] from the Cartographer on a space station in exchange for Navigation Data.

## Additional information

Internal game identifier is <code>STARCHART_D</code>. A variant, <code>A1S6_STARMAP</code>, exists with the same description.

This item indicates the location of one of the following locations type in the current star system:
- [[Plaque]] (33.3% chance)
- [[Monolith]] (33.3% chance)
- [[Ruin]] (33.3% chance)

Chances are driven by the reward table (<code>METADATA/REALITY/TABLES/REWARDTABLE.MBIN</code>) entry <code>R_STARCHART_D</code>.
