# Dream Aerial

## Quick Facts

- **Category:** Curiosity
- **Type:** Subconscious Access Device
- **Value:** 16
- **Added in:** Cosmos

**Dream Aerial** is a curiosity.

## Summary

**Dream Aerial** is a [[curiosity]] used to locate [[Organic Frigates]].

## Game description

A signal receiver and amplifier, tuned to the wavelength of the unconscious mind. It is every colour all at once, splitting the surrounding light into a shimmering rainbow.

Use Relay Song (E) while in deep space to search for cosmic megafauna.

## Source

The blueprint can be obtained from frigate expeditions.

- **Crafting** · needs the blueprint: 3 × [[Living Glass]] + 1 × [[Solar Mirror]] → 1 × Dream Aerial

## Use

Upon use a new location in the current star system will be revealed where the living frigate can be located.

Each system has exactly one living frigate it can offer.  Unlike a freighter which allows you to re-roll the class by reloading, the frigate's name and class are always the same in the same system. If you reject the first one you find, you must switch to another system to get one with a different class.

Upon accepting a living frigate from a system, no further living frigates can be recruited from it. Trying to use another Dream Aerial in that system will result in an error, notifying the player that there is no cosmic megafauna present in the system.

## Additional information

A list of documented frigates can be found in the [[Starship Catalogue - Frigate]].
