# Dynamic Resonator

## Quick Facts

- **Category:** Component
- **Total Value:** 27500
- **Updated:** Atlas Rises

**Dynamic Resonator** is a product used in crafting.

## Summary

An electromagnetic frequency oscillator used in constructing many technological items.

## Game description

Electromagnetic frequency oscillator. A device necessary in the construction of many of the technologies that aid in the exploration of the galaxy.

## Source

Dynamic Resonator cannot be crafted.

Original formula:

Antimatter x2 + Chrysonite x100 + Microdensity Fabric x4 → Dynamic Resonator

Dynamic Resonators could also be purchased at a Galactic Trade Terminal.

## Use

### Crafting

**Dynamic Resonator** is not used as an ingredient for crafting.

### Refining

**Dynamic Resonator** is not used as an ingredient for refining using a Refiner.

### Cooking

**Dynamic Resonator** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

The resource type is Oxide, and is shown when a formula containing it is pinned.
