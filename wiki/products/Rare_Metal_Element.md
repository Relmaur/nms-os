# Rare Metal Element

## Quick Facts

- **Category:** Curiosity
- **Type:** Concentrated Metal Deposit
- **Value:** 4,200.0
- **Added in:** Origins

**Rare Metal Element** is a curiosity.

## Summary

**Rare Metal Element** is a [[curiosity]] and it is worth 4,200  Units each.

## Game description

A highly-prized metal product, this rare element is used in the manufacture of several advanced technologies.

Metal is highly reactive and quickly bonds to exposed skin. User is advised to handle with extreme caution.

Synthesised from Magnetised Ferrite.

## Source

A possible reward from [[Frigate|Frigates]] expeditions.
