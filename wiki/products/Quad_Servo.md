# Quad Servo

## Quick Facts

- **Category:** Component
- **Type:** Anomalous Material
- **Total Value:** 20,000.0
- **Updated:** Frontiers

**Quad Servo** is a component.

## Summary

**Quad Servo** is a component that is used for crafting.

## Game Description

A highly sprung motor arm salvaged from inside of a Sentinel patrol unit. It occasionally twitches, as if experiencing the echo of combat.

## Source

It can be obtained by the following methods:

- destroying the Combat Supplies containers dropped by Sentinel Quads
- Suspicious Packet (Goods) from the Scrap Dealer
- a gift from Guild Envoys of the Mercenaries Guild

## Use

**Quad Servo** is used as an ingredient for crafting the following products:

- Fuel Oxidiser -- Quad Servo x2 + Gold x50 → Fuel Oxidiser
- Liquidator Legs -- Quad Servo x1 + Hydraulic Wiring x2 → Liquidator Legs
