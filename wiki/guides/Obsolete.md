# Obsolete

**Obsolete** is a game mechanic page.

## Summary

**Obsolete** refers to objects that have become outdated. These objects were valid in earlier updates but are no longer available because they were removed from the game. Obsolete objects include certain types of Technology.

Gameplay methods may also become obsolete when they are no longer effective.

## Obsolete Objects

In No Man's Sky, obsolete objects are items or technologies that have been phased out or replaced by newer versions in later updates.

Resources can become obsolete. Obsolete resources can no longer be crafted. If a resource was unlearned, its Blueprint can no longer be researched. Loading a save file containing an obsolete resource in a version where that resource was removed will cause it to be deleted from the player inventory or replaced with an advanced version of the same resource.

Technology behaves in a similar way. If an obsolete technology exists in a save file from a version in which that technology was removed, it is replaced with Obsolete Technology.

In terms of lore, obsolete technology is considered to be corrupted by The Atlas.

Obsolete objects are placed in this category. Obsolete technologies are placed in this category instead.

## Obsolete Methods

Some gameplay methods have become obsolete. These methods have no associated lore. When a bug or exploit that enables a method is fixed, the method becomes ineffective and is therefore considered obsolete.

An example is the Black Hole Roulette method. This method involved entering a star system that contained a Black Hole and creating a save point in order to approach the Galaxy Centre.

## Discontinued Objects

Discontinued objects are not considered obsolete, although they are similar. These objects are also removed from the game, like obsolete resources and technologies. However, players who obtained these objects before their removal are able to keep them. The same rule applies to technology.

If an object is removed before a player obtains it, the object becomes unobtainable. Such objects may still be acquired using Third-Party Tools such as NomNom Save Editor, or by returning to a game version released before the object was removed.
