# Base Complexity Item Values

**Base Complexity Item Values** is an index page.

## Summary

**Base Complexity Item Values** are values that are assigned to each structure type available within a Player base. Reddit user *Nazgutek* has done extensive testing and has posted an almost complete list of these values.

## Purpose

This table provides players invaluable information when planning their base construction. A maximum of 2000 points can be used when building a base.

## Testing notes from Nazgutek

Method:

- dropped base limit value to 1000 (PC Config edit)
- Built cuboid rooms until base complexity was 91%
- Found item that required building 10 to raise base complexity by 1% (Infrastructure Sphere in this case)
- Ensured 10 1pt items raised base complexity from 91% to 92% to verify total base complexity was exactly 910
- Verified rounding behaviour by building up to 98% then placing 1pt items to tick to 99%, then being able to place 9 more to hit 99% and the limit warning.
- Placed items either multiple times or with Spheres to derive values.

Note: I had weird behaviour with storage containers, and found container #4 only cost 1 point.
