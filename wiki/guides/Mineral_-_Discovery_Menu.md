# Mineral - Discovery Menu

**Mineral - Discovery Menu** is a game mechanics page.

## Summary

The Discovery Menu section on a Mineral discovery page. This page is accessed by clicking on a mineral graphical icon on the Planet Discovery Menu.

The page is composed of several text sections describing a mineral. These sections include:

- **Name** - the mineral name (or rename if applicable)
- **Discovered** - the name of the player that discovered the mineral, and when
- **Metal Content** - numerical percentage descriptor=
- **Formation Process** - text descriptor
- **Notes** - text descriptor

## Name Generation

The names are procedurally generated with certain customized terms (such as the name of the planet) being inserted in the proper spot.
