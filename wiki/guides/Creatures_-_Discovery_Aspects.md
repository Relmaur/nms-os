# Creatures - Discovery Aspects

**Creatures - Discovery Aspects** is a game mechanics page.

## Summary

The Discovery Menu section on a Fauna discovery page includes a selection of three to five descriptive sentences that are generated based on certain creature aspects. This page provides a cross-reference of these sentences and their related aspects, linking biome types and Analysis Visor scan keywords to Discovery Menu sentences.

The tables are organized according to the common order of sentences in Discovery Menu paragraphs, namely:
**Environment -> Behaviour -> Diet.**
