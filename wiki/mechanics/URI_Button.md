# URI Button

**URI Button** is part of game mechanics.

## Summary

The **URI Button** is a means of starting a new game on a chosen specific planet.

The URI is the address that you get in [[Photo Mode]], it starts with <code>nms://location:</code>. Enter any URI in the URI input field and you will start a new game on the closest astronomical body. Default is [[Creative mode]], but there's a workaround for people who want to use a different mode.

URI stands for Uniform Resource Locator. The colour code in the screenshots is computer-readable, while the URI location is the format for copying and pasting, while the [[Glyphs]] are the human-readable in-game coordinates.

## How to travel to an URI

1. Load whichever save file you want, preferably one where you can travel/warp to the planet where you want to start your new playthrough.
1. Once you are on the planet of your choice, open the "Photo Mode". Notice the URI!
1. Capture a screenshot using Steam Overlay (F12) or the software of your choice.
1. Find a way to have the URI ready in front of you. For example, crop the URI and print a cleaned version of it.
1. Save and return to the "Choose Game Mode" screen.
1. Start a new game, and press the URI Button instead of choosing a Game Mode.
1. Enter the URI, starting with "<code>nms://location:</code>" (without the quotation marks) and confirm.

The URI-based game will load and it might bug a little bit, asking you to "initialize", like in "Normal Mode". After the loading, you will be on the planet of your choice.

## How to change the game mode

The default mode for this New Game is Creative. Follow the next steps if you prefer to play in Normal; the assumption is that this will also work for Permadeath and Survival.

1. To play in Normal mode: Go back to the Main Menu. Don't bother saving or anything...
1. Simply start a new game and select Normal.
1. The game will load and you'll spawn on the planet of your choice instead of a random planet.

## Additional Information

This was meant as an internal debugging tool at Hello Games, and has been stripped from the official game soon after it was introduced.
