# Game Content

**Game Content** is an index page.

## Summary

The **Game Content** is a page presenting all the information that can be found in the game with a similar setup, the tabs are the sections below. This way the player can easily refer to any related object, information or setting that can be found in the game.

## Discoveries

The [[Discoveries]] tab shows the player the recently discovered systems they visited in great details, including planetary information regarding [[flora]], [[fauna]] and [[mineral|minerals]] as well.

## Catalogue

The Catalogue tab shows a complete database of all discovered elements currently present in the game.
