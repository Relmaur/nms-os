# Starship Names

**Starship Names** is a game mechanics page.

## Summary

**Starship Names** describes the process used in generating [[starship]] names, and the various words that can be used.

Ship names can be generated using any of the following formats, with words selected from the categories below. Note that PROCNAME, NUMERAL, and SHIPCODE are procedurally generated, so their values are not listed.

| Method | Example |
| --- | --- |
| The %NOUN% of %PROPERTY% | [[The Spear of Abstraction]] |
| %PROCNAME%'s %ADJECTIVE% %VERB% | [[Aimineo's Inspiring Fabricator]] |
| %NOUN% of the %PROCNAME% | [[Anvil of the Nowadano]] |
| %PROCNAME% %VERB% %NUMERAL% | [[Adomaki Void-Dancer VIII]] |
| %ADJECTIVE% %NOUN% %SHIPCODE% | [[Exhausted Foe FW6]] |
| %ADJECTIVE% %PROCNAME% %NUMERAL% | [[Reckless Inuyamag XVI]] |
| %PROCNAME%'s %POSSESSION% | [[Sawasa's Indiscretion]] |
| %PROCNAME%'s %POSSESSION% %SHIPCODE% | [[Gayamat’s Transporter BU4]] |
| %PROCNAME%'s %ADJECTIVE% %POSSESSION% | [[Sembokut's Relentless Last Laugh]] |
| %PROCNAME% of %PROPERTY% | [[Aomoriy of Inevitability]] |
| %ADJECTIVE% %NOUN% %SHIPCODE% | [[Blazing Daughter IH6]] |
| %PROCNAME% %SHIPCODE% | [[Eppusio CP4]] |
| %SHIPCODE% %PROCNAME% | [[DV8 Zurug]] |
| %PREFIX% %PROCNAME% | [[The Haunted Kaiutsii]] |

## Prefix
