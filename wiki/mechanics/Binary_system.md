# Binary system

## Quick Facts

- **Type:** Star System
- **Description:** Type of system
- **Added in:** Orbital

**Binary system** is a type of star system.

## Main

A **binary system** is a [[Star system|Star]] system with two stars. The color can vary between any mixed combination of yellow, red, green and blue stars in appearance.

## Galaxy Map

Note that the [[Spectral class]] of the star as displayed on the [[Galactic Map]] will only identify the primary star spectral class, which determines solely the characteristics of resources in a star system.

The visual appearance of a binary system is only represented as a visual impression while in space in the star system.

## Skybox

The sky is a background so it is not possible to fly to any of the stars.

## Additional Information

For triple star systems, see [[Ternary system]].
