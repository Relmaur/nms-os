# Riverland Terrain

**Riverland Terrain** is a geographical feature.

## Summary

**Riverland Terrain**, refers to a occurrence of [[planet]] surfaces that have no oceans or seas but feature rivers of water the fill shallow or deep ravines. [[Moon|Moons]],  and  [[planet|planets]] will never have riverland terrain.

A planet with riverland terrain will feature very limited water.

The riverland planets will appear similar to pangean worlds from space in many cases.

## Types

No specific variation has been noticed as a repeating pattern on planets that would allow type categories at this time.

## Game application

In No Man's Sky, all features are procedurally generated, so any type of [[Terrain Archetype|archetype]] can be present in the game are by definition undetermined. This terrain *typically* occurs in combination with Craters, MESA, Hills or Honeycomb [[Terrain Archetype|Terrain Archetypes]], but it is not limited to those.

A game example of a riverland terrain planet is [[Decilipo Toga]].
