# Journey Milestones

**Journey Milestones** are in-game exploration achievements.

## Summary

**Journey Milestones** are in-game exploration achievements that the player can acquire during their exploration of [[No Man's Sky]]. Certain ranks reward the player with [[achievement|achievements]] (Steam and Xbox, or **trophies** on PlayStation).

## Additional information

- After reaching the highest rank of any Journey Milestones, the counter will not stop and counts the player's progression further.
- The names of each rank are extracted from the NMS_LOC1_ENGLISH.MBIN (1.77) game file, while the related values are extracted from the LEVELEDSTATSTABLE.MBIN (1.77) game file.
- The milestone titles are named after historic or ongoing space exploration missions, [see here](https://www.nasa.gov/missions).

### Generations

In the NMS_LOC1_ENGLISH.MBIN game file there is a Journey Milestone called Generations which has a description of *"I regenerated X time"*, where X means how many times the player [[death|died]], and names for each rank. This is not present in the LEVELEDSTATSTABLE.MBIN game file where values are specified.
