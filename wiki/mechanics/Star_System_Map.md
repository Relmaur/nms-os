# Star System Map

The **Star System Map** is an interface that displays points of interest in any star system.

## Summary

The **Star System Map** displays points of interest in any [[star system]].

It can be opened when the player is aboard a [[Starship]], [[Corvette]], [[Freighter]] or [[Space Station]] by opening the [[Quick Menu]] and selecting "Star System Map".

## Destinations

The Star System Map will display several locations in the local star system. These locations include [[planet|planets]] and their [[moon|moons]]. Other relevent locations are listed below.

- [[Deep Space Outpost]]
- [[Infested Outpost]]
- [[Space Hulk]]
- [[Minor Wreckage]]
- [[Asteroid Belt]]
- [[Ice Field]]
- [[Habitable Asteroid]]
- [[Habitable Comet Fragment]]
