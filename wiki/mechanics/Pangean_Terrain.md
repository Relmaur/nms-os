# Pangean Terrain

**Pangean Terrain** is a geographical feature.

## Summary

**Pangean Terrain**, refers to a common occurrence of [[planet]] surfaces that have no water.  All [[Biome - Exotic|exotic]] and [[Biome - Dead|dead]] [[planet|planets]] will be pangean. [[Moon|Moons]] are always pangean.

A planet with pangean terrain will not feature any water. This is distinct from the generally used definition of pangea as it refers to Earth, where one single super continent exists surrounded by oceans..

## Types

No specific variation has been noticed as a repeating pattern of pangean generation on planets that would allow type categories at this time.

## Game application

In No Man's Sky, all features are procedurally generated, so any type of [[Terrain Archetype|archetype]] can be present in the game are by definition undetermined.

A game example of a pangean planet is [[Dulverc]].
