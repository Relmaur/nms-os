# Buy Antimatter

## Quick Facts

- **Type:** Technology component
- **Description:** Matter used in Hyperdrive fuel cells.
- **Added in:** Atlas Rises

**Buy Antimatter** is a source-of-resources page.

## Summary

**Buy Antimatter** provides a list of locations for purchasing [[antimatter]] throughout the Galactic Hub. All discoveries were documented in PS4/Normal mode. If you would like to add a discovery, these links are helpful:

- [[Glyph]] Reference
- Pilgrim's Star Path [convert coordinates to Glyphs](https://pahefu.github.io/pilgrimstarpath/)

## Where to find the Blueprint for Antimatter

There is a crashed 35/10 B Rasa style ship in the following system: [https://imgur.com/gallery/ZN2Zp [HUBRE-$-149] Russka in the Rorouxalk Expanse].

- Coordinates are: 044C:0083:0D54:0149
- Glyphs:

At the marked crash site (choose planet with Rasa notation) there is the typical round beacon you'll see at crashed ship sites. **Choose the option that mentions the pilot to get the recipe for Antimatter**. If it doesn't work? Try a reload and choose the other option...
