# Star System - Discovery Menu

**Star System - Discovery Menu** is a game mechanics page.

## Summary

The Discovery Menu section on a [[star system]] discovery page is composed of several sections providing information about system.

This menu is accessed by ...

Selecting a star system from the left side of the screen (which shows the star system visit history), will provide a screen with these sections displayed:

- **Name** - the planet/moon name (or rename if applicable)
- **Edit/Upload Icon** - a pencil to the left of the name.
- **Discovered** - the name of the player that discovered the planet/moon, and when
- **Number of planets/moons** - Count of planets and moons
- **System Conditions Icons** - a set of three icons will be under the planet/moon count.
- **Graphical Image** - a visual image of the system with all planets/moons
- **Discovery Services Status** - Status of connection to Hello Games Discovery Servers

## Star System Name

The names are initially procedurally generated with certain customized terms and patterns recurring.  It is completely possible to observe repeated procedurally generated system names across the universe, however they are unlikely to occur in the same [[region]] of a [[galaxy]] based on observations collected by travellers.

If the system has been previously discovery and uploaded, then the player applied name will be displayed.

### Name Edit/Upload

The icon is visible in white when the name has not yet been edited/uploaded to the [[Discoveries|discovery]] servers of [[Hello Games]]. After it is edited and uploaded, it will be shaded out.  Only one traveller can update the system name, afterwards it is normally fixed and uneditable for other travellers.   Clicking on the icon to upload the name will reward the traveller with a small number of nanites.

In rare cases, systems that have been discovered in the past have changed names.  This mainly occurred during the cross platform PC/PS/Xbox universe merger during the [[Expeditions]] update.  For more information refer to [[Universe Evolution]] for details.

## System Status Icons

Three icons under the planet data will indicate the [[star system]] wide conditions for the dominant [[race]], the [[economy]] and the [[Conflict Level]] of the system.

## Discovery Services

The icon will be green if the game is currently connected and receiving the current conditions of the star system from the Hello Games discovery servers. The text will say *Online Discovery Services Active*.

The icon will be red if there is no connection and the text will say *Discovery services offline*.

The star system name will always be correct if the icon is green based on observations as of the [[Outlaws]] era.
