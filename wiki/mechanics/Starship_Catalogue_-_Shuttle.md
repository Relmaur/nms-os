# Starship Catalogue - Shuttle

## Summary

The following is a list of various Shuttle-Archetype [[starship|starships]] discovered by different players during the Echoes through current eras.

(For a list of all ship types, refer to the [[Starship Catalogue]])

Remember that even though all starships are available in all class grades, the maximum inventory size depends on the design of the ship itself. It is important to know which design is best suited to you when looking for a new starship.

## Description

Ships of this Archetype have balanced stats, with no significant class bonus compared to the other archetypes. These ships look typically blocky and small with a square-ish canopy, though some ships in this class do sometimes use a tube-like fuselage.

## Inventory

The inventory ranges for Shuttle are 18-23 for small and 19-28 for medium.
