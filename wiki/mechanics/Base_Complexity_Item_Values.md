# Base Complexity Item Values

**Base Complexity Item Values** is an index page.

## Summary

## Purpose

This table provides players invaluable information when planning their base construction. A maximum of 2000 points can be used when building a base.

## Testing notes from Nazgutek

Method:
1. dropped base limit value to 1000 (PC Config edit)
1. Built cuboid rooms until base complexity was 91%
1. Found item that required building 10 to raise base complexity by 1% (Infrastructure Sphere in this case)
1. Ensured 10 1pt items raised base complexity from 91% to 92% to verify total base complexity was exactly 910
1. Verified rounding behaviour by building up to 98% then placing 1pt items to tick to 99%, then being able to place 9 more to hit 99% and the limit warning.
1. Placed items either multiple times or with Spheres to derive values.
Note: I had weird behaviour with storage containers, and found container #4 only cost 1 point.
