# Ingredient Storage

**Ingredient Storage** is a specialized inventory system used for culinary ingredients within the [[Nutrient Processor]].

## Overview

Ingredient Storage allows players to store and access cooking components across all instances of the [[Nutrient Processor]], including those located in planetary bases, freighters, and aboard the [[Space Anomaly]] (see: [[Cronus's Grill System]]).

This storage is shared globally and functions independently from standard [[Storage Container]] systems or personal inventories. It streamlines cooking by allowing ingredients to be selected directly from storage when using any Nutrient Processor.

## Inventory Capacity

Ingredient Storage provides a global pool of **fifty (50) slots** accessible from any Nutrient Processor. Each slot may hold:
- Up to 50 units of a single ingredient
- Exceptions:
  - **Hypnotic Eye** and **Larval Core**: up to 5 units per slot
  - **Carbon Nanotubes**: up to 10 units per slot
  - **Creature Pellets**: up to 25 units per slot
  - Ingredients like [[Carbon]], [[Salt]], or [[Frost Crystal]] follow standard normal/survival stack limits

## Functionality

- Accessed when clicking on an input slot in the Nutrient Processor
- Contents are shared globally — including across bases, freighters, and the [[Space Anomaly]]
- Requires no wiring or power to function
- Cannot be accessed directly; only appears when preparing food

## Reported Issues

Some players (especially from legacy saves) have reported that their Nutrient Processor displays only **10 slots** instead of the full 50. There is no known fix, and the issue has not been officially acknowledged by Hello Games.

## Use Cases

- Enables efficient preparation of multi-step recipes
- Reduces inventory clutter during cooking
- Essential for meal submissions to [[Iteration: Cronus]]

## Limitations

- Not accessible outside of the Nutrient Processor interface
- Cannot store finished meals or non-ingredient items
- Each slot can contain only 50 of each ingredient instead of 100 in regular inventories

## Release History

- [[Relics]] - introduced as a feature.
