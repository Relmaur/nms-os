# Distress Beacon

**Distress Beacon** is an interactable object.

## Summary

**Distress Beacon** is an interactable object that can be found at [[Crashed Freighter]] or [[Crashed Ship]]. It can also appear as a separate [[Point of Interest]].

When it is related to Crashed Ship, it broadcasts a message that the Crashed Ship was removed.

## Additional information

- One of the Distress Beacon logs inspired the creation of [[Unification Day 2017]].
