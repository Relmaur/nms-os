# Planetary Settlement - Citizen Requests

## Summary

**Planetary Settlement - Citizen Requests** contains a detailed description of the Citizen Requests which the Settlement Overseer must oversee at the [[Planetary Settlement|Settlement Administration Terminal]] in a [[Planetary Settlement]].
