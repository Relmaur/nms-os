# Multi-Tool Upgrade Station

**Multi-Tool Upgrade Station** is a type of terminal.

## Summary

**Multi-Tool Upgrade Station** is a computer [[terminal]] found in inhabited [[space station|space stations]].

It is a feature that allows upgrades to the player [[Multi-tool|Multi-tools]] beyond what can be achieved through the inventory menu.

It is located immediately adjacent to the Multi-tool [[Technology Merchant]] in inhabited systems.

### Features

The following features can be accessed with the Multi-Tool Upgrade Station:
- Install slot
- Purchase multi-tool inventory Slots
- Upgrade multi-tool class

## Install a Slot

Occasionally players may acquire a [[Multi-Tool Expansion Slot]]. This can be used to add one slot to a selected multi-tool. Using this option will consume the Multi-Tool Expansion Slot module.

The maximum number of slots available depends on the type and class of multi-tool ([[Multi-tool Catalogue - Alien|Alien]], [[Multi-tool Catalogue - Experimental|Experimental]], [[Multi-tool Catalogue - Pistol|Pistol]], or [[Multi-tool Catalogue - Rifle|Rifle]]).

## Purchase Multi-Tool inventory Slots

As an alternative if a traveller does not have a Multi-Tool Expansion Slot, the traveller can choose to expand the slot count on a selected multi-tool by payment of certain amount of  Units, starting from 100K and escalating to over 100M.
You can add slots up until the fixed limit of 60.

## Upgrade Multi-Tool Class

The traveller can choose to upgrade the class of a selected multi-tool:
- C to B: 10,000 nanites
- B to A: 25,000 nanites
- A to S: 50,000 nanites

## Release History

- [[Origins]] - introduced as a feature.
- [[Waypoint]] - maximum number of slots increased to 60.
