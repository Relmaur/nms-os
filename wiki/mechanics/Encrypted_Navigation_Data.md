# Encrypted Navigation Data

**Encrypted Navigation Data** is an interactable object.

## Summary

**Encrypted Navigation Data** is an interactable object that can be found on desks and tables inside various buildings and [[space station|space stations]].

It has various appearances and can interacted with. It rewards the player with 11-14 [[Nanite Cluster|Nanite Clusters]] or 1 [[Navigation Data]].

## Additional information

- The [[Expanding Cube Gadget]] and [[Holographic Globe Gadget]] have the same look, which are decorations available for purchase at [[Quicksilver Synthesis Companion]].

## Release history

- [[Release]] - Added to the game.
- *Unknown Update* - Renamed from Device to Encrypted Navigation Data. Removed healing and shield recharge capabilites, and no longer provides units.
- [[NEXT]] - Added Navigation Data as reward to its loot table.
