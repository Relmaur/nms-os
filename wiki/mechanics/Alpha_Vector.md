# Alpha Vector

## Quick Facts

- **Type:** Fighter
- **Class:** C
- **Inventory:** Small
- **Slots:** 16
- **Damage:** 5
- **Shield:** 0
- **Warp:** 0
- **Added in:** Release

**Domanish S84**, later renamed to the **Tashi's Gambit**, and later renamed again to the **Alpha Vector** is a starship.

## Summary

**Alpha Vector** (promotional name), previously known in-game as **Domanish S84** (from launch till NEXT), **Tashi's Gambit EF9** (NEXT till Outlaws), and now by **Alpha Vector** (in-game), is an exclusive [[starship]] for players who pre-ordered [[No Man's Sky]] on Playstation 4. To claim the ship, go into the Options menu and under Extras select Redeem Bonus Content.

## Location

If you didn't pre-order No Mans Sky on PS4, you can still get the **Alpha Vector** though save editors.
**Seed:** 0x8E8E2193DD4A9EDA *(Thanks to )*
Alternatively, a replica of the ship can be created using the [[Starship Fabricator Terminal]] and using a Class C (or any) reactor, along with the Omega Cockpit, Tri-Booster, and Horizon Wings (Fin). Not to be confused with Horizon Wings (withoutFin).

Then, based on the version, the ship would be painted using default Matte paint in different colors.

To recreate a **Domanish S84**, Primary Gray, Secondary Blue and Accent White.

To recreate a **Tashi's Gambit** or the in-game (not promo-art) **Alpha Vector**, Primary Gray, Secondary Green (possibly Turquoise) and Accent Blue.

To recreate a promo-art **Alpha Vector**, change the Thruster to Mono-Booster, the wings to Horizon Wings without fin, Primary White, Secondary Red, and Accent White. This is also the current design for the PC pre-order **Prime Vector ([[Horizon Omega]]).**

## Description

Your starship is your transport to the stars. Give your epic voyage an initial boost with this Alpha Vector attack starship pre-upgraded with lasers for protection and a [[Hyperdrive technology|hyperdrive]] that allows you to jump to nearby [[star system|star systems]].

## Default loadout

The Alpha Vector starship has 16 inventory slots and comes equipped with the following [[technology]]:
- [[Launch Thruster]]
- [[Pulse Engine]]
- [[Deflector Shield]]
- [[Photon Cannon]]
- [[Hyperdrive]]
- [[Phase Beam]]
- [[Photonix Core]]

Players can only redeem this ship after playing part of the tutorial. However, players will still need to repair the Launch Thrusters and Pulse Engine before taking off.

## Trivia

- Despite being called the "Alpha" Vector, the ship does not use the "Alpha Cockpit" Fuselage and instead uses the "Omega Fuselage".
