# Galactic Map

**Galactic Map** is a feature.

## Summary

**Galaxy Map** is a ginormous interface that endlessly displays countless [[star system|star systems]]. It can be opened when boarding a spaceship or freighter. On a [[Starship]], open the [[Quick Menu]] in space and select Open Galaxy Map. On PC it can also be opened directly by pressing . On a [[freighter]], open it from the "Freighter Warp" terminal, one of the consoles on the central circular platform on the bridge of the ship. It is located on the opposite side of the [[Frigate Expedition]] officer.

A screen for investigating information on other star systems and traveling there by warp. Since the warp capability of ship and freighters is a very short distance compared to the size of the galaxy, it is mainly used to investigate and travel to nearby star systems. Several routes can be set.

## Destination

It shows the distance in light-years for the current destination.
- [[Galaxy Centre|Galactic Core]]
- Free Explore *(no distance indicated)*
- Custom Waypoint *(N/A if none selected from the [[Discoveries]] list)*
- [[Black Hole]] *(N/A if none selected on the map)*
- [[Atlas Interface|Atlas Station]] *(N/A if [[The Atlas Path]] is completed)*
- Current Mission *(N/A if an open ended mission selected, like [[New Beginnings]])*

## Filter

It shows different colour codings for the star systems, but there is no in-game legend for explaining these.
- No Filter *(star systems have their designated [[System colours|colour]])*
- Lifeform ''system colour code:
  - red - [[Vy'keen]]
  - yellow - [[Gek]]
  - blue - [[Korvax]]
  - white - [[Uncharted system|Uncharted]] or [[Abandoned system|Abandoned]])*- [[Conflict Level|Conflict]] *(requires [[Conflict Scanner]] to be installed, system colour code: green - low, yellow - medium, red - high)''
- [[Economy]] ''(requires [[Economy Scanner]] to be installed, system colour code:
  - green - [[Trading Economy|Trading]]
  - purple - [[Advanced Materials Economy|Advanced Materials]]
  - dark blue - [[Scientific Economy|Scientific]]
  - orange - [[Mining Economy|Mining]]
  - yellow - [[Manufacturing Economy|Manufacturing]]
  - light blue - [[Technology Economy|Technology]]
  - red - [[Power Generation Economy|Power Generation]])''
