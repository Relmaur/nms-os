# Starship Fabricator Terminal

**Starship Fabricator Terminal** is a terminal that allows players to fabricate new [[Starship|starships]] using salvaged components and a purchased Reactor Core.

## Summary

A **Starship Fabricator Terminal** is located on the lower level of each non-[[abandoned]], non-[[Outlaw System|Outlaw]] [[Space Station]], in the rear center section, near the [[Starship Outfitting Terminal]] and [[Appearance Modifier]].

To fabricate a ship:
- Purchase a **Reactor Core** from the [[Starship Technology Merchant]] (located on the upper level).
- Salvage existing ships at the [[Starship Outfitting Terminal]] to gain starship parts.
- Use the Fabricator Terminal to combine parts and build a new ship.

Supported ship types include:
- [[Starship Catalogue - Fighter|Fighter]]
- [[Starship Catalogue - Hauler|Hauler]]
- [[Starship Catalogue - Explorer|Explorer]]
- [[Solar Ship|Solar]] (added in Worlds Part I)

## Release History

- [[Orbital]] – Introduced as a feature.
- [[Update 5.00|Worlds Part I]] – Added Solar Ship fabrication.

## Additional Information

- Salvaging a starship yields visual components that are stored and can be reused in the builder.
- Reactor Cores are single-use and required for each fabrication.
- Only parts of the same ship type can be combined.
- Fabricated ships are added to the player's collection and occupy a ship slot.
