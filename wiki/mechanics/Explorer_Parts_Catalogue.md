# Explorer Parts Catalogue

**Explorer Parts Catalogue** is an index page.

## Summary

This page contains a list of body shapes and parts for the [[Explorer]] version of the [[starship]].

In total, there are two (2) hull base shapes, five (5) hull auxiliary parts, and twenty (20) wing style parts. Depending on the model, one ship can display multiple parts.

The names used are not game based, but are generally accepted by the community following a revision of the naming style suggested by . The one exception is recently there is a preferred usage for the Slave hull type to be described as Firespray.

## Hull Base

This provides the general appearance of the starship, known as the silhouette. There are two general types (in order of size):
- Hopper (traditionally called Starhopper)
- Firespray (previously called Slave or K-Basse)

## Hull Auxiliary Parts

The 5 Auxiliary parts provide the customized appearance of each starship model. They can be combined in many ways, and some starships may feature multiple items from this list.
- Chin Spikes
- Chin Dishes
- Spectrometer
- Front Antennae
- Rear Antennae

## Inventory Sizes

- If a solar pod is present, the ship is T2.
- If a big T3 pod is present, the ship is T3.
- In all other cases, the ship is T1.
