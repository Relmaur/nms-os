# Station Core

The **Station Core** is a space station management device.

## Summary

The **Station Core** is found on [[Space station|Space stations]], and is referred to as the Flightpath and Landing Overseer.

It accepts [[Station Override|Station Overrides]] for functions currently unknown. In [[Expedition 3: Cartographers]] attempts to use it will result in **Access Denied** response.

A [[Forged Passport]] to improve/restore your standing may also be used.

## Location

It can be found on Space stations in the starship hangar behind the ship landing area.

## Station Core Terminal

The core includes a ramp leading to a [[terminal]] display.

The terminal visuals consists of a series of phrases in the standard game [[alphabet]] that are connected to a circular graphic. Those connected to blue lines read "Online" while those in red read "Error".

Below the graphic are two additional lines:

- Station Status: Nominal
- System A.I Mode: Slumber

The Outlaw Station Core Terminal writing consists of nearly the same as the normal Station Core, but instead of "Online", "Error" is displayed, and the phrases below the graphic are:

- Station Status: Hijack
- System A.I Mode: /

## Interaction

When interacting with the **Station Core**, the following information will be displayed:

*Life support systems: [Stable/Unstable]... Commercial monitoring: [Online/Offline]... Flight path management: __% efficiency... Atlas/Aeron Surveillance Uplink: [Functional/Rejected]...*

You will then be given the choice to enter an Override code, a Forged Passport, or leave.

## Additional information

Station cores appear to have multiple different eye variants. Some include white and blue.
