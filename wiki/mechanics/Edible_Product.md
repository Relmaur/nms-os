# Edible Product

**Edible Product** is a type of consumable.

## Summary

**Edible Product** is a type of [[consumable]]. Products belong to this type are prepared from [[Raw Ingredient|Raw Ingredients]].

## Use

- Can be used as [[bait]] for [[fishing]].
- Can be consumed for various [[Exosuit]] bonuses.
- Many can be [[Cooking|cooked]] into other [[Edible Product|Edible Products]].
- Can be presented to [[Iteration: Cronus]] in the [[Space Anomaly]] for [[Nanite Cluster|nanite]] Nanites rewards.
- Can be fed to [[Organic Frigates]] to [[Organic Frigates|change]] their Combat/Exploration/Industry/Trade values.

## List of Edible Products

## Additional information

- If fed to an Organic Frigate, and Edible Product will have different results based on which frigate it is fed to. If fed to the same frigate, it will always produce the same result.
