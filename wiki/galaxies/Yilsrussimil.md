# Yilsrussimil

## Quick Facts

- **Galaxy number:** 257
- **Previous:** Odyalutai
- **Next:** Calypso
- **Added in:** Echoes

**Yilsrussimil** is the 257th galaxy but can't be reached without mods or game edits, resulting from an error condition.
It is confirmed that the next galaxy is Calypso.

## Summary

It appears that **Yilsrussimil ** cannot be reached without using game edits.
**Yilsrussimil**, and all reported galaxies beyond it, were mistakenly believed to be distinct galaxies beyond the 256th, [[Odyalutai]].

What players failed to realize when they travelled through the 256th Core was that without any provision in the game code at the time for looping back to [[Euclid]], they would simply be spawned near the edge of 256.

Galaxies "past" the 256th were thought to be copies of **Odyalutai**, but with a randomised name and colour. This phenomenon has proven to be controversial amongst the player community. It is a challenge for players devoted to researching the game mechanics who do not realize the galaxies beyond 256 only occur due to a software code glitch.

To this day, the myth of galaxies beyond Odyalutai persists. A simple test can be applied to readily verify that all galaxies beyond 256 are, in fact, the same galaxy. Every [[Discoveries|discovery]], Uploaded [[Habitable Base|base]], and [[Communications Station]] that is uploaded in any of the subsequent post 256 (e.g. "impostor") galaxies affects Odyalutai itself, as well as any of the other resulting 'glitch' galaxies.
