# Negative Galaxies

## Quick Facts

- **Galaxy number:** 0
- **Previous:** Uewamoisow
- **Next:** Euclid
- **Added in:** Atlas Rises

**Negative Galaxies** are galaxy clones.

## Summary

**Negative galaxies** are presumed galaxies that precede [[Euclid]] (Galaxy 1). While No Man's Sky will generate names for an apparently infinite number of negative galaxy designations, these are all really just different names for the same place; all galaxy names and numbers below Euclid point to Galaxy 256, [[Odyalutai]]. For example, if you tell the game you are in Galaxy 0, it will tell you that you are in Pequibanu, as seen on the right, though you are actually in Odyalutai. However, galaxies starting from Hacolulusu will instead represent a galaxy in the 1-255 range, with Hacolulusu representing Euclid.

## Accessing

There is no legitimate way known to currently reach any galaxies outside the range of 0 to 255; however, they can be reached using mods or save game edits. As of the Atlas Rises update, Iousongola (255) is now the last galaxy that can be reached by normal means.

Before the Atlas Rises update, however, Hacolulusu would send the player to a galaxy with the ID of -2,147,483,647. It is presumed that this represents the overflowing of the 32-bit integer limit, and made travel to negative galaxies technically possible without save game editing. This means that Pequibanu would have been the last galaxy the player could go to before finding Euclid again.
