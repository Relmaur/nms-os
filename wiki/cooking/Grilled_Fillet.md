# Grilled Fillet

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Aquarius

**Grilled Fillet** is a consumable.

## Summary

**Grilled Fillet** is a consumable and one of the Edible Products.

## Game Description

A piece of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **5% health**.

- When consumed through a Nutrient Ingestor, **Grilled Fillet** provides **+35% Breathing Efficiency** for 5 minutes.

## Fishing Bait

When applied as bait, Grilled Fillet gives the following bonus towards your next catch:

- Catch Rarity Improvement: 27%
- Catch Size Improvement: 3%

Grilled Fillet can be cooked using a Nutrient Processor with the following ingredients:

- Longjaw Snapper x1 → Grilled Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Grilled Fillet** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Grilled Fillet x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Grilled Fillet x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Grilled Fillet x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Grilled Fillet x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Grilled Fillet x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
