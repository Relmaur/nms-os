# Creamed Organ Soup

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 26,000.0
- **Updated:** Omega

**Creamed Organ Soup** is a consumable.

## Summary

**Creamed Organ Soup** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition past or pellets.

Food such as this can be **highly valuable**.

## Source

Creamed Organ Soup can be cooked using a Nutrient Processor with the following ingredients:

- Stewed Organs x1 + Creamy Sauce x1 → Creamed Organ Soup x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Crystalline Soup x1 + Creamy Sauce x1 → Creamed Organ Soup x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Chewy 'Dumpling' Stew x1 + Creamy Sauce x1 → Creamed Organ Soup x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Gelatinous Goop x1 + Creamy Sauce x1 → Creamed Organ Soup x1 (*"Combine and Reduce"*, 2.5 sec./unit output)

## Recipes

**Creamed Organ Soup** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 20% life support when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +62% Sprint Distance *(10:00)*

## Fishing Bait

When applied as bait, Creamed Organ Soup gives the following bonus towards your next catch:

- Catch Rarity Improvement: 24%
- Catch Size Improvement: 35%
