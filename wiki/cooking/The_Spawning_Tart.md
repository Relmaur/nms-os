# The Spawning Tart

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 160,000.0
- **Updated:** NextGen

**The Spawning Tart** is a consumable.

## Summary

**The Spawning Tart** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

The Spawning Tart can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Monstrous Custard x1 → The Spawning Tart x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**The Spawning Tart** is not used as an ingredient for cooking using a Nutrient Processor.
