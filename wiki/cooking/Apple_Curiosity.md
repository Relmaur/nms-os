# 'Apple' Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 78,000
- **Updated:** Swarm

'**Apple' Curiosity** is a consumable.

## Summary

'**Apple' Curiosity** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

Flavour profile: vibrant, colourful, piquant.

Recipe Complexity: 100%

## Source

'Apple' Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Crab 'Apple' x1 → 'Apple' Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Wriggling Jam x1 + Cream x1 → 'Apple' Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Wriggling Jam x1 + Bone Cream x1 → 'Apple' Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

'**Apple' Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, 'Apple' Curiosity gives the following bonus towards your next catch:

- Catch Rarity Improvement: 15%
- Catch Size Improvement: 9%
- Other notes: Attracts storm-loving fish
