# Syrupy Tingler

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 78,000
- **Updated:** WorldsOne

**Syrupy Tingler** is a consumable.

## Summary

**Syrupy Tingler** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Syrupy Tingler can be cooked using a Nutrient Processor with the following ingredients:

- Syrupy Batter x1 + Ever-burning Jam x1 + Cream x1 → Syrupy Tingler x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Ever-burning Jam x1 + Bone Cream x1 → Syrupy Tingler x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Syrupy Tingler** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Restores 50% health once consumed.

## Release History

- Worlds Part I - Added as a consumable.
