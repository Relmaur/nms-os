# Fishy Slab

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 39,000
- **Updated:** Aquarius

**Fishy Slab** is a consumable.

## Summary

**Fishy Slab** is a consumable and one of the Edible Products.

## Game Description

A huge slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Use

Exosuit nutrient system will restore **50% hazard protection**.

- When consumed through a Nutrient Ingestor, **Fishy Slab** provides **+49% Breathing Efficiency** for 6 minutes.

## Source

Fishy Slab can be cooked using a Nutrient Processor with the following ingredients:

- Stonescale Shark x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Helion Bass x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Black-Eyed Shark x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Cave Prowler x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- The Lunker x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Blind Titancore x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Helix Sawfish x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Translucent Gulper x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- The Maw of Titan x1 → Fishy Slab x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Fishy Slab** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Fishy Slab x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Fishy Slab x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Fishy Slab x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Fishy Slab x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Fishy Slab x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
