# Interstellar Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 80,200
- **Updated:** WorldsTwo

**Interstellar Fancy** is a consumable.

## Summary

**Interstellar Fancy** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

Flavour profile: astonishing, vibrant, tropical.

Recipe Complexity: 100%

## Source

Interstellar Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Stellar Custard x1 → Interstellar Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Interstellar Fancy** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Interstellar Fancy gives the following bonus towards your next catch:

- Catch Rarity Improvement: 8%
- Catch Size Improvement: 28%

## Additional Information

Exosuit nutrient system will restore 50% hazard protection when consumed.

- Beyond - Added as a consumable.
