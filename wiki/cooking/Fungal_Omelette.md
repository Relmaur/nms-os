# Fungal Omelette

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 24,000.0
- **Updated:** Prisms

**Fungal Omelette** is a consumable.

## Summary

**Fungal Omelette** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Use

Gives Spring Boost when consumed.

## Source

Fungal Omelette can be cooked using a Nutrient Processor with the following ingredients:

- Creature Egg x1 + Bone Cream (Cheese) x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Tall Eggs x1 + Bone Cream (Cheese) x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Giant Egg x1 + Bone Cream (Cheese) x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Creature Egg x1 + Tangy Cheese x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Tall Eggs x1 + Tangy Cheese x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Giant Egg x1 + Tangy Cheese x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Creature Egg x1 + ProtoCheese x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Tall Eggs x1 + ProtoCheese x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Giant Egg x1 + ProtoCheese x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Scrambled Marrow x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Omelette x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)

## Recipes

**Fungal Omelette** is not used as an ingredient for cooking using a Nutrient Processor.
