# Caramel Ice Cream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 56,000.0
- **Updated:** Prisms

**Caramel Ice Cream** is a consumable.

## Summary

**Caramel Ice Cream** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Caramel Ice Cream can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Crunchy Caramel x1 → Caramel Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Crunchy Caramel x1 → Caramel Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Crunchy Caramel x1 → Caramel Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Crunchy Caramel x1 → Caramel Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

**Caramel Ice Cream** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 25% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +53% Cold Resistance *(10:00)*

## Fishing Bait

When applied as bait, Caramel Ice Cream gives the following bonus towards your next catch:

- Catch Rarity Improvement: 74%
- Catch Size Improvement: 12%
