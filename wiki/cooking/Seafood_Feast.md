# Seafood 'Feast'

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 39,000
- **Updated:** Aquarius

**Seafood 'Feast'** is a consumable.

## Summary

**Seafood 'Feast'** is a consumable and one of the Edible Products.

## Game Description

A huge slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Use

Exosuit nutrient system will restore **25% hazard protection**.

- When consumed through a Nutrient Ingestor, **Seafood 'Feast'** provides **+39% Breathing Efficiency** for 6 minutes.

## Source

Seafood 'Feast' can be cooked using a Nutrient Processor with the following ingredients:

- Colossal Meltfin x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Giant Icefin x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Boiling Shark x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Bitterscale Ray x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Saltscale Bloater x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Crystalfin Shark x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Thunderfin x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Colossal Mossback x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Many-Mouthed Lunker x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Leviathan Spawn x1 → Seafood 'Feast' x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Seafood 'Feast'** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Seafood 'Feast' x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Seafood 'Feast' x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Seafood 'Feast' x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Seafood 'Feast' x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Seafood 'Feast' x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
