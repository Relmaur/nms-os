# Tangy Vegetable Stew

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 36,000.0
- **Updated:** Omega

**Tangy Vegetable Stew** is a consumable.

## Summary

**Tangy Vegetable Stew** is a consumable and one of the Edible Products.

## Game description

## Source

Tangy Vegetable Stew can be cooked using a Nutrient Processor with the following ingredients:

- Fibrous Stew x1 + Partially-Liquid Cheese x1 → Tangy Vegetable Stew x1 (*"Combine and Reduce"*, 2.5 sec./unit output)

## Recipes

**Tangy Vegetable Stew** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 20% life support power when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +63% Sprint Distance *(10:00)*

## Fishing Bait

When applied as bait, Tangy Vegetable Stew gives the following bonus towards your next catch:

- Catch Rarity Improvement: 49%
- Catch Size Improvement: 6%
- Other notes: Attracts nocturnal fish
