# Salty Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 100,000
- **Updated:** WorldsOne

**Salty Doughnut** is a consumable.

## Summary

**Salty Doughnut** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

## Source

Salty Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Salty Custard x1 → Salty Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Salty Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +30% Mining Speed *(10:00)*

## Fishing Bait

When applied as bait, Salty Doughnut gives the following bonus towards your next catch:

- Catch Rarity Improvement: 16%
- Catch Size Improvement: 0%
