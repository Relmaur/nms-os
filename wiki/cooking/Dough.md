# Dough

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 3,200
- **Updated:** WorldsTwo

**Dough** is a consumable.

## Summary

**Dough** is a consumable and one of the Edible Products.

## Game Description

A refined product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

Flavour profile: mediocre, dry, harsh.

Recipe Complexity: 54%

## Source

Dough can be cooked using a Nutrient Processor with the following ingredients:

- Refined Flour x1 + Wild Yeast x1 → Dough x1 (*"Component Churn"*, 2.5 sec./unit output)

## Recipes

**Dough** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Bread -- Dough x1 → Bread x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Lumpen Doughnut -- Clarified Oil x1 + Dough x1 + Processed Sugar x1 → Lumpen Doughnut x1 (*"Accelerated Fry"*, 2.5 sec./unit output)
- Proto-Beignet -- Proto-Oil x1 + Dough x1 + Processed Sugar x1 → Proto-Beignet x1 (*"Accelerated Fry"*, 2.5 sec./unit output)

## Fishing Bait

When applied as bait, Dough gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts diurnal fish

## Additional Information

Restores 25% Hazard Protection once consumed.
