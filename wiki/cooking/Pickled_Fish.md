# Pickled Fish

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 28,000
- **Updated:** Aquarius

**Pickled Fish** is a consumable.

## Summary

**Pickled Fish** is a consumable and one of the Edible Products.

## Game Description

A small morsel of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **1% health**.

- When consumed through a Nutrient Ingestor, **Pickled Fish** provides **+37% Breathing Efficiency** for 4:30 minutes.

## Fishing Bait

When applied as bait, Pickled Fish gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Source

Pickled Fish can be cooked using a Nutrient Processor with the following ingredients:

- Needlefish x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Bulging Snapper x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Nucleic Skipper x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Lamptip Ray x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Frostscale Trout x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Warty Frogfish x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Wispscale Darter x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Bladdersac x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Hexscale Minnow x1 → Pickled Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Pickled Fish** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Pickled Fish x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Pickled Fish x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Pickled Fish x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Pickled Fish x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Pickled Fish x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
