# Grilled Tentacle

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Aquarius

**Grilled Tentacle** is a consumable.

## Summary

**Grilled Tentacle** is a consumable and one of the Edible Products.

## Game Description

A slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **25% hazard protection**.

- When consumed through a Nutrient Ingestor, **Grilled Tentacle** provides **+36% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Grilled Tentacle gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: -%

## Source

Grilled Tentacle can be cooked using a Nutrient Processor with the following ingredients:

- Green-Ring Octopus x1 → Grilled Tentacle x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Bleached Octopus x1 → Grilled Tentacle x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Hypnotic Octopus x1 → Grilled Tentacle x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Candelabra Octopus x1 → Grilled Tentacle x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Wrackjaw x1 → Grilled Tentacle x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Grilled Tentacle** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Grilled Tentacle x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Grilled Tentacle x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Grilled Tentacle x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Grilled Tentacle x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Grilled Tentacle x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
