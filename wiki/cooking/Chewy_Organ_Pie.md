# Chewy Organ Pie

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 40,000.0
- **Updated:** Prisms

**Chewy Organ Pie** is a consumable.

## Summary

**Chewy Organ Pie** is a consumable and one of the edible products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Chewy Organ Pie can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Offal Sac x1 → Chewy Organ Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Feline Liver x1 → Chewy Organ Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Scooped Innards x1 → Chewy Organ Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Chewy Organ Pie** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will power 15 seconds sprint overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +11% Sprint recovery time *(10:00)*

## Fishing Bait

When applied as bait, Chewy Organ Pie gives the following bonus towards your next catch:

- Catch Rarity Improvement: 21%
- Catch Size Improvement: 0%
- Other notes: Attracts diurnal fish
