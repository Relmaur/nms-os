# Fish Fry

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 28,000
- **Updated:** Aquarius

**Fish Fry** is a consumable.

## Summary

**Fish Fry** is a consumable and one of the Edible Products.

## Game Description

A small morsel of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **1% health**.

- When consumed through a Nutrient Ingestor, **Fish Fry** provides **+36% Breathing Efficiency** for 4:30 minutes.

## Fishing Bait

When applied as bait, Fish Fry gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 12%

## Source

Fish Fry can be cooked using a Nutrient Processor with the following ingredients:

- Tiny Scuttlefish x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Venemous Triggerfin x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Spotted Protofin x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Oilfin x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Pyrefin x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Rimescale Snapper x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Common Shimmertail x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Fool's Goldfish x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Fragile Icthyoscale x1 → Fish Fry x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Fish Fry** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Fish Fry x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Fish Fry x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Fish Fry x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Fish Fry x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Fish Fry x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
