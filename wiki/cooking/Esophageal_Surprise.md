# Esophageal Surprise

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 57,800.0
- **Updated:** Prisms

**Esophageal Surprise** is a consumable.

## Summary

**Esophageal Surprise** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

## Source

Esophageal Surprise can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Cactus Nectar x1 → Esophageal Surprise x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Cake Batter x1 + Cactus Jelly x1 + Cream x1 → Esophageal Surprise x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Cake Batter x1 + Cactus Jelly x1 + Bone Cream x1 → Esophageal Surprise x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Esophageal Surprise** is not used as an ingredient for cooking using a Nutrient Processor.
