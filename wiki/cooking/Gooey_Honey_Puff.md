# Gooey Honey Puff

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 38,400.0
- **Updated:** NextGen

**Gooey Honey Puff** is a consumable.

## Summary

**Gooey Honey Puff** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Gooey Honey Puff can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Sticky 'Honey' x1 → Gooey Honey Puff x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Gooey Butter x1 → Gooey Honey Puff x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Gooey Honey Puff** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Consuming **Gooey Honey Puff** gives a short boost to the Jetpack.
