# 'Apple' Ice Cream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 56,000
- **Updated:** Swarm

'**Apple' Ice Cream** is a consumable.

## Summary

'**Apple' Ice Cream** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

Flavour profile: vivid, prismatic, tropical.

Recipe Complexity: 100%

## Source

'Apple' Ice Cream can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Crab 'Apple' x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Crab 'Apple' x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frozen Tubers x1 + Wriggling Jam x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Wriggling Jam x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Crab 'Apple' x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Crab 'Apple' x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Wriggling Jam x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Wriggling Jam x1 → 'Apple' Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

'**Apple' Ice Cream** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, 'Apple' Ice Cream gives the following bonus towards your next catch:

- Catch Rarity Improvement: 64%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Additional information

Restores 25% hazard protection once consumed.

Grants +59% Cold Resistance when consumed through the Nutrient Ingestor
