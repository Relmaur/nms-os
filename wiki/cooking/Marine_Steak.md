# Marine Steak

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 35,400
- **Updated:** Aquarius

**Marine Steak** is a consumable.

## Summary

**Marine Steak** is a consumable and one of the Edible Products.

## Game Description

A slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **25% hazard protection**.

- When consumed through a Nutrient Ingestor, **Marine Steak** provides **+36% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Marine Steak gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts dinural fish

## Source

Marine Steak can be cooked using a Nutrient Processor with the following ingredients:

- Greenscale Bloater x1 → Marine Steak x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Venomtooth Wriggler x1 → Marine Steak x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Glowing Catfish x1 → Marine Steak x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Marine Steak** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Marine Steak x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Marine Steak x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Marine Steak x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Marine Steak x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Marine Steak x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
