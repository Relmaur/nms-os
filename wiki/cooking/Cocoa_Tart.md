# Cocoa Tart

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 54,000.0
- **Updated:** Origins

**Cocoa Tart** is a consumable.

## Summary

**Cocoa Tart** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable.** It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subject to further processing.

## Source

Cocoa Tart can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Bittersweet Cocoa x1 → Cocoa Tart x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Cocoa Tart** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will power 15 seconds sprint overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +9% Sprint Recovery Time *(10:00)*

## Fishing Bait

When applied as bait, Cocoa Tart gives the following bonus towards your next catch:

- Catch Rarity Improvement: 12%
- Catch Size Improvement: 20%
