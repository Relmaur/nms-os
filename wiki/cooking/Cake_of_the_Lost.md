# Cake of the Lost

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 199,200.0
- **Updated:** Prisms

**Cake of the Lost** is a consumable.

## Summary

**Cake of the Lost** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

## Source

Cake of the Lost can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Viscous Custard x1 → Cake of the Lost x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Salty Custard x1 → Cake of the Lost x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Monstrous Custard x1 → Cake of the Lost x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Stellar Custard x1 → Cake of the Lost x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Very Thick Custard x1 → Cake of the Lost x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Cake of the Lost** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,059% Fauna Analysis Rewards *(10:00)*

## Fishing Bait

When applied as bait, Cake of the Lost gives the following bonus towards your next catch:

- Catch Rarity Improvement: 65%
- Catch Size Improvement: 6%
