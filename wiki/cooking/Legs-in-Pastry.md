# 'Legs-in-Pastry'

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 40,000
- **Updated:** Swarm

'**Legs-in-Pastry'** is a consumable.

## Summary

'**Legs-in-Pastry'** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

Flavour profile: tropical, manifold, ephemeral.

Recipe Complexity: 100%

## Source

'Legs-in-Pastry' can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Leg Meat x1 → 'Legs-in-Pastry' x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

'**Legs-in-Pastry'** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, 'Legs-in-Pastry' gives the following bonus towards your next catch:

- Catch Rarity Improvement: 17%
