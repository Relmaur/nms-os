# Latticed Sinew

## Quick Facts

- **Category:** Consumable
- **Type:** Raw Ingredient
- **Value:** 1,400.0
- **Added in:** NextGen

**Latticed Sinew** is a consumable.

## Summary

Latticed Sinew is a [[consumable]] and one of the [[Raw Ingredient|Raw Ingredients]].

## Game description

A nutritious meat product, harvested from the corpse of the creature that once contained it.

Process in a [[Nutrient Processor]] to generate edible products.

## Source

This ingredient can be sourced by killing [[Spiralis|Burrowing Creatures]].

## Additional information

Provides 1-3 Health when consumed.
