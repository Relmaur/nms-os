# Baked Eggs

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 2,200.0
- **Updated:** Origins

**Baked Eggs** is a consumable.

## Summary

**Baked Eggs** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Baked Eggs can be cooked using a Nutrient Processor with the following ingredients:

- Larval Core x1 → Baked Eggs x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Creature Egg x1 → Baked Eggs x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Tall Eggs x1 → Baked Eggs x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Giant Egg x1 → Baked Eggs x1 (*"Bind Proteins"*, 2.5 sec./unit output)

## Recipes

**Baked Eggs** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

Nutrient Ingestor Effect +42% Life Support Tanks, Duration 4 minutes
