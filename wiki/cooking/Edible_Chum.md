# Edible Chum

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Aquarius

**Edible Chum** is a consumable.

## Summary

**Edible Chum** is a consumable and one of the Edible Products.

## Game Description

A piece of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **1% health**.

- When consumed through a Nutrient Ingestor, **Edible Chum** provides **+37% Breathing Efficiency** for 5 minutes.

## Fishing Bait

When applied as bait, Edible Chum gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Source

Edible Chum can be cooked using a Nutrient Processor with the following ingredients:

- Rockfin x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Immortal Flatfish x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Wandering Kelpfin x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Toxic Stonefish x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Solar Roach x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Jungle Redfin x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Murmurfish x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Inverted Snapper x1 → Edible Chum x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Edible Chum** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Edible Chum x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Fish Biscuit -- Sugar Dough x1 + Edible Chum x1 → Fish Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Marine Pie -- Edible Chum x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Edible Chum x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Edible Chum x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Edible Chum x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
