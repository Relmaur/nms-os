# Volatile Chocolate Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 123,700.0
- **Updated:** NextGen

**Volatile Chocolate Fancy** is a consumable.

## Summary

**Volatile Chocolate Fancy** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

## Source

Volatile Chocolate Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Bittersweet Cocoa x1 → Volatile Chocolate Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Volatile Chocolate Fancy** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +43% Shield Strength *(10:00)*

## Fishing Bait

When applied as bait, Volatile Chocolate Fancy gives the following bonus towards your next catch:

- Catch Rarity Improvement: 16%
- Catch Size Improvement: 7%
- Other notes: Attracts nocturnal fish
