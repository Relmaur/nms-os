# Curdy Cracker

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 60,000.0
- **Updated:** Omega

**Curdy Cracker** is a consumable.

## Summary

**Curdy Cracker** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully chosen ingredients.

## Source

Curdy Cracker can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Bone Cream (Cheese) x1 → Curdy Cracker x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Tangy Cheese x1 → Curdy Cracker x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Partially-Liquid Cheese x1 → Curdy Cracker x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + ProtoCheese x1 → Curdy Cracker x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Curdy Cracker** is not used as an ingredient for cooking using a Nutrient Processor.
