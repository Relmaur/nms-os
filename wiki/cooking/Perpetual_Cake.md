# Perpetual Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 67,000.0
- **Updated:** Prisms

**Perpetual Cake** is a consumable.

## Summary

**Perpetual Cake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

## Source

Perpetual Cake can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Anomalous Jam x1 + Cream x1 → Perpetual Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Cake Batter x1 + Anomalous Jam x1 + Bone Cream x1 → Perpetual Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Perpetual Cake** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 50% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +329% Jetpack Tanks *(10:00)*

## Fishing Bait

When applied as bait, Perpetual Cake gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 6%
- Other notes: Attracts nocturnal fish
