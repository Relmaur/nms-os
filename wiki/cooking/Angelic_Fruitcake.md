# Angelic Fruitcake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 31,300
- **Updated:** Swarm

**Angelic Fruitcake** is a consumable.

## Summary

**Angelic Fruitcake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

Flavour profile: colourful, explosive, tropical.

Recipe Complexity: 100%

## Source

Angelic Fruitcake can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Crab 'Apple' x1 → Angelic Fruitcake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Wriggling Jam x1 + Cream x1 → Angelic Fruitcake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Wriggling Jam x1 + Bone Cream x1 → Angelic Fruitcake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Angelic Fruitcake** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Angelic Fruitcake gives the following bonus towards your next catch:

- Catch Rarity Improvement: 50%
- Catch Size Improvement: 3%

## Additional information

Consume directly for 8 seconds jetpack overload.

Process with Nutrient Ingestor for 10 minutes +6,205% mineral analysis rewards.
