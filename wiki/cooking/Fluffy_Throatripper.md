# Fluffy Throatripper

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 142,900.0
- **Updated:** Prisms

**Fluffy Throatripper** is a consumable.

## Summary

**Fluffy Throatripper** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

## Source

Fluffy Throatripper can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Cactus Nectar x1 → Fluffy Throatripper x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Cactus Jelly x1 + Cream x1 → Fluffy Throatripper x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Cactus Jelly x1 + Bone Cream x1 → Fluffy Throatripper x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Fluffy Throatripper** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,181% Flora Analysis Reward *(10:00)*

## Fishing Bait

When applied as bait, Fluffy Throatripper gives the following bonus towards your next catch:

- Catch Rarity Improvement: 56%
- Catch Size Improvement: 7%
