# Jam Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 70,000.0
- **Updated:** Frontiers

**Jam Doughnut** is a consumable.

## Summary

**Jam Doughnut** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

## Source

Jam Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Ever-burning Jam x1 → Jam Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Lumpen Doughnut x1 + Grahj'am x1 → Jam Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Lumpen Doughnut x1 + Cactus Jelly x1 → Jam Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Lumpen Doughnut x1 + Furball Jelly x1 → Jam Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Jam Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +87% Solar Panel Power *(10:00)*

## Fishing Bait

When applied as bait, Jam Doughnut gives the following bonus towards your next catch:

- Catch Rarity Improvement: 26%
- Catch Size Improvement: 32%
- Other notes: Attracts nocturnal fish
