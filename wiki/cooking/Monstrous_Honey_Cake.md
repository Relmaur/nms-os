# Monstrous Honey Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 149,700.0
- **Updated:** NextGen

**Monstrous Honey Cake** is a consumable.

## Summary

**Monstrous Honey Cake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Wailing Batter.

## Source

Monstrous Honey Cake can be cooked using a Nutrient Processor with the following ingredients:

- Wailing Batter x1 + Synthetic Honey x1 → Monstrous Honey Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Monstrous Honey Cake** is not used as an ingredient for cooking using a Nutrient Processor.
