# Jammy Burster

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 81,900
- **Updated:** WorldsOne

**Jammy Burster** is a consumable.

## Summary

**Jammy Burster** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Jammy Burster can be cooked using a Nutrient Processor with the following ingredients:

- Syrupy Batter x1 + Grahj'am x1 + Cream x1 → Jammy Burster x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Furball Jelly x1 + Cream x1 → Jammy Burster x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Grahj'am x1 + Bone Cream x1 → Jammy Burster x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Furball Jelly x1 + Bone Cream x1 → Jammy Burster x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Jammy Burster** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Restores 50% health once consumed.
