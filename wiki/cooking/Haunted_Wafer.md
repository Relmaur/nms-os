# Haunted Wafer

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 80,000.0
- **Updated:** WorldsOne

**Haunted Wafer** is a consumable.

## Summary

**Haunted Wafer** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully-chosen ingredients.

## Source

Haunted Wafer can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Larval Core x1 → Haunted Wafer x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Hypnotic Eye x1 → Haunted Wafer x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Fiendish Roe x1 → Haunted Wafer x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Haunted Wafer** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 50% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +44% Toxic Resistance *(6:36)*

## Fishing Bait

When applied as bait, Haunted Wafer gives the following bonus towards your next catch:

- Catch Rarity Improvement: 12%
- Catch Size Improvement: 21%
