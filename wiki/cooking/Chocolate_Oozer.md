# Chocolate Oozer

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 60,500
- **Updated:** WorldsOne

**Chocolate Oozer** is a consumable.

## Summary

**Chocolate Oozer** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Chocolate Oozer can be cooked using a Nutrient Processor with the following ingredients:

- Syrupy Batter x1 + Bittersweet Cocoa x1 → Chocolate Oozer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Chocolate Oozer** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Restores 50% health once consumed.

## Release History

- Worlds Part I - Added as a consumable.
