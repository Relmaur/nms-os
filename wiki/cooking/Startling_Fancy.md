# Startling Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 78,000.0
- **Updated:** Prisms

**Startling Fancy** is a consumable.

## Summary

**Startling Fancy** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Startling Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Ever-burning Jam x1 + Cream x1 → Startling Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Ever-burning Jam x1 + Bone Cream x1 → Startling Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Startling Fancy** is not used as an ingredient for cooking using a Nutrient Processor.
