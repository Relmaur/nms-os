# Chocolate Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 60,500.0
- **Updated:** NextGen

**Chocolate Curiosity** is a consumable.

## Summary

**Chocolate Curiosity** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Chocolate Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Bittersweet Cocoa x1 → Chocolate Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Chocolate Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.
