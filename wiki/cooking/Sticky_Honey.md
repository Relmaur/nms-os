# Sticky 'Honey'

## Quick Facts

- **Category:** Consumable
- **Type:** Raw Ingredient
- **Value:** 3,200
- **Added in:** WorldsTwo

**Sticky 'Honey**' is a consumable.

## Summary

**Sticky 'Honey**' is a [[consumable]] and one of the [[Raw Ingredient|Raw Ingredients]].

## Game description

An animal byproduct, this nutritious morsel can be easily farmed without harm to the animal that produces it.

Process in a Nutrient Processor to generate edible products.

## Source

This ingredient is an [[Animal Byproduct]] that can be sourced by gathering from blob-type creatures ([[Lok]]) when fed [[Creature Pellets]].

Some plants on  planets have it as a second component.

## Additional information

Restores 20% [[life support]] power once consumed.
