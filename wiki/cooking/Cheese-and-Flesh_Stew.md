# Cheese-and-Flesh Stew

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 36,000
- **Updated:** WorldsTwo

**Cheese-and-Flesh Stew** is a consumable.

## Summary

**Cheese-and-Flesh Stew** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

Flavour profile: otherwordly, sublime, vivid.

Recipe Complexity: 100%

## Source

Cheese-and-Flesh Stew can be cooked using a Nutrient Processor with the following ingredients:

- Mystery Meat Stew x1 + Partially-Liquid Cheese x1 → Cheese-and-Flesh Stew x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Well-Stirred Stew x1 + Partially-Liquid Cheese x1 → Cheese-and-Flesh Stew x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Soiled Soup x1 + Partially-Liquid Cheese x1 → Cheese-and-Flesh Stew x1 (*"Combine and Reduce"*, 2.5 sec./unit output)

## Recipes

**Cheese-and-Flesh Stew** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 20% life support power when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +60% Sprint Distance *(10:00)*

## Fishing Bait

When applied as bait, Cheese-and-Flesh Stew gives the following bonus towards your next catch:

- Catch Rarity Improvement: 73%
- Catch Size Improvement: 7%
- Other notes: Attracts storm-loving fish
