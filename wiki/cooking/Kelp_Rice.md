# Kelp Rice

## Quick Facts

- **Category:** Consumable
- **Type:** Raw Ingredient
- **Value:** 1,200.0
- **Added in:** WorldsOne

**Kelp Rice** is a consumable.

## Summary

**Kelp Rice** is a [[consumable]] and one of the [[Raw Ingredient|Raw Ingredients]] used in many recipes.

Kelp Rice can be created by cooking [[Kelp Sac|Kelp Sacs]], which can be harvested from [[Candle Kelp]].

## Game Description

An edible plant, harvested from planetary flora.

Process in a Nutrient Processor to generate edible products.

## Use

Exosuit nutrient system will restore **10% [[hazard protection]]**.
- When consumed through a [[Nutrient Ingestor]], **Kelp Rice** provides **+36% Breathing Efficiency** for 3 minutes.

## Source

- **Nutrient Processor** · *Extract Nutrients* · 2.5 s per unit: 1 × [[Kelp Sac]] → 1 × Kelp Rice
