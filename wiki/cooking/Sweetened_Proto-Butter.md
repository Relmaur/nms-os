# Sweetened Proto-Butter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 32,000
- **Updated:** Swarm

**Sweetened Proto-Butter** is a consumable.

## Summary

**Sweetened Proto-Butter** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

Flavour profile: colourful, prismatic, explosive.

Recipe Complexity: 72%

## Source

Sweetened Proto-Butter can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Butter x1 + Processed Sugar x1 → Sweetened Proto-Butter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Recipes

**Sweetened Proto-Butter** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Honeybutter Doughnut -- Lumpen Doughnut x1 + Sweetened Proto-Butter x1 → Honeybutter Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Proto-Batter -- Sweetened Proto-Butter x1 + Refined Flour x1 + Creature Egg x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Proto-Batter -- Sweetened Proto-Butter x1 + Refined Flour x1 + Giant Egg x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Proto-Batter -- Sweetened Proto-Butter x1 + Refined Flour x1 + Tall Eggs x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Wailing Batter -- Sweetened Proto-Butter x1 + Refined Flour x1 + Larval Core x1 → Wailing Batter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Fishing Bait

When applied as bait, Sweetened Proto-Butter gives the following bonus towards your next catch:

- Catch Rarity Improvement: 52%
- Catch Size Improvement: 3%

## Additional Information

Exosuit nutrient system will restore 40% life support power when consumed.
