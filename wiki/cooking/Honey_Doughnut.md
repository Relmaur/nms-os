# Honey Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 65,000
- **Updated:** WorldsOne

**Honey Doughnut** is a consumable.

## Summary

**Honey Doughnut** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

## Source

Honey Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Synthetic Honey x1 → Honey Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Honey Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +28% Mining Speed *(10:00)*

## Additional Information

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.
