# Stewed Organs

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 6,400.0
- **Updated:** Omega

**Stewed Organs** is a consumable.

## Summary

**Stewed Organs** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Stewed Organs can be cooked using a Nutrient Processor with the following ingredients:

- Offal Sac x1 + Offal Sac x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Offal Sac x1 + Feline Liver x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Feline Liver x1 + Feline Liver x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Scooped Innards x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Offal Sac x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Feline Liver x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Crystal Flesh x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Latticed Sinew x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Crunchy Wings x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Lumpy Brainstem x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Scooped Innards x1 + Dirty Meat x1 → Stewed Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)

## Recipes

**Stewed Organs** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Creamed Organ Soup -- Stewed Organs x1 + Creamy Sauce x1 → Creamed Organ Soup x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Devilled Organs -- Stewed Organs x1 + Scorching Sauce x1 → Devilled Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Flavoursome Organs -- Stewed Organs x1 + Flavoursome Sauce x1 → Flavoursome Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Tangy Organ Surprise -- Stewed Organs x1 + Partially-Liquid Cheese x1 → Tangy Organ Surprise x1 (*"Combine and Reduce"*, 2.5 sec./unit output)

## Additional information

Upon consumption the player's character receives a 15-second sprint power surge.
