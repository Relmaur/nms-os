# Caramel Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 65,000.0
- **Updated:** NextGen

**Caramel Doughnut** is a consumable.

## Summary

**Caramel Doughnut** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Caramel Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Crunchy Caramel x1 → Caramel Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Caramel Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +60% Resources Mined *(10:00)*
