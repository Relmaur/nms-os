# Jellymeat

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Aquarius

**Jellymeat** is a consumable.

## Summary

**Jellymeat** is a consumable and one of the Edible Products.

## Game Description

A slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **25% hazard protection**.

- When consumed through a Nutrient Ingestor, **Jellymeat** provides **+38% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Jellymeat gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts dinural fish

## Source

Jellymeat can be cooked using a Nutrient Processor with the following ingredients:

- Golden Jellyfish x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Toxic Jelly x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Many-Eyed Jellyfish x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Jelly of the Veil x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Crystal Jelly x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Mellifluous Jellyfish x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Glass Angel x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Aurora Jellyfish x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Child of Helios (Fish) x1 → Jellymeat x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Jellymeat** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Jellymeat x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Jellied Eel -- Jellymeat x1 + Fleshy Cylinder x1 → Jellied Eel x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Jellymeat x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Sea's Bounty -- Jellymeat x1 + Fleshy Cylinder x1 + Assorted Roe x1 → Sea's Bounty x1 (*"Sea's Bounty"*, 2.5 sec./unit output)
- Seafood Stew -- Jellymeat x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Jellymeat x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Jellymeat x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
