# Writhing, Roiling Batter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 100,000.0
- **Used for:** Crafting, Cooking
- **Updated:** NextGen

**Writhing, Roiling Batter** is a consumable.

## Summary

**Writhing, Roiling Batter** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable**.
It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Writhing, Roiling Batter can be cooked using a Nutrient Processor with the following ingredients:

- Delicate Meringue x1 + Refined Flour x1 + Larval Core x1 → Writhing, Roiling Batter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Usage

### Crafting

**Writhing, Roiling Batter** is not used as an ingredient for crafting.

### Refining

**Writhing, Roiling Batter** is not used as an ingredient for refining using a Refiner.

## Consume

- Replenishes **20% Life Support power** when consumed without a Nutrient Processor.
- Fueling a Nutrient Ingestor with **Writhing, Roiling Batter** will grant +5% Sprint Recovery Time for 4:00 per unit consumed.

## Fishing Bait

When applied as bait, Writhing, Roiling Batter gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish
