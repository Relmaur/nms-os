# Soft Custard Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 94,800.0
- **Updated:** Prisms

**Soft Custard Fancy** is a consumable.

## Summary

**Soft Custard Fancy** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Soft Custard Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Viscous Custard x1 → Soft Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Salty Custard x1 → Soft Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Monstrous Custard x1 → Soft Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Stellar Custard x1 → Soft Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Very Thick Custard x1 → Soft Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Soft Custard Fancy** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

Effect when consumed in the Nutrient Ingestor: +6,355% Fauna analysis rewards.

Exosuit nutrient system will activate +8 seconds Jetpack overload.
