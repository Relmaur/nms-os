# Syrupy Caramel Slice

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 64,900
- **Updated:** WorldsOne

**Syrupy Caramel Slice** is a consumable.

## Summary

**Syrupy Caramel Slice** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Syrupy Caramel Slice can be cooked using a Nutrient Processor with the following ingredients:

- Syrupy Batter x1 + Crunchy Caramel x1 → Syrupy Caramel Slice x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Syrupy Caramel Slice** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Restores 50% health once consumed.

## Release History

- Worlds Part I - Added as a consumable.
