# Chewy Biscuit

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 56,000
- **Updated:** WorldsTwo

**Chewy Biscuit** is a consumable.

## Summary

**Chewy Biscuit** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully-chosen ingredients.

Flavour profile: tangy, fruity, roasted.

Recipe Complexity: 68%

## Source

Chewy Biscuit can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Nourishing Slime x1 → Chewy Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Sweetened Mucous x1 → Chewy Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Chewy Biscuit** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Chewy Biscuit gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Additional Information

Exosuit nutrient system will restore 25% hazard protection when consumed.
