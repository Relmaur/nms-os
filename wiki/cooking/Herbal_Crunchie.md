# Herbal Crunchie

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 60,000
- **Updated:** WorldsOne

**Herbal Crunchie** is a consumable.

## Summary

**Herbal Crunchie** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully-chosen ingredients.

## Use

- Replenishes 5% Life Support when consumed.
- Fueling a Nutrient Ingestor with **Herbal Crunchie** will grant +4,474% Flora Analysis Rewards for 6:36 per unit consumed.

## Source

Herbal Crunchie can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + NipNip Buds x1 → Herbal Crunchie x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + GekNip x1 → Herbal Crunchie x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Herbal Crunchie** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Herbal Crunchie gives the following bonus towards your next catch:

- Catch Rarity Improvement: 43%
- Catch Size Improvement: 4%
- Other notes: N/A

## Additional Information

The in-game display text previously incorrectly stated that consumption will activate 5 seconds jetpack overload. This has sense been patched.
