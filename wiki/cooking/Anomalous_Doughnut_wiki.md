# Anomalous Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 70,000
- **Updated:** Swarm

**Anomalous Doughnut** is a consumable.

## Summary

**Anomalous Doughnut** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

Flavour profile: aromatic, ephemeral, synesthetic.

Recipe Complexity: 91%

## Source

Anomalous Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Anomalous Jam x1 → Anomalous Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Anomalous Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Anomalous Doughnut gives the following bonus towards your next catch:

- Catch Rarity Improvement: 47%
- Catch Size Improvement: 6%
- Other notes: Attracts storm-loving fish

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6443% Fauna Analysis Rewards *(10:00)*

## Additional information

When using anomalous doughnuts in the nutrient ingestor, you get a massive buff to fauna analysis. If you just consume them, you only get a jet pack boost.
