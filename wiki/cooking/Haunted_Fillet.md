# Haunted Fillet

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 39,000.0
- **Updated:** Aquarius

**Haunted Fillet** is a consumable.

## Summary

**Haunted Fillet** is a consumable and one of the Edible Products.

## Game Description

A small morsel of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Use

Exosuit nutrient system will activate **8 seconds of jetpack overload**.

- When consumed through a Nutrient Ingestor, **Haunted Fillet** provides **+50% Breathing Efficiency** for 7:30 minutes.

## Source

Haunted Fillet can be cooked using a Nutrient Processor with the following ingredients:

- The Angler x1 → Haunted Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Haunted Fillet** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Haunted Fillet x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Haunted Fillet x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Haunted Fillet x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Haunted Fillet x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Haunted Fillet x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Additional Information

- Probably the rarest food product in the game.
- This multiplies the value of The Angler by over 24 times.

## Release History

- Aquarius - Added as a consumable.
