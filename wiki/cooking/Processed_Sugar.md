# Processed Sugar

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 1,600
- **Used for:** Cooking
- **Updated:** WorldsTwo

**Processed Sugar** is a consumable.

## Summary

**Processed Sugar** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

Flavour profile: coarse, unrefined, warming.

Recipe Complexity: 56%

## Source

Processed Sugar can be cooked using a Nutrient Processor with the following ingredients:

- Grahberry x1 → Processed Sugar x1 (*"Nutrient Refining"*, 2.5 sec./unit output)
- Sweetroot x1 → Processed Sugar x1 (*"Nutrient Refining"*, 2.5 sec./unit output)
- Cactus Nectar x1 → Processed Sugar x1 (*"Nutrient Refining"*, 2.5 sec./unit output)
