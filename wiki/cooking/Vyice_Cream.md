# Vy'ice Cream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 44,000.0
- **Updated:** Prisms

**Vy'ice Cream** is a consumable.

## Summary

**Vy'ice Cream** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Vy'ice Cream can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Grahberry x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Grahberry x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frozen Tubers x1 + Grahj'am x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Grahj'am x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Grahberry x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Grahberry x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Grahj'am x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Grahj'am x1 → Vy'ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

**Vy'ice Cream** is not used as an ingredient for cooking using a Nutrient Processor.
