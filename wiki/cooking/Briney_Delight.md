# Briney Delight

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 80,200.0
- **Updated:** NextGen

**Briney Delight** is a consumable.

## Summary

**Briney Delight** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

## Source

Briney Delight can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Salty Custard x1 → Briney Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Briney Delight** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 50% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +59% Toxic Resistance *(10:00)*

## Fishing Bait

When applied as bait, Briney Delight gives the following bonus towards your next catch:

- Catch Rarity Improvement: 12%
- Catch Size Improvement: 4%
- Other notes: Attracts nocturnal fish
