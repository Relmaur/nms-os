# Salty Platter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 52,500
- **Updated:** Aquarius

**Salty Platter** is a consumable.

## Summary

**Salty Platter** is a consumable and one of the Edible Products.

## Game Description

A slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **25% hazard protection**.

- When consumed through a Nutrient Ingestor, **Salty Platter** provides **+48% Breathing Efficiency** for 8:30 minutes.

## Fishing Bait

When applied as bait, Salty Platter gives the following bonus towards your next catch:

- Catch Rarity Improvement: 27%
- Catch Size Improvement: 3%

## Source

Salty Platter can be cooked using a Nutrient Processor with the following ingredients:

- Fish x1 + Fish x1 + Fish x1 → Salty Platter x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Salty Platter** is not used as an ingredient for cooking using a Nutrient Processor.

## Release History

- Aquarius - Added as a consumable.
