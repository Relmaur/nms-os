# Nourishing Oozer

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 81,900
- **Updated:** WorldsTwo

**Nourishing Oozer** is a consumable.

## Summary

**Nourishing Oozer** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

Flavour profile: synesthetic, complex, piquant.

Recipe Complexity: 100%

## Source

Nourishing Oozer can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Sweetened Mucous x1 + Cream x1 → Nourishing Oozer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Nourishing Oozer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Nourishing Oozer** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Nourishing Oozer gives the following bonus towards your next catch:

- Catch Rarity Improvement: 23%
- Catch Size Improvement: 7%
- Other notes: Attracts nocturnal fish

## Additional Information

Restores 1% health once consumed.
