# Fruity Pudding

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 40,000.0
- **Updated:** NextGen

**Fruity Pudding** is a consumable.

## Summary

**Fruity Pudding** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Fruity Pudding can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Pilgrimberry x1 → Fruity Pudding x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Grahberry x1 → Fruity Pudding x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Fruity Pudding** is not used as an ingredient for cooking using a Nutrient Processor.
