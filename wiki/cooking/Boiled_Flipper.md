# Boiled Flipper

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Aquarius

**Boiled Flipper** is a consumable.

## Summary

**Boiled Flipper** is a consumable and one of the Edible Products.

## Game Description

A piece of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **25% hazard protection**.

- When consumed through a Nutrient Ingestor, **Boiled Flipper** provides **+43% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Boiled Flipper gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 14%

## Source

Boiled Flipper can be cooked using a Nutrient Processor with the following ingredients:

- Wandering Shellback x1 → Boiled Flipper x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Moon Turtle x1 → Boiled Flipper x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Iceshell Turtle x1 → Boiled Flipper x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Boiled Flipper** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Boiled Flipper x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Boiled Flipper x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Boiled Flipper x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Boiled Flipper x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Boiled Flipper x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
