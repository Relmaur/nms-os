# Mucal Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 81,900
- **Updated:** WorldsTwo

**Mucal Curiosity** is a consumable.

## Summary

**Mucal Curiosity** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

Flavour profile: colourful, smooth, explosive.

Recipe Complexity: 100%

## Source

Mucal Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Sweetened Mucous x1 + Cream x1 → Mucal Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Mucal Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Mucal Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Mucal Curiosity gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 25%

## Additional Information

Restores 1% health once consumed.

- Worlds Part I - Added as a consumable.
