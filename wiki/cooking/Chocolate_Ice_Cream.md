# Chocolate Ice Cream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 44,000.0
- **Updated:** Prisms

**Chocolate Ice Cream** is a consumable.

## Summary

**Chocolate Ice Cream** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Chocolate Ice Cream can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Bittersweet Cocoa x1 → Chocolate Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Bittersweet Cocoa x1 → Chocolate Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Bittersweet Cocoa x1 → Chocolate Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Bittersweet Cocoa x1 → Chocolate Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

**Chocolate Ice Cream** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 25% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +54% Cold Resistance *(10:00)*

## Fishing Bait

When applied as bait, Chocolate Ice Cream gives the following bonus towards your next catch:

- Catch Rarity Improvement: 15%
- Catch Size Improvement: 32%
- Other notes: Attracts diurnal fish
