# Delicate Meringue

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 5,400.0
- **Updated:** Origins

**Delicate Meringue** is a consumable.

## Summary

**Delicate Meringue** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable.** It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subject to further processing.

## Source

Delicate Meringue can be cooked using a Nutrient Processor with the following ingredients:

- Larval Core x1 + Processed Sugar x1 → Delicate Meringue x1 (*"Component Churn"*, 2.5 sec./unit output)
- Creature Egg x1 + Processed Sugar x1 → Delicate Meringue x1 (*"Component Churn"*, 2.5 sec./unit output)
- Tall Eggs x1 + Processed Sugar x1 → Delicate Meringue x1 (*"Component Churn"*, 2.5 sec./unit output)
- Giant Egg x1 + Processed Sugar x1 → Delicate Meringue x1 (*"Component Churn"*, 2.5 sec./unit output)

## Usage

### Crafting

**Delicate Meringue** is not used as an ingredient for crafting.

### Refining

**Delicate Meringue** is not used as an ingredient for refining using a Refiner.

### Cooking

**Delicate Meringue** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Extra-Fluffy Batter -- Delicate Meringue x1 + Refined Flour x1 + Creature Egg x1 → Extra-Fluffy Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Extra-Fluffy Batter -- Delicate Meringue x1 + Refined Flour x1 + Giant Egg x1 → Extra-Fluffy Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Extra-Fluffy Batter -- Delicate Meringue x1 + Refined Flour x1 + Tall Eggs x1 → Extra-Fluffy Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Writhing, Roiling Batter -- Delicate Meringue x1 + Refined Flour x1 + Larval Core x1 → Writhing, Roiling Batter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Consume

- Replenishes **25% Hazard Protection** when consumed without a Nutrient Processor.
- Fueling a Nutrient Ingestor with **Delicate Meringue** will grant +9% Sprint Recovery Time for 7:00 per unit consumed.

## Fishing Bait

When applied as bait, Delicate Meringue gives the following bonus towards your next catch:

- Catch Rarity Improvement: 19%
- Catch Size Improvement: 26%
