# Honey Butter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 32,000.0
- **Updated:** SentinelUp

**Honey Butter** is a consumable.

## Summary

**Honey Butter** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable.** It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subject to further processing.

## Source

Honey Butter can be cooked using a Nutrient Processor with the following ingredients:

- Churned Butter x1 + Synthetic Honey x1 → Honey Butter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Bone Butter x1 + Synthetic Honey x1 → Honey Butter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Recipes

**Honey Butter** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Cake Batter -- Honey Butter x1 + Refined Flour x1 + Creature Egg x1 → Cake Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Cake Batter -- Honey Butter x1 + Refined Flour x1 + Giant Egg x1 → Cake Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Cake Batter -- Honey Butter x1 + Refined Flour x1 + Tall Eggs x1 → Cake Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Honeybutter Doughnut -- Lumpen Doughnut x1 + Honey Butter x1 → Honeybutter Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Wailing Batter -- Honey Butter x1 + Refined Flour x1 + Larval Core x1 → Wailing Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
