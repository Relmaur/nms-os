# Perpetual Honeycake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 80,800.0
- **Updated:** Prisms

**Perpetual Honeycake** is a consumable.

## Summary

**Perpetual Honeycake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Perpetual Honeycake can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Anomalous Jam x1 + Cream x1 → Perpetual Honeycake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Anomalous Jam x1 + Bone Cream x1 → Perpetual Honeycake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Perpetual Honeycake** is not used as an ingredient for cooking using a Nutrient Processor.
