# Haunted Chocolate Dreams

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 148,000.0
- **Updated:** NextGen

**Haunted Chocolate Dreams** is a consumable.

## Summary

**Haunted Chocolate Dreams** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Wailing Batter.

## Source

Haunted Chocolate Dreams can be cooked using a Nutrient Processor with the following ingredients:

- Wailing Batter x1 + Bittersweet Cocoa x1 → Haunted Chocolate Dreams x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Haunted Chocolate Dreams** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,535% Flora Analysis Rewards *(10:00)*

## Fishing Bait

When applied as bait, Haunted Chocolate Dreams gives the following bonus towards your next catch:

- Catch Rarity Improvement: 18%
- Catch Size Improvement: 36%
