# Thick, Sweet Batter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 48,000.0
- **Updated:** NextGen

**Thick, Sweet Batter** is a consumable.

## Summary

**Thick, Sweet Batter** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable**.
It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Thick, Sweet Batter can be cooked using a Nutrient Processor with the following ingredients:

- Gooey ProtoButter x1 + Refined Flour x1 + Creature Egg x1 → Thick, Sweet Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Gooey Butter x1 + Refined Flour x1 + Creature Egg x1 → Thick, Sweet Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Gooey ProtoButter x1 + Refined Flour x1 + Tall Eggs x1 → Thick, Sweet Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Gooey Butter x1 + Refined Flour x1 + Tall Eggs x1 → Thick, Sweet Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Gooey ProtoButter x1 + Refined Flour x1 + Giant Egg x1 → Thick, Sweet Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Gooey Butter x1 + Refined Flour x1 + Giant Egg x1 → Thick, Sweet Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
