# Mushed Root Pie

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 40,000.0
- **Updated:** NextGen

**Mushed Root Pie** is a consumable.

## Summary

**Mushed Root Pie** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in star contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Mushed Root Pie can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Sweetroot x1 → Mushed Root Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Mushed Root Pie** is not used as an ingredient for cooking using a Nutrient Processor.
