# Chocolate Dream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 19,200.0
- **Updated:** NextGen

**Chocolate Dream** is a consumable.

## Summary

**Chocolate Dream** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Chocolate Dream can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Bittersweet Cocoa x1 → Chocolate Dream x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Chocolate Dream** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +43% Shield Strength *(10:00)*

## Fishing Bait

When applied as bait, Chocolate Dream gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 2%
- Other notes: Attracts diurnal fish
