# Unbound Cream Horn

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 128,000.0
- **Updated:** Prisms

**Unbound Cream Horn** is a consumable.

## Summary

**Unbound Cream Horn** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

## Source

Unbound Cream Horn can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Cream x1 → Unbound Cream Horn x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Bone Cream x1 → Unbound Cream Horn x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Unbound Cream Horn** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,362% Fauna Analysis Rewards *(10:00)*

## Fishing Bait

When applied as bait, Unbound Cream Horn gives the following bonus towards your next catch:

- Catch Rarity Improvement: 10%
- Catch Size Improvement: 3%
- Other notes: Attracts nocturnal fish
