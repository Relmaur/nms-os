# Gooey Chocolate Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 60,500.0
- **Updated:** NextGen

**Gooey Chocolate Cake** is a consumable.

## Summary

**Gooey Chocolate Cake** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Gooey Chocolate Cake can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Bittersweet Cocoa x1 → Gooey Chocolate Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Gooey Chocolate Cake** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will power 15 seconds sprint overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,173% Mineral Analysis Reward *(10:00)*

## Fishing Bait

When applied as bait, Gooey Chocolate Cake gives the following bonus towards your next catch:

- Catch Rarity Improvement: 46%
- Catch Size Improvement: 7%
