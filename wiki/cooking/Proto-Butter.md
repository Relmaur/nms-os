# Proto-Butter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 9,400
- **Updated:** WorldsTwo

**Proto-Butter** is a consumable.

## Summary

**Proto-Butter** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

Flavour profile: pleasingly sweet, crisp, tangy.

Recipe Complexity: 71%

## Source

Proto-Butter can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Cream x1 → Proto-Butter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Recipes

**Proto-Butter** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Clarified Oil -- Bone Butter x1 + Proto-Butter x1 → Clarified Oil x1 (*"Nutrient Refining"*, 2.5 sec./unit output)
- Clarified Oil -- Churned Butter x1 + Proto-Butter x1 → Clarified Oil x1 (*"Nutrient Refining"*, 2.5 sec./unit output)
- Gooey ProtoButter -- Proto-Butter x1 + Sticky 'Honey' x1 → Gooey ProtoButter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Honied Proto-Butter -- Proto-Butter x1 + Synthetic Honey x1 → Honied Proto-Butter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Pastry -- Refined Flour x1 + Proto-Butter x1 → Pastry x1 (*"Component Churn"*, 2.5 sec./unit output)
- Proto-Oil -- Proto-Butter x1 + Proto-Butter x1 → Proto-Oil x1 (*"Nutrient Refining"*, 2.5 sec./unit output)
- Sweetened Proto-Butter -- Proto-Butter x1 + Processed Sugar x1 → Sweetened Proto-Butter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Syrupy Proto-Butter -- Proto-Butter x1 + Syrupy Nectar x1 → Syrupy Proto-Butter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Fishing Bait

When applied as bait, Proto-Butter gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Additional Information

Restores 25% hazard protection when consumed.
