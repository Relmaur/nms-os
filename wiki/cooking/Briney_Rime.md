# Briney Rime

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 36,000.0
- **Updated:** NextGen

**Briney Rime** is a consumable.

## Summary

**Briney Rime** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Briney Rime can be cooked using a Nutrient Processor with the following ingredients:

- Salty Custard x1 + Frozen Tubers x1 → Briney Rime x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Salty Custard x1 + Frost Crystal x1 → Briney Rime x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

**Briney Rime** is not used as an ingredient for cooking using a Nutrient Processor.
