# Gelatinous Sponge

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 68,100
- **Updated:** WorldsTwo

**Gelatinous Sponge** is a consumable.

## Summary

**Gelatinous Sponge** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

Flavour profile: complex, smooth, tropical.

Recipe Complexity: 100%

## Source

Gelatinous Sponge can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Sweetened Mucous x1 + Cream x1 → Gelatinous Sponge x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Cake Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Gelatinous Sponge x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Gelatinous Sponge** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Gelatinous Sponge gives the following bonus towards your next catch:

- Catch Rarity Improvement: 22%
- Catch Size Improvement: 1%

## Additional Information

Restores 1% health once consumed.
