# Honied Angel Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 20,900.0
- **Updated:** WorldsOne

**Honied Angel Cake** is a consumable.

## Summary

**Honied Angel Cake** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Honied Angel Cake can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Synthetic Honey x1 → Honied Angel Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Honied Angel Cake** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.
