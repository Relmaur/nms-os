# Honey-Soaked Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 62,200.0
- **Updated:** NextGen

**Honey-Soaked Fancy** is a consumable.

## Summary

**Honey-Soaked Fancy** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Honey-Soaked Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Synthetic Honey x1 → Honey-Soaked Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Honey-Soaked Fancy** is not used as an ingredient for cooking using a Nutrient Processor.
