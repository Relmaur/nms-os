# Jellied Eel

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 52,500
- **Updated:** Aquarius

**Jellied Eel** is a consumable.

## Summary

**Jellied Eel** is a consumable and one of the Edible Products.

## Game Description

A slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **50% hazard protection**.

- When consumed through a Nutrient Ingestor, **Jellied Eel** provides **+46% Breathing Efficiency** for 7:30 minutes.

## Fishing Bait

When applied as bait, Jellied Eel gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: -%

## Source

Jellied Eel can be cooked using a Nutrient Processor with the following ingredients:

- Jellymeat x1 + Fleshy Cylinder x1 → Jellied Eel x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Jellied Eel** is not used as an ingredient for cooking using a Nutrient Processor.

## Release History

- Aquarius - Added as a consumable.
