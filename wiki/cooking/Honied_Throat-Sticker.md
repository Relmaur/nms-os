# Honied Throat-Sticker

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 71,500.0
- **Updated:** Prisms

**Honied Throat-Sticker** is a consumable.

## Summary

**Honied Throat-Sticker** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Honied Throat-Sticker can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Cactus Nectar x1 → Honied Throat-Sticker x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Cactus Jelly x1 + Cream x1 → Honied Throat-Sticker x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Cactus Jelly x1 + Bone Cream x1 → Honied Throat-Sticker x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Honied Throat-Sticker** is not used as an ingredient for cooking using a Nutrient Processor.
