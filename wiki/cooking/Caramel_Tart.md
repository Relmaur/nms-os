# Caramel Tart

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 62,000.0
- **Updated:** NextGen

**Caramel Tart** is a consumable.

## Summary

**Caramel Tart** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Caramel Tart can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Crunchy Caramel x1 → Caramel Tart x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Caramel Tart** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 15 second sprint overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +7% Sprint Recovery Time *(10:00)*

## Fishing Bait

When applied as bait, Caramel Tart gives the following bonus towards your next catch:

- Catch Rarity Improvement: 57%
- Catch Size Improvement: 6%
