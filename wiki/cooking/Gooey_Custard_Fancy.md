# Gooey Custard Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 97,200.0
- **Updated:** Prisms

**Gooey Custard Fancy** is a consumable.

## Summary

**Gooey Custard Fancy** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Gooey Custard Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Viscous Custard x1 → Gooey Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Very Thick Custard x1 → Gooey Custard Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Gooey Custard Fancy** is not used as an ingredient for cooking using a Nutrient Processor.
