# Perpetual Jam Fluffer

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 34,100.0
- **Updated:** Prisms

**Perpetual Jam Fluffer** is a consumable.

## Summary

**Perpetual Jam Fluffer** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Perpetual Jam Fluffer can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Anomalous Jam x1 + Cream x1 → Perpetual Jam Fluffer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Anomalous Jam x1 + Bone Cream x1 → Perpetual Jam Fluffer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Perpetual Jam Fluffer** is not used as an ingredient for cooking using a Nutrient Processor.
