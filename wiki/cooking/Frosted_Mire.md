# Frosted Mire

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 35,200
- **Updated:** WorldsTwo

**Frosted Mire** is a consumable.

## Summary

**Frosted Mire** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

Flavour profile: ephemeral, smooth, vibrant.

Recipe Complexity: 100%

## Source

Frosted Mire can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Sweetened Mucous x1 + Cream x1 → Frosted Mire x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Frosted Mire x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Frosted Mire** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Frosted Mire gives the following bonus towards your next catch:

- Catch Rarity Improvement: 25%
- Catch Size Improvement: -%
- Other notes: Attracts storm-loving fish

## Additional Information

Restores 1% health once consumed.
