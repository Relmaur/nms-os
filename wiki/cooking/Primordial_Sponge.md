# Primordial Sponge

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 180,700
- **Updated:** WorldsOne

**Primordial Sponge** is a consumable.

## Summary

**Primordial Sponge** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Wailing Batter.

## Source

Primordial Sponge can be cooked using a Nutrient Processor with the following ingredients:

- Wailing Batter x1 + Sweetened Mucous x1 + Cream x1 → Primordial Sponge x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Wailing Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Primordial Sponge x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Primordial Sponge** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Restores 1% health once consumed.

## Release History

- Worlds Part I - Added as a consumable.
