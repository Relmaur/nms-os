# Jam Oozers

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 81,900.0
- **Updated:** Prisms

**Jam Oozers** is a consumable.

## Summary

**Jam Oozers** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Jam Oozers can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Grahj'am x1 + Cream x1 → Jam Oozers x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Grahj'am x1 + Bone Cream x1 → Jam Oozers x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Furball Jelly x1 + Cream x1 → Jam Oozers x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Furball Jelly x1 + Bone Cream x1 → Jam Oozers x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Jam Oozers** is not used as an ingredient for cooking using a Nutrient Processor.
