# 'Apple' Roll

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 42,000
- **Updated:** Swarm

'**Apple' Roll** is a consumable.

## Summary

'**Apple' Roll** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully chosen ingredients.

Flavour profile: roasted, crisp, floral.

Recipe Complexity: 63%

## Source

'Apple' Roll can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Crab 'Apple' x1 → 'Apple' Roll x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Wriggling Jam x1 → 'Apple' Roll x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

'**Apple' Roll** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, 'Apple' Roll gives the following bonus towards your next catch:

- Catch Rarity Improvement: 35%
- Catch Size Improvement: 2%

## Additional Information

Restores 20% Life Support when consumed directly

+42% Sprint Distance when consumed through the Nutrient Ingestor
