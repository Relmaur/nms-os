# Sea's Bounty

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 71,450
- **Updated:** Aquarius

**Sea's Bounty** is a consumable.

## Summary

**Sea's Bounty** is a consumable and one of the Edible Products.

## Game Description

A huge slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

Flavour profile: prismatic,vivid,manifold.

Recipe Complexity: 100%

## Source

Sea's Bounty can be cooked using a Nutrient Processor with the following ingredients:

- Jellymeat x1 + Fleshy Cylinder x1 + Assorted Roe x1 → Sea's Bounty x1 (*"Sea's Bounty"*, 2.5 sec./unit output)

## Recipes

**Sea's Bounty** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 50% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +55% Breathing Efficiency *(10:00)*

## Fishing Bait

When applied as bait, Sea's Bounty gives the following bonus towards your next catch:

- Catch Rarity Improvement: 19%
- Catch Size Improvement: 3%
- Other notes: Attracts nocturnal fish
