# Whitebait

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 28,000
- **Updated:** Aquarius

**Whitebait** is a consumable.

## Summary

**Whitebait** is a consumable and one of the Edible Products.

## Game Description

A small morsel of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **1% health**.

- When consumed through a Nutrient Ingestor, **Whitebait** provides **+45% Breathing Efficiency** for 4:30 minutes.

## Fishing Bait

When applied as bait, Whitebait gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts nocturnal fish

## Source

Whitebait can be cooked using a Nutrient Processor with the following ingredients:

- Pondskipper x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Waspfish x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Field's Dartfish x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Common Sunfish x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Ice Darter x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Shadowfin x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- [[File:|18px|text-bottom|link=Sweetwater Minnow]] Sweetwater Minnow x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Lesser Dustfin x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Vectorfin x1 → Whitebait x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Whitebait** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Whitebait x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Whitebait x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Whitebait x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Whitebait x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Whitebait x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
