# Cream Fingers

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 105,000
- **Updated:** WorldsOne

**Cream Fingers** is a consumable.

## Summary

**Cream Fingers** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully chosen ingredients.

## Source

Cream Fingers can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Cream x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Proto-Cream x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Bone Cream x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Salty Custard x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Viscous Custard x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Stellar Custard x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Monstrous Custard x1 → Cream Fingers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Cream Fingers** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 20% life support power when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +22% Hazard Protection Battery *(6:36)*

## Fishing Bait

When applied as bait, Cream Fingers gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Additional information

Very valuable for a simple recipe.
