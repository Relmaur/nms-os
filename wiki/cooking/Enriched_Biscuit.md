# Enriched Biscuit

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 56,000.0
- **Updated:** Omega

**Enriched Biscuit** is a consumable.

## Summary

**Enriched Biscuit** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully chosen ingredients.

## Source

Enriched Biscuit can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Bone Milk x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Craw Milk x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Fresh Milk x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Warm Proto-Milk x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Wild Milk x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Creature Egg x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Giant Egg x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Tall Eggs x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Bone Nuggets x1 → Enriched Biscuit x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Enriched Biscuit** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, **Enriched Biscuit** gives the following bonus towards your next catch:

Catch Rarity Improvement: 28%

Catch Size Improvement: 3%

## Additional Information

Restores 25% hazard protection once consumed.

Process with Nutrient Ingestor for 6:36 minutes with +22% Hazard Protection Battery.
