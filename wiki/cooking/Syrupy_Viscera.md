# Syrupy Viscera

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 32,000
- **Updated:** WorldsTwo

**Syrupy Viscera** is a consumable.

## Summary

**Syrupy Viscera** is a consumable and it is an Edible Product.

## Game Description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

## Source

Syrupy Viscera can be cooked using a Nutrient Processor with the following ingredients:

- Nightmare Sausage x1 + Processed Sugar x1 → Syrupy Viscera x1 (*"Component Churn"*, 2.5 sec./unit output)

## Usage

### Crafting

**Syrupy Viscera** is not used as an ingredient for crafting.

### Refining

**Syrupy Viscera** is not used as an ingredient for refining using a Refiner.

### Cooking

**Syrupy Viscera** is not used as an ingredient for cooking using a Nutrient Processor.

## Consume

- Can not be consumed without a Nutrient Processor.
- Fueling a Nutrient Ingestor with **Syrupy Viscera** will grant +15% Sprint Distance for 2:00 per unit consumed.

## Fishing Bait

When applied as bait, Syrupy Viscera gives the following bonus towards your next catch:

- Catch Rarity Improvement: 11%
- Catch Size Improvement: 2%
- Other notes: N/A
