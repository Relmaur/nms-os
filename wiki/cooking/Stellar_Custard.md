# Stellar Custard

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 28,000
- **Updated:** WorldsTwo

**Stellar Custard** is a consumable.

## Summary

**Stellar Custard** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

Flavour profile: colourful, delicate, astonishing.

Recipe Complexity: 100%

## Source

Stellar Custard can be cooked using a Nutrient Processor with the following ingredients:

- Silicon Egg x1 + Cream x1 + Processed Sugar x1 → Stellar Custard x1 (*"Component Churn"*, 2.5 sec./unit output)

## Use

Exosuit nutrient system will restore 50% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor
