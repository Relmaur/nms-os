# Wailing Caramel Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 152,300.0
- **Updated:** NextGen

**Wailing Caramel Cake** is a consumable.

## Summary

**Wailing Caramel Cake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Wailing Batter.

## Source

Wailing Caramel Cake can be cooked using a Nutrient Processor with the following ingredients:

- Wailing Batter x1 + Crunchy Caramel x1 → Wailing Caramel Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Wailing Caramel Cake** is not used as an ingredient for cooking using a Nutrient Processor.
