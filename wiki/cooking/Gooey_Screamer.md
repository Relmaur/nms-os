# Gooey Screamer

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 167,200
- **Updated:** Fractal

**Gooey Screamer** is a consumable.

## Summary

**Gooey Screamer** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Wailing Batter.

## Source

Gooey Screamer can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Monstrous Custard x1 → Gooey Screamer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Wailing Batter x1 + Sticky 'Honey' x1 → Gooey Screamer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Wailing Batter x1 + Gooey Butter x1 → Gooey Screamer x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Gooey Screamer** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

- Provides a Jetpack Supercharge similar to the Deuterium plant boost when it is consumed.
- If fed through a Nutrient Ingestor, provides a 6,129% bonus to Fauna Analysis Rewards.
