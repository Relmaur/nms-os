# Custard Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 105,000
- **Updated:** Prisms

**Custard Doughnut** is a consumable.

## Summary

**Custard Doughnut** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable.**

## Source

Custard Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Viscous Custard x1 → Custard Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Lumpen Doughnut x1 + Very Thick Custard x1 → Custard Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Custard Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +29% Mining Speed *(10:00)*

## Fishing Bait

When applied as bait, Custard Doughnut gives the following bonus towards your next catch:

- Catch Rarity Improvement: 13%
- Catch Size Improvement: 2%
