# Delicate Legs

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Aquarius

**Delicate Legs** is a consumable.

## Summary

**Delicate Legs** is a consumable and one of the Edible Products.

## Game Description

A piece of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **20% life support power**.

- When consumed through a Nutrient Ingestor, **Delicate Legs** provides **+42% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Delicate Legs gives the following bonus towards your next catch:

- Catch Rarity Improvement: 23%
- Catch Size Improvement: 2%

## Source

Delicate Legs can be cooked using a Nutrient Processor with the following ingredients:

- Spiny Starfish x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Caustic Urchin x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Shalebound Starfish x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Anemone Anomaly x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Pulp Urchin x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Golden Urchin x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Ocean's Star x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Emeril Sunstar x1 → Delicate Legs x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Delicate Legs** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Delicate Legs x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Delicate Legs x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Delicate Legs x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Delicate Legs x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Delicate Legs x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
