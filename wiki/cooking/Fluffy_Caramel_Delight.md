# Fluffy Caramel Delight

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 23,600.0
- **Updated:** WorldsOne

**Fluffy Caramel Delight** is a consumable.

## Summary

**Fluffy Caramel Delight** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Fluffy Caramel Delight can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Crunchy Caramel x1 → Fluffy Caramel Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Fluffy Caramel Delight** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Release History

- Beyond - Added as a consumable.
