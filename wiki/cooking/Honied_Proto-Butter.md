# Honied Proto-Butter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 36,000.0
- **Updated:** WorldsOne

**Honied Proto-Butter** is a consumable.

## Summary

**Honied Proto-Butter** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Honied Proto-Butter can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Butter x1 + Synthetic Honey x1 → Honied Proto-Butter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Recipes

**Honied Proto-Butter** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Honeybutter Doughnut -- Lumpen Doughnut x1 + Honied Proto-Butter x1 → Honeybutter Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)
- Proto-Batter -- Honied Proto-Butter x1 + Refined Flour x1 + Creature Egg x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Proto-Batter -- Honied Proto-Butter x1 + Refined Flour x1 + Giant Egg x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Proto-Batter -- Honied Proto-Butter x1 + Refined Flour x1 + Tall Eggs x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Wailing Batter -- Honied Proto-Butter x1 + Refined Flour x1 + Larval Core x1 → Wailing Batter x1 (*"Component Churn"*, 2.5 sec./unit output)

## Additional Information

Exosuit nutrient system will restore 40% life support power when consumed.
