# Creamy Treat

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 62,000.0
- **Updated:** Prisms

**Creamy Treat** is a consumable.

## Summary

**Creamy Treat** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Creamy Treat can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Cream x1 → Creamy Treat x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Bone Cream x1 → Creamy Treat x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Creamy Treat** is not used as an ingredient for cooking using a Nutrient Processor.
