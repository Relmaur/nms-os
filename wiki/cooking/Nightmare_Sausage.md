# Nightmare Sausage

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 16,000
- **Updated:** WorldsTwo

**Nightmare Sausage** is a consumable.

## Summary

**Nightmare Sausage** is a consumable and it is an Edible Product.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Nightmare Sausage can be cooked using a Nutrient Processor with the following ingredients:

- Gelatinous Membrane x1 + Larval Core x1 → Nightmare Sausage x1 (*"Preserve Flesh"*, 2.5 sec./unit output)
- Gelatinous Membrane x1 + Hypnotic Eye x1 → Nightmare Sausage x1 (*"Preserve Flesh"*, 2.5 sec./unit output)
- Gelatinous Membrane x1 + Hadal Core x1 → Nightmare Sausage x1 (*"Preserve Flesh"*, 2.5 sec./unit output)

## Usage

### Crafting

**Nightmare Sausage** is not used as an ingredient for crafting.

### Refining

**Nightmare Sausage** is not used as an ingredient for refining using a Refiner.

### Cooking

**Nightmare Sausage** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Syrupy Viscera -- Nightmare Sausage x1 + Processed Sugar x1 → Syrupy Viscera x1 (*"Component Churn"*, 2.5 sec./unit output)
- Wriggling Tack -- Sugar Dough x1 + Nightmare Sausage x1 → Wriggling Tack x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Use

Cannot be consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +1,612% Flora Analysis Rewards *(2:00)*

When applied as bait, Nightmare Sausage gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
