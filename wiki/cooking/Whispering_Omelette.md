# Whispering Omelette

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 96,000.0
- **Updated:** Prisms

**Whispering Omelette** is a consumable.

## Summary

**Whispering Omelette** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Whispering Omelette can be cooked using a Nutrient Processor with the following ingredients:

- Larval Core x1 + Tangy Cheese x1 → Whispering Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Larval Core x1 + Bone Cream (Cheese) x1 → Whispering Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)

## Recipes

**Whispering Omelette** is not used as an ingredient for cooking using a Nutrient Processor.
