# Wriggling Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 70,000
- **Updated:** WorldsOne

**Wriggling Doughnut** is a consumable.

## Summary

**Wriggling Doughnut** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

## Source

Wriggling Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Wriggling Jam x1 → Wriggling Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Wriggling Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

+6548% Flora Analysis Rewards when processed through a nutrient ingestor.
