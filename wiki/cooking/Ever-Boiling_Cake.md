# Ever-Boiling Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 64,300.0
- **Updated:** Prisms

**Ever-Boiling Cake** is a consumable.

## Summary

**Ever-Boiling Cake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

## Source

Ever-Boiling Cake can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Ever-burning Jam x1 + Cream x1 → Ever-Boiling Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Cake Batter x1 + Ever-burning Jam x1 + Bone Cream x1 → Ever-Boiling Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Ever-Boiling Cake** is not used as an ingredient for cooking using a Nutrient Processor.
