# Custard Tart

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 78,000.0
- **Updated:** Prisms

**Custard Tart** is a consumable.

## Summary

**Custard Tart** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Custard Tart can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Viscous Custard x1 → Custard Tart x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Salty Custard x1 → Custard Tart x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Very Thick Custard x1 → Custard Tart x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Custard Tart** is not used as an ingredient for cooking using a Nutrient Processor.
