# Candied 'Apples'

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 78,000
- **Updated:** WorldsTwo

**Candied 'Apples'** is a consumable.

## Summary

**Candied 'Apples'** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

Flavour profile: piquant, polyphonic, prismatic.

Recipe Complexity: 100%

## Source

Candied 'Apples' can be cooked using a Nutrient Processor with the following ingredients:

- Syrupy Batter x1 + Crab 'Apple' x1 → Candied 'Apples' x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Wriggling Jam x1 + Cream x1 → Candied 'Apples' x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Wriggling Jam x1 + Bone Cream x1 → Candied 'Apples' x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Candied 'Apples'** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Candied 'Apples' gives the following bonus towards your next catch:

- Catch Rarity Improvement: 23%
- Catch Size Improvement: 7%
- Other notes: Attracts storm-loving fish

## Additional Information

Restores 50% health once consumed.
