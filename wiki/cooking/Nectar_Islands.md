# Nectar Islands

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 94,800
- **Updated:** WorldsOne

**Nectar Islands** is a consumable.

## Summary

**Nectar Islands** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Extra-Fluffy Batter.

## Source

Nectar Islands can be cooked using a Nutrient Processor with the following ingredients:

- Extra-Fluffy Batter x1 + Syrupy Nectar x1 → Nectar Islands x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Extra-Fluffy Batter x1 + Butter Syrup x1 → Nectar Islands x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Nectar Islands** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will power 15 seconds sprint overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,532% Fauna Analysis Rewards *(10:00)*

## Fishing Bait

When applied as bait, Nectar Islands gives the following bonus towards your next catch:

- Catch Rarity Improvement: 61%
- Catch Size Improvement: 8%
- Other notes: Attracts nocturnal fish
