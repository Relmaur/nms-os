# Unbound Monstrosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 152,200.0
- **Updated:** Prisms

**Unbound Monstrosity** is a consumable.

## Summary

**Unbound Monstrosity** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

## Source

Unbound Monstrosity can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Anomalous Jam x1 + Cream x1 → Unbound Monstrosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Anomalous Jam x1 + Bone Cream x1 → Unbound Monstrosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Unbound Monstrosity** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +315% Jetpack Tanks *(10:00)*

## Fishing Bait

When applied as bait, Unbound Monstrosity gives the following bonus towards your next catch:

- Catch Rarity Improvement: 41%
- Catch Size Improvement: 8%
- Other notes: Attracts nocturnal fish
