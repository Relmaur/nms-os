# Devilled Organs

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 18,800.0
- **Updated:** Omega

**Devilled Organs** is a consumable.

## Summary

**Devilled Organs** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Devilled Organs can be cooked using a Nutrient Processor with the following ingredients:

- Stewed Organs x1 + Scorching Sauce x1 → Devilled Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Crystalline Soup x1 + Scorching Sauce x1 → Devilled Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Chewy 'Dumpling' Stew x1 + Scorching Sauce x1 → Devilled Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)
- Gelatinous Goop x1 + Scorching Sauce x1 → Devilled Organs x1 (*"Combine and Reduce"*, 2.5 sec./unit output)

## Recipes

**Devilled Organs** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 20% life support power when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +54% Heat Resistance *(10:00)*

## Fishing Bait

When applied as bait, Devilled Organs gives the following bonus towards your next catch:

- Catch Rarity Improvement: 8%
- Catch Size Improvement: 8%
- Other notes: Attracts diurnal fish
