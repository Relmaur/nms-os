# Sticky Finger

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 41,000
- **Updated:** WorldsOne

**Sticky Finger** is a consumable.

## Summary

**Sticky Finger** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully-chosen ingredients.

## Source

Sticky Finger can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Crunchy Caramel x1 → Sticky Finger x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Sticky Finger** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 25% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +74% Life Support Tanks *(6:36)*

## Fishing Bait

When applied as bait, Sticky Finger gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 17%
