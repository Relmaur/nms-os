# Honey Ice Cream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 56,000
- **Updated:** WorldsOne

**Honey Ice Cream** is a consumable.

## Summary

**Honey Ice Cream** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

## Source

Honey Ice Cream can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Synthetic Honey x1 → Honey Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Synthetic Honey x1 → Honey Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frozen Tubers x1 + Sticky 'Honey' x1 → Honey Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Sticky 'Honey' x1 → Honey Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frozen Tubers x1 + Syrupy Nectar x1 → Honey Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Syrupy Nectar x1 → Honey Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
