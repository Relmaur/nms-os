# Purged Ribs

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 9,200
- **Updated:** WorldsTwo

**Purged Ribs** is a consumable.

## Summary

**Purged Ribs** is a consumable and it is an Edible Product.

## Game Description

The char of the Nutrient Processor's highest power setting has burned the stench from this one rancid slab. They writh no more...

Can be consumed as it stands or subjected to further processing.

Flavour profile: floral, tangy, bracing.

Recipe Complexity: 77%

## Source

Purged Ribs can be cooked using a Nutrient Processor with the following ingredients:

- Rancid Flesh x1 → Purged Ribs x1 (*"Purge By Fire"*, 2.5 sec./unit output)

## Recipes

**Purged Ribs** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 2% health when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +54% Toxic Resistance *(7:30)*

## Fishing Bait

When applied as bait, Purged Ribs gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 27%
- Other notes: N/A
