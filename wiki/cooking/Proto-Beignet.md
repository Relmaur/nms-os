# Proto-Beignet

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 72,000.0
- **Updated:** WorldsOne

**Proto-Beignet** is a consumable.

## Summary

**Proto-Beignet** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Proto-Beignet can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Oil x1 + Dough x1 + Processed Sugar x1 → Proto-Beignet x1 (*"Accelerated Fry"*, 2.5 sec./unit output)

## Recipes

**Proto-Beignet** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.
