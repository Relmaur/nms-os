# Syrup-Drenched Delight

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 73,600
- **Updated:** WorldsTwo

**Syrup-Drenched Delight** is a consumable.

## Summary

**Syrup-Drenched Delight** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Cake Batter.

Flavour profile: explosive, astonishing, delicate.

Recipe Complexity: 100%

## Source

Syrup-Drenched Delight can be cooked using a Nutrient Processor with the following ingredients:

- Cake Batter x1 + Syrupy Nectar x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Cake Batter x1 + Butter Syrup x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Syrupy Nectar x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Butter Syrup x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Syrupy Nectar x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Butter Syrup x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Sticky 'Honey' x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Gooey Butter x1 → Syrup-Drenched Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Syrup-Drenched Delight** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Syrup-Drenched Delight gives the following bonus towards your next catch:

- Catch Rarity Improvement: 27%
- Catch Size Improvement: 0%
- Other notes: Attracts nocturnal fish

## Additional Information

Restores 2% health once consumed in Exosuit.

+62% Resources mined, for 10 min, When consumed in Nutrient Ingestor.
