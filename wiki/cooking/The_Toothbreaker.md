# The Toothbreaker

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 62,000.0
- **Updated:** Origins

**The Toothbreaker** is a consumable.

## Summary

**The Toothbreaker** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable.**

## Source

The Toothbreaker can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Crystal Flesh x1 → The Toothbreaker x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**The Toothbreaker** is not used as an ingredient for cooking using a Nutrient Processor.
