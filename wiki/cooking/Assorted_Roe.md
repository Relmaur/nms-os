# Assorted Roe

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 39,000
- **Updated:** Aquarius

**Assorted Roe** is a consumable.

## Summary

**Assorted Roe** is a consumable and one of the Edible Products.

## Game Description

A small morsel of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **50% health**.

- When consumed through a Nutrient Ingestor, **Assorted Roe** provides **+56% Breathing Efficiency** for 7:30 minutes.

## Fishing Bait

When applied as bait, Assorted Roe gives the following bonus towards your next catch:

- Catch Rarity Improvement: 9%
- Catch Size Improvement: 0%

## Source

Assorted Roe can be cooked using a Nutrient Processor with the following ingredients:

- Fish x1 + Fish x1 → Assorted Roe x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Assorted Roe** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Sea's Bounty -- Jellymeat x1 + Fleshy Cylinder x1 + Assorted Roe x1 → Sea's Bounty x1 (*"Sea's Bounty"*, 2.5 sec./unit output)

## Release History

- Aquarius - Added as a consumable.
