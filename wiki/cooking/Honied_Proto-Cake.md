# Honied Proto-Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 62,200.0
- **Updated:** WorldsOne

**Honied Proto-Cake** is a consumable.

## Summary

**Honied Proto-Cake** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Honied Proto-Cake can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Synthetic Honey x1 → Honied Proto-Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Honied Proto-Cake** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

- Beyond - Added as a consumable.
