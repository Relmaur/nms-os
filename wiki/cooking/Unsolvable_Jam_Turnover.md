# Unsolvable Jam Turnover

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 80,800.0
- **Updated:** Prisms

**Unsolvable Jam Turnover** is a consumable.

## Summary

**Unsolvable Jam Turnover** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Unsolvable Jam Turnover can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Anomalous Jam x1 + Cream x1 → Unsolvable Jam Turnover x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Anomalous Jam x1 + Bone Cream x1 → Unsolvable Jam Turnover x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Unsolvable Jam Turnover** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

Will activate 15 seconds Sprint Overload when consumed.

+307% Jetpack Tanks, for 10:00, when consumed through a Nutrient Ingestor.
