# Mystery Meat Pie

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 40,000
- **Updated:** WorldsTwo

**Mystery Meat Pie** is a consumable.

## Summary

**Mystery Meat Pie** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be highly valuable.

Flavour profile: complex, colourful, vivid.

Recipe Complexity: 87%

## Source

Mystery Meat Pie can be cooked using a Nutrient Processor with the following ingredients:

- Pie Case x1 + Meaty Chunks x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Processed Meat x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Meaty Wings x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Diplo Chunks x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Scaly Meat x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Strider Sausage x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)
- Pie Case x1 + Raw Steak x1 → Mystery Meat Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Recipes

**Mystery Meat Pie** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Mystery Meat Pie gives the following bonus towards your next catch:

- Catch Rarity Improvement: 45%
- Catch Size Improvement: 3%
