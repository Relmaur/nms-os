# Monstrous Doughnut

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 180,000.0
- **Updated:** NextGen

**Monstrous Doughnut** is a consumable.

## Summary

**Monstrous Doughnut** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable.**

## Source

Monstrous Doughnut can be cooked using a Nutrient Processor with the following ingredients:

- Lumpen Doughnut x1 + Monstrous Custard x1 → Monstrous Doughnut x1 (*"Nutrient Injection"*, 2.5 sec./unit output)

## Recipes

**Monstrous Doughnut** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- -37% Recharge Time *(10:00)*

## Fishing Bait

When applied as bait, Monstrous Doughnut gives the following bonus towards your next catch:

- Catch Rarity Improvement: 44%
- Catch Size Improvement: 7%
