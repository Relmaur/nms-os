# Extra-Fluffy Batter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 14,000
- **Updated:** WorldsTwo

**Extra-Fluffy Batter** is a consumable.

## Summary

**Extra-Fluffy Batter** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable.** It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subject to further processing.

Flavour profile: sour, sugary, bland.

Recipe Complexity: 37%

## Source

Extra-Fluffy Batter can be cooked using a Nutrient Processor with the following ingredients:

- Delicate Meringue x1 + Refined Flour x1 + Creature Egg x1 → Extra-Fluffy Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Delicate Meringue x1 + Refined Flour x1 + Tall Eggs x1 → Extra-Fluffy Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Delicate Meringue x1 + Refined Flour x1 + Giant Egg x1 → Extra-Fluffy Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
