# Jammy Rounds

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 38,000.0
- **Updated:** Omega

**Jammy Rounds** is a consumable.

## Summary

**Jammy Rounds** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully chosen ingredients.

## Source

Jammy Rounds can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Grahj'am x1 → Jammy Rounds x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Use

**Jammy Rounds** is not used as an ingredient for cooking using a Nutrient Processor.

## Release History
