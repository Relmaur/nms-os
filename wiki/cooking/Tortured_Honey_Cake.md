# Tortured Honey Cake

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 125,400.0
- **Updated:** NextGen

**Tortured Honey Cake** is a consumable.

## Summary

**Tortured Honey Cake** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

## Source

Tortured Honey Cake can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Synthetic Honey x1 → Tortured Honey Cake x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Tortured Honey Cake** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will activate 8 seconds jetpack overload when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +6,139% Fauna Analysis Rewards *(10:00)*

## Fishing Bait

When applied as bait, Tortured Honey Cake gives the following bonus towards your next catch:

- Catch Rarity Improvement: 10%
- Catch Size Improvement: 2%
- Other notes: Attracts diurnal fish
