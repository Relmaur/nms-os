# Squirming Fancy

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 153,300
- **Updated:** WorldsTwo

**Squirming Fancy** is a consumable.

## Summary

**Squirming Fancy** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

Flavour profile: delicate, vivid, manifold.

Recipe Complexity: 100%

## Source

Squirming Fancy can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Sweetened Mucous x1 + Cream x1 → Squirming Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Squirming Fancy x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Usage

### Crafting

**Squirming Fancy** is not used as an ingredient for crafting.

### Refining

**Squirming Fancy** is not used as an ingredient for refining using a Refiner.

### Cooking

**Squirming Fancy** is not used as an ingredient for cooking using a Nutrient Processor.

## Consume

- Restores 1% health when consumed without a Nutrient Processor.
- Fueling a Nutrient Ingestor with **Squirming Fancy** will grant +6047% Fauna Analysis Rewards for 10:00 per unit consumed.

## Fishing Bait

When applied as bait, Squirming Fancy gives the following bonus towards your next catch:

- Catch Rarity Improvement: 20%
- Catch Size Improvement: 1%
