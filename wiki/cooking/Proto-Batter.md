# Proto-Batter

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 48,000
- **Updated:** Swarm

**Proto-Batter** is a consumable.

## Summary

**Proto-Batter** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

Flavour profile: sour, bland, salted.

Recipe Complexity: 41%

## Source

Proto-Batter can be cooked using a Nutrient Processor with the following ingredients:

- Sweetened Proto-Butter x1 + Refined Flour x1 + Creature Egg x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Honied Proto-Butter x1 + Refined Flour x1 + Creature Egg x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Sweetened Proto-Butter x1 + Refined Flour x1 + Tall Eggs x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
- Honied Proto-Butter x1 + Refined Flour x1 + Tall Eggs x1 → Proto-Batter x1 (*"Component Churn"*, 2.5 sec./unit output)
