# Custard Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 97,200.0
- **Updated:** Prisms

**Custard Curiosity** is a consumable.

## Summary

**Custard Curiosity** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Custard Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Viscous Custard x1 → Custard Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Very Thick Custard x1 → Custard Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Custard Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.
