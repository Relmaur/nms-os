# Splicer's Delight

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 81,900
- **Updated:** WorldsOne

**Splicer's Delight** is a consumable.

## Summary

**Splicer's Delight** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Splicer's Delight can be cooked using a Nutrient Processor with the following ingredients:

- Syrupy Batter x1 + Sweetened Mucous x1 + Cream x1 → Splicer's Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Syrupy Batter x1 + Sweetened Mucous x1 + Bone Cream x1 → Splicer's Delight x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Splicer's Delight** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Restores 50% health once consumed.

## Release History

- Worlds Part I - Added as a consumable.
