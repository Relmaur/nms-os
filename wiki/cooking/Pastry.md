# Pastry

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 24,000
- **Updated:** Swarm

**Pastry** is a consumable.

## Summary

**Pastry** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. Food such as this can be **highly valuable.** It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subject to further processing.

Flavour profile: homely, musty, coarse.

Recipe Complexity: 48%

## Source

Pastry can be cooked using a Nutrient Processor with the following ingredients:

- Refined Flour x1 + Churned Butter x1 → Pastry x1 (*"Component Churn"*, 2.5 sec./unit output)
- Refined Flour x1 + Proto-Butter x1 → Pastry x1 (*"Component Churn"*, 2.5 sec./unit output)
- Refined Flour x1 + Bone Butter x1 → Pastry x1 (*"Component Churn"*, 2.5 sec./unit output)

## Recipes

**Pastry** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Pie Case -- Pastry x1 → Pie Case x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Fishing Bait

When applied as bait, Pastry gives the following bonus towards your next catch:

- Catch Rarity Improvement: 26%
- Catch Size Improvement: 2%
