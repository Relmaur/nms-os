# Poached Worms

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,100
- **Updated:** Voyagers

**Poached Worms** is a consumable.

## Summary

**Poached Worms** is a consumable and one of the Edible Products.

## Game Description

A small morsel of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **2% health**.

- When consumed through a Nutrient Ingestor, **Poached Worms** provides **+43% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Poached Worms gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts storm-loving fish

## Source

Poached Worms can be cooked using a Nutrient Processor with the following ingredients:

- Bileworm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Sea Cucumber x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Briny Worm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Encrusted Worm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Gas-Worm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Writhing Brainworm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Glowworm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- All-Seeing Worm x1 → Poached Worms x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Poached Worms** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Poached Worms x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Poached Worms x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Poached Worms x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Poached Worms x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Poached Worms x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
