# Spiced Ice

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 44,000.0
- **Updated:** Prisms

**Spiced Ice** is a consumable.

## Summary

**Spiced Ice** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Spiced Ice can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Ever-burning Jam x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Ever-burning Jam x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frozen Tubers x1 + Fireberry x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Fireberry x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Ever-burning Jam x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Ever-burning Jam x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Fireberry x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Fireberry x1 → Spiced Ice x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

**Spiced Ice** is not used as an ingredient for cooking using a Nutrient Processor.
