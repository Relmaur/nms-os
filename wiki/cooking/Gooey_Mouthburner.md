# Gooey Mouthburner

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 78,000.0
- **Updated:** Prisms

**Gooey Mouthburner** is a consumable.

## Summary

**Gooey Mouthburner** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Thick, Sweet Batter.

## Source

Gooey Mouthburner can be cooked using a Nutrient Processor with the following ingredients:

- Thick, Sweet Batter x1 + Ever-burning Jam x1 + Cream x1 → Gooey Mouthburner x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Thick, Sweet Batter x1 + Ever-burning Jam x1 + Bone Cream x1 → Gooey Mouthburner x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Gooey Mouthburner** is not used as an ingredient for cooking using a Nutrient Processor.
