# Seared Fillet

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 35,400
- **Updated:** Aquarius

**Seared Fillet** is a consumable.

## Summary

**Seared Fillet** is a consumable and one of the Edible Products.

## Game Description

A slab of seafood, created in the Nutrient Processor. Food such as this can be highly valuable.

Can be consumed as it stands or subjected to further processing.

## Nutrient Ingestor

Exosuit nutrient system will restore **25% hazard protection**

- When consumed through a Nutrient Ingestor, **Seared Fillet** provides **+44% Breathing Efficiency** for 5:30 minutes.

## Fishing Bait

When applied as bait, Seared Fillet gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%
- Other notes: Attracts nocturnal fish

## Source

Seared Fillet can be cooked using a Nutrient Processor with the following ingredients:

- Dragonfish x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Bleached Bonefish x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Sulphurfish x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Glacier Fish x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Iceblood Gulper x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Sunspine Basker x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Mantis Ray x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Shimmering Lashtail x1 → Seared Fillet x1 (*"Seafood Assembly"*, 2.5 sec./unit output)

## Recipes

**Seared Fillet** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Fish and Rice -- Seared Fillet x1 + Kelp Rice x1 → Fish and Rice x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Marine Pie -- Seared Fillet x1 + Pie Case x1 → Marine Pie x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Seafood Stew -- Seared Fillet x1 + Any other cooked seafood x1 → Seafood Stew x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Seared Fillet x1 + Pulpy Roots x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
- Starched Fish -- Seared Fillet x1 + Sweetroot x1 → Starched Fish x1 (*"Seafood Assembly"*, 2.5 sec./unit output)
