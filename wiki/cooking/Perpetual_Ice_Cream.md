# Perpetual Ice Cream

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 44,000.0
- **Updated:** Prisms

**Perpetual Ice Cream** is a consumable.

## Summary

**Perpetual Ice Cream** is a consumable and one of the Edible Products.

Each ice cream provides a 320% jetpack boost for 10 minutes when used in the Nutrient Ingestor.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Perpetual Ice Cream can be cooked using a Nutrient Processor with the following ingredients:

- Viscous Custard x1 + Frozen Tubers x1 + Hexaberry x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Hexaberry x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frozen Tubers x1 + Anomalous Jam x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Viscous Custard x1 + Frost Crystal x1 + Anomalous Jam x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Hexaberry x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Hexaberry x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frozen Tubers x1 + Anomalous Jam x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)
- Very Thick Custard x1 + Frost Crystal x1 + Anomalous Jam x1 → Perpetual Ice Cream x1 (*"Rapid Chilling"*, 2.5 sec./unit output)

## Recipes

**Perpetual Ice Cream** is not used as an ingredient for cooking using a Nutrient Processor.
