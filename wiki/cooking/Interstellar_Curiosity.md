# Interstellar Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 92,300.0
- **Updated:** WorldsOne

**Interstellar Curiosity** is a consumable.

## Summary

**Interstellar Curiosity** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Interstellar Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Stellar Custard x1 → Interstellar Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Interstellar Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Exosuit nutrient system will power 15 seconds sprint overload when consumed.
