# Cream Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 64,900.0
- **Updated:** Prisms

**Cream Curiosity** is a consumable.

## Summary

**Cream Curiosity** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

## Source

Cream Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Cream x1 → Cream Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Proto-Batter x1 + Bone Cream x1 → Cream Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Cream Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.
