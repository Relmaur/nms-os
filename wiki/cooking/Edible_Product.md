# Edible Product

**Edible Product** is a type of consumable.

## Summary

**Edible Product** is a type of consumable. Products belong to this type are prepared from Raw Ingredients.

## Use

- Can be used as bait for fishing.
- Can be consumed for various Exosuit bonuses.
- Many can be cooked into other Edible Products.
- Can be presented to Iteration: Cronus in the Space Anomaly for nanite rewards.
- Can be fed to Organic Frigates to change their Combat/Exploration/Industry/Trade values.
