# Sugar Dough

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 5,000
- **Updated:** Swarm

**Sugar Dough** is a consumable.

## Summary

**Sugar Dough** is a consumable and one of the Edible Products.

## Game Description

A basic food product, created in the Nutrient Processor.

This nutrient paste is the basis for a wide range of biscuit recipes and can be baked as-is, or combined with other nutrient sources for extra flavour.

## Consume

- Exosuit nutrient system will restore 5% life support power when consumed.
- Fueling a Nutrient Ingestor with **Sugar Dough** will grant +13% Hazard Protection Battery for 2:00 per unit consumed.

## Source

Sugar Dough can be cooked using a Nutrient Processor with the following ingredients:

- Refined Flour x1 + Processed Sugar x1 → Sugar Dough x1 (*"Component Churn"*, 2.5 sec./unit output)

## Usage

### Crafting

**Sugar Dough** is not used as an ingredient for crafting.

### Refining

**Sugar Dough** is not used as an ingredient for refining using a Refiner.
