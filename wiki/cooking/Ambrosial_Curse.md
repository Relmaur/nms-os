# Ambrosial Curse

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 199,200
- **Updated:** Swarm

**Ambrosial Curse** is a consumable.

## Summary

**Ambrosial Curse** is a consumable and one of the Edible Products.

## Game Description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Writhing, Roiling Batter. Some caution is advised.

Flavour profile: polyphonic, chromatic, intense.

Recipe Complexity: 100%

## Source

Ambrosial Curse can be cooked using a Nutrient Processor with the following ingredients:

- Writhing, Roiling Batter x1 + Syrupy Nectar x1 → Ambrosial Curse x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)
- Writhing, Roiling Batter x1 + Butter Syrup x1 → Ambrosial Curse x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Ambrosial Curse** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Ambrosial Curse gives the following bonus towards your next catch:

- Catch Rarity Improvement: 12%
- Catch Size Improvement: 2%
- Other notes: Attracts nocturnal fish

## Additional Information

Grants an 8 second jetpack overload once consumed.

Grants +6523% Fauna Analysis Results for 10 minutes when consumed in a Nutrient Ingestor
