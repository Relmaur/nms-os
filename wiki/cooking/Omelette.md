# Omelette

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 18,000
- **Updated:** Origins

**Omelette** is a consumable.

## Summary

**Omelette** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Food such as this can be **highly valuable**.

## Source

Omelette can be cooked using a Nutrient Processor with the following ingredients:

- Creature Egg x1 + Tangy Cheese x1 → Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Tall Eggs x1 + Tangy Cheese x1 → Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Giant Egg x1 + Tangy Cheese x1 → Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)

## Recipes

**Omelette** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Bugs-in-a-Blanket -- Omelette x1 + Juicy Thorax x1 → Bugs-in-a-Blanket x1 (*"Bind Proteins"*, 2.5 sec./unit output)
- Fungal Omelette -- Omelette x1 + Foraged Mushrooms x1 → Fungal Omelette x1 (*"Bind Proteins"*, 2.5 sec./unit output)
