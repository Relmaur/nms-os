# Salty Cruncher

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 33,000.0
- **Updated:** WorldsOne

**Salty Cruncher** is a consumable.

## Summary

**Salty Cruncher** is a consumable and one of the Edible Products.

## Game Description

A well-baked biscuit, created in the Nutrient Processor.

What was once a thin sheet of vaguely-sweetend nutrient paste has been elevated with the addition of carefully-chosen ingredients.

## Source

Salty Cruncher can be cooked using a Nutrient Processor with the following ingredients:

- Sugar Dough x1 + Salt x1 → Salty Cruncher x1 (*"Dough Augmentation"*, 2.5 sec./unit output)
- Sugar Dough x1 + Kelp Sac x1 → Salty Cruncher x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Recipes

**Salty Cruncher** is not used as an ingredient for cooking using a Nutrient Processor.

## Use

Exosuit nutrient system will restore 25% hazard protection when consumed.

## Nutrient Ingestor

Provides the following effects when automatically consumed using a Nutrient Ingestor

- +22% Hazard Protection Battery *(6:36)*

## Fishing Bait

When applied as bait, Salty Cruncher gives the following bonus towards your next catch:

- Catch Rarity Improvement: 7%
- Catch Size Improvement: 2%
- Other notes: Attracts nocturnal fish
