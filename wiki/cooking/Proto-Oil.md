# Proto-Oil

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 48,000
- **Updated:** WorldsOne

**Proto-Oil** is a consumable.

## Summary

**Proto-Oil** is a consumable and one of the Edible Products.

## Game Description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subjected to further processing.

## Source

Proto-Oil can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Butter x1 + Proto-Butter x1 → Proto-Oil x1 (*"Nutrient Refining"*, 2.5 sec./unit output)

## Recipes

**Proto-Oil** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Proto-Beignet -- Proto-Oil x1 + Dough x1 + Processed Sugar x1 → Proto-Beignet x1 (*"Accelerated Fry"*, 2.5 sec./unit output)
- Solidified Grease Pie -- Pie Case x1 + Proto-Oil x1 → Solidified Grease Pie x1 (*"Assemble Pie"*, 2.5 sec./unit output)

## Additional Information

Exosuit nutrient system will restore 25% hazard protection when consumed.
