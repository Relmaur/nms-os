# Caramel Curiosity

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 64,900
- **Updated:** WorldsTwo

**Caramel Curiosity** is a consumable.

## Summary

**Caramel Curiosity** is a consumable and one of the Edible Products.

## Game description

A highly refined food product, created in the Nutrient Processor.

These cake-like nutrients are processed from a base of Proto-Batter.

Flavour profile: vivid, piquant, vibrant.

Recipe Complexity: 100%

## Source

Caramel Curiosity can be cooked using a Nutrient Processor with the following ingredients:

- Proto-Batter x1 + Crunchy Caramel x1 → Caramel Curiosity x1 (*"Assemble Baked Product"*, 2.5 sec./unit output)

## Recipes

**Caramel Curiosity** is not used as an ingredient for cooking using a Nutrient Processor.

## Fishing Bait

When applied as bait, Caramel Curiosity gives the following bonus towards your next catch:

- Catch Rarity Improvement: 12%
- Catch Size Improvement: 41%
- Other notes: Attracts diurnal fish

## Additional information

Grants a 15 second sprint overload once consumed.
