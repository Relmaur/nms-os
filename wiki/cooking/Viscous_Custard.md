# Viscous Custard

## Quick Facts

- **Category:** Consumable
- **Type:** Edible Product
- **Total Value:** 32,000
- **Updated:** Swarm

**Viscous Custard** is a consumable.

## Summary

**Viscous Custard** is a consumable and one of the Edible Products.

## Game description

A refined food product, created in the Nutrient Processor. Food such as this can be highly valuable. It has both the identifying shapes and aromas of an actual food item, in stark contrast with conventional nutrition paste or pellets.

Can be consumed as it stands or subject to further processing.

Flavour profile: juicy, sharp, bracing.

Recipe Complexity: 67%

## Source

Viscous Custard can be cooked using a Nutrient Processor with the following ingredients:

- Creature Egg x1 + Cream x1 + Processed Sugar x1 → Viscous Custard x1 (*"Component Churn"*, 2.5 sec./unit output)
- Tall Eggs x1 + Cream x1 + Processed Sugar x1 → Viscous Custard x1 (*"Component Churn"*, 2.5 sec./unit output)
- Giant Egg x1 + Cream x1 + Processed Sugar x1 → Viscous Custard x1 (*"Component Churn"*, 2.5 sec./unit output)
