# Cadmium

## Quick Facts

- **Type:** Refined Stellar Metal: Red
- **Rarity:** Rare
- **Blueprint Value:** 83.0
- **Symbol:** **Cd**
- **Updated:** Waypoint

**Cadmium** is a resource.

## Summary

**Cadmium** (**Cd**) is a resource. It can be found on planets orbiting Class K/M systems (red stars).

## Game description

A chromatic metal, generated by fusion in the heart of a star. Such stellar material ends up forming deposits in the crust of local planets.

Cadmium is found on planets orbiting red stars, and can be placed in a Refiner to create purified Chromatic Metal for use in the manufacture of advanced technologies.

## Source

- It can be found on planets orbiting red stars, where it can be mined with the Terrain Manipulator attachment for the Multi-tool.
- Dismantling Pulse Engine Upgrade modules.
- Dismantling any class of Photon Cannon Upgrade yields 125 cadmium.
- Dismantling any class of Positron Ejector Upgrade yields 125 cadmium.
- Dismantling select ship upgrades can yield different amounts of cadmium.

Cadmium can be refined using a Refiner with the following ingredients:

- Cadmium ×1 + Chromatic Metal ×1 → Cadmium ×2 (*"Chromatic Expansion"*, 0.36 sec./unit output)

## Use

### Crafting

**Cadmium** is used as an ingredient for crafting the following products:

- Amplified Warp Shielding -- Warp Hypercore x1 + Quantum Computer x2 + Cadmium x250 → Amplified Warp Shielding
- AtlasPass v2 -- Cadmium x200 + Microprocessor x1 → AtlasPass v2
- Emeril Drive -- Cadmium x250 + Wiring Loom x4 → Emeril Drive
- Soul Engine -- Metal Plating x3 + Living Pearl x1 + Cadmium x120 → Soul Engine
- State Phasure -- Photic Jade x1 + Cadmium x100 → State Phasure
- Warp Core Resonator -- Cadmium x250 + Quantum Computer x1 + Antimatter Housing x4 → Warp Core Resonator

### Refining

**Cadmium** is used as an ingredient for refining the following products using a Refiner:

- Cadmium -- Cadmium x1 + Chromatic Metal x1 → Cadmium x2 (*"Chromatic Expansion"*, 0.36 sec./unit output)
- Chromatic Metal -- Cadmium x2 → Chromatic Metal x1 (*"Extract Chromatic Material"*, 0.28 sec./unit output)
- Chromatic Metal -- Gold x1 + Silver x1 + Cadmium x1 → Chromatic Metal x10 (*"Chromatic Stellar Fusion"*, 4.8 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Cadmium x1 → Chromatic Metal x2 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Cadmium x1 → Magnetised Ferrite x2 (*"Stellar / Metal Fusion"*, 0.18 sec./unit output)

### Cooking

**Cadmium** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

- Cadmium (from latin *cadmia* or from the Greek character Cadmus, ruler of Thebes) is a slightly blueish-white soft metal, however Cadmium deposits in the game may be Otavite or Greenockite, which are cadmium-ores that can be red in colour. Cadmium is commonly used in batteries, electroplating, pigments, and nuclear fission.
