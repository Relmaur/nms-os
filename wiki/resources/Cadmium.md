# Cadmium

## Quick Facts

- **Symbol:** Cd
- **Value:** 83.0

**Cadmium** is a resource.

## Summary

**Cadmium** (**Cd**) is a [[resource]]. It can be found on planets orbiting Class K/M systems ([[System colours|red stars]]).

## Game description

A chromatic metal, generated by fusion in the heart of a star. Such stellar material ends up forming deposits in the crust of local [[planet|planets]].

Cadmium is found on planets orbiting red stars, and can be placed in a Refiner to create purified [[Chromatic Metal]] for use in the manufacture of advanced technologies.

## Source

- It can be found on planets orbiting [[System colours|red stars]], where it can be mined with the Terrain Manipulator attachment for the [[Multi-tool]].
- Dismantling [[Pulse Engine Upgrade]] modules.
- Dismantling any class of [[Photon Cannon Upgrade]] yields 125 cadmium.
- Dismantling any class of [[Positron Ejector Upgrade]] yields 125 cadmium.
- Dismantling select ship upgrades can yield different amounts of cadmium.

- **Refiner** · *Chromatic Expansion* · 0.36 s per unit: 1 × [[Cadmium]] + 1 × [[Chromatic Metal]] → 2 × Cadmium

## Additional Information

- Cadmium (from latin *cadmia* or from the Greek character Cadmus, ruler of Thebes) is a slightly blueish-white soft metal, however Cadmium deposits in the game may be Otavite or Greenockite, which are cadmium-ores that can be red in colour. Cadmium is commonly used in batteries, electroplating, pigments, and nuclear fission.
