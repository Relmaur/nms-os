# Cursed Dust

## Quick Facts

- **Category:** Special
- **Type:** Ashes of Despair
- **Rarity:** Rare
- **Blueprint Value:** 959
- **Used for:** Upgrading
- **Symbol:** **?**
- **Updated:** Breach

**Cursed Dust** is a resource.

## Summary

**Cursed Dust** is a resource and one of the Localised Earth Elements.

## Game Description

A powdery desert soil, slick with the gland expressions of a colossal sandworm. Historically, some have regarded this dust as the divine parent of such worms. It smells curiously sweet.

Cursed Dust gathers in the terrain deposits of planets blighted by titan worm activity.

## Source

- Obtained as a mission reward from the Bounty Master at an Outlaw station.
- Obtained from trading terminals in abandoned space stations.

## Use

### Crafting

**Cursed Dust** is not used as an ingredient for crafting.

### Refining

**Cursed Dust** is used as an ingredient for refining the following products using a Refiner:

- Residual Goop -- Cursed Dust x2 → Residual Goop x1 (*"Doom Cycling"*, 0.04 sec./unit output)

### Cooking

**Cursed Dust** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

- Available as a planetary Resource Deposit in Expedition 4.
- Used to achieve a milestone in Expedition 4: Emergence.
- Returns as a Resource Deposit in Expedition 13: Adrift.
