# Thamium9

## Quick Facts

- **Type:** Isotope
- **Rarity:** Uncommon
- **Value:** 21.0
- **Symbol:** Th
- **Added in:** Origins

**Thamium9** is a resource.

## Summary

**Thamium9** (**Th**) is one of the uncommon [[Isotope elements]].

It is required to create [[Warp Cell|Warp Cells]] which are required to power a [[Starship]]'s [[Hyperdrive]].

## Game description

Powerful element used to charge [[Multi-tool|mining equipment]], weaponry and [[Life Support]] systems. Also used in the creation of products and experimental tech devices.

Found in red flowering vegetation and planetary flora.

## Source

This element is found on all [[planet|planets]], and is abundant on barren planets. It used to be mined easily from [[asteroid|asteroids]]; however, fewer asteroids are now composed of Thamium9.

It can also be purchased from planetary [[Trading Post|Trading Posts]] and all ship captains visiting these trading posts.

## Use

Thamium9 is an obsolete resource and no longer has a purpose in the game, with the exception of Our Journey Continues, where it takes on the same use as [[Oxygen]].

## Additional information

- Thamium9 can be sold in the [[Galactic trade terminal|Marketplace]].
- It can be found as an atmospheric component on the [[Exploration Guide]].
