# Activated Emeril

## Quick Facts

- **Type:** Refined Stellar Metal: Green
- **Rarity:** Rare
- **Blueprint Value:** 134.0
- **Symbol:** **Em+**
- **Updated:** Waypoint

**Activated Emeril** is a resource.

## Summary

**Activated Emeril** (**Em+**) is a resource that can be found on extreme weather planets.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

This Emeril has been activated by the extreme conditions in which it was formed, and is highly valuable.

Emeril is found on planets orbiting green stars, and can be placed in a Refiner to create purified Chromatic Metal.

## Sources

- Mined from large deposits using the Terrain Manipulator. These deposits can be found using the Multi-tool.
- Can be provided by Frigate expeditions.

## Uses

### Crafting

**Activated Emeril** is not used as an ingredient for crafting.

### Refining

**Activated Emeril** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Activated Emeril x1 → Chromatic Metal x3 (*"Extract Chromatic Material"*, 0.16 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Activated Emeril x1 → Chromatic Metal x6 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Activated Emeril x1 → Magnetised Ferrite x6 (*"Stellar / Metal Fusion"*, 0.06 sec./unit output)

### Cooking

**Activated Emeril** is not used as an ingredient for cooking using a Nutrient Processor.
