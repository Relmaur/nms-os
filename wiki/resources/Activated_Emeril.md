# Activated Emeril

## Quick Facts

- **Type:** Refined Stellar Metal: Green
- **Rarity:** Rare
- **Symbol:** Em+
- **Value:** 134.0
- **Added in:** Waypoint

**Activated Emeril** is a resource.

## Summary

**Activated Emeril** (**Em+**) is a [[resource]] that can be found on extreme weather planets.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

This [[Emeril]] has been activated by the extreme conditions in which it was formed, and is highly valuable.

Emeril is found on planets orbiting [[System colours|green stars]], and can be placed in a [[Refiner]] to create purified [[Chromatic Metal]].

## Sources

- Mined from large deposits using the [[Terrain Manipulator]]. These deposits can be found using the Multi-tool.
- Can be provided by [[Frigate]] expeditions.
