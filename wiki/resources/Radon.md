# Radon

## Quick Facts

- **Category:** Earth
- **Type:** Compressed Atmospheric Gas
- **Rarity:** Uncommon
- **Blueprint Value:** 20.0
- **Used for:** Crafting, Charging
- **Symbol:** **Rn**
- **Updated:** WorldsOne

**Radon** is a resource.

## Summary

**Radon** (**Rn**) is a resource and one of the Compressed Atmospheric Gas earth elements.

## Game description

A colourless, odourless gas with a relatively short half-life.

Found in both Radioactive and Frozen atmospheres, this gas is produced by the decay of other high-energy elements.

## Source

- As a secondary element in some flora.
- From Mutant Plants in Irradiated biomes.
- From Atmosphere Harvesters built on planets with Irradiated or Frozen biomes.
- Using Gas Extractor at a Radon Concentrated Gas Cloud.
- It can be found at Resource Depots.

Radon can be refined using a Refiner with the following ingredients:

- Sulphurine ×3 → Radon ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Sulphurine ×1 + Oxygen ×1 → Radon ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Sulphurine ×1 + Chromatic Metal ×1 → Radon ×1 (*"Gas Catalysation"*, 0.36 sec./unit output)

## Use

### Crafting

**Radon** is used as an ingredient for crafting the following products:

- Enriched Carbon -- Radon x250 + Condensed Carbon x50 → Enriched Carbon

### Refining

**Radon** is used as an ingredient for refining the following products using a Refiner:

- Enriched Carbon -- Radon x100 + Carbon x20 + Chlorine x5 → Enriched Carbon x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Enriched Carbon -- Radon x100 + Carbon x20 + Salt x10 → Enriched Carbon x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Enriched Carbon -- Radon x100 + Condensed Carbon x10 + Chlorine x5 → Enriched Carbon x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Enriched Carbon -- Radon x100 + Condensed Carbon x10 + Salt x10 → Enriched Carbon x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Frost Crystal -- Dioxite x1 + Radon x1 → Frost Crystal x1 (*"Encourage Growth"*, 0.36 sec./unit output)
- Gamma Root -- Uranium x1 + Radon x1 → Gamma Root x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Methane -- Nitrogen x3 + Sulphurine x3 + Radon x3 → Methane x1 (*"Organic Fusion"*, 0.16 sec./unit output)
- Nitrogen -- Radon x1 + Chromatic Metal x1 → Nitrogen x1 (*"Gas Catalysation"*, 0.36 sec./unit output)
- Nitrogen -- Radon x1 + Oxygen x1 → Nitrogen x1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Nitrogen -- Radon x3 → Nitrogen x1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Uranium -- Radon x1 + Di-hydrogen x1 → Uranium x1 (*"Catalyse Radiation"*, 0.16 sec./unit output)
- Uranium -- Radon x1 + Ferrite Dust x1 → Uranium x1 (*"Metal Enrichment"*, 0.36 sec./unit output)
- Uranium -- Radon x1 + Magnetised Ferrite x1 → Uranium x3 (*"Metal Enrichment"*, 0.36 sec./unit output)
- Uranium -- Radon x1 + Pure Ferrite x1 → Uranium x2 (*"Metal Enrichment"*, 0.36 sec./unit output)

### Cooking

**Radon** is not used as an ingredient for cooking using a Nutrient Processor.
