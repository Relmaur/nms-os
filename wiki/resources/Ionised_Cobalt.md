# Ionised Cobalt

## Quick Facts

- **Category:** Earth
- **Type:** Processed Subterranean Mineral
- **Rarity:** Rare
- **Blueprint Value:** 162.0
- **Used for:** Building, Crafting, Charging, Upgrading, Refining
- **Symbol:** **Co+**
- **Updated:** Waypoint

**Ionised Cobalt** is a resource.

## Summary

**Ionised Cobalt** (**Co+**) is a resource and one of the earth elements.

The British spelling of this word is used in the wiki.

## Game description

A highly energised form of Cobalt, this processed metal can be used to create Advanced Ion Batteries, a conveniently portable source of energy for the Exosuit.

In widespread use as a key component in the creation of advanced technologies and structures.

## Source

- Available from some Galactic Trade Terminals.

Ionised Cobalt can be refined using a Refiner with the following ingredients:

- Cobalt ×2 → Ionised Cobalt ×1 (*"Ionise Mineral"*, 0.36 sec./unit output)
- Ionised Cobalt ×1 + Oxygen ×2 → Ionised Cobalt ×6 (*"Efficient Cobalt Ionisation"*, 0.36 sec./unit output)
- Cobalt ×2 + Oxygen ×2 → Ionised Cobalt ×5 (*"Efficient Cobalt Ionisation"*, 0.36 sec./unit output)
- Marrow Bulb ×1 + Pugneum ×1 → Ionised Cobalt ×2 (*"Pugneum Washing"*, 0.36 sec./unit output)
- Marrow Bulb ×1 + Oxygen ×1 → Ionised Cobalt ×2 (*"Bonded Cobalt Extraction"*, 0.36 sec./unit output)
- Cobalt ×1 + Marrow Bulb ×1 → Ionised Cobalt ×2 (*"Ionise Bulbs"*, 0.36 sec./unit output)
- Ionised Cobalt ×1 + Marrow Bulb ×1 → Ionised Cobalt ×2 (*"Ionise Bulbs"*, 0.36 sec./unit output)

### Cooking

**Ionised Cobalt** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

- 13 Ionised Cobalt are required to charge a Portal Glyph. It is actually less efficient than using standard Cobalt, as 20 Cobalt are used instead and the ratio of Cobalt: Ionised Cobalt is 2:1.
- The description refers to Advanced Ion Batteries, although they were removed from the game in Origins.
