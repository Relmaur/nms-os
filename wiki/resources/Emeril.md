# Emeril

## Quick Facts

- **Type:** Refined Stellar Metal: Green
- **Rarity:** Rare
- **Value:** 114.0
- **Symbol:** Em
- **Added in:** Waypoint

**Emeril** is a resource.

## Summary

**Emeril** (**Em**) is a [[resource]]. It can be found on planets orbiting Class E systems ([[System colours|green stars]]).

## Game description

A chromatic metal, generated by fusion in the heart of a star.

Emeril is found on planets orbiting green stars, and can be placed in a Refiner to create purified [[Chromatic Metal]] for use in the manufacture of advanced technologies.

## Source

It can be found on planets orbiting [[System colours|green stars]], where it can be mined with the Terrain Manipulator attachment for the [[Multi-tool]].

It can also be collected by feeding the fauna on certain planets. After a short period of time, they may dig some up or generate the element by various bodily functions.

- **Refiner** · *Chromatic Expansion* · 0.36 s per unit: 1 × [[Emeril]] + 1 × [[Chromatic Metal]] → 2 × Emeril

### Exploit

Once the player has [[Personal Refiner Mk 2]]/[[Medium Refiner]]/[[Large Refiner]], they can use it to produce limitless Emeril:

1. Start with x5 Emeril
1. Refine x2 Emeril to create x3 Chromatic Metal.
1. Refine x3 Emeril and x3 Chromatic Metal to create x6 Emeril.
1. Repeat steps 2-3, creating x1 extra Emeril for every x5 Emeril started with.

## Additional information

The game has two Emeril resources, one from pre-NEXT and one post-NEXT. Pre-NEXT Emeril has the name "TRADEABLE6" in the game files, while post-NEXT Emeril has the name "UI_GREEN2".

They feature different descriptions and are treated as different elements, just with the same name.
