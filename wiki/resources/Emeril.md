# Emeril

## Quick Facts

- **Type:** Refined Stellar Metal: Green
- **Rarity:** Rare
- **Blueprint Value:** 114.0
- **Symbol:** **Em**
- **Updated:** Waypoint

**Emeril** is a resource.

## Summary

**Emeril** (**Em**) is a resource. It can be found on planets orbiting Class E systems (green stars).

## Game description

A chromatic metal, generated by fusion in the heart of a star.

Emeril is found on planets orbiting green stars, and can be placed in a Refiner to create purified Chromatic Metal for use in the manufacture of advanced technologies.

## Source

It can be found on planets orbiting green stars, where it can be mined with the Terrain Manipulator attachment for the Multi-tool.

It can also be collected by feeding the fauna on certain planets. After a short period of time, they may dig some up or generate the element by various bodily functions.

Emeril can be refined using a Refiner with the following ingredients:

- Emeril ×1 + Chromatic Metal ×1 → Emeril ×2 (*"Chromatic Expansion"*, 0.36 sec./unit output)

### Exploit

Once the player has Personal Refiner Mk 2/Medium Refiner/Large Refiner, they can use it to produce limitless Emeril:

- Start with x5 Emeril
- Refine x2 Emeril to create x3 Chromatic Metal.
- Refine x3 Emeril and x3 Chromatic Metal to create x6 Emeril.
- Repeat steps 2-3, creating x1 extra Emeril for every x5 Emeril started with.

## Use

### Crafting

**Emeril** is used as an ingredient for crafting the following products:

- AtlasPass v3 -- Emeril x200 + Microprocessor x1 → AtlasPass v3
- Chromatic Warp Shielding -- Warp Hypercore x1 + Solar Mirror x2 + Emeril x250 → Chromatic Warp Shielding
- Indium Drive -- Emeril x250 + Wiring Loom x5 → Indium Drive
- Novae Reclaiment -- State Phasure x1 + Emeril x100 → Novae Reclaiment
- Plasmatic Warp Injector -- Emeril x250 + Solar Mirror x1 + Antimatter Housing x5 → Plasmatic Warp Injector
- Venom Urchin -- Emeril x100 + Gold x50 → Venom Urchin

### Refining

**Emeril** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Emeril x2 → Chromatic Metal x3 (*"Extract Chromatic Material"*, 0.16 sec./unit output)
- Chromatic Metal -- Gold x1 + Silver x1 + Emeril x1 → Chromatic Metal x20 (*"Chromatic Stellar Fusion"*, 4.8 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Emeril x1 → Chromatic Metal x3 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Emeril -- Emeril x1 + Chromatic Metal x1 → Emeril x2 (*"Chromatic Expansion"*, 0.36 sec./unit output)
- Gold -- Ferrite Dust x1 + Oxygen x1 + Emeril x1 → Gold x10 (*"Chromatic Alchemy"*, 4.8 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Emeril x1 → Magnetised Ferrite x3 (*"Stellar / Metal Fusion"*, 0.12 sec./unit output)

### Cooking

**Emeril** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

The game has two Emeril resources, one from pre-NEXT and one post-NEXT. Pre-NEXT Emeril has the name "TRADEABLE6" in the game files, while post-NEXT Emeril has the name "UI_GREEN2".

They feature different descriptions and are treated as different elements, just with the same name.
