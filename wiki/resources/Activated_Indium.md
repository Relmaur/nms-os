# Activated Indium

## Quick Facts

- **Type:** Refined Stellar Metal: Blue
- **Rarity:** Rare
- **Blueprint Value:** 165
- **Symbol:** **In+**
- **Updated:** WorldsTwo

**Activated Indium** is a resource.

## Summary

**Activated Indium** (**In+**) is a resource.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

Indium is found on planets orbiting blue stars, and can be placed in a Refiner to create purified Chromatic Metal.

This Indium has been activated by the extreme conditions in which it was formed, and is highly valuable.

## Sources

- It can be found on planets orbiting blue stars (typically extreme weather planets). It's easy to spot because of its specific blue color.
- Can be returned by industrial Frigate expeditions.

## Use

### Crafting

**Activated Indium** is not used as an ingredient for crafting.

### Refining

**Activated Indium** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Activated Indium x1 → Chromatic Metal x4 (*"Extract Chromatic Material"*, 0.12 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Activated Indium x1 → Chromatic Metal x8 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Activated Indium x1 → Magnetised Ferrite x8 (*"Stellar / Metal Fusion"*, 0.045 sec./unit output)

### Cooking

**Activated Indium** is not used as an ingredient for cooking using a Nutrient Processor.
