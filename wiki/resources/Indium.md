# Indium

## Quick Facts

- **Type:** Refined Stellar Metal: Blue
- **Rarity:** Rare
- **Blueprint Value:** 132
- **Symbol:** **In**
- **Updated:** WorldsTwo

**Indium** is a resource.

## Summary

**Indium** (**In**) is a resource.

## Game description

A chromatic metal, generated by fusion in the heart of a star. Such stellar material ends up forming deposits in the crust of local planets.

Indium is found on planets orbiting blue stars, and can be placed in a Refiner to create purified Chromatic Metal for use in the manufacture of advanced technologies.

## Source

It can be found on planets orbiting blue stars. It's easy to spot because of its specific blue color.

Indium can be refined using a Refiner with the following ingredients:

- Indium ×1 + Chromatic Metal ×1 → Indium ×2 (*"Chromatic Expansion"*, 0.36 sec./unit output)

### Exploit

NOTE: prior to Synthesis update the Indium output was twice as high.

Once the player has Medium Refiner/Large Refiner, they can use it to produce limitless Indium:

- Start with x6 Indium.
- Refine x2 Indium to create x4 Chromatic Metal.
- Refine x4 Indium and x4 Chromatic Metal to create x8 Indium.
- Repeat steps 2-3, creating 8 Indium for every 6 Indium started with.

Convert 1/3 of your Indium to Chromatic Metal, then combine with remaining 2/3rds of Indium to make 33% more.

Note: Adding Pure Ferrite to this equation doubles the yield

- Refine x1 Indium + x1 Pure Ferrite to create x4 Chromatic Metal.

## Use

### Crafting

**Indium** is used as an ingredient for crafting the following products:

- Albumen Pearl Orb -- Indium x60 + Paraffinium x20 → Albumen Pearl Orb
- Atlantid Drive -- Indium x250 + Atlantideum x200 + Living Glass x1 → Atlantid Drive
- Modified Quanta -- Novae Reclaiment x1 + Indium x100 → Modified Quanta
- Reality De-Threader -- Indium x250 + Magnetic Resonator x1 + Antimatter Housing x6 → Reality De-Threader
- Temporal Warp Computer -- Warp Hypercore x1 + Magnetic Resonator x2 + Indium x250 → Temporal Warp Computer

### Refining

**Indium** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Gold x1 + Silver x1 + Indium x1 → Chromatic Metal x30 (*"Chromatic Stellar Fusion"*, 4.8 sec./unit output)
- Chromatic Metal -- Indium x2 → Chromatic Metal x4 (*"Extract Chromatic Material"*, 0.1 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Indium x1 → Chromatic Metal x4 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Indium -- Indium x1 + Chromatic Metal x1 → Indium x2 (*"Chromatic Expansion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Indium x1 → Magnetised Ferrite x4 (*"Stellar / Metal Fusion"*, 0.09 sec./unit output)

### Cooking

**Indium** is not used as an ingredient for cooking using a Nutrient Processor.
