# Methane

## Quick Facts

- **Category:** Earth
- **Type:** Compressed Atmospheric Gas
- **Rarity:** Uncommon
- **Blueprint Value:** 35
- **Used for:** Crafting
- **Symbol:** **CH4**
- **Updated:** WorldsTwo

**Methane** is a resource.

## Summary

**Methane** (**CH4**) is a resource and one of the Compressed Atmospheric Gas earth elements.

## Game description

An atmospheric gas found in hostile conditions of gas giants.

Methane is readily harvested from equipment deployed on gas worlds.

## Source

- From Atmosphere Harvesters built on gas planets or the Stellar Extractor Room.

Methane can be refined using a Refiner with the following ingredients:

- Nitrogen ×3 + Sulphurine ×3 + Radon ×3 → Methane ×1 (*"Organic Fusion"*, 0.16 sec./unit output)
