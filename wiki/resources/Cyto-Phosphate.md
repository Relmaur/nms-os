# Cyto-Phosphate

- **Category:** Earth
- **Type:** Organic Compound
- **Rarity:** Rare
- **Blueprint Value:** 201.0
- **Used for:** Building, Crafting, Charging, Upgrading, Refining
- **Symbol:** **Cy**

**Cyto-Phosphate** is a resource.

## Summary

**Cyto-Phosphate** (**Cy**) is a resource and one of the earth elements.

## Game description

A blue-green organic compound produced during the metabolic cycle of deep-sea plantlife. Rich in soluble energy, cyto-phosphates are crucial in many submarine technologies.

The Mining Laser will harvest cyto-phosphate compounds from underwater flora.

## Source

It can be mined from various underwater flora, but be aware as this mining process may spawn Abyssal Horrors.

## Use

### Crafting

**Cyto-Phosphate** is used as an ingredient for crafting the following products:

- Aquatic Crystal -- Cyto-Phosphate x80 → Aquatic Crystal
- Archive Bypass Implant -- Wiring Loom x2 + Cyto-Phosphate x90 + Hadal Core x3 → Archive Bypass Implant
- Barnacle -- Cyto-Phosphate x80 → Barnacle
- Candelabra Bloom -- Cyto-Phosphate x80 → Candelabra Bloom
- Curly Coral -- Cyto-Phosphate x80 → Curly Coral
- Hydrothermal Fuel Cell -- Salt x40 + Cyto-Phosphate x40 + Carbon x40 → Hydrothermal Fuel Cell
- Shadow Lure -- Antimatter x2 + Metal Plating x1 + Cyto-Phosphate x40 → Shadow Lure x20

### Refining

**Cyto-Phosphate** is used as an ingredient for refining the following products using a Refiner:

- Condensed Carbon -- Cyto-Phosphate x1 → Condensed Carbon x1 (*"Algal Processing"*, 0.24 sec./unit output)
- Glass -- Cyto-Phosphate x50 + Salt x50 → Glass x1 (*"Salt Crystal Polishing"*, 10 sec./unit output)

### Cooking

**Cyto-Phosphate** is not used as an ingredient for cooking using a Nutrient Processor.
