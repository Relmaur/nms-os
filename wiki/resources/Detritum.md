# Detritum

## Quick Facts

- **Type:** Neutral
- **Rarity:** Rare
- **Symbol:** De
- **Value:** 27.5
- **Added in:** Atlas Rises

**Detritum (De)** is one of the game's many resources.

## Summary

This game element is a member of the [[Neutral/Exotic elements]] crossover class. It shows as a [[Neutral elements|Neutral]] based on the info panel and an [[Exotic elements (Atlas)|Exotic]] based on the icon seen when harvesting.

It required an [[Exocraft Mining Laser|Exocraft mining laser]] to harvest.

## Game description

A hyper-dense mineral common to the majority of planets, found in large rock formations. This substance can only be extracted with a high powered laser.

## Source

As described in the Game description, this element can be recovered from various rock formations on many planets. As it is very dense, it takes longer to harvest than many of the other resources in the game.

## Use

Detritum is an obsolete resource and no longer has a purpose in the game.

- Appears in scans using the [[Exocraft]] scanner
