# Ammonia

## Quick Facts

- **Category:** Earth
- **Type:** Localised Earth Element
- **Rarity:** Uncommon
- **Blueprint Value:** 62.0
- **Used for:** Building, Crafting, Charging, Upgrading
- **Symbol:** **NH3**
- **Updated:** Endurance

**Ammonia** is a resource.

## Summary

**Ammonia** (**NH3**) is a resource and one of the localised earth elements.

## Game description

Local mineral extract, typically found in large deposits or extracted from common materials after inspection with an Analysis Visor.

Typically found on planets with a toxic environment.

## Source

- As a secondary element in some minerals or Hotspots on planets with Toxic biomes.
- Found in Hotspots on Mega Exotic planets located in green stellar systems.
- Also available from some Galactic Trade Terminals.
- Recycling Toxic Industrial Waste at a Waste Processing Plant.

Ammonia can be refined using a Refiner with the following ingredients:

- Fungal Mould ×2 + Salt ×1 → Ammonia ×1 (*"Floral Titration"*, 0.36 sec./unit output)
- Nitrogen ×1 + Di-hydrogen ×1 → Ammonia ×1 (*"Organic Fusion"*, 0.16 sec./unit output)
- Ferrite Dust ×1 + Paraffinium ×2 → Ammonia ×1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Pure Ferrite ×1 + Paraffinium ×2 → Ammonia ×1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)

## Use

### Crafting

**Ammonia** is used as an ingredient for crafting the following products:

- Atmosphere Harvester -- Ammonia x100 + Metal Plating x2 + Hermetic Seal x2 → Atmosphere Harvester
- Fungal Cluster -- Fungal Mould x50 + Ammonia x25 → Fungal Cluster
- Herox -- Ammonia x50 + Ionised Cobalt x50 → Herox
- Toxin Suppressor -- Ammonia x150 + Silver x60 + Copper x75 → Toxin Suppressor

### Refining

**Ammonia** is used as an ingredient for refining the following products using a Refiner:

- Dioxite -- Ammonia x2 + Ferrite Dust x1 → Dioxite x1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)

- Fungal Mould -- Ammonia x1 + Methane x1 → Fungal Mould x1 (*"Organic Expansion"*, 0.36 sec./unit output)
- Fungal Mould -- Ammonia x1 + Nitrogen x1 → Fungal Mould x1 (*"Encourage Growth"*, 0.24 sec./unit output)

**Ammonia** is not used as an ingredient for cooking using a Nutrient Processor.

### Charging

Ammonia charges Toxic Protection Upgrades.
