# Tropheum

## Quick Facts

- **Type:** Neutral
- **Rarity:** Rare
- **Symbol:** Tr
- **Value:** 137.5
- **Added in:** Atlas Rises

**Tropheum** is a resource.

## Summary

**Tropheum (Tr)** is a rare [[resource]], and a member of the [[Neutral elements]] class.

## Game description

A rare element that is released from the incapacitated engines of defeated [[starship|starships]]

## Source

As described in the Game Description, this element can be recovered from destroying starships. It may also be gained from destroying [[Sentinel Drone|Sentinel Drones]].

## Use

Tropheum is an obsolete resource and no longer has a purpose in the game.

## Additional information

- Tropheum can be sold in the [[Galactic trade terminal|Marketplace]].
- Tropheum can be requested for a bribe in the rank 4 find missing persons mission from the [[Mission Board]]
