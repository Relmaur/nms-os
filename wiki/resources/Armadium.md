# Armadium

## Quick Facts

- **Type:** Neutral/Exotic
- **Rarity:** Rare
- **Symbol:** Ar
- **Value:** 27.5
- **Added in:** Atlas Rises

**Armadium (Ar)** is a resource.

## Summary

**Armadium** is a member of the [[Neutral/Exotic elements]] crossover class. It shows as a [[Neutral elements|Neutral]] based on the info panel and an [[Exotic elements (Atlas)|Exotic]] based on the icon seen when harvesting.

## Game description

This shielding substance is gained through the destruction of planetary [[depot|depots]]. It is capable of withstanding sustained blast fire long enough for [[Sentinel]] drones to respond.

## Source

As described in the Game description, this element can be recovered from depots.

These depots can be discovered by using the [[Exocraft]] Signal Booster, selecting the Subspace radar, and then Scan for Depots.

## Use

Armadium is an obsolete resource and no longer has a purpose in the game.

## Additional information

- Armadium can be sold in the [[Galactic trade terminal|Marketplace]].
- Appears in scans using the Exocraft subspace radar
