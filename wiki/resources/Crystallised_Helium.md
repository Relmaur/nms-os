# Crystallised Helium

## Quick Facts

- **Type:** Localised Earth Element
- **Rarity:** Uncommon
- **Blueprint Value:** 82
- **Symbol:** **He**
- **Updated:** WorldsTwo

**Crystallised Helium** is a resource.

## Summary

**Crystallised Helium** (**He**) is a resource.

## Game description

A supercooled chemical extract, typically found in large deposits or extracted from smaller mineral formations after inspection with an Analysis Visor.

Extracted from deposits formed in the hostile conditions of gas giants.

## Source

It can be found on planets orbiting purple stars, specifically on gas giants.

Crystallised Helium can be refined using a Refiner with the following ingredients:

- Lithium ×1 + Quartzite ×1 → Crystallised Helium ×1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Lithium ×1 + Activated Quartzite ×1 → Crystallised Helium ×2 (*"Environmental Element Transfer"*, 0.18 sec./unit output)

## Use

### Crafting

**Crystallised Helium** is used as an ingredient for crafting the following products:

- Exocraft Summoning Unit -- Activated Quartzite x140 + Quantum Computer x3 + Crystallised Helium x90 → Exocraft Summoning Unit

### Refining

**Crystallised Helium** is used as an ingredient for refining the following products using a Refiner:

- Activated Quartzite -- Methane x1 + Crystallised Helium x1 + Quartzite x1 → Activated Quartzite x1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Ferrite Dust -- Crystallised Helium x1 → Ferrite Dust x1 (*"Ferrite Dust Extraction"*, 0.36 sec./unit output)
- Lithium -- Crystallised Helium x1 + Activated Quartzite x1 → Lithium x2 (*"Environmental Element Transfer"*, 0.18 sec./unit output)
- Lithium -- Crystallised Helium x1 + Quartzite x1 → Lithium x1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Marrow Bulb -- Crystallised Helium x1 + Methane x1 → Marrow Bulb x1 (*"Organic Expansion"*, 0.36 sec./unit output)
- Sodium Nitrate -- Methane x1 + Crystallised Helium x1 + Activated Quartzite x1 → Sodium Nitrate x2 (*"Loosen Bonds"*, 0.18 sec./unit output)
- Uranium -- Crystallised Helium x1 + Ferrite Dust x1 → Uranium x1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Uranium -- Crystallised Helium x1 + Magnetised Ferrite x1 → Uranium x3 (*"Loosen Bonds"*, 0.12 sec./unit output)
- Uranium -- Crystallised Helium x1 + Pure Ferrite x1 → Uranium x2 (*"Loosen Bonds"*, 0.18 sec./unit output)

### Cooking

**Crystallised Helium** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

Is used for upgrading certain settlement buildings.
