# Activated Cadmium

## Quick Facts

- **Type:** Refined Stellar Metal: Red
- **Rarity:** Rare
- **Symbol:** Cd+
- **Value:** 111.0
- **Added in:** Waypoint

**Activated Cadmium** is a resource.

## Summary

**Activated Cadmium** (**Cd+**) is a [[resource]]. It can be found on planets orbiting Class M systems ([[System colours|red stars]]).

These planets are often extreme weather worlds.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

This Cadmium has been activated by the extreme conditions in which it was formed, and is highly valuable.

Cadmium is found on planets orbiting red stars, and can be placed in a [[Refiner]] to create purified [[Chromatic Metal]].

## Sources

It can be found on planets orbiting [[System colours|red stars]], **(typically extreme weather planets)** where it can be mined with the Terrain Manipulator attachment for the [[Multi-tool]].
