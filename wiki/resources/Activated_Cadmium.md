# Activated Cadmium

## Quick Facts

- **Type:** Refined Stellar Metal: Red
- **Rarity:** Rare
- **Blueprint Value:** 111.0
- **Symbol:** **Cd+**
- **Updated:** Waypoint

**Activated Cadmium** is a resource.

## Summary

**Activated Cadmium** (**Cd+**) is a resource. It can be found on planets orbiting Class M systems (red stars).

These planets are often extreme weather worlds.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

This Cadmium has been activated by the extreme conditions in which it was formed, and is highly valuable.

Cadmium is found on planets orbiting red stars, and can be placed in a Refiner to create purified Chromatic Metal.

## Sources

It can be found on planets orbiting red stars, **(typically extreme weather planets)** where it can be mined with the Terrain Manipulator attachment for the Multi-tool.

## Use

### Crafting

**Activated Cadmium** is not used as an ingredient for crafting.

### Refining

**Activated Cadmium** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Activated Cadmium x1 → Chromatic Metal x2 (*"Extract Chromatic Material"*, 0.2 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Activated Cadmium x1 → Chromatic Metal x4 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Activated Cadmium x1 → Magnetised Ferrite x4 (*"Stellar / Metal Fusion"*, 0.09 sec./unit output)

### Cooking

**Activated Cadmium** is not used as an ingredient for cooking using a Nutrient Processor.
