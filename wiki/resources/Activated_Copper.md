# Activated Copper

## Quick Facts

- **Type:** Refined Stellar Metal: Yellow
- **Rarity:** Common
- **Blueprint Value:** 75.0
- **Symbol:** **Cu+**
- **Updated:** Waypoint

**Activated Copper** is a resource.

## Summary

**Activated Copper** (**Cu+**) is a resource.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

This Copper has been activated by the extreme conditions in which it was formed, and is highly valuable.

Copper is found on planets orbiting yellow stars, and can be placed in a Refiner to create purified Chromatic Metal.

## Sources

It can be found on planets orbiting yellow stars, **(typically extreme weather planets)** where it can be mined with the Terrain Manipulator attachment for the Multi-tool.

It can also be salvaged from starships at a Starship Outfitting Terminal.

## Uses

### Crafting

**Activated Copper** is used as an ingredient for crafting the following products:

- Mind Ark -- Hypnotic Eye x1 + Atlantideum x99 + Activated Copper x64 → Mind Ark

### Refining

**Activated Copper** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Activated Copper x1 → Chromatic Metal x1 (*"Extract Chromatic Material"*, 0.24 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Activated Copper x1 → Chromatic Metal x2 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Activated Copper x1 → Magnetised Ferrite x2 (*"Stellar / Metal Fusion"*, 0.18 sec./unit output)

### Cooking

**Activated Copper** is not used as an ingredient for cooking using a Nutrient Processor.
