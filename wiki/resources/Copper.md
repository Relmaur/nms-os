# Copper

## Quick Facts

- **Type:** Refined Stellar Metal: Yellow
- **Rarity:** Common
- **Blueprint Value:** 41.0
- **Symbol:** **Cu**
- **Updated:** WorldsOne

**Copper** is a resource.

## Summary

**Copper (Cu)** is a resource.

## Game description

A chromatic metal, generated by fusion in the heart of a star. Such stellar material ends up forming deposits in the crust of local planets.

Copper is found on planets orbiting yellow stars, and can be placed in a Refiner to create purified Chromatic Metal for use in the manufacture of advanced technologies.

## Source

Copper sources include:

- Resource Deposits and Hotspots on planets orbiting yellow stars.
- Galactic Trade Terminals.
- Secondary element in cave minerals (rare).

### Mining

A Terrain Manipulator or Autonomous Mining Units are needed to mine copper deposits. A Mineral Extractor is required to harvest copper located using the Survey Device upgrade to the Analysis Visor.

### Refining

Copper can be refined using a Refiner with the following ingredients:

- Copper ×1 + Chromatic Metal ×1 → Copper ×2 (*"Chromatic Expansion"*, 0.36 sec./unit output)

### Refining

**Copper** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Copper x2 → Chromatic Metal x1 (*"Extract Chromatic Material"*, 0.36 sec./unit output)
- Chromatic Metal -- Gold x1 + Silver x1 + Copper x1 → Chromatic Metal x5 (*"Chromatic Stellar Fusion"*, 4.8 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Copper x1 → Chromatic Metal x1 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Copper -- Copper x1 + Chromatic Metal x1 → Copper x2 (*"Chromatic Expansion"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Copper x1 → Magnetised Ferrite x1 (*"Stellar / Metal Fusion"*, 0.36 sec./unit output)

### Cooking

**Copper** is not used as an ingredient for cooking using a Nutrient Processor.
