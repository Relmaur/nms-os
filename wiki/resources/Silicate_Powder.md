# Silicate Powder

## Quick Facts

- **Category:** Metal
- **Type:** Abundant Mineral
- **Rarity:** Common
- **Blueprint Value:** 2.0
- **Used for:** Building, Charging
- **Symbol:** **Si**
- **Updated:** Origins

**Silicate Powder** is a resource.

## Summary

**Silicate Powder** (**Si**) is a resource and one of the metal elements.

## Game description

An abundant mineral element, found within the geological strata of all rocky worlds. Easily extracted using a Terrain Manipulator. Create a tunnel anywhere to begin extraction.

Process in a Refiner to create Glass.

## Source

- It can be mined from soil using the Terrain Manipulator.

### Refining

**Silicate Powder** is used as an ingredient for refining the following products using a Refiner:

- Deuterium -- Di-hydrogen x1 + Silicate Powder x1 → Deuterium x1 (*"Di-hydrogen Cycling"*, 0.24 sec./unit output)
- Glass -- Silicate Powder x40 → Glass x1 (*"Silicate Forging"*, 5 sec./unit output)

### Cooking

**Silicate Powder** is not used as an ingredient for cooking using a Nutrient Processor.
