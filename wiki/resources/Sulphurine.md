# Sulphurine

## Quick Facts

- **Category:** Earth
- **Type:** Compressed Atmospheric Gas
- **Rarity:** Common
- **Blueprint Value:** 20.0
- **Used for:** Crafting, Charging
- **Symbol:** **Su**
- **Updated:** Aquarius

**Sulphurine** is a resource.

## Summary

**Sulphurine** (**Su**) is a resource and one of the Compressed Atmospheric Gas earth elements.

## Game description

A pungent atmospheric gas. High concentrations are extremely hazardous to organic life.

With the aid of specialised machinery, can be extracted from the atmospheres of Scorched, Desert and Volcanic planets.

## Source

- As a secondary element in some flora
- Rarely as a primary resource in some minerals
- From Atmosphere Harvesters built on planets with Scorched, Barren or Volcanic biomes
- Using Gas Extractor at a Sulphurine Concentrated Gas Cloud
- Raiding some Resource Depots
- From Mutant Plants in Frozen biomes
- From a freighter's Stellar Extractor Room when in a Green Star System

Sulphurine can be refined using a Refiner with the following ingredients:

- Nitrogen ×3 → Sulphurine ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Nitrogen ×1 + Oxygen ×1 → Sulphurine ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Nitrogen ×1 + Chromatic Metal ×1 → Sulphurine ×1 (*"Gas Catalysation"*, 0.36 sec./unit output)

## Use

### Crafting

**Sulphurine** is used as an ingredient for crafting the following products:

- Thermic Condensate -- Sulphurine x250 + Condensed Carbon x50 → Thermic Condensate

### Refining

**Sulphurine** is used as an ingredient for refining the following products using a Refiner:

- Cactus Flesh -- Pyrite x1 + Sulphurine x1 → Cactus Flesh x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Faecium -- Nitrogen x1 + Sulphurine x1 → Faecium x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Methane -- Nitrogen x3 + Sulphurine x3 + Radon x3 → Methane x1 (*"Organic Fusion"*, 0.16 sec./unit output)
- Paraffinium -- Sulphurine x1 + Ferrite Dust x1 → Paraffinium x1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Paraffinium -- Sulphurine x1 + Magnetised Ferrite x1 → Paraffinium x3 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Paraffinium -- Sulphurine x1 + Pure Ferrite x1 → Paraffinium x2 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Radon -- Sulphurine x1 + Chromatic Metal x1 → Radon x1 (*"Gas Catalysation"*, 0.36 sec./unit output)
- Radon -- Sulphurine x1 + Oxygen x1 → Radon x1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Radon -- Sulphurine x3 → Radon x1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Solanium -- Di-hydrogen x1 + Sulphurine x1 → Solanium x1 (*"Sulphur Injection"*, 0.16 sec./unit output)
- Solanium -- Phosphorus x1 + Sulphurine x1 → Solanium x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Thermic Condensate -- Sulphurine x100 + Carbon x20 + Chlorine x5 → Thermic Condensate x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Thermic Condensate -- Sulphurine x100 + Carbon x20 + Salt x10 → Thermic Condensate x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Thermic Condensate -- Sulphurine x100 + Condensed Carbon x10 + Chlorine x5 → Thermic Condensate x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Thermic Condensate -- Sulphurine x100 + Condensed Carbon x10 + Salt x10 → Thermic Condensate x1 (*"High-Speed Sublimation"*, 45 sec./unit output)

### Cooking

**Sulphurine** is not used as an ingredient for cooking using a Nutrient Processor.
