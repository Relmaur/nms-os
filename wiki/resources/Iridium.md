# Iridium

## Quick Facts

- **Type:** Neutral
- **Rarity:** Uncommon
- **Description:** A soft, white and lustrous transition metal
- **Symbol:** Ir
- **Value:** 96.0
- **Added in:** Atlas Rises

**Iridium** is a resource.

## Summary

**Iridium** is a [[resource]], and a member of the [[Neutral elements]] class.

## Game description

A soft, white and lustrous transition metal.

A much prized commodity, and popular cargo for many traders.

Can be combined with other elements to create valuable alloys if [[Blueprint|formula]] is available.

## Source

Iridium can be mined in space from [[asteroid|asteroids]] of various types, where it most often appears as crystals in the shape of a multi-pointed star. Deposits can also be found on [[planet|planets]] within arch shaped rocks, but are much rarer than other resource nodes found on planets.

Two types of resource node types can always be found on one planet (e.g. [[Aluminium]] and [[Copper]]), but if one finds only one resource node type, the planet definitely possesses Iridium nodes. Note that [[Heridium]] nodes can be found on every planet and are therefore excluded from this rule.

## Use

Iridium is considered to be an obsolete mineral in the game now.

## Additional information

- Iridium can be sold in the [[Galactic trade terminal|Marketplace]].
