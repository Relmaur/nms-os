# Deuterium

## Quick Facts

- **Category:** Earth
- **Type:** High Energy Substance
- **Rarity:** Common
- **Blueprint Value:** 34.0
- **Used for:** Charging, Upgrading
- **Symbol:** **D**
- **Updated:** Adrift

**Deuterium** is a resource.

## Summary

**Deuterium** (**D**) is a resource and one of the earth elements.

Blue Deuterium Rich Plants gives a short-term boost to the player's jetpack when interacted with. This can help the player travel greater distances using the "jetpack + melee" combo.

## Game Description

A stable hydrogen isotope used heavily in both small-scale fusion reactors and neutron-scattering shield technology.

Deuterium very rarely occurs naturally. Most of the galaxy's supply comes from the processing of Di-hydrogen and Tritium in Refiners.

## Source

Deuterium can be obtained in a variety of ways:

- purchased from terminals or NPCs
- refining process
- dismantling Deuterium-based technology, such as Pulse Engine Upgrades.

Refining it requires a medium or large refiner.
Deuterium can be refined using a Refiner with the following ingredients:

- Di-hydrogen ×1 + Tritium ×1 → Deuterium ×1 (*"Di-hydrogen Cycling"*, 0.24 sec./unit output)
- Di-hydrogen ×1 + Silicate Powder ×1 → Deuterium ×1 (*"Di-hydrogen Cycling"*, 0.24 sec./unit output)

## Use

### Crafting

**Deuterium** is used as an ingredient for crafting the following products:

- Incinerator -- Wiring Loom x1 + Deuterium x200 → Incinerator
- Neutron Shielding -- Ionised Cobalt x50 + Deuterium x95 + Wiring Loom x1 → Neutron Shielding
- Pulse Spitter -- Deuterium x200 + Wiring Loom x1 → Pulse Spitter

### Refining

**Deuterium** is not used as an ingredient for refining using a Refiner.

### Cooking

**Deuterium** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional Information

The Deuterium-rich plants mentioned above originally produced deuterium when harvested, but this was patched out soon after the initial NEXT release.

Because of this, Deuterium has to be obtained using other means.
