# Cactus Flesh

## Quick Facts

- **Category:** Flora
- **Type:** Harvested Agricultural Substance
- **Rarity:** Rare
- **Blueprint Value:** 28
- **Used for:** Building, Crafting, Cooking
- **Symbol:** **Cc**
- **Updated:** WorldsTwo

**Cactus Flesh** is a resource.

## Summary

**Cactus Flesh** (**Cc**) is a resource and one of the Harvested Agricultural Substance flora elements.

## Game Description

Succulent, edible cactus flesh from the Echinocactus plant. As well as being juicy on the tongue, the flesh has many industrial uses.

The Echinocactus thrives only on desert planets, but can be farmed in all environments with the aid of a Hydroponics Tray.

## Source

As described in the Game description, this element can be recovered from specific Echinocactus plants in desert/barren biomes.

It can also be found mixed with carbon in carbon-based plants or trees. For easy discovery, scan these flora with your visor and see what elements are in them.

It should be noted that the spawn rate for the "classic" Echinocactus plants is really low and is easier to find the element mixed with other flora found on barren planets

With assistance from a Farmer, Cactus Flesh can also be grown as a product of the Echinocactus plant, with a harvest time of 16 hours and a yield of 100.

Cactus Flesh can be refined using a Refiner with the following ingredients:

- Cactus Flesh ×1 + Pyrite ×1 → Cactus Flesh ×2 (*"Organic Expansion"*, 0.36 sec./unit output)
- Pyrite ×2 + Oxygen ×1 → Cactus Flesh ×1 (*"Encourage Growth"*, 0.36 sec./unit output)
- Pyrite ×1 + Sulphurine ×1 → Cactus Flesh ×1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Pyrite ×1 + Methane ×1 → Cactus Flesh ×1 (*"Organic Expansion"*, 0.36 sec./unit output)

## Use

### Crafting

**Cactus Flesh** is used as an ingredient for crafting the following products:

- Echinocactus -- Cactus Flesh x50 + Pyrite x25 → Echinocactus
- Poly Fibre -- Cactus Flesh x100 + Star Bulb x200 → Poly Fibre
- Unstable Gel -- Cactus Flesh x200 → Unstable Gel

### Refining

**Cactus Flesh** is used as an ingredient for refining the following products using a Refiner:

- Cactus Flesh -- Cactus Flesh x1 + Pyrite x1 → Cactus Flesh x2 (*"Organic Expansion"*, 0.36 sec./unit output)
- Carbon -- Cactus Flesh x1 → Carbon x2 (*"Burn Plantlife"*, 0.12 sec./unit output)
- Oxygen -- Cactus Flesh x1 + Kelp Sac x1 + Condensed Carbon x1 → Oxygen x10 (*"Artificial Photosynthesis"*, 3.6 sec./unit output)
- Pyrite -- Cactus Flesh x2 + Salt x1 → Pyrite x1 (*"Floral Titration"*, 0.36 sec./unit output)

### Cooking

**Cactus Flesh** is used as an ingredient for cooking the following products using a Nutrient Processor:

- Cactus Nectar -- Cactus Flesh x1 → Cactus Nectar x1 (*"Extract Nutrients"*, 2.5 sec./unit output)
- Creature Pellets -- Faecium x1 + Cactus Flesh x1 → Creature Pellets x1 (*"Prepare Bait"*, 2.5 sec./unit output)
- Salty Juice -- Cactus Flesh x1 + Salt x1 + Fire Water x1 → Salty Juice x1 (*"Liquidise"*, 2.5 sec./unit output)
- Tooth Pickers -- Sugar Dough x1 + Cactus Flesh x1 → Tooth Pickers x1 (*"Dough Augmentation"*, 2.5 sec./unit output)

## Fishing Bait

When applied as bait, Cactus Flesh gives the following bonus towards your next catch:

- Catch Rarity Improvement: 6%
- Catch Size Improvement: 2%

## Additional Information

- The "Cc" symbol for this material is probably short for "Cucrassula," the name for the edible substance which comes from this plant, baked and eaten by Gek (and possibly other races).
- In Latin, the original name of this element means *eunuch* or *castrated*.
