# Vy

## Quick Facts

- **Rarity:** Common
- **Symbol:** Vy
- **Added in:** Pre-release

**Vy** (full name unknown) is a resource.

## Summary

**Vy** (full name unknown) is a red crystal [[resource]]. It is only available in [[pre-release]] builds of [[No Man's Sky]].

## Known locations

This is an element commonly found on the pre-release [[planet]] [[Kraddakk]]. A brown icon for this element is also displayed in the 18-minute gameplay video when scavenging space debris.

## Additional information

It is very likely there is a full name and this is only an abbreviation. This has only been seen in the pre-release version of the game.

According to [[Sean Murray]], the crystals are not worth that much.
