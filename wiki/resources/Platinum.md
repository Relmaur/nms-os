# Platinum

## Quick Facts

- **Category:** Exotic
- **Type:** Valuable Asteroid Mineral
- **Rarity:** Rare
- **Blueprint Value:** 505.0
- **Used for:** Building, Charging, Upgrading
- **Symbol:** **Pt**
- **Updated:** Waypoint

**Platinum** is a resource.

## Summary

**Platinum** (**Pt**) is a resource and one of the exotic elements.

Platinum is the most expensive single element.

## Game description

Extremely valuable interstellar trading mineral, typically mined from asteroids. Occasionally found in underground planetary deposits.

Universally prized for its hardiness and versatility.

## Source

- Can be bought from some Galactic Trade Terminals or Ship Traders.
- Can be mined from crystalline/amorphous asteroids.
- As a secondary element in some minerals in caves.
- By destroying freighter cargo

Platinum can be refined using a Refiner with the following ingredients:

- Geodesite ×1 → Platinum ×250 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Iridesite ×1 → Platinum ×250 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Silver ×1 + Gold ×1 → Platinum ×1 (*"Transmutation"*, 0.24 sec./unit output)
- Ferrite Dust ×1 + Oxygen ×1 + Chromatic Metal ×250 → Platinum ×10 (*"Chromatic Alchemy"*, 4.8 sec./unit output)
