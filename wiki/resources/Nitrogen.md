# Nitrogen

## Quick Facts

- **Category:** Earth
- **Type:** Compressed Atmospheric Gas
- **Rarity:** Rare
- **Blueprint Value:** 20
- **Used for:** Crafting
- **Symbol:** **N**
- **Updated:** WorldsTwo

**Nitrogen** is a resource.

## Summary

**Nitrogen** (**N**) is a resource and one of the Compressed Atmospheric Gas earth elements.

## Game description

A reactive atmospheric gas found wherever there is organic life.

Nitrogen is readily harvested from the atmospheres of Toxic and Lush planets.

## Source

- As a secondary element in some flora.
- From Atmosphere Harvesters built on planets with Lush and Toxic biomes.
- Using Gas Extractor at a Nitrogen Concentrated Gas Cloud on Toxic or Lush biomes.
- It can be found at Resource Depots.
- From Stellar Extractor Room while being in solar systems with Red/Orange stars.

Nitrogen can be refined using a Refiner with the following ingredients:

- Radon ×3 → Nitrogen ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Radon ×1 + Oxygen ×1 → Nitrogen ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Radon ×1 + Chromatic Metal ×1 → Nitrogen ×1 (*"Gas Catalysation"*, 0.36 sec./unit output)
- Methane ×3 → Nitrogen ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Methane ×1 + Oxygen ×1 → Nitrogen ×1 (*"Gas Transfer"*, 0.36 sec./unit output)
- Methane ×1 + Chromatic Metal ×1 → Nitrogen ×1 (*"Gas Catalysation"*, 0.36 sec./unit output)

## Use

### Crafting

**Nitrogen** is used as an ingredient for crafting the following products:

- Nitrogen Salt -- Nitrogen x250 + Condensed Carbon x50 → Nitrogen Salt

### Refining

**Nitrogen** is used as an ingredient for refining the following products using a Refiner:

- Ammonia -- Nitrogen x1 + Di-hydrogen x1 → Ammonia x1 (*"Organic Fusion"*, 0.16 sec./unit output)
- Faecium -- Nitrogen x1 + Sulphurine x1 → Faecium x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Fungal Mould -- Ammonia x1 + Nitrogen x1 → Fungal Mould x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Kelp Sac -- Salt x1 + Nitrogen x1 → Kelp Sac x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Marrow Bulb -- Cobalt x1 + Nitrogen x1 → Marrow Bulb x1 (*"Encourage Growth"*, 0.24 sec./unit output)
- Methane -- Nitrogen x3 + Sulphurine x3 + Radon x3 → Methane x1 (*"Organic Fusion"*, 0.16 sec./unit output)
- Nitrogen Salt -- Nitrogen x100 + Carbon x20 + Chlorine x5 → Nitrogen Salt x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Nitrogen Salt -- Nitrogen x100 + Carbon x20 + Salt x10 → Nitrogen Salt x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Nitrogen Salt -- Nitrogen x100 + Condensed Carbon x10 + Chlorine x5 → Nitrogen Salt x1 (*"High-Speed Sublimation"*, 10 sec./unit output)
- Nitrogen Salt -- Nitrogen x100 + Condensed Carbon x10 + Salt x10 → Nitrogen Salt x1 (*"High-Speed Sublimation"*, 45 sec./unit output)
- Sodium Nitrate -- Ferrite Dust x1 + Nitrogen x1 → Sodium Nitrate x1 (*"Gas Catalysation"*, 0.48 sec./unit output)
- Sodium Nitrate -- Magnetised Ferrite x1 + Nitrogen x1 → Sodium Nitrate x3 (*"Gas Catalysation"*, 0.16 sec./unit output)
- Sodium Nitrate -- Pure Ferrite x1 + Nitrogen x1 → Sodium Nitrate x2 (*"Gas Catalysation"*, 0.24 sec./unit output)
- Sodium Nitrate -- Sodium Nitrate x1 + Nitrogen x1 → Sodium Nitrate x2 (*"Gas Catalysation"*, 0.18 sec./unit output)

### Cooking

**Nitrogen** is not used as an ingredient for cooking using a Nutrient Processor.
