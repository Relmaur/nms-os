# Pure Ferrite

## Quick Facts

- **Category:** Metal
- **Type:** Processed Metallic Minerals
- **Rarity:** Uncommon
- **Blueprint Value:** 28
- **Used for:** Building, Crafting, Charging, Upgrading, Refining
- **Symbol:** **Fe+**
- **Updated:** WorldsTwo

**Pure Ferrite** is a resource.

## Summary

**Pure Ferrite** (**Fe+**) is a resource and one of the metal elements.

## Game description

Processed metal, free of dust and pebbles. Used to construct a wide variety of structures and technologies.

Typically purified from Ferrite dust using a Refiner, but can occasionally be found in large deposits. Collection may require an Advanced Mining Laser.

## Source

- As a primary or secondary element in some minerals. These minerals usually require Advanced Mining Laser to harvest.
- Also available from some Galactic Trade Terminals.

Pure Ferrite can be refined using a Refiner with the following ingredients:

- Ferrite Dust ×2 + Pugneum ×1 → Pure Ferrite ×3 (*"Matter Expansion"*, 0.36 sec./unit output)
- Magnetised Ferrite ×1 → Pure Ferrite ×2 (*"Demagnetise Metal"*, 0.16 sec./unit output)
- Ferrite Dust ×1 → Pure Ferrite ×1 (*"Extract Metallic Elements"*, 0.12 sec./unit output)
- Polished Stone ×1 → Pure Ferrite ×2 (*"Recycle Stone"*, 0.12 sec./unit output)
