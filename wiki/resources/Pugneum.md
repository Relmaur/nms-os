# Pugneum

## Quick Facts

- **Category:** Special
- **Type:** Anomalous Material
- **Rarity:** Rare
- **Blueprint Value:** 138.0
- **Used for:** Building, Crafting, Charging, Upgrading
- **Symbol:** **Pg**
- **Updated:** Interceptor

**Pugneum** is a resource.

## Summary

**Pugneum** (**Pg**) is a resource and one of the special elements.

## Game description

This oily, unsettling liquid leaks from the circuitry of Sentinels.

Prized by the Vy'keen, Pugneum is thought to share some essential properties with Nanites. It hums in a sinister fashion upon contact with organic matter.

## Source

Drops from destroyed Sentinels; the received amount depends on what type of sentinel is destroyed, see more information here.

Also available from some Galactic Trade Terminals.

Pugneum can be refined using a Refiner with the following ingredients:

- Atlantideum ×1 → Pugneum ×2 (*"Restore Harmony"*, 0.12 sec./unit output)

### Cooking

**Pugneum** is not used as an ingredient for cooking using a Nutrient Processor.

## Additional information

- Pugneum can be sold at the Galactic Trade Terminal.
- Pugneum can be requested for a bribe in the rank 4 find missing persons mission from the Mission Board
- Needed to open cargo containers on crashed freighters.
- Needed in small amounts (10-25 per component) to repair damaged components in crashed starships and damaged multi-tools. (Example: Scorched Plating)
