# Gold

## Quick Facts

- **Category:** Exotic
- **Type:** Valuable Asteroid Mineral
- **Rarity:** Uncommon
- **Blueprint Value:** 353.0
- **Used for:** Building, Crafting, Charging, Upgrading
- **Symbol:** **Au**
- **Updated:** WorldsOne

**Gold** is a resource.

## Summary

**Gold** (**Au**) is a resource and one of the exotic elements.

## Game description

Highly valuable interstellar trading mineral, typically mined from asteroids. Occasionally found in underground planetary deposits.

Universally prized for its beauty and versatility.

## Source

Gold found in the wild as 'Metal Fingers'
(NEXT)

- As a primary (very rare) or secondary element in some minerals in caves.
- Can be mined from asteroids.
- Can be mined from deposits on Exotic planets.
- Can be extracted from Deep-Level Mineral Deposits on exotic planets.
- Acquired as loot dropped by pirates.
- Can be found in Metal 'Fingers'.
- Can be received from Gold Nuggets after they are analysed.
- Also available from some Galactic Trade Terminals.

Gold can be refined using a Refiner with the following ingredients:

- Lemmium ×1 → Gold ×125 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Mordite ×1 + Pugneum ×1 → Gold ×1 (*"Organic / Anomaly Synthesis"*, 0.36 sec./unit output)
- Faecium ×1 + Residual Goop ×1 → Gold ×1 (*"Alchemical Construction"*, 0.24 sec./unit output)
- Faecium ×1 + Pugneum ×1 → Gold ×2 (*"Pugneum Alchemy"*, 0.36 sec./unit output)
- Ferrite Dust ×1 + Oxygen ×1 + Emeril ×1 → Gold ×10 (*"Chromatic Alchemy"*, 4.8 sec./unit output)
- Magno-Gold ×1 → Gold ×125 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Grantine ×1 → Gold ×125 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Living Pearl ×1 → Gold ×100 (*"Calcite Transmutation"*, 0.24 sec./unit output)
- Hexite ×1 → Gold ×1 (*"Alchemical Construction"*, 0.24 sec./unit output)
