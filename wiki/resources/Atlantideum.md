# Atlantideum

## Quick Facts

- **Category:** Special
- **Type:** Disharmonic Metal
- **Rarity:** Rare
- **Used for:** Upgrading, Refining
- **Symbol:** ∞
- **Value:** 138.0
- **Added in:** WorldsOne

**Atlantideum** is a resource.

## Summary

**Atlantideum** (**∞**) is a [[resource]] and one of the [[special elements]].

## Game Description

This ethereal substance spills from the bodies of corrupted Sentinels as they fall, a shower of prismatic grains seeking out their next host. It evades all attempts to contain it, as if it had a will of its own, a strong desire for its own freedom.

It possesses a crystalline beauty that cannot be reconciled with the corruption from whence it flows.

## Source

Atlantideum can be acquired in a variety of ways:
- Mining purple crystals on [[Dissonant Planet|Dissonant Planets]]
- Killing corrupted sentinel [[Corrupted Sentinel Drone|drones]] or [[Corrupted Sentinel Quadruped|quadrupeds]] (66%)
- Looting wheelbarrows at [[Harmonic Camp|Harmonic Camps]] (8%)

## Use

### Station Cores

Atlantideum can be used on a [[Korvax]] [[Station Core]] via the *Feed Curious Circuits* option. The Core returns a binary code which translates to "*I see her*".

### Learning about Autophage History

Atlantideum can be used at Korvax monoliths to access texts that tell the story of the [[Autophage]] faction.
