# Atlantideum

## Quick Facts

- **Category:** Special
- **Type:** Disharmonic Metal
- **Rarity:** Rare
- **Blueprint Value:** 138.0
- **Used for:** Upgrading, Refining
- **Symbol:** **∞**
- **Updated:** WorldsOne

**Atlantideum** is a resource.

## Summary

**Atlantideum** (**∞**) is a resource and one of the special elements.

## Game Description

This ethereal substance spills from the bodies of corrupted Sentinels as they fall, a shower of prismatic grains seeking out their next host. It evades all attempts to contain it, as if it had a will of its own, a strong desire for its own freedom.

It possesses a crystalline beauty that cannot be reconciled with the corruption from whence it flows.

## Source

Atlantideum can be acquired in a variety of ways:

- Mining purple crystals on Dissonant Planets
- Killing corrupted sentinel drones or quadrupeds (66%)
- Looting wheelbarrows at Harmonic Camps (8%)

## Use

### Crafting

**Atlantideum** is used as an ingredient for crafting the following products:

- Atlantid Drive -- Indium x250 + Atlantideum x200 + Living Glass x1 → Atlantid Drive
- Mind Ark -- Hypnotic Eye x1 + Atlantideum x99 + Activated Copper x64 → Mind Ark
- Polyphonic Core -- Atlantideum x190 + Quantum Computer x1 + Living Glass x1 → Polyphonic Core
- Resonance Matrix -- Crystallised Heart x1 + Atlantideum x160 + Quartzite x250 → Resonance Matrix

### Refining

**Atlantideum** is used as an ingredient for refining the following products using a Refiner:

- Living Slime -- Mordite x5 + Atlantideum x5 → Living Slime x1 (*"Reanimation"*, 14.4 sec./unit output)
- Pugneum -- Atlantideum x1 → Pugneum x2 (*"Restore Harmony"*, 0.12 sec./unit output)
- Runaway Mould -- Atlantideum x1 + Pugneum x1 → Runaway Mould x3 (*"Reality Pollution"*, 0.24 sec./unit output)

### Cooking

**Atlantideum** is not used as an ingredient for cooking using a Nutrient Processor.

### Station Cores

Atlantideum can be used on a Korvax Station Core via the *Feed Curious Circuits* option. The Core returns a binary code which translates to "*I see her*".

### Learning about Autophage History

Atlantideum can be used at Korvax monoliths to access texts that tell the story of the Autophage faction.
