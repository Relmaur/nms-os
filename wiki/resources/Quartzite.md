# Quartzite

## Quick Facts

- **Type:** Refined Stellar Material: Purple
- **Rarity:** Rare
- **Blueprint Value:** 132
- **Symbol:** **Qu**
- **Updated:** WorldsTwo

**Quartzite** is a resource.

## Summary

**Quartzite** (**Qu**) is a resource.

## Game description

A chromatic mineral, generated by fusion in the heart of a star.
Such stellar material ends up forming deposits in the crust of local planets.

Quartzite is found on planets orbiting purple stars, and can be placed in a Refiner to create purified Chromatic Metal for use in the manufacture of advanced technologies.

## Source

It can be found on planets orbiting purple stars, where it can be mined with the Terrain Manipulator attachment for the Multi-tool.

Quartzite can be refined using a Refiner with the following ingredients:

- Activated Quartzite ×1 + Carbon ×1 → Quartzite ×1 (*"Chromatic Alchemy"*, 0.1 sec./unit output)
- Quartzite ×1 + Chromatic Metal ×1 → Quartzite ×2 (*"Chromatic Expansion"*, 0.18 sec./unit output)

## Use

### Crafting

**Quartzite** is used as an ingredient for crafting the following products:

- Resonance Matrix -- Crystallised Heart x1 + Atlantideum x160 + Quartzite x250 → Resonance Matrix

### Refining

**Quartzite** is used as an ingredient for refining the following products using a Refiner:

- Activated Quartzite -- Methane x1 + Crystallised Helium x1 + Quartzite x1 → Activated Quartzite x1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Activated Quartzite -- Methane x1 + Lithium x1 + Quartzite x1 → Activated Quartzite x1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Chromatic Metal -- Gold x1 + Silver x1 + Quartzite x1 → Chromatic Metal x30 (*"Chromatic Stellar Fusion"*, 4.8 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Quartzite x1 → Chromatic Metal x4 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Chromatic Metal -- Quartzite x2 → Chromatic Metal x4 (*"Extract Chromatic Material"*, 0.1 sec./unit output)
- Crystallised Helium -- Lithium x1 + Quartzite x1 → Crystallised Helium x1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Lithium -- Crystallised Helium x1 + Quartzite x1 → Lithium x1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Quartzite x1 → Magnetised Ferrite x4 (*"Stellar / Metal Fusion"*, 0.09 sec./unit output)
- Quartzite -- Quartzite x1 + Chromatic Metal x1 → Quartzite x2 (*"Chromatic Expansion"*, 0.18 sec./unit output)

### Cooking

**Quartzite** is not used as an ingredient for cooking using a Nutrient Processor.
