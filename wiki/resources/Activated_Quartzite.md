# Activated Quartzite

## Quick Facts

- **Type:** Refined Stellar Metal: Purple
- **Rarity:** Rare
- **Blueprint Value:** 165
- **Symbol:** **Qu+**
- **Updated:** WorldsTwo

**Activated Quartzite** is a resource.

## Summary

**Activated Quartzite** (**Qu+**) is a resource.

## Game description

A chromatic metal, generated by fusion in the heart of a star.

Quartzite is found on planets orbiting purple stars, and can be placed in a Refiner to create purified Chromatic Metal.

This Quartzite has been activated by the extreme conditions in which it was formed, and is highly valuable.

## Sources

It can be found on planets orbiting purple stars, **(typically extreme weather planets)** where it can be mined with the Terrain Manipulator attachment for the Multi-tool. It's easy to spot because of its specific purple color.

Activated Quartzite can be refined using a Refiner with the following ingredients:

- Methane ×1 + Lithium ×1 + Quartzite ×1 → Activated Quartzite ×1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Methane ×1 + Crystallised Helium ×1 + Quartzite ×1 → Activated Quartzite ×1 (*"Loosen Bonds"*, 0.36 sec./unit output)

## Use

### Crafting

**Activated Quartzite** is used as an ingredient for crafting the following products:

- Exocraft Summoning Unit -- Activated Quartzite x140 + Quantum Computer x3 + Crystallised Helium x90 → Exocraft Summoning Unit

### Refining

**Activated Quartzite** is used as an ingredient for refining the following products using a Refiner:

- Chromatic Metal -- Activated Quartzite x1 → Chromatic Metal x4 (*"Extract Chromatic Material"*, 0.1 sec./unit output)
- Chromatic Metal -- Pure Ferrite x1 + Activated Quartzite x1 → Chromatic Metal x8 (*"Chromatic Metal Fusion"*, 0.36 sec./unit output)
- Crystallised Helium -- Lithium x1 + Activated Quartzite x1 → Crystallised Helium x2 (*"Environmental Element Transfer"*, 0.18 sec./unit output)
- Lithium -- Crystallised Helium x1 + Activated Quartzite x1 → Lithium x2 (*"Environmental Element Transfer"*, 0.18 sec./unit output)
- Magnetised Ferrite -- Ferrite Dust x1 + Activated Quartzite x1 → Magnetised Ferrite x8 (*"Stellar / Metal Fusion"*, 0.045 sec./unit output)
- Quartzite -- Activated Quartzite x1 + Carbon x1 → Quartzite x1 (*"Chromatic Alchemy"*, 0.1 sec./unit output)
- Sodium Nitrate -- Methane x1 + Crystallised Helium x1 + Activated Quartzite x1 → Sodium Nitrate x2 (*"Loosen Bonds"*, 0.18 sec./unit output)
- Sodium Nitrate -- Methane x1 + Lithium x1 + Activated Quartzite x1 → Sodium Nitrate x2 (*"Loosen Bonds"*, 0.18 sec./unit output)

### Cooking

**Activated Quartzite** is not used as an ingredient for cooking using a Nutrient Processor.
