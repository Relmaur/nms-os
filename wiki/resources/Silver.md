# Silver

## Quick Facts

- **Category:** Exotic
- **Type:** Valuable Asteroid Mineral
- **Rarity:** Common
- **Blueprint Value:** 186.0
- **Used for:** Building, Charging, Upgrading, Refining
- **Symbol:** **Ag**
- **Updated:** Endurance

**Silver** is a resource.

## Summary

**Silver** (**Ag**) is a resource and one of the exotic elements. It is one of the main ingredients for crafting freighter related base building products.

## Game description

Valuable interstellar trading mineral, typically mined from asteroids. Occasionally found in underground planetary deposits.

Prized by people in all systems for its lustre and shine.

## Source

- Can be mined from asteroids.
- Can be found in Resource Deposits.
- Can be extracted from Deep-Level Mineral Deposits.
- As a secondary element in some minerals in caves.
- Also available from some Galactic Trade Terminals.

Silver can be refined using a Refiner with the following ingredients:

- Herox ×1 → Silver ×250 (*"Extreme Alloy Separation"*, 1 sec./unit output)
- Aronium ×1 → Silver ×250 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Dirty Bronze ×1 → Silver ×250 (*"Extreme Alloy Separation"*, 1.2 sec./unit output)
- Comet Dust ×5 → Silver ×1 (*"Crystal Processing"*, 0.36 sec./unit output)
