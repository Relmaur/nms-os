## Summary

**Basalt** (**B**) is a resource.

## Game description

Local mineral extract, typically found in large deposits or extracted from common minerals after inspection with an Analysis Visor.

Typically found on planets with a volcanic environment.

## Source

- In resource deposits on Volcanic planets, though not all eligible planets will present deposits.
- As a secondary element in some Minerals on Volcanic planets.

Basalt can be refined using a Refiner with the following ingredients:

- Pyrite ×1 + Magnetised Ferrite ×1 → Basalt ×1 (*"Volcanic Transmutation"*, 0.36 sec./unit output)
- Phosphorus ×1 + Magnetised Ferrite ×1 → Basalt ×2 (*"Volcanic Transmutation"*, 0.36 sec./unit output)

## Use

### Crafting

**Basalt** is used as an ingredient for crafting the following products:

- Mounted Flamethrower -- Phosphorus x50 + Basalt x50 + Methane x90 → Mounted Flamethrower
- Voltaic Amplifier -- Basalt x70 + Ion Battery x2 + Wiring Loom x1 → Voltaic Amplifier

### Refining

**Basalt** is not used as an ingredient for refining using a Refiner.

### Cooking

**Basalt** is not used as an ingredient for cooking using a Nutrient Processor.
