# Uranium

## Quick Facts

- **Category:** Earth
- **Type:** Localised Earth Element
- **Rarity:** Uncommon
- **Blueprint Value:** 62
- **Used for:** Building, Crafting, Charging, Upgrading
- **Symbol:** **U**
- **Updated:** WorldsTwo

**Uranium** is a resource.

## Summary

**Uranium** (**U**) is a resource and one of the localised earth elements. It is used as fuel for the starship's Launch Thruster.

## Game description

Local mineral extract, typically found in large deposits or extracted from common minerals after inspection with an Analysis Visor.

Typically found on planets with a radioactive environment.

## Source

- In Mineral deposits on Irradiated biomes.
- Can be found in Metal 'Fingers'.
- Also available from some Galactic Trade Terminals, but the purchase price is much higher than the nominal value.
- Recycling Radioactive Industrial Waste at a Waste Processing Plant.

Uranium can be refined using a Refiner with the following ingredients:

- Phosphorus ×2 + Ferrite Dust ×1 → Uranium ×1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Phosphorus ×2 + Pure Ferrite ×1 → Uranium ×1 (*"Environmental Element Transfer"*, 0.36 sec./unit output)
- Crystallised Helium ×1 + Ferrite Dust ×1 → Uranium ×1 (*"Loosen Bonds"*, 0.36 sec./unit output)
- Crystallised Helium ×1 + Pure Ferrite ×1 → Uranium ×2 (*"Loosen Bonds"*, 0.18 sec./unit output)
- Crystallised Helium ×1 + Magnetised Ferrite ×1 → Uranium ×3 (*"Loosen Bonds"*, 0.12 sec./unit output)
- Gamma Root ×2 + Salt ×1 → Uranium ×1 (*"Floral Titration"*, 0.36 sec./unit output)
- Radon ×1 + Di-hydrogen ×1 → Uranium ×1 (*"Catalyse Radiation"*, 0.16 sec./unit output)
- Radon ×1 + Ferrite Dust ×1 → Uranium ×1 (*"Metal Enrichment"*, 0.36 sec./unit output)
- Radon ×1 + Pure Ferrite ×1 → Uranium ×2 (*"Metal Enrichment"*, 0.36 sec./unit output)
- Radon ×1 + Magnetised Ferrite ×1 → Uranium ×3 (*"Metal Enrichment"*, 0.36 sec./unit output)
