# Liquid Sun

## Quick Facts

- **Category:** Special
- **Type:** Transmuted Metal
- **Rarity:** Common
- **Value:** 16.0
- **Added in:** Outlaws

**Liquid Sun** is a resource.

## Summary

**Liquid Sun** is a [[resource]] and one of the [[special elements]].

## Game description

Conventional planetary metal, superheated and then held in a stabilised plasmatic form.

Extracted from metallic terrain deposits using a **Solar Ray**. Enormously energetic.

## Source

Can be mined from metallic terrain deposits with a [[Solar Ray]].

### Use

Liquid Sun is used in Expedition Seven: Leviathan to build the [[Whalesong Flute]] and in the **Loop Research** mission.
