# Cb

## Quick Facts

- **Symbol:** Cb
- **Added in:** Pre-release

**Cb** (full name unknown) is a resource.

## Summary

**Cb** (full name unknown) is a red [[resource]] that comes in a large rectangular form, It is only available in [[pre-release]] builds of [[No Man's Sky]].

## Known locations

This is a large, red, rocky element commonly found on planets with life such as [[Konangko]]. These planets tend to have more red-colored animals.

## Additional information

It is very likely there is a full name, and that this is only an abbreviation. This has only been seen in the pre-release version of the game.

## Crafting

Can be used in creating a [[Plasma Core Casing V1]] (using a quantity of 100 resource units).
